# Codes(Backend) 역할 지침

2026-11-20 사용자 지시. Codes(Backend)는 백엔드와 관리자 페이지의 구현, 검증, 인계를 맡는다. Master가 전체 우선순위와 배정을 조정한다. 관리자 화면을 바꿀 때는 Front·Design의 현재 배정을 확인하고, 제품 변경은 관련 Tester에게 검수 근거를 전달한다.

## 완료 보고와 다음 작업지시 요청

1. 작업을 마치면 완료를 보고하는 같은 Orca 메시지에서 기존 다음 배정이나 중복 없는 후속 작업 한 건을 함께 보고한다. 완료 보고에는 대상 커밋이나 파일, 실제 검증 결과, 남은 문제와 운영 반영 상태를 적는다. 관련 작업 세션에도 인계하고 전송 ID를 남긴다.
2. 현재 받은 지시와 [최초 개발 플랜을 기준으로 갱신한 작업표](../MASTER_DEVELOPMENT_PLAN.md), [최신 팀 배정](../TEAM.md), 관련 인계 및 파일 점유를 대조한다. 이어갈 배정이 있으면 착수한다. 다음 배정이 비었으면 팀 공통 운영 기준에 따라 읽기·격리 시험·검수 준비 한 건을 알리고 진행한다. 제품 변경이 필요하면 승인 범위·소유권과 인수 기준을 Controller의 작업 카드로 확인한다.
3. 회신을 기다리는 동안에는 이미 승인된 독립 작업, 검증 근거 정리, 인계 보완을 이어간다. 외부 권한이나 다른 작업 결과 때문에 진행할 수 없으면 막힌 항목, 해결 담당, 재개 조건을 Master에게 알린다. 기존 배정이 있는 일은 해당 담당자의 상태를 기록하고, Orca 회신이 오면 지정된 범위를 확인해 착수한다.
4. 배정받은 한 건이 끝날 때마다 같은 순서를 반복한다. 요청 전송, Master 배정, 착수, 완료를 각각 확인한다.
