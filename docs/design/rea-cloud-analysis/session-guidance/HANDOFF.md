# 보호 분석 세션 안내 비교 시안

[세션 안내 비교 열기](http://127.0.0.1:8769/docs/design/rea-cloud-analysis/session-guidance/compare.html) · [HTML 원본](compare.html) · [WAV 세션 화면 대조](../REGISTERED-PCM-WAV-RESULT-REVIEW.md)

`5b27bfc`의 문구·초점 제안을 담은 기존 네 상태에 403 접근 거절을 추가했다. **초점 확인**을 누르면 해당 상태의 첫 위치로 이동한다. 401은 `2854c24` 격리 관측, 403은 `0327324` Front 작성자의 격리 관측을 바탕으로 옮긴 고정 시안이다. [401 격리 관측](../../../handoffs/REA-CLOUD-PROTECTED-ANALYSIS-SESSION-GUARD.md) · [403 작성자 관측](../../../handoffs/REA-CLOUD-PROTECTED-ANALYSIS-MOUNT-403.md)

| 상태 | 첫 초점과 이어지는 동작 |
| --- | --- |
| 확인 중 | **로그인 상태를 확인하고 있어요** 안내에 초점이 간다. 이 상태의 다음 Tab은 재로그인 예시 카드로 이동한다. |
| 재로그인 필요 · 401 | **다시 로그인해 주세요.** 안내에 초점이 가고 다음 Tab으로 **다시 로그인** 링크에 닿는다. 링크는 시안 안에서 확인 문구를 표시하고 주소·초점을 유지한다. |
| 접근 거절 · 403 | **이 화면에 접근할 수 없어요.** 안내에 초점이 가고 계정과 접근 권한을 확인하도록 안내한다. 카드 안의 동작은 **초점 확인**뿐이다. 안내의 다음 Tab은 비교 화면의 다음 카드로 이동한다. |
| 자료 선택 가능 | 빈 **등록 자료 선택**에 초점이 간다. 시험 자료를 고르면 Tab으로 권리 체크에 도달한다. 자료를 해제하거나 초점 경로를 다시 열면 체크가 초기화된다. |
| 빈 목록 | **분석할 수 있는 등록 자료가 없어요.** 안내에 초점이 가고 다음 Tab으로 **목록 다시 조회**에 닿는다. 실행 확인 뒤에도 같은 빈 목록 예시를 표시한다. |

## 작성자 검수

- 390×900에서 401 뒤에 403, 1440×900에서 401·403이 같은 행에 나란히 표시됐다. 각 폭 23개 확인 지점에서 가로 넘침은 0px이었고 버튼·링크·선택 상자·권리 체크 라벨은 높이 44px 이상이었다.
- Tab·Shift+Tab·Enter·Space·방향키로 두 안내와 이어지는 Tab 이동, 기존 확인 중·선택·빈 목록의 조작을 확인했다. 401에서 링크를 Enter로 열었을 때 확인 문구·주소·초점이 유지됐다. 403 안내 안에는 링크나 자료 조작이 없었다.
- 로컬 HTML·글꼴 요청만 관측했다. 실제 인증·자료 조회와 외부·API·운영 요청은 각각 0건이었다. 화면 캡처는 로컬 `tmp/session-guidance-401-403-proof/`에 있다.
