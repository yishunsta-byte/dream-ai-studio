# 등록 PCM WAV 음악 결과 비교 시안

[비교 시안 열기](http://127.0.0.1:8769/docs/design/rea-cloud-analysis/pcm-wav-result/compare.html) · [HTML 원본](compare.html) · [음악 결과 안내 대조](../REGISTERED-PCM-WAV-RESULT-REVIEW.md) · [격리 권한 실측](../../../handoffs/REA-REGISTERED-PCM-WAV-AUTHORITY-VERIFICATION.md) · [읽기 어댑터](../../../handoffs/REA-REGISTERED-PCM-WAV-READER.md)

`66a11b59e3c0848fda6605171325edeb4cbb2ba6`과 `f1d2b53`에서 확인한 8 kHz·16비트 PCM 시험 WAV의 관찰값을 고정했다. 두 WAV는 실측에서 각 소유자가 자신의 자료로 분석했다. 비교 화면은 이 두 결과 예시를 한 선택 상자에 담는다. 분석을 다시 실행하거나 WAV를 재생하는 기능은 연결하지 않았다.

| 자료 | 관찰 구간 | 채널 | 최대 정규화 RMS | 분석 추정 |
| --- | --- | --- | --- | --- |
| 시험 WAV A | 0–125 ms | 1 | 25% | 이 결과에 포함된 추정이 없어요. |
| 시험 WAV B | 0–125 ms | 1 | 12.5% | 이 결과에 포함된 추정이 없어요. |

**분석으로 생성한 초안**은 읽기 전용으로 표시한다. 제작자가 공개한 프롬프트를 확인하지 못했다는 안내를 초안 바로 아래에 둔다. **내 수정본**은 시험 자료를 전환해도 각각 유지된다. 수정본은 브라우저 메모리에만 보관한다.

| 조작 | 결과와 초점 |
| --- | --- |
| 하나의 시험 자료 접근 철회 | 관찰값·초안·수정본을 지운 뒤 남은 자료만 선택할 수 있다. 접근 불가를 알리고 빈 선택 상자로 초점을 옮긴다. 새로 고른 자료는 생성 초안으로 시작한다. |
| 남은 시험 자료 접근 철회 | 결과를 지우고 빈 목록 안내 제목에 초점을 둔다. 다음 Tab으로 **격리 시험 다시 시작**을 선택할 수 있다. 다시 시작하면 두 시험 자료와 최초 초안이 복원되고 선택 상자로 초점이 간다. |
| 공급원 미연결 보기 | 등록 자료 분석 준비 안내를 표시하고 자료 선택과 분석 실행을 비활성화한다. 표시한 관찰·초안을 지우고 메모리의 수정본을 초기화한다. 보기 버튼에 초점을 유지한다. |

## 작성자 브라우저 검수

- 390×900에서는 자료 아래에 결과를 놓았고 1440×900에서는 나란히 놓았다. 각 폭에서 두 표본, 긴 수정 입력, 철회 후 새 선택, 빈 목록, 다시 시작, 미연결을 포함한 18개 확인 지점의 문서 가로 넘침은 모두 0px이었다.
- Tab·Shift+Tab·방향키·Enter로 보기 전환, 자료 선택, 편집, 철회 및 복구를 실행했다. 선택 전환 중 생성 초안 보존과 자료별 수정본 격리, 철회 뒤 수정본 초기화 및 대상별 초점 이동을 확인했다.
- 브라우저는 로컬 HTML과 글꼴만 불러왔다. 외부·API·운영 요청은 각각 0건이었다. 390px와 1440px의 결과·재선택·미연결 스크린샷은 로컬 `tmp/pcm-wav-design-proof/`에 저장했다.
