상단 원본 시각에는 시험 영상의 디코딩 시각을, 초안 옆에는 30 fps를 가정해 환산한 편집 근사치를 표시한다. **분석으로 생성한 초안**은 읽기 전용이며 **내 수정본**은 결과별로 이 페이지를 열어 둔 동안 유지된다. 실제 재생과 저장은 연결하지 않았다.

## 브라우저 확인

- 390×844에서 세로 배치, 1440×900에서 나란히 배치됐다. 세 결과를 선택한 상태와 수정본을 입력한 상태 모두 문서의 가로 넘침은 0px이었다.
- 첫 Tab으로 결과 선택에 진입했다. 방향키로 결과를 바꾸면 초점이 선택에 유지되고 화면의 원본 시각, 관찰, 추정 및 편집 기준이 갱신됐다. 상태 안내 영역의 문구도 갱신됐다. 다음 Tab은 내 수정본으로 이동했다.
- 전환 후보의 수정본을 편집한 뒤 같은 1000 ms의 디코딩 프레임으로 전환했다. 전환 후보로 돌아오면 해당 수정본이 복원됐고 생성 초안은 그대로였다.
- 브라우저에서 로컬 HTML과 글꼴 요청만 관측했다. API, 외부, 운영 요청은 각각 0건이었다.
