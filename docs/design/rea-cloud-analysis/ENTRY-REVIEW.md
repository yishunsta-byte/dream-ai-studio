# 클라우드 콘텐츠 분석 진입 디자인 대조

제품 기준 `a48bb40`, 시안 `051dbcb`. 기준 파일과 일치하는 메뉴·분석 셸·공용 CSS를 Chromium에서 렌더링했다. 계정과 경로 이동은 디자인 검수용 합성 상태였다. 실제 로그인 권한과 키보드 회귀는 독립 검수에서 판정한다. [시안 열기](http://127.0.0.1:8769/docs/design/rea-cloud-analysis/index.html)

| 항목 | 관찰과 제품 연결 기준 |
|---|---|
| 메뉴 발견성 | 390px에서는 브랜드·계정 아래 한 줄, 1440px에서는 브랜드 옆에 ‘콘텐츠 분석’이 보였다. 두 폭에서 ‘내 프로젝트’에서 선택하면 제목과 현재 메뉴에 같은 이름이 표시됐다. 이 배치와 명칭을 유지한다. |
| 화면 제목 | H1 ‘콘텐츠 분석’ 아래 H2 ‘등록 자료 분석’이 이어진다. 등록 자료가 화면의 입력 방식이라면 H1 아래 한 줄에서 ‘프로젝트에 등록한 자료에서 관찰 근거를 확인하고 초안을 다듬어요’라고 안내하고, 입력 카드 제목은 ‘분석 자료’로 둔다. |
| 미연결 상태 | 비활성 선택과 실행 버튼을 먼저 지나야 공급자 미연결 사유가 보인다. 카드 첫 부분에 **등록 자료 분석을 준비 중이에요**와 연결 상태를 표시한다. 결과 카드도 같은 상태를 근거로 **분석 연결을 기다리고 있어요**라고 표시한다. 권한 제한, 연결 후 자료 0건, 분석 후 관찰 근거 0건은 각각 다른 문구를 쓴다. |
| 등록 자료 안내 | 현재 화면에는 선택할 수 없는 자료 목록만 보인다. 미연결일 때는 검증된 등록 사본의 예시 형식 PNG·M4A·MP4와 게시물 URL 미지원 안내를 제공한다. 실제 목록과 권리 확인은 접근 권한이 확인된 공급자 연결 뒤 표시한다. 미연결 상태에서 파일 전송이나 게시물 URL 입력이 가능한 것처럼 보여주는 조작은 숨긴다. |
| 운영 화면과 예시 | 현재 개발본의 보호된 화면에는 예시 자료·측정값·초안이 없었다. 도움말에서 시안을 연결하는 경우 링크에 ‘시험 자료 예시’라고 표기한다. 제품 결과는 등록 자료의 직접 관찰, 분석 추정, 생성 초안을 각각 이름으로 구분한다. |

**완료 조건.** 390px·1440px 모두 첫 화면에서 ‘콘텐츠 분석’을 찾을 수 있고 메뉴·제목이 일치해야 한다. 공급자 미연결 상태의 사유와 등록 자료 안내를 비활성 조작보다 먼저 읽을 수 있어야 한다. 운영 화면에는 실제 공급자가 확인한 자료와 결과만 표시한다. 가로 넘침은 0px이어야 한다. 관찰 캡처는 `tmp/rea-entry-review-a48bb40/`에 있다.
