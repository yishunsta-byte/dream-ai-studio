# 등록 PNG 분석 사용 흐름 대조

고정 격리 브라우저 인계 `0abded0`, 목록 재조회 초점 수정 `eb0e07b`, 등록 자료 시안 `12f88db`를 대조했다. 실측은 합성 인증과 등록 PNG를 연결한 소유 루프백에서 Front가 수행한 결과다. 운영 클라우드 화면에는 이 연결이 적용되지 않았다. [등록 PNG 브라우저 실측](../../handoffs/REA-CLOUD-PROTECTED-PNG-BROWSER-PG17.md) · [등록 자료 시안](registered-cases.html) · [목록과 철회 시안 대조](REGISTERED-LIST-REVIEW.md)

## 자료 선택과 권리 확인

| 단계 | 고정 화면과 확인 범위 | 안내 기준 |
| --- | --- | --- |
| 첫 목록 | 목록을 불러온 뒤 `등록 자료 1`처럼 현재 목록 안에서만 유효한 이름을 표시한다. 서버 이름·프로젝트 ID·자료 ID는 화면과 접근성 이름에 넣지 않는다. 실측에서 두 폭 모두 첫 진입 때 초점을 가져가지 않았다. | 자료가 선택되기 전에는 사용 권리 확인과 분석을 잠근다. 숫자 이름은 현재 목록에서 다시 고를 수 있도록 돕는 이름이다. 목록이 갱신되면 같은 이름에 이전 선택을 연결하지 않는다. |
| 자료 선택 | **등록 자료 선택** 다음 Tab으로 **이 자료를 분석할 권리가 있어요**에 도달한다. 시안도 같은 권리 문구를 사용하지만 시험 작품 이름이 표시된다. | ‘이 자료를 분석할 권리가 있는지 확인해 주세요’를 분석 실행 전에 읽을 수 있게 한다. 확인은 선택한 자료마다 다시 받는다. 분석 가능 여부는 실제 요청에서 등록 상태와 권한을 다시 확인한 뒤 결정된다. |
| 권리 확인 후 실행 | Front 실측에서 체크 전 분석 요청 0건, Space·Tab·Enter 후 정상 분석과 결과 제목 초점 이동을 확인했다. 자료 변경이나 체크 해제는 진행 중 요청을 취소하고 이전 결과를 지운다. | 실행 직후 분석 중 안내를 제공한다. 키보드로 실행한 경우 **분석 취소**로 초점을 이동할 수 있어야 한다. 사용자가 먼저 다른 조작으로 이동한 경우 현재 초점을 유지한다. |

선택·실행 동작은 `eb0e07b:components/reference-analysis/studio-registered-analysis.tsx`에서 확인했다. [보호 목록 UI 계약](../../handoffs/REA-CLOUD-PROTECTED-MATERIALS-UI-ADAPTER.md)

## 결과에서 읽는 내용

| 항목 | 고정 화면·시안 대조와 권장 문구 |
| --- | --- |
| 관찰 근거 | 격리 PNG 결과는 원본 이미지 기준 영역의 위치·크기, 불투명도 반영 면적, 대표색의 비중과 밝기 구간을 표시한다. Front 실측에서 `#e02020`을 확인했다. 시안의 시험 설명 대신 실제 영역과 관찰값을 함께 표시한다. |
| 분석 추정 | PNG 결과에는 추정값이 없고 고정 화면은 ‘이 결과에 포함된 추정이 없어요’로 표시한다. 관찰값과 추정 항목을 각각의 제목 아래 둔다. |
| 생성 초안과 수정본 | 고정 등록 화면은 **창작 초안**, **프롬프트 편집**, **초안 복사**를 표시한다. 공개 원본 URL이 있는 로컬 결과에서만 기존 초안 비교와 출처 문구가 추가된다. 시안처럼 등록 결과에도 **분석으로 생성한 초안**, **내 수정본**, ‘제작자가 공개한 프롬프트는 확인되지 않았어요’를 읽을 수 있게 한다. 초안과 수정본, 복사 대상이 서로 구분돼야 한다. |

## 자료에 접근할 수 없을 때와 목록 재조회

| 전환 | 고정 화면과 확인 범위 | 안내와 초점 기준 |
| --- | --- | --- |
| 접근 제한을 인지한 시점 | 격리 실측에서는 서버 권한을 철회한 뒤 **다시 분석**을 눌렀을 때 접근이 거절됐다. 고정 코드는 선택 무효나 자료 접근 불가 응답을 받으면 목록을 다시 조회한다. 시안은 시험 상태 선택으로 이 변화를 재현한다. | 해당 응답을 받으면 이전 선택·권리 확인·결과·수정 초안을 지운다. 이 화면에서 권한을 철회할 수 있다고 안내하거나, 권한이 바뀌는 순간 화면도 자동 갱신된다고 안내하지 않는다. |
| 목록을 다시 받는 중 | `eb0e07b`에서 분석 화면을 숨기고 **등록 자료 목록을 불러오고 있어요**가 그려진 뒤 안내로 초점을 옮긴다. 이 중간 초점은 고정 소스에서 확인했다. `0abded0`의 브라우저 결과는 재조회 완료 뒤 초점을 기록한다. | 예전 결과 영역과 자료 조작을 표시하지 않는다. 갱신 시작을 알아볼 수 있게 안내를 표시하고 그 위치에 초점을 둔다. 이전 응답이 늦게 도착해도 선택·결과를 복원하지 않는다. |
| 완료 후 자료가 남음 | 고정 코드는 **선택한 자료에 접근할 수 없어요**와 남은 목록을 표시하고 선택 상자로 초점을 옮긴다. 이번 단일 PNG 통합 실측은 이 분기를 포함하지 않는다. 시안은 두 시험 자료로 남은 항목을 다시 고르는 경우를 보여준다. | 안내를 선택 영역 가까이에 둔다. 남은 자료를 다시 선택하고 사용 권리를 다시 확인한다. 이전 자료명이나 접근 불가 사유는 화면에 내보내지 않는다. |
| 완료 후 자료 0건 | Front는 **분석할 수 있는 등록 자료가 없어요**로 초점이 이동하고 선택·체크·결과·초안이 모두 사라짐을 확인했다. 화면은 **목록 다시 조회**와 **내 프로젝트 열기**를 제공한다. | **내 프로젝트 열기**의 목적은 접근 가능한 프로젝트 목록을 여는 것이다. 분석용 자료 목록과 자료별 권한은 프로젝트 목록에서 확인할 수 있다고 안내하지 않는다. |

목록 상태와 초점 처리는 `eb0e07b:components/reference-analysis/studio-protected-materials-analysis.tsx`에서 확인했다. [브라우저 검수 조작과 확인 항목](../../../tests/reference-analysis/studio-protected-materials-browser.ego.mjs)

## 390px·1440px 완료 기준

| 폭 | 화면 기준 |
| --- | --- |
| 390px | 자료 선택·권리 확인·실행 아래에 분석 결과가 이어진다. 결과 제목 뒤 관찰 근거, 추정 안내, 생성 초안과 수정본을 순서대로 읽는다. 긴 영역 위치·색 코드·버튼이 화면을 넘지 않는다. |
| 1440px | 입력 카드 옆에 결과 카드가 온다. 결과 카드 안의 관찰·추정·초안은 같은 자료의 결과로 이어진다. 실행 또는 재조회 후 초점이 이동한 안내나 결과가 화면에 보여야 한다. |
| 두 폭 공통 | 첫 진입, 선택→체크→실행, 결과 제목, 재조회 안내, 남은 자료 선택 또는 0건 안내의 초점을 각각 확인한다. 선택 변경과 체크 해제 후 이전 초안이 되살아나지 않아야 한다. 가로 넘침은 0px이다. |

Front의 두 폭 실측은 세로 900px에서 카드 위치, 성공·빈 목록의 초점과 넘침을 확인했다. 이 문서는 실제 표시와 디자인 권고의 대조다. 추가 권한·요청·저장소 실측은 PG Tester의 독립 검수 범위다.
