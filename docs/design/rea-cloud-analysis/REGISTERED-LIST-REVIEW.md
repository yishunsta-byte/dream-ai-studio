# 등록 자료 보호 목록 UI 대조

기존 콘텐츠 분석 시안 `051dbcb`의 결과 구성을 보호 목록 격리 계약 `7514ad0`에 맞췄다. HTML의 **시안 상태**에서 일곱 가지 화면을 바꿔 볼 수 있다. 목록 조회와 분석 결과는 시험 자료로 재현했다. ## 표시 항목과 요청 데이터

| 항목 | 표시 기준 |
| --- | --- |
| `label` | 사용자에게 공개할 수 있는 이름임이 확인된 경우만 일반 문자열로 표시한다. 현재 어댑터는 `등록 이미지` 또는 `등록 영상` 뒤에 자료 ID 끝 8자리를 붙인다. 이 값을 그대로 화면에 내보내면 내부 식별자 일부가 드러난다. 안전한 표시 이름 계약을 정하기 전에는 `등록 자료 1`과 같이 현재 목록 안에서만 구분하는 이름을 사용한다. |
| `projectId`, `assetId` | 현재 선택과 단건 분석 요청을 연결하는 참조값으로만 사용한다. 화면 텍스트, 접근성 이름, 표시용 폼 값, URL·기록, 오류, 복사 가능한 결과에 포함하지 않는다. 선택 컨트롤은 현재 목록 안에서만 유효한 값을 사용한다. |
| 제공 범위 | 목록 응답에 미디어 종류 필드는 없다. 종류를 `label`에서 추론하거나 이 계약에 음악 목록을 포함한다고 안내하지 않는다. 저장소 경로 및 내부 식별자, 권한·등록 검증값, 계정·공급자 오류 정보는 화면으로 보내지 않는다. 초기 HTML, Flight, 프리페치도 자료 데이터 없이 유지한다. |

## 상태와 다음 동작

| 관찰한 응답 또는 상태 | 화면과 조작 |
| --- | --- |
| `200`, 자료 있음 | 보호 목록을 표시한다. 선택과 권리 확인이 끝나면 그 자료만 분석한다. 결과는 직접 관찰, 분석 추정, 편집용 초안으로 구분한다. |
| `200`, 빈 배열 | ‘분석할 수 있는 등록 자료가 없어요’를 표시하고 내 프로젝트와 목록 다시 조회로 이어준다. 목록이 비어 있거나 개별 분석 근거가 비어 있을 때는 각각의 원인을 표시한다. |
| `401 AUTH_REQUIRED` | 목록과 결과를 지우고 재로그인을 제공한다. 로그인 후 고정된 콘텐츠 분석 화면으로 돌아와 새 계정과 권한을 확인한다. |
| `403` | 목록과 결과를 지우고 접근 제한을 안내한다. 응답만 보고 개별 자료 철회나 오리진 오류를 단정하지 않는다. |
| 선택 자료가 최신 목록에서 빠졌거나 자료에 접근할 수 없다는 단건 응답 | 선택, 동의, 결과 및 수정 초안을 지운다. 최신 목록의 접근 가능 자료를 남기고 다시 선택하도록 안내한다. 상세 사유, 기존 자료 이름과 결과는 화면에 표시하지 않는다. |
| `503` 또는 연결 실패 | 목록과 결과를 지우고 다시 조회를 제공한다. 503은 공급원 미연결·오류·취소를 동일하게 처리한다. 사용자가 요청을 취소한 경우 늦게 오는 응답을 무시한다. |
| 운영에서 공급원 미연결 | ‘등록 자료 분석을 준비 중이에요’를 표시하고 선택·실행과 다시 조회를 숨긴다. `204` 사전 요청으로 화면 상태를 전환하지 않는다. |

자료가 바뀌면 기존 요청의 결과 반영을 즉시 무효화하고 이름, 권리 확인, 결과와 편집 중인 초안을 지운다. 계정 변경, 자료 철회, 목록 연결 실패에도 같은 원칙을 적용한다. 이전 자료가 늦게 돌아와도 자동 선택하거나 결과를 되살리지 않는다. 성공 시 결과 제목으로 키보드 초점을 이동하며, 390px에서는 결과가 입력 카드 아래, 1440px에서는 옆에 표시된다.

시안에서 자료를 선택한 상태로 **선택 자료 권한 철회**를 열면 해당 시험 자료만 빠진다. 선택 없이 열면 두 항목을 유지하고 **선택한 시험 자료 철회** 버튼을 눌렀을 때 지정한 자료만 빠진다. 상태 선택으로 철회한 직후에는 초점이 상태 선택에 남아 다음 Tab으로 자료 선택에 닿는다. 버튼으로 철회한 직후에는 다시 선택할 수 있도록 초점을 자료 선택에 돌린다. 이 조작은 시험 데이터만 다룬다. [독립 검수의 철회 대상 재현](../../handoffs/REA-REGISTERED-PROTOTYPE-INDEPENDENT-REVIEW.md)

## 확인 결과

Chromium 390×844 및 1440×900에서 가로 넘침 0px, 권리 확인·분석 실행·결과 초점의 키보드 흐름을 확인했다. 각 자료를 선택해 분석과 수정 후 철회했을 때 대상 항목만 빠졌고, 초안·동의·결과가 지워지며 남은 항목을 새로 분석할 수 있었다. 각 자료의 진행 중 응답을 철회 이후에 완료시켜도 결과가 표시되지 않았고 초점은 상태 선택에 남았다. 선택 없이 철회 화면을 연 경우에는 방향키로 두 항목을 탐색해도 목록이 유지되고 버튼 실행 뒤 자료 선택으로 초점이 돌아왔다. 분석·철회·목록 재조회 시험에서 실제 API와 운영 요청은 각각 0건이었다. 운영 연결과 재로그인 뒤 권한은 제품 연결 후 검수 대상이다.
