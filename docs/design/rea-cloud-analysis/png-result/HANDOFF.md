# 등록 PNG 분석 초안 표시 비교 인계

[비교 HTML 열기](http://127.0.0.1:8769/docs/design/rea-cloud-analysis/png-result/compare.html) · [HTML 원본](compare.html) · [등록 PNG 흐름 대조](../REGISTERED-PNG-FLOW-REVIEW.md)

두 화면은 같은 시험 PNG를 기준으로 전체 영역의 시작 위치와 크기, 대표색 구간 `#e02020`의 비중 100%, 불투명도 반영 면적, 상대 밝기 구간과 추정 없음 안내를 공유한다. 16×16의 붉은 시험 이미지에서 한 관찰 영역을 보여준다. 초안 문장은 조작을 비교하기 위한 시험 문구다. [고정 PNG 실측](../../../handoffs/REA-CLOUD-PROTECTED-PNG-BROWSER-PG17.md) · [결과 안내 대조](../RESULT-GUIDANCE-REVIEW.md)

| 화면 | 편집과 복사 대상 |
| --- | --- |
| 현재 격리 화면 | **창작 초안**의 **프롬프트 편집** 입력을 바꿀 수 있다. **초안 복사**는 입력칸에 있는 현재 문구를 복사하며 ‘창작 초안을 복사했어요’라고 알린다. |
| 제안 화면 | **분석으로 생성한 초안**은 읽기 전용이며 ‘제작자가 공개한 프롬프트는 확인되지 않았어요’를 곁에 표시한다. **내 수정본**을 바꿔도 생성 초안은 유지된다. **생성 초안 복사**와 **수정본 복사**는 각각 지정한 문구를 복사하고 결과를 알린다. |

공백만 남은 편집본은 자동 복사 버튼을 비활성화한다. 자동 복사가 거절되면 해당 텍스트로 초점을 옮겨 전체를 선택하고 직접 복사 안내를 제공한다.

Chromium 390×844와 1440×900에서 1열·2열, 가로 넘침 0px, 버튼 높이 44px 이상을 확인했다. Tab·Shift+Tab으로 편집과 복사에 도달했고, Enter로 각 복사를 실행한 뒤 붙여넣기 값 세 가지를 두 폭에서 대조했다. 복사 거부를 주입했을 때 선택 범위와 초점, 직접 복사 안내를 확인했다. 루프백 HTML과 글꼴만 요청했으며 API·운영 요청은 각각 0건이었다. 캡처는 `tmp/png-result-proof/`에 있다.
