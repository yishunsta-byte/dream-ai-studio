## 권리 확인·접근 불가·공급원 미연결

| 상태 | 현행 동작과 문구 기준 |
| --- | --- |
| 사용 권리 확인 전 | 보호 목록 화면에서 자료를 선택하면 `이 자료를 분석할 권리가 있는지 확인해 주세요.`라고 안내하고 실행은 비활성 상태다. 체크는 그 자료에 대한 사용자 확인으로 표시하고, 실제 분석 승인 여부는 공급원이 판단한다. PG17 시험에서 권리 메모만 있거나 제작용 링크만 있거나 분석 승인 행이 없으면 결과가 나오지 않았다. |
| 접근 불가 후 목록 갱신 | PG17에서는 분석 승인 철회·등록 세대 변경 뒤 결과가 차단됐다. 보호 화면은 `source_unavailable` 또는 `invalid_selection`이면 이전 선택·체크·결과·수정본을 지우고 목록을 다시 조회한다. 공통 응답이므로 화면에는 접근 불가로 안내한다. |
| 접근 불가 뒤 빈 목록 또는 선택 가능 | 빈 목록이면 `분석할 수 있는 등록 자료가 없어요.`에 초점을 두고 **목록 다시 조회**, **내 프로젝트 열기**를 제공한다. 다른 자료가 남으면 `선택한 자료에 접근할 수 없어요.`와 새 선택 안내를 표시하며 빈 선택 상자로 초점을 옮긴다. 새 자료에 대해 다시 권리를 확인한다. |
| 공급원 미연결 | `등록 자료 분석을 준비 중이에요.`와 `등록 자료 분석 공급자가 아직 연결되지 않았어요.`가 해당한다. 자료 선택·실행은 비활성 상태다. 클라우드 화면의 `예: M4A · 목표 범위`는 준비 안내의 예시다. 격리 PCM WAV 실측을 운영 지원 형식이나 성공 화면으로 안내하지 않는다. |
