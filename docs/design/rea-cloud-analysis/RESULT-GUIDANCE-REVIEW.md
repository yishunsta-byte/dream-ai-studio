## 초안과 내 수정본

- **분석으로 생성한 초안**은 `draft.prompt`를 보여주는 비교 기준이다. 곁에 ‘제작자가 공개한 프롬프트는 확인되지 않았어요’를 표시한다. DTO에는 제작자 프롬프트나 공개 여부 필드가 없다.
- **내 수정본**은 해당 초안을 사용자가 바꿀 수 있는 별도 입력이다. 수정하거나 복사해도 관찰 근거·추정과 원래 분석 초안은 유지한다. 수정 비교를 표시한다면 기존 안내대로 첫 수정과 마지막 수정 사이를 포함한 구간임을 설명한다.
- 로컬 `sourceUrl` 경로의 **공개 원본** 링크는 미디어 파일을 가리킨다. 등록 자료 화면은 현재 `sourceUrl`이 없으면 ‘프롬프트 편집’만 표시하고 `PromptComparison`에 있는 초안 출처 안내와 비교 기준을 렌더링하지 않는다. 등록 결과를 연결할 때도 초안 이름과 출처 안내, 수정본 이름을 동일하게 읽을 수 있어야 한다.
