# 로컬 분석 주소 오류·복구 비교 시안 인계

[비교 HTML 열기](http://127.0.0.1:8769/docs/design/rea-cloud-analysis/local-url-recovery/compare.html) · [HTML 원본](compare.html) · [입력 오류 검토](../LOCAL-URL-RECOVERY-REVIEW.md)

| 시험 상황 | 제안 화면의 표시와 조작 |
| --- | --- |
| 잘못된 형식 | HTTPS 주소 입력을 안내하고 URL 입력에 초점을 놓는다. 시험 주소를 고르거나 직접 입력을 고칠 수 있다. |
| 미지원 게시물 | 직접 파일 주소를 입력해 달라고 안내한다. YouTube와 Threads 시험 주소는 입력값으로만 취급한다. |
| 파일 응답 실패 | 오류 제목에 초점을 놓는다. 다음 Tab은 주소 입력에 닿는다. 같은 주소에서는 확인한 권리를 유지해 같은 폼에서 재실행할 수 있다. |
| 주소 변경 또는 권리 해제 | 원본 주소·관찰 근거·수정 초안을 지운다. 주소를 바꾸면 권리 체크를 해제한다. 권리를 해제하면 URL은 유지하고 다시 확인할 때까지 실행을 잠근다. |
| 정상 직접 파일 | 권리 확인과 실행 뒤 고정 관찰 근거와 시험 초안을 보여주고 **분석 결과** 제목으로 초점을 옮긴다. 실행 중 사용자가 폼 밖으로 옮긴 초점은 유지한다. |

기존 고정 화면 `13ca0b0`은 주소 형식을 브라우저에서 확인하고 게시물이나 파일 검증 실패에서 공통 오류를 제공한다. 시안의 상황별 오류와 실패 후 제목 초점은 제안이다. 성공 제목과 폼 밖 초점 유지는 후속 `a0c7757`에서 확인한 기준을 반영했다. 시안에서 받아들이는 응답은 고정 시험 자료다. [기존 실측](../../../handoffs/REA-LOCAL-RESULTS-INDEPENDENT-REVIEW.md) · [후속 키보드 확인 코드](../../../../tests/reference-analysis/local-url-analysis-screen.ego.mjs)

Chromium 390×844와 1440×900에서 Tab·Enter·Space, 오류 확인 뒤 주소 정정과 권리 재확인, 성공 제목의 초점 및 실패 뒤 재시도를 확인했다. 권리 해제와 주소 변경 후 이전 결과가 제거됐고 폼 밖 초점도 유지됐다. 두 폭 모두 가로 넘침 0px, 주요 조작 높이 44px 이상이었다. 루프백 HTML과 글꼴만 요청했으며 외부 플랫폼·API·운영 요청은 각각 0건이었다. 캡처는 `tmp/local-url-recovery-proof/`에 있다.
