# 관리자 ‘내 프로젝트’ 상태 안내

관리자가 목록을 열었을 때 조회 성공 여부와 다음 행동을 바로 알 수 있도록 한다. 현재 화면의 네 상태와 기존 한국시간 조회 시각을 그대로 사용한다. [현재 화면 구현](../../components/admin/admin-projects.tsx) · [사용자 매뉴얼](api-user-manual.md)

| 조회 상태 | 화면에 표시할 문구 | 다음 행동 |
|---|---|---|
| 미연결 | **프로젝트 목록 미연결** · 이 환경에서 내 프로젝트를 조회하려면 운영 담당자의 연결 확인이 필요해요. | 카드 안에서 **연결 상태 도움말**을 펼친다. 조회 시각과 건수는 생략한다. |
| 조회 실패 | **프로젝트 목록을 불러오지 못했어요** · 잠시 뒤 다시 불러와 주세요. | **다시 불러오기**를 한 곳에만 둔다. 계속 실패하면 같은 카드의 도움말을 펼칠 수 있다. |
| 정상 조회 0건 | **내 프로젝트가 0개예요** · 현재 로그인한 계정으로 조회한 결과예요. | 조회 시각을 한국시간으로 표시하고 **다시 불러오기**를 제공한다. |
| 정상 조회 1건 이상 | **내 프로젝트 N개** · 조회 시각과 기존 목록을 표시한다. | 제목을 누르면 해당 프로젝트 상세로 이동한다. |

### 펼친 도움말의 실제 문구

**미연결** — 운영 담당자에게 ‘관리자 화면의 내 프로젝트 목록 연결을 확인해 주세요’라고 알려 주세요. 이 목록은 현재 로그인한 계정의 프로젝트를 보여줘요.

**조회 실패** — 다시 불러와도 같은 문구가 보이면 ‘내 프로젝트’, 오류 문구, 발생 시각을 운영 담당자에게 알려 주세요.

### 배치와 확인 방법

- 도움말을 상태 카드 안에 인라인으로 펼친다. 매뉴얼 웹 주소가 정해지기 전에도 안내를 읽을 수 있다. 네이티브 `details/summary`를 쓰면 키보드로 열고 닫을 수 있다.
- 실패 상태에는 현재 섹션 제목 옆과 경고 문장 안에 새로고침 링크가 각각 있다. 카드 안의 하나로 통합한다. 다시 조회한 뒤 ‘내 프로젝트’ 섹션을 유지하고 결과를 확인할 수 있어야 한다.
- 320·390픽셀에서 긴 문구는 줄바꿈하고 도움말과 재시도의 조작 영역은 각각 높이 44픽셀 이상으로 둔다. 1280픽셀에서도 동일한 순서로 읽힌다.
- 네 상태를 각각 입력해 확인한다. 실패·미연결에서 0건이 표시되거나, 0건에서 경고가 보이거나, 프로젝트 상태가 게시 서버 연결 상태를 바꾸면 수정한다. 도움말을 펼치고 접을 때 초점은 같은 조작 요소에 남아야 한다.

이 문서는 적용 전 디자인 명세다. 위 동작은 프런트엔드 반영 후 검증한다.
