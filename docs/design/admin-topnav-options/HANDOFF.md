# 02 작업 콘솔 제품 반영 인계

상단 메뉴의 프로젝트 목록을 기본 화면으로 삼고, 행에서 해당 프로젝트의 다음 작업으로 이동한다. 390px에서는 프로젝트명과 상태를 첫 줄, **내용 버전**과 **출력 파일** 요약을 그 아래에 표시한다. 상세 진입 시 초점을 상세 제목에 옮기고 제목을 화면에 표시한다. [작업 콘솔 시안](index.html) · [기능 비교](../../handoffs/ADMIN-TOPNAV-OPTIONS-FUNCTIONAL-REVIEW.md)

| 제품 연결 | 반영 조건 |
|---|---|
| 메뉴와 주소 | 기존 `/admin#admin-overview`, `#admin-project-list`, `#admin-review`, `#admin-account` 주소를 보존한다. 해시 없는 기본 화면을 프로젝트 목록으로 쓰는 경우 직접 입력한 해시가 우선한다. 직접 진입, 새로고침, 뒤로·앞으로 가기에서 주소·선택 메뉴·도착 영역이 일치해야 한다. 실제 메뉴 링크의 `aria-current="location"`과 도착 제목 초점을 확인한다. 개요의 클라우드 개인 관리 링크와 조건부 전체 목록 링크를 유지한다. |
| 실제 프로젝트 조회 | 기존 관리자 인증과 로그인 계정의 소유 범위에서 서버 조회를 사용한다. 미연결, 일시 실패, 정상 0건, 성공 목록을 각각 표시한다. 검색과 필터에는 조회한 실제 목록을 사용한다. 재조회는 추가 서버 요청을 실행하고 `#admin-project-list`로 돌아온다. 제목은 실제 `/cloud/projects/{id}` 상세로 연결하고, 전체 목록은 `/cloud/projects`로 연결한다. 상세 제목이나 해당 기능의 제목에 초점이 보여야 한다. |
| 리비전과 출력 | 현행 관리자 목록 응답의 행에는 내용 리비전과 출력 파일 수가 없다. 소유자 범위의 목록 또는 승인된 요약 계약에서 현재 버전의 리비전과 확인된 출력 개수를 제공할 때 실제 값을 표시한다. 조회 근거가 없으면 ‘확인 불가’, 정상 조회 결과가 0건이면 ‘없음’을 표시한다. 새 데이터를 붙이는 경우 버전이 바뀌었을 때 이전 결과를 현재 버전으로 집계하지 않는다. |
| 검수·게시 | 프로젝트 검수는 해당 프로젝트 흐름에 연결한다. 실제 게시 큐는 목록 재조회, 권리 확인, 게시 준비, 게시, 철회 확정과 같은 요청 재시도를 기존 컴포넌트에 연결한다. 서버가 미연결이면 상태 안내를 보여준다. 작품의 검수 상태와 공개 여부를 각각 표시한다. |
| 계정 및 연결 상태 | 제품의 `AccountMenu`와 세션 경계를 사용한다. 로그인 계정을 표시하고 로그아웃, 실패 시 재시도, `/account/password`의 비밀번호 변경으로 연결한다. 기타 운영 기능 6개의 상태와 설명은 공통 연결 상태 영역에서 찾을 수 있게 한다. |

제품 구현 검수는 390px·1440px에서 마지막 행 키보드 진입, 관리자 해시 직접 진입과 뒤로·앞으로 가기, 재조회 실패→성공, 상세 이동, 게시 큐와 계정 조작까지 포함한다. 시안의 프로젝트·리비전·출력 수는 예시 데이터다. | 390×844 | 4개 행 모두 내용 버전·출력 파일 라벨과 값 표시. 가로 넘침 0px. | 목록 스크롤 483px에서 진입. 데저트 모션 에디션 상세를 열고 제목에 초점이 도달했다. 제목은 화면 상단 기준 18~52px에 표시됐다. |
