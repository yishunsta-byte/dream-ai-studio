# 게시 준비 취소와 공개 철회 시안 인계

[비교 HTML 열기](http://127.0.0.1:8769/docs/design/admin-topnav-options/publication-revocation/compare.html) · [HTML 원본](compare.html) · [게시 상태 대조](../PUBLICATION-STATE-REVIEW.md)

| 시험 상태 | 확인과 완료 안내 |
| --- | --- |
| 게시 중 세대 2 · 준비 세대 3 | **게시 준비 취소**를 열면 준비 세대 3과 기존 게시 세대 2가 확인 영역에 함께 표시된다. 확정 후 준비 항목이 ‘없음’으로 바뀌고 ‘게시 중인 세대 2는 계속 공개돼요’라고 안내한다. 준비와 게시 상태를 각각 갱신한다. |
| 게시 중 세대 2 · 준비 없음 | **공개 철회**를 열면 게시 중 세대 2와 공개 목록·표지 주소에 미치는 영향을 표시한다. 확정 후 게시 항목이 ‘없음’으로 바뀌고 해당 세대가 공개 목록과 표지 주소에서 내려갔다고 안내한다. |

T289는 준비 세대가 있으면 그 세대를 먼저 철회한다. 확인 안내에는 작품과 대상 세대를 넣고, 결과에는 현재 남아 있는 공개 상태를 반영한다. 시안의 두 사례는 서로 독립된 시험 상태다. 권리 확인은 게시 준비·게시 요구 사항이며 철회를 여는 제약으로 쓰지 않는다. [T289 게시 큐 계약](../../../handoffs/T289-ADMIN-PUBLICATION-QUEUE.md) · [대상 세대 판정](../../../../components/admin/publication-model.ts)

확인 영역을 열면 제목에 초점을 두고 다음 Tab은 **돌아가기**에 닿는다. 돌아가기 또는 Escape는 기존 상태를 유지하고 진입 버튼으로 초점을 돌린다. 확정 후에는 사라진 조작 대신 해당 카드 제목에 초점을 두고 상태 영역에 결과를 표시한다. **예시 다시 보기**로 각 상태를 독립적으로 복원하며 진입 버튼에 초점을 돌린다.

Chromium 390×844와 1440×900에서 1열과 2열, 가로 넘침 0px, 표시된 조작 영역 높이 44px 이상을 확인했다. 키보드로 두 사례의 확인 열기, 취소, 확정, 초기화를 검증했다. 준비 취소 후 공개 세대 유지와 공개 철회 후 해당 세대 제거를 확인했다. 브라우저는 루프백 HTML과 글꼴만 받았고 API·운영 요청은 각각 0건이었다. 운영에서 게시·철회를 실행하지 않았다. 캡처는 `tmp/publication-revocation-proof/`에 있다.
