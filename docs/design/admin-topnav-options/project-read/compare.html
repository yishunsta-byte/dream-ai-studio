    검색 조건에 맞는 프로젝트가 없어요.

    내 프로젝트 전체 화면 →
    연결 상태 도움말

    /admin#admin-overview

    개요

    개인 작업실에서 현재 계정으로 접근할 수 있는 프로젝트를 확인할 수 있어요.

    클라우드 개인 관리 →내 프로젝트 전체 화면 →

    /cloud/projects

    내 프로젝트

    개인 작업실의 프로젝트 목록 화면이에요. 이 화면에서 현재 계정으로 조회한 결과를 확인할 수 있어요.

    개인 관리 보기 →관리자 목록 예시로 돌아가기

    /cloud/manage

    개인 관리

    조회에 성공하면 이번 목록의 건수와 기록된 프로젝트 상태를 확인할 수 있어요.

    내 프로젝트 보기 →관리자 개요 예시로 돌아가기

    /cloud/projects/{id}#admin-project-heading

    프로젝트 상세

    개인 작업실에서 읽기 전용으로 보는 시험 프로젝트예요.

    ← 내 프로젝트
