# 관리자 프로젝트 조회 상태 비교 시안 인계

[비교 HTML 열기](http://127.0.0.1:8769/docs/design/admin-topnav-options/project-read/compare.html) · [접근 거절에 바로 열기](http://127.0.0.1:8769/docs/design/admin-topnav-options/project-read/compare.html#admin-login) · [HTML 원본](compare.html) · [운영·T362 대조](../PROJECT-READ-STATE-REVIEW.md)

| 시험 상태 | 건수·조회 시각과 다음 조작 |
| --- | --- |
| 정상 목록 | 전체 2개와 고정 조회 시각을 보여준다. 제목 검색과 상태 필터를 적용하고 프로젝트 제목에서 상세로 이동할 수 있다. |
| 정상 조회 0건 | ‘내 프로젝트가 0개예요’와 성공 조회 시각을 보여준다. 다시 불러오기와 내 프로젝트 전체 화면을 제공한다. |
| 검색 결과 0건 | 성공한 목록의 전체 2개와 조회 시각이 유지되고, 필터 결과에만 ‘0개 표시’가 나온다. **검색 조건 지우기**로 되돌리고 검색 입력으로 초점을 보낸다. |
| 목록 미연결 | 건수와 조회 시각을 숨긴다. 연결 상태 도움말에서 연락할 내용을 안내하고, 개인 화면 이동은 관리자 개요에서 체험할 수 있다. |
| 조회 오류 | 건수와 조회 시각을 숨긴다. **다시 불러오기**는 고정 오류 응답을 보여주고 프로젝트 콘솔 제목에 초점을 돌린다. |
| 접근 거절 | 관리자 메뉴와 프로젝트 목록 대신 `/admin/login?error=forbidden`의 목적지와 담당자 문의 안내를 보여준다. 버튼은 로그인 경로의 예시를 알려준다. |

관리자 개요와 내 프로젝트 메뉴, 개인 목록(`/cloud/projects`), 개인 관리(`/cloud/manage`), 개인 읽기 전용 상세 이동은 같은 문서의 프래그먼트로 재현한다. 실제 주소는 화면에 설명용으로 표시했다. 개인 화면의 결과는 해당 경로에서 다시 조회되는 제품 흐름이며, 시안은 목적지와 다음 링크만 안내한다. T362 상태와 실제 읽기 연결은 별도 운영 검증 범위다. [고정 관리자 목록](../../../../components/admin/admin-projects.tsx) · [T362 읽기 인계](../../../handoffs/T362-OPERATIONAL-READ-HANDOVER.md)

접근 거절의 시안 주소 `#admin-login`을 새 문서로 열거나 새로고침하면 로그인 안내만 표시한다. 거절 상태에서는 관리자 메뉴, 목록 건수, 조회 시각과 프로젝트 행을 숨긴다. 상태 버튼으로 허용된 예시와 접근 거절을 오가면 브라우저 기록에 각각 남는다. 뒤로·앞으로 가기로 `#admin-login`에 도달하면 로그인 안내로 복원하고 제목에 초점을 둔다. 해당 제목에서 다음 Tab은 로그인 안내 버튼에 닿는다. 이 경로는 시안 상태 전환을 재현한다.

Chromium 390×844와 1440×900에서 상태 6개와 가로 넘침 0px, 보이는 조작 영역 높이 44px 이상을 확인했다. Tab·Enter로 상태 선택, 현재 메뉴 다시 선택, 도움말 펼치기·접기, 재조회, 접근 거절 안내를 확인했다. 키보드로 필터를 지우거나 상태를 바꾸고 상세와 개인 관리·목록으로 이동했다. 관리자 목록과 상세 제목의 초점, 브라우저 뒤로 가기의 관리자 현재 위치 복원도 확인했다. `#admin-login`의 새 문서 진입, 새로고침, 뒤로·앞으로 가기를 각각 재검증했고 관리자 메뉴와 프로젝트 데이터가 표시되지 않았다. 브라우저에는 루프백 HTML과 글꼴 요청만 있었으며 API·운영 요청은 각각 0건이었다. 캡처는 `tmp/project-read-state-proof/`에 있다.
