# 관리자 내 프로젝트 조회 상태 대조

운영 배포 기록 `073f919`, 고정 제품 `e4fa378`, T362 운영 읽기 인계를 대조했다. 배포 검수에서는 390px·1440px의 관리자 메뉴와 **프로젝트 목록 미연결**을 확인했다. 운영의 로그인된 계정에서 정상 목록이나 정상 0건을 확인한 기록은 없다. [운영 관리자 배포 기록](../../handoffs/ADMIN-WORK-CONSOLE-LIVE-DEPLOYMENT.md) · [T362 조회 인계](../../handoffs/T362-OPERATIONAL-READ-HANDOVER.md)

## 상태별 표시와 다음 행동

| 상태 | 고정 제품의 동작 | 화면 안내 기준 |
| --- | --- | --- |
| 정상 목록 | 권한이 확인된 현재 계정의 목록 읽기가 성공하면 **내 프로젝트 N개**와 한국시간 조회 시각을 표시한다. 제목 검색·상태 필터, 프로젝트 상세, 다시 불러오기, 내 프로젝트 전체 화면을 제공한다. | 필터의 ‘N개 표시’와 조회 성공 건수를 구분한다. 검색에 맞는 항목이 없으면 ‘검색 조건에 맞는 프로젝트가 없어요’를 표시하고 조건을 바꿀 수 있게 한다. 내용 버전·출력 파일은 확인 불가로 표시하고, 목록의 상태는 기록된 프로젝트 상태임을 안내한다. |
| 정상 조회 0건 | 빈 배열로 정상 조회되면 **내 프로젝트가 0개예요**와 조회 시각을 표시한다. 다시 불러오기와 **내 프로젝트 전체 화면**을 열 수 있다. | ‘현재 계정으로 조회할 수 있는 프로젝트가 없어요’로 범위를 밝힌다. 0건을 자료 삭제나 접근 거절의 근거로 해석하지 않는다. T361 HTTPS 격리의 경우 DB 읽기 승인을 회수한 계정에 인증 성공 뒤 빈 목록이 표시됐다. |
| 공급원 미연결 | 관리자 목록의 읽기 설정이 고정 제품에서 요구하는 PostgreSQL 모드가 아니면 읽기를 시작하기 전에 **프로젝트 목록 미연결**을 표시한다. | **연결 상태 도움말**에서 운영 담당자에게 관리자 목록 연결을 확인해 달라고 안내한다. 건수·조회 시각이 없고 카드 안에 재조회 조작이 없다. |
| 조회 오류 | 읽기 경로가 선택된 뒤 데이터를 받지 못하면 **프로젝트 목록을 불러오지 못했어요**를 표시한다. 실패 원인이나 일시성은 이 화면의 상태만으로 판별할 수 없다. | **다시 불러오기**를 한 곳에 둔다. 새 문서 요청으로 목록을 읽고 `#admin-project-list`에 돌아온다. 같은 오류가 계속되면 화면 이름·문구·시각을 운영 담당자에게 전달하게 한다. |
| 접근 거절 | 관리자 진입 단계에서 미인증이면 `/admin/login?next=%2Fadmin`, 허용 범위 밖이면 `/admin/login?error=forbidden`, 인증 확인 실패면 `/admin/login?error=unavailable`로 이동한다. 이때 관리자 목록을 읽지 않는다. 개인 상세는 타인·보관·없는 프로젝트를 같은 404로 처리한다. | 로그인 안내에서 사유와 다음 행동을 제공한다. 프로젝트 카드나 건수를 로그인 오류와 함께 표시하지 않는다. 상세 404에서는 **내 프로젝트**로 돌아와 다시 선택하도록 안내한다. |

## 관리자 화면에서 개인 작업실로 이동

- 관리자 상단의 **내 프로젝트**는 `/admin#admin-project-list`에서 **프로젝트 콘솔**을 연다. 프로젝트 제목은 `/cloud/projects/{id}#admin-project-heading`의 개인 읽기 전용 상세로 이어진다. 상세 상단의 **← 내 프로젝트**는 `/cloud/projects`로 돌아간다. 관리자 콘솔의 메뉴 위치는 브라우저 뒤로 가기로 복원한다. [관리자 메뉴](../../../components/admin/admin-navigation.tsx) · [개인 프로젝트 상세](../../../components/cloud/project-detail-readonly.tsx)
- 정상 조회 카드의 **내 프로젝트 전체 화면**은 `/cloud/projects`를 연다. 미연결·조회 실패에서는 관리자 **개요**에 같은 목적지 링크가 있다. **클라우드 개인 관리**는 개요에서 `/cloud/manage`로 이동하며, 이번 목록의 건수와 기록된 상태 분포를 보여준다. 개인 목록에도 **개인 관리 보기**가 있다. 이동한 화면의 조회 결과는 그 화면에서 확인한다. [관리자 개요](../../../components/admin/admin-hub.tsx) · [개인 관리](../../../app/%28cloud%29/cloud/manage/page.tsx)
- T356의 새 HTTPS 조회 연결 범위는 프로젝트 목록·상세 GET과 개인 클라우드 목록·상세다. 관리자 콘솔의 현재 진입 조건에는 여전히 `postgres` 모드가 필요하다. 또한 T362에 기록된 운영 `406/PGRST106`은 그 요청 시점의 `project_read` 미노출을 뜻한다. 프로젝트 건수, 운영 DB의 스키마 설치 여부, 실효 권한과 행 격리는 이 응답에서 알 수 없다. [T356 앱 연결 범위](../../handoffs/T356-PROJECT-HTTPS-READ-APP-INTEGRATION.md) · [T362 운영 읽기 판정](../../handoffs/T362-R-PROJECT-READ-ACTIVATION-REVIEW.md)

## 390px·1440px 완료 기준

| 폭 | 검수 기준 |
| --- | --- |
| 390×844 | 상단 메뉴에서 **내 프로젝트**를 찾고 제목·상태·다음 조작을 읽을 수 있다. 검색과 상태 필터가 필요한 폭에서 줄바꿈하고, 긴 프로젝트명과 상태가 잘리지 않는다. 카드 안의 문의·재조회 링크와 필터에 44px 이상의 조작 영역을 확보한다. |
| 1440×900 | 상단 메뉴에서 현재 위치가 표시된다. 정상 목록의 제목·상태·다음 단계가 같은 행에서 읽히고 조회 건수와 필터 결과 건수를 구분할 수 있다. |
| 두 폭 공통 | Tab·Enter로 상단 메뉴를 열면 **프로젝트 콘솔** 제목에 초점이 보이고 고정 메뉴에 가려지지 않는다. 실패에서 다시 불러오기 후 해당 제목과 새 상태를 확인한다. 도움말은 펼치고 접을 때 초점을 유지한다. 목록 제목 링크로 열면 상세 제목에 초점이 보이고, 브라우저 뒤로 가면 관리자 **내 프로젝트**가 현재 위치로 복원된다. 정상 0건·검색 결과 0건·미연결·조회 실패·접근 거절에서 문구, 조회 시각 노출, 다음 조작을 각각 확인한다. 가로 넘침은 0px이다. |

위 표는 후속 검수 기준이다. 기존 T286의 네 상태 화면 검수는 합성 공급자로 390px·1280px에서 수행했다. 이번 대조에서는 운영 요청, 제품 및 매뉴얼 변경을 수행하지 않았다. [기존 네 상태 화면 검수](../../handoffs/T286-ADMIN-PROJECTS-RC-VERIFY.md) · [목록 상태 디자인 기준](../admin-project-read-help.md)

## 관리자 HTTPS 조회 후보에서 추가로 확인할 차이

`44288d3`은 관리자 HTTPS 연결 계약이다. `e4fa378`의 관리자 콘솔에서 목록을 조회하려면 `postgres` 모드가 필요하다. 운영 검수에서 확인한 상태는 목록 미연결이다. T361-R은 `633c10b`의 개인 화면과 목록·상세 GET을 격리 환경의 HTTPS로 검증했다. `dcab613`의 390px·1440px 검수(`3abd4fe`)는 정적 시안에서 재조회와 거절 안내의 초점을 확인한 기록이다. 아래 화면 기준은 관리자 HTTPS 후보에서 확인할 항목이다. [HTTPS 연결 계약](../../handoffs/ADMIN-PROJECT-HTTPS-READ-CONTRACT.md) · [T361-R 격리 실측](../../handoffs/T361-R-PROJECT-HTTPS-READ-STACK-REVIEW.md) · [시안 독립 검수](../../handoffs/ADMIN-PROJECT-READ-STATE-PROTOTYPE-INDEPENDENT-REVIEW.md)

| HTTPS에서 갈리는 조건 | 표시와 조작 기준 |
| --- | --- |
| 로그인 유지 중 DB의 프로젝트 읽기 승인 회수 | T361-R에서는 같은 로그인으로 Auth가 성공하고 A의 목록만 비었으며 B의 목록은 유지됐다. 관리자 후보에서도 갱신 응답이 정상 빈 배열이면 기존 **내 프로젝트가 0개예요**, 현재 계정 안내, 새 한국시간 조회 시각과 **다시 불러오기**를 사용한다. 이전 목록의 제목·건수는 제거한다. 0건 응답에서는 승인 회수 사유를 확인할 수 없으므로 화면에는 현재 계정의 조회 결과만 안내한다. |
| HTTPS 모드의 설정 오류, 선택한 스키마 미노출 또는 조회 전송 실패 | 잘못된 설정 형식·대상은 Data API 호출 전에 차단한다. 설정 검증을 통과한 스키마가 미노출이면 Data API가 요청을 거절한다. T362의 `406/PGRST106`은 해당 시점의 노출 상태만 보여준다. 정상 배열을 받지 못한 경우는 기존 **프로젝트 목록을 불러오지 못했어요**, **다시 불러오기**, 문의 도움말을 사용한다. 프로젝트 건수와 조회 시각은 생략하고 원시 응답 코드는 운영 근거에 둔다. [T362 미노출 관측](../../handoffs/T362-R-PROJECT-READ-ACTIVATION-REVIEW.md) |
| HTTPS 재인증에서 세션 또는 계정 일치 확인 실패 | 화면 인증과 조회 인증의 계정이 일치하지 않으면 목록을 요청하기 전에 차단한다. 로그인 필요·권한 거절·인증 확인 실패로 분류되면 기존 관리자 로그인 판정(`/admin/login?next=%2Fadmin`, `?error=forbidden`, `?error=unavailable`)을 따른다. 로그인 화면에서 **관리자 로그인** 및 해당 상태 문구를 확인한다. 현행 `unavailable` 문구는 ‘로그인 설정이 아직 끝나지 않았어요.’다. 재인증 확인 실패에는 ‘관리자 로그인 상태를 확인할 수 없어요.’를 새 안내 문구로 제안한다. 이 상태에서는 관리자 목록·건수·조회 시각과 목록 재조회를 표시하지 않는다. [현행 관리자 로그인 문구](../../../app/admin/login/page.tsx) |

**390×844·1440×900 후보 검수 기준.** 정상 0건과 조회 실패에서 **다시 불러오기**를 Enter로 실행하면 새 문서를 열고 `#admin-project-list`의 **프로젝트 콘솔** 제목에 초점을 돌려준다. 390px에서는 고정 상단 메뉴 아래에 제목과 상태 안내가 보이고 1440px에서도 같은 제목에 초점 표시가 보이는지 확인한다. 재인증으로 이동하면 두 폭 모두 **관리자 로그인** 제목과 상태 안내를 읽을 수 있고 Tab으로 첫 로그인 입력에 도달하는지 확인한다. 조회 콘솔 제목으로 초점을 복원하는 검사는 콘솔이 표시되는 분기에 적용한다. [목록 제목 초점 구현](../../../components/admin/admin-navigation.tsx)

이 증분은 고정 소스와 인계만 대조했다. 관리자 HTTPS 연결 실측과 후보 화면의 독립 검수는 각각 Backend와 UI Tester의 배정에서 확인한다.
