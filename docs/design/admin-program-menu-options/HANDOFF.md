# 관리자 분석 스튜디오 · 기존 콘텐츠 화면 교체

사용자 결정에 따라 기존 통합 콘텐츠 분석 화면을 Style DNA, 음악 분석, 쇼츠 분석의 세 작업 화면으로 교체하는 디자인이다. 새 세 프로그램은 상단의 별도 버튼으로 열고, **완성본 검수·게시**는 운영 메뉴에서 계속 사용한다.

| 시안 | 분석 작업대 |
| --- | --- |
| 라이브 콘솔 | 상단 프로그램 메뉴 아래에 입력과 대형 프리뷰를 나란히 배치하고 결과는 그 아래에 둔다. |
| 시그널 랩 | 소스·프리뷰·결과의 세 열을 한 화면에서 읽는다. 모바일에서는 입력부터 한 열로 이어진다. |
| 프리미어 스튜디오 | 포스터형 프리뷰를 왼쪽에 넓게 두고 오른쪽에 입력과 결과를 쌓는다. |

## 제품 전환 시 확인할 연결

- **메뉴와 화면**에서 기존 **콘텐츠 분석·공개**와 **기본 분석** 진입, 매체 전환과 기존 분석 결과 공개 준비를 걷어낸다. Style DNA, 음악 분석, 쇼츠 분석의 별도 링크를 둔다. 기존 콘텐츠 화면 북마크의 진입은 새 프로그램 선택으로 안내한다.
- **Style DNA**는 이미지 직접 URL과 파일 입력, 의미 분석 결과와 한영 프롬프트를 제공한다. 통합 기준 `617b81e`에서 Style DNA 요청은 `/api/admin/reference-analysis`를 사용하므로 제품 전환에서도 이 이미지 요청이 이어져야 한다.
- **음악 분석**은 현재 `AdminMusicSemantic`의 파일과 전송 동의 흐름을 독립 작업 화면에 연결한다. **쇼츠 분석**은 `AdminShortsAnalysis`의 YouTube 주소와 사전 설정 조회·전송 동의 흐름을 연결한다.
- **API연동**은 세 프로그램의 설정 상태를 고유 행으로 표시한다. 프로그램에 연결된 링크로 돌아갈 수 있게 한다.
- **저장된 공개 결과**는 화면 교체와 별개로 취급한다. 기존 공개 목록과 완성본 검수·게시를 구분한다.
