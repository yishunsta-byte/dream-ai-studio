## 390px·1440px 완료 기준

| 환경 | 검수 기준 |
| --- | --- |
| 390×844 | 작품 상세에서 제목과 닫기가 보이고 표지 대체 영역이 플레이어의 버튼이나 탐색 막대를 덮지 않는다. 음원·영상 조작과 오류 후 다시 불러오기가 화면 폭 안에 들어온다. 상세 자체는 세로로 스크롤할 수 있고 문서 가로 넘침은 0px이다. |
| 1440×900 | 작품 제목과 매체를 한 상세에서 읽고 조작할 수 있다. 로딩과 재생 오류는 해당 플레이어 가까이에서 표시한다. 표지 실패가 플레이어 레이아웃이나 탭 순서를 바꾸지 않는다. |
| 두 폭 공통 | Tab·Enter로 작품을 열고 상세 제목을 인식할 수 있으며 Tab·Shift+Tab으로 닫기와 플레이어·복구 조작에 접근한다. 재생 중 대기·오류와 파일 다시 불러오기를 상태 영역에서 알린다. **재생 파일 다시 불러오기**를 누르면 초점이 재생기로 이동한다. Escape 또는 닫기로 재생을 멈추고 작품을 열었던 버튼으로 초점을 돌린다. 기존 문서에 그 버튼이 없으면 작품 영역으로 초점을 보낸다. 공개 홈을 새 문서로 연 뒤에는 그 문서의 작품 목록에서 다시 검색할 수 있어야 한다. |

위 표는 후속 검수 기준이다. 기존 브라우저 기록은 로컬 Chromium의 1280px 영상, 390px 음악, 320px 철회 오류와 Escape 복귀를 확인했다. 운영의 실제 게시 작품·저장소 버전 보장·Vercel 전송·모바일 실기기 및 철회 뒤 남은 버퍼 재생 시간은 미확인이다. 이번 작업은 고정 소스와 검수 기록을 읽기 전용으로 대조했다. [T370 브라우저 실측 22행](../../handoffs/T370-PUBLIC-PLAYBACK-HTTP-VERIFICATION.md?plain=1#L22)
