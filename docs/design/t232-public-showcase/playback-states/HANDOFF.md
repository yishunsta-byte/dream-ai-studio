# 공개 작품 상세 재생 상태 비교 시안 인계

[비교 HTML 열기](http://127.0.0.1:8769/docs/design/t232-public-showcase/playback-states/compare.html) · [HTML 원본](compare.html) · [공개 재생 상태 대조](../PLAYBACK-STATE-REVIEW.md)

| 시험 상태 | 화면과 다음 조작 |
| --- | --- |
| 영상 연결 | 작품 표지와 영상 조작을 표시한다. 재생하거나 재생 중 탐색하면 시험 대기 안내가 나온다. 일시 정지한 상태의 탐색은 위치만 바뀐다. |
| 음원 연결 | 별도 표지와 제목으로 구분되는 음원 조작을 표시한다. |
| 영상 표지 실패 | 이미 실패한 표지 대신 대체 바탕을 표시하고 영상 조작은 유지한다. 시험 재생을 시작하면 대체 바탕이 재생 예시로 바뀐다. |
| 재생 미연결 | 표지·작품 설명과 재생 파일 미연결 안내를 보여준다. 재생 조작과 파일 재시도는 표시하지 않는다. |
| 재생 오류 | **재생 파일 다시 불러오기**는 같은 문서, 같은 파일의 로딩과 실패를 재현한다. **최신 작품 목록 열기**는 별도의 새 문서를 연다. |
| 조회 후 작품 없음 | 열린 상세에서는 공통 재생 오류를 보여준다. **최신 작품 목록 열기**로 이동한 새 문서에는 시험 작품과 기존 상세 조작이 없으며 현재 목록에서 볼 수 없다고 안내한다. |

상세를 열 때 닫기 버튼에 초점을 두고 Tab으로 재생·탐색·복구 조작에 도달한다. 파일 재시도 시 초점은 재생 버튼으로 돌아간다. Escape 또는 닫기로 상세를 닫으면 원래 작품 버튼에 초점이 돌아온다. 최신 목록으로 이동한 새 문서에서는 목록 제목에 초점을 두고 상태 비교로 돌아갈 수 있다.

Chromium 390×844와 1440×900에서 여섯 상태, Tab·Enter·Escape·방향키, 상세와 문서의 가로 넘침 0, 조작 높이 44px 이상을 확인했다. 파일 재시도에서 문서가 유지되고 최신 목록은 새 문서에서 열린다는 점을 확인했다. 목록과 재생은 고정 시험 데이터이며, 루프백 HTML·글꼴·표지 이미지만 요청했다. 실제 재생 파일·API·운영 요청은 0건이다. 캡처는 `tmp/playback-state-proof/`에 있다. [재사용한 표지 자료](../assets/ASSETS.md)
