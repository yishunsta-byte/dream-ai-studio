# Spectrum Lab API 연동 및 사용 매뉴얼

관리자 통합본 `fa0aa2c`의 화면과 응답을 기준으로 정리했다. 경로는 **관리자 → 콘텐츠 분석·공개 → 사용 매뉴얼**과 **관리자 → API 연동**이다.

## 사용 매뉴얼 문구

### 기본 분석

1. **이미지, 음악, 영상** 중 매체를 고르고 **URL 주소** 또는 **파일 업로드**를 선택하세요.
2. 자료를 분석할 권리를 확인한 뒤 **권리 확인하고 분석**을 누르세요. 파일은 4 MiB까지 올릴 수 있어요. URL은 지원 도메인의 직접 HTTPS 파일 주소를 사용하세요. URL 파일은 64 MiB까지 읽어요.
3. **관찰 근거**를 확인한 뒤 **생성 프롬프트**를 검토하세요. URL 입력에 Threads 게시물 주소나 브라우저 임시 주소를 넣었다면 권한이 있는 원본 파일을 저장해서 올리세요.

| 매체 | 기본 분석 지원 형식 | 결과에서 확인할 내용 |
| --- | --- | --- |
| 이미지 | PNG · JPG · JPEG · WebP | 영역별 팔레트와 밝기 |
| 음악 | MP3 · WAV · M4A, 최대 24초 분석 | 채널·구간별 음량·추정 박자 |
| 영상 | MP4 · MOV · WebM, 최대 20초·240프레임 분석 | 프레임 시각과 장면 전환 후보 |

지원 URL 도메인은 `interactive-examples.mdn.mozilla.net`, `mdn.github.io`, `tonejs.github.io`예요. 쿼리와 프래그먼트가 빠진 주소를 사용하세요.

### Gemini 의미 분석

| 매체 | 화면에서 할 일 | Gemini에 보내는 자료 | 결과 |
| --- | --- | --- | --- |
| 이미지 | 이미지의 URL 또는 파일을 선택하고 **Style DNA로 분석**을 누르세요. | 분석용 이미지 사본 | 인물·사물·행동·맥락·구도·조명의 추정과 한영 프롬프트 |
| 음악 | **음악 → 파일 업로드**에서 4 MiB 이하의 MP3·WAV·M4A를 고르세요. 전송에 동의하고 **음악 의미 분석 실행**을 누르세요. | 선택한 음악 원본 | 장르·악기·추정 템포·구간 구조와 복사할 수 있는 Suno 프롬프트 |
| 쇼츠 | **영상 → YouTube 쇼츠 분석**에서 공개 YouTube 쇼츠 또는 시청 주소를 입력하세요. 전송에 동의하고 **쇼츠 분석**을 누르세요. | 공개 YouTube 영상 주소 | 첫 장면·화면 구성·소리·시간대별 근거와 영상 프롬프트 |

추정과 미확인 표기를 확인하고 중요한 내용은 원본과 대조하세요. 음악에서 다른 분석이 진행 중이면 잠시 기다린 뒤 다시 실행하세요.

### 모델 설정을 확인하거나 다시 연결할 때

- **이미지** Style DNA에서 설정 안내가 표시되면 **API 연동 보기**를 누르세요. 기본 팔레트·밝기 결과와 이미 편집한 공개 초안을 계속 확인할 수 있어요.
- **음악** 파일 선택 뒤 모델 설정을 확인해요. 미설정 안내가 표시되면 **API 연동 보기**에서 음악 항목의 상태를 확인하세요. 조회 실패에 **설정 다시 확인**이 표시되면 해당 버튼으로 다시 시도하세요. 운영 담당자가 설정을 반영한 뒤 다른 매체를 선택했다가 음악으로 돌아와 파일을 다시 선택하세요.
- **쇼츠** 영상 탭을 열면 쇼츠 모델 설정을 먼저 확인해요. 설정 미완료 또는 조회 실패 안내에서 **API 연동 보기**로 이동할 수 있어요. **설정 다시 확인**에서 모델이 연결된 것으로 확인되면 YouTube 주소 입력을 이어가세요.
- **음악·쇼츠 설정 변경 이후** 실행 중 모델 설정이 해제되면 이전 전송 동의가 해제돼요. 설정을 복구한 뒤 전송 자료를 다시 확인하고 동의한 다음 실행하세요.

### 결과 공개

공개할 기본 분석 결과를 골라 **제목, 요약, 생성 프롬프트**를 편집하세요. 문구와 공개할 권리를 확인한 뒤 **공개 동의 → 공개하기**를 실행하세요. 공개 페이지에는 세 문구와 매체·공개 시각이 표시돼요. Gemini 의미 분석의 전송 동의와 공개 동의는 각각 해당 화면에서 받아요. 공개를 내리려면 **공개한 분석 결과**에서 **공개 철회**를 선택하세요.

## API 연동 화면

**API 연동 → API 응답 확인**을 누르면 기본 분석, 세 의미 분석과 공개 목록의 응답 상태를 확인할 수 있어요.

> 응답 확인은 GET·OPTIONS로 내부 API와 서버 설정 상태만 조회해요. 실제 모델 응답은 각 분석 화면에서 확인할 수 있어요.

| 표시 항목 | 상태를 확인하는 요청 | 확인된 상태의 문구 |
| --- | --- | --- |
| 미디어 분석 | `OPTIONS /api/admin/reference-analysis`의 Allow에 POST 포함 | POST 경로 확인 |
| Gemini · 이미지 Style DNA | `GET /api/admin/reference-analysis`, `semantic.image` | 서버 설정 확인 또는 Gemini 서버 설정 필요 |
| Gemini · 음악 의미 분석 | `GET /api/admin/music-semantic`, `semantic.music` | 서버 설정 확인 또는 Gemini 서버 설정 필요 |
| Gemini · YouTube Shorts 분석 | `GET /api/admin/shorts-analysis`, `semantic.shorts` | 서버 설정 확인 또는 Gemini 서버 설정 필요 |
| 분석 결과 공개 | `GET /api/admin/reference-publications`, `items` 배열 | 공개 목록 조회 확인 |

설정 값은 `configured`와 `not_configured` 두 값으로 판단한다. 401은 **다시 로그인해 주세요**, 403은 **관리자 권한이 필요해요**, 503은 **현재 서비스에 연결할 수 없어요**로 표시한다. 형식 오류는 응답 확인 안내, 네트워크 오류와 시간 초과는 연결 확인 안내를 보여준다. 클릭 전 상태는 **확인 전**으로 둔다. 각 상태를 서비스 이름과 함께 읽을 수 있도록 배치한다.

1440px에서는 이름·경로·설명 옆에 상태를 둔다. 390px에서는 상태를 각 항목 아래에 둬 긴 경로와 오류 문구가 줄바꿈된다. 키보드로 상태 확인을 시작하고 확인 뒤 버튼으로 다시 실행할 수 있다. 상태 갱신은 읽기 흐름을 방해하지 않도록 알린다.

## 통합 검수 조건

- 390px·1440px에서 음악 설정 있음과 쇼츠 설정 없음, 반대 상태를 합성 응답으로 각각 확인한다.
- 한 경로에서 인증 또는 연결 오류가 발생해도 나머지 경로의 상태가 각 응답대로 유지된다.
- 상태 확인을 여러 번 실행해도 요청은 GET·OPTIONS만 전송한다. 확인 동작 자체에 미디어, Gemini 호출, 공개 쓰기는 필요 없다.
- 사용 매뉴얼은 기본 분석과 의미 분석의 입력·전송·결과를 실제 화면 명칭으로 설명한다. 공개 승인과 Gemini 전송 동의를 각각 안내한다.

## 보호된 Preview에서 화면 확인

1. 전달받은 Preview의 커밋을 확인하고 승인된 계정으로 관리자 화면을 열어요.
2. 390px과 1440px에서 **콘텐츠 분석·공개 → 사용 매뉴얼 → API 연동 보기**를 확인해요. API 연동 제목이 고정 메뉴 아래에서 보이고, **분석기로 이동**을 누르면 분석기 제목으로 돌아와요.
3. **API 응답 확인**을 누르고 기본 분석, 이미지, 음악, 쇼츠, 공개 목록의 항목당 상태를 기록해요. 상태표의 행 제목과 문구를 운영 담당자에게 전달할 수 있어요.
4. 의미 분석 모델이 미설정이면 해당 화면에서 안내를 확인해요. 영상 탭의 쇼츠 설정은 탭을 연 뒤 조회하고, 음악 설정은 권한이 있는 시험 파일을 선택하면 조회해요. 읽기 검수는 이 상태를 확인하는 데서 끝나요.
