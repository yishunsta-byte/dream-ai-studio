# 관리자 콘텐츠 분석·공개 디자인 비교

2026년 11월 20일 사용자 요청에 따라 운영 관리자 화면의 콘텐츠 분석·공개 메뉴를 검토하고 반응형 HTML 시안 3개를 제작했다. [비교 HTML](index.html) · [로컬 비교 페이지](http://127.0.0.1:8798/)

| 시안 | 배치와 강조점 |
|---|---|
| 프리미어 콘솔 | 자홍·보라색 장면 이미지, 큰 배너와 분석 결과 미리보기, 입력과 관찰 근거를 나란히 배치 |
| 스펙트럼 랩 | 민트색 파형과 구간별 관찰 근거, 수치·프롬프트 검토에 집중 |
| 큐레이션 데스크 | 구릿빛 공개 준비 카드와 분석 입력을 한 화면에 배치, 제목·요약·프롬프트를 확인하고 공개 관리 |

- 사용자가 표시한 분석 권리 체크박스는 모든 시안에서 제외했다. **권리 확인하고 분석** 동작과 사용 권리 안내를 분석 입력에 붙였다. 향후 제품 적용 시 이 명시적 동작이 확인 값을 전달한다. 공개 동의는 별도 동작으로 유지했다.
- 지원하는 직접 HTTPS 파일 주소 입력, Threads 게시물 주소의 입력란 안내, 예시 결과·프롬프트 확인, 예시 공개와 철회를 시안 안에서 확인할 수 있다. 장면 이미지와 파형은 UI 샘플이며 실제 분석 응답으로 표시하지 않는다. 기존 `public/showcase/t240`의 이미지 세 장을 최적화해 사용했다.
- Chromium 390px에서 세 시안의 입력·안내·예시 분석·공개·철회를 확인하고, 시안 1200px 및 비교 페이지 390px·1440px에서 가로 넘침 0을 확인했다. 비교 페이지는 데스크톱에서 가로 3열, 모바일에서 세로 3개로 표시된다.
- 현재 운영 관리자로 접속해 MDN 공개 JPG 직접 주소로 실제 분석을 재확인했다. `POST /api/admin/reference-analysis`가 422를 반환하고 **분석하지 못했어요**가 표시됐다. 운영 변경과 운영 공개·철회는 수행하지 않았다.

**Master 전달문** · 조회한 운영 기능 기준으로 관리자 콘텐츠 분석 시안 3개를 완성했습니다. 분석 권리 체크박스는 시안에서 제거했고, 지원하지 않는 게시물 주소는 입력란에서 안내합니다. 시안 선택 후 제품 적용 범위를 정할 수 있습니다. 실제 운영 JPG 분석은 여전히 422로 실패합니다.
