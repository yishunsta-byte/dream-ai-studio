2026년 11월 20일 · `ba983c7` 결과 영역 기준 · 모든 내용 예시는 이 문서에서 만든 합성 입력과 응답이다. [기존 의미 분석 검수 기준](SEMANTIC-ANALYSIS-ACCEPTANCE.md)

## 결과 영역 배치

**1440px**에서는 현재의 왼쪽 미디어 소스, 오른쪽 결과 열을 사용한다. 결과 열의 제목 아래에 매체·결과 수와 **결과 선택**을 두고, 그 아래 한 줄에 **관찰 근거 · 의미 분석 · 생성 프롬프트** 보기 버튼을 놓는다. **관찰 근거**를 처음 연다. **의미 분석** 본문은 상태 안내 다음에 근거 표식을 붙인 항목을 세로로 나열한다. 기존 공개 준비와 공개 목록은 이 작업 영역 아래에 둔다.

```text
1440px
┌─ 미디어 소스 ─────────┐  ┌─ 분석 결과 ──────────────────────────┐
│ 현재 입력과 실행       │  │ 이미지 분석 · 결과 17개  [결과 선택] │
│ URL 주소 / 파일 업로드 │  │ [관찰 근거] [의미 분석] [생성 프롬프트] │
└───────────────────────┘  │ 상태 안내                            │
                           │ 항목 · 근거 표식 / 본문              │
                           └─────────────────────────────────────┘
```

**390px**에서는 미디어 소스 → 결과 → 공개 준비 → 공개 목록 순으로 한 열에 배치한다. 결과 제목과 결과 선택은 각 줄에 놓고, 그 아래 세 보기 버튼을 줄바꿈 가능한 버튼 그룹으로 둔다. 항목마다 **구분·항목명**과 **영역/시각**을 먼저 표시하고, 다음 줄에서 본문을 읽게 한다. 타임코드와 긴 문구는 브라우저를 확대해도 가로 스크롤 없이 줄바꿈한다.

```text
390px
미디어 소스 → 분석 결과
이미지 분석 · 결과 17개
[결과 선택]
[관찰 근거] [의미 분석] [생성 프롬프트]
상태 안내
관찰 · 인물             좌측 상단
한 사람이 화면 왼쪽에 보여요.
공개 준비 → 공개 목록
```

## 합성 예시로 확인할 표시

| 입력 예시 | 배치와 표시 내용 |
|---|---|
| **이미지** · 한 사람과 빨간 컵, 목재 테이블이 보이는 연출 사진 | **의미 분석**에서 `관찰 · 인물` 한 사람 `[왼쪽 영역]`, `관찰 · 사물` 빨간 컵 `[중앙 영역]`, `관찰 · 행동` 손이 컵 손잡이를 잡고 있음 `[중앙 영역]`, `추정 · 맥락` 식사 공간일 수 있음 `[컵과 테이블]`을 네 행에 둔다. 실제로 마시는지는 `미확인 · 행동`으로 표시한다. |
| **영상** · 컵을 테이블에 내려놓는 연출 클립 | `관찰 · 행동`에 `00:02.100 컵을 들고 있음 → 00:04.000 컵이 테이블 위에 놓임`을 두 근거 줄로 표시한다. 선택한 구간의 실제 근거만 펼치며, 재생으로 이동하는 조작은 연결 가능한 원본 시각이 있을 때 표시한다. |
| **음악** · 짧은 피아노 샘플 | **관찰 근거**의 `00:02.000–00:06.000 · 2채널 · 최대 정규화 RMS 37%` 한 행을 확인한다. 의미 응답이 없으면 **의미 분석**에서 지원 범위 안내를 표시한다. **생성 프롬프트**는 ‘건반을 누른 뒤 잔향이 서서히 줄어드는 짧은 연주’처럼 창작용 초안을 별도로 표시한다. |

| 상태 | 화면에서 달라지는 부분 |
|---|---|
| **로딩** | 의미 분석 보기의 첫 줄에 `의미 분석 중`을 표시한다. 기존 관찰 결과나 프롬프트가 먼저 도착하면 바로 볼 수 있다. 구분 행은 실제 응답이 도착할 때 붙인다. |
| **부분 분석** | 첫 줄에 `일부 항목만 확인했어요`를 표시한다. 도착한 항목을 보여주고 나머지는 `미확인` 또는 지원 범위 안내를 해당 위치에 둔다. |
| **모델 실패** | 의미 분석 보기에 `의미 분석을 완료하지 못했어요`를 표시한다. 현재 입력에서 얻은 규칙 관찰 결과와 기존 창작 초안을 각각 유지한다. 기능에서 재시도를 지원할 때는 이 영역에서 **의미 분석 다시 시도**를 제공한다. |

보기 전환과 결과 선택은 기존 버튼 그룹과 키보드 순서를 따른다. 상태 갱신은 상태 줄에서 한 번 알리고 사용자의 초점을 이동시키지 않는다. 입력을 바꾸면 이전 입력의 의미 분석을 지운다. 새 프롬프트 제안이 도착해도 기존 **생성 원문**과 **내 수정본**을 덮어쓰지 않는다. 공개 준비에는 담당자가 확인한 최종 문구를 사용한다.

모델 응답을 원본 근거로 확인하기 전에는 항목 바로 앞에 **추정** 또는 **미확인**을 표시한다. 완료 상태나 민트색 강조는 항목의 확인 여부를 대신하지 않는다.
