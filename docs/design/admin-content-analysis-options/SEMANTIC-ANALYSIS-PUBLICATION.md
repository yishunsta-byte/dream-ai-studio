# 스펙트럼 랩 의미 분석 공개 검수 화면 명세

2026년 11월 20일 · 운영 기준 `ba983c7` · 아래 이미지·영상 예시는 직접 작성한 합성 사례다. [의미 분석 결과 화면 명세](SEMANTIC-ANALYSIS-LAYOUT.md)

## 현재 동작과 제안 범위

| 영역 | 현재 동작 |
|---|---|
| 관리자 **공개 준비** | 공개할 결과를 선택하고 **제목**(80자), **요약**(600자), **생성 프롬프트**(2,000자)를 편집한다. 매체는 실제 분석 결과에서 온다. 결과 또는 공개 문구를 변경하면 공개 동의가 해제된다. |
| 공개 동의 | 기존 체크 항목은 **이 결과를 공개할 권리를 확인했고, 공개 결과 페이지에 표시하는 데 동의해요**다. 선택한 뒤 **공개하기**를 실행하면 현재 공개 입력을 검증하고 전송한다. 분석을 실행할 때의 권리 확인과 공개 동의는 각각의 작업에서 받는다. |
| 공개 웹 `/analysis-results` | 공개 상태인 항목에서 제목·요약·생성 프롬프트·매체·공개 시각을 보여준다. 문구는 평문으로 표시한다. 원본 주소, 원본 파일, 계정, 관리자 관찰 행, 측정값과 내부 오류는 공개 결과의 별도 필드로 제공하지 않는다. 관리자가 편집 가능한 공개 문구에 넣은 내용은 그 문구의 일부가 된다. |

## 공개 전 미리보기 배치

공개할 결과 선택 → 공개 입력 → **웹 공개 미리보기** → 기존 공개 동의 → **공개하기** 순서로 배치한다. **웹 공개 미리보기** 옆에 **관리자용 근거**를 둔다. 1440px에서는 두 영역을 나란히 두고, 390px에서는 웹 공개 미리보기 아래에 **관리자용 근거 보기**를 펼칠 수 있게 둔다. 영역명과 설명으로 표시 범위를 구분한다.

| 영역 | 미리보기에서 볼 내용 |
|---|---|
| **웹 공개 미리보기** | 현재 편집란의 제목·요약·생성 프롬프트와 매체를 공개 웹 카드의 읽기 순서대로 표시한다. 제출 시와 같이 앞뒤 공백을 제거한 평문으로 미리 본다. 공개 시각은 `공개 후 표시` 안내만 둔다. 공개할 요약에 해석이나 미확인 내용을 넣는다면 `추정`, `미확인`을 그 문장에 포함해 웹에서도 읽히게 한다. |
| **관리자용 근거** | 선택한 결과의 관찰·추정·미확인 표식, 영역·타임코드와 근거 설명을 보여준다. 공개 미리보기 옆에 **관리자 화면에서만 표시**를 붙인다. 근거 표식과 원본 정보에 공개용 자동 복사는 제공하지 않는다. |
| **공개 동의** | 웹 미리보기 아래에 기존 공개 동의를 둔다. 미리보기를 읽거나 관리자용 근거를 펼쳐도 동의 상태는 바뀌지 않는다. 공개 표시는 체크한 다음 **공개하기**를 실행하는 기존 흐름으로 이어진다. |

## 합성 사례

### 이미지 · 빨간 컵을 잡은 사람

| 관리자용 근거 | 웹 공개 미리보기 |
|---|---|
| **관찰** 왼쪽 영역에 사람, 중앙 영역에 빨간 컵과 손잡이를 잡은 손. **추정** 컵과 목재 테이블을 보면 식사 공간일 수 있음. **미확인** 실제로 마시는지 확인되지 않음. | **제목** 빨간 컵을 잡은 손<br>**요약** 관찰 · 사람이 빨간 컵의 손잡이를 잡고 있어요. 추정 · 식사 공간으로 보일 수 있어요. 미확인 · 실제로 마시는지는 확인되지 않았어요.<br>**생성 프롬프트** 목재 테이블 위 빨간 컵과 손을 가까이 담고 배경을 부드럽게 흐리게 연출한다.<br>**매체** 이미지 |

### 영상 · 컵을 테이블에 내려놓는 동작

| 관리자용 근거 | 웹 공개 미리보기 |
|---|---|
| **관찰** `00:02.100` 손에 컵이 있고 `00:04.000` 컵이 테이블 위에 놓여 있음. **추정** 테이블을 정리하는 동작일 수 있음. **미확인** 물건을 놓는 목적과 영상 속 음성. | **제목** 컵을 내려놓는 장면<br>**요약** 관찰 · 사람이 컵을 들다가 테이블에 놓아요. 동작의 목적은 미확인입니다.<br>**생성 프롬프트** 손과 컵을 따라가다 컵이 테이블에 닿는 순간에 컷을 전환한다.<br>**매체** 영상 |

웹 미리보기와 같은 제목·요약·생성 프롬프트가 공개 카드에 보이고, 관리자용 영역 좌표·타임코드와 원본 정보가 카드로 옮겨지지 않는지 확인한다. 관리자 화면의 추정과 미확인을 요약에 포함할 경우 해당 표현이 승인 전후 그대로 유지되는지 확인한다.
