# P2 V5 · 배경음악 겹침과 역할 전환

로컬 가상 프로젝트의 편집 페이지에서 30fps, 4초짜리 음성·음악 두 클립으로 시작했다. Chrome 157의 실제 선택기, 추가 버튼, 시작 시간 칸을 조작했다.

1. 첫 음성 클립을 음악으로 바꿔 두 곡이 같은 0~4초에 위치하게 하자 저장이 비활성화됐다. 두 번째 곡의 ‘확인할 것’ 표시를 선택하면 ‘배경 음악은 곡 사이 겹치기로만 겹칠 수 있어요.’가 나타났다.
2. 세 번째 음악을 추가하고 시작을 0으로 옮기자 ‘배경 음악이 세 곡 이상 겹쳐요.’가 나타났다. 시작을 4초로 옮기면 세 곡 경고는 사라지고 첫 두 곡의 경고와 저장 차단이 유지됐다.
3. 첫 클립의 역할을 목소리로 되돌렸다. 남은 음악 두 곡은 끝과 시작이 같은 프레임에서 맞닿았고, 겹침 경고가 해제되며 저장 버튼이 활성화됐다.
4. ‘목소리가 나올 때 이 음악을 낮춰요’가 켜져 있는 음악을 효과음으로 바꿨다. 해제 안내와 체크박스 제거를 확인했다. 다시 음악으로 바꿔도 체크박스는 꺼져 있었다.

실제 저장 전 초안 상태의 화면 검증이다. 소리 합성 결과는 별도 검증 대상이다. 원자료 tmp/p2-audio-range/overlap.json.

> 플래너 전달문 — 두 곡 및 세 곡 겹침의 오류 표시·저장 차단과 경계 복귀, 음악→효과음→음악 전환 시 음량 낮추기 해제를 실제 편집 화면에서 확인했습니다.
