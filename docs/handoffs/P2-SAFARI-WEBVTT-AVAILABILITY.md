# Safari 자막 재생 검수 가능 여부

팀 등록부와 기존 Orca 연결을 대조했다. orca host list에는 현재 Windows 호스트 한 대만 표시됐고, orca environment list에는 저장된 환경이 없었다. 이 Windows 호스트에서 Safari 실행 경로와 연결된 iPhone·iPad 장비도 확인되지 않았다. 이 결과는 팀 등록부와 현재 연결 범위에 해당한다.

실제 Safari에서 WebVTT 재생은 미확인으로 남는다. 검수 입력으로는 Firefox에서 사용한 제품 편집용 ZIP과 합성 MP4가 준비돼 있다. 해당 ZIP의 자막 두 개는 한글·겹침·역방향 탐색의 같은 기준으로 검수할 수 있다. [합성 파일의 해시와 검수 기준](P2-FIREFOX-WEBVTT.md)

> 플래너 전달문 — 등록된 호스트는 Windows 한 대이며 저장된 원격 환경과 연결된 iOS 장비가 확인되지 않았습니다. Safari 재생은 미확인입니다.
