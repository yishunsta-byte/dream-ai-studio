# 로컬 PG 기획 승인 독립 검수

MASTER 배정 `msg_ba9ba0cc0d2a`. 커밋 `0d4c792`의 격리 Git 사본에서 실제 Next.js HTTP·Chromium·임시 PG17로 검수했다. 실제 로컬 HTTP에서 생성한 프로젝트의 브리프를 승인하고 기획 초안을 저장했다. DB 시험용 자료 참조는 격리 사본의 별도 초안에만 설정했다.

| 시나리오 | 결과 |
|---|---|
| 명시적 화면 승인 | 확인 전 승인 버튼은 비활성이었다. Space로 확인을 선택한 뒤 대본을 수정하면 확인이 풀리고 비활성화됐다. 저장본의 원문으로 되돌려 재확인하고 Enter로 승인하면 `승인된 기획` 제목에 초점이 이동했다. |
| 승인 후 다시 열기 | 다시 연 화면에서 저장본의 대본과 두 장면 설명은 읽기 전용이었다. 제작 개방 문구가 유지됐고 프로젝트 상세는 장면 제작 `할 일`, 수정·조립 `잠김`을 표시했다. DB에 장면 2건과 승인 감사 1건, 프로젝트 승인 포인터가 있고 타임라인은 0건이었다. |
| 동시 승인과 원자성 | 최신 저장본에 요청 두 건을 보내면 200·409, 승인 감사 1건이었다. 감사 INSERT 실패를 주입하면 503이며 승인 포인터·기획/제작 단계·장면·감사 상태가 기준에 머물렀다. 실패 후 승인 가능 상태도 조회됐다. |
| 승인 거절 | 타인 404, 익명 401, 확인하지 않은 요청 400, 다른 출처 403. 구버전과 현재 버전에 맞지 않는 초안 ID는 409였다. |
| 자료 참조가 있는 기존 초안 | 소유 PNG 자산 ID가 연결된 초안을 GET과 화면에서 읽을 수 있었다. 화면에서 입력은 읽기 전용이고 저장·승인 조작은 없었다. 두 직접 요청도 409였다. DB의 자료 참조와 초안 행 1건이 유지됐고 장면·감사·타임라인은 0건, 제작·편집은 잠김이었다. |

기존 [HTTP 시험](../../tests/postgres/local-project-brief-http.mjs)에 검수 사본 전용 화면 대조를 연결했다. 전체 실행 종료 코드 0. 브라우저 공간과 PostgreSQL 프로세스·리스너·임시 클러스터 정리를 확인했다.
