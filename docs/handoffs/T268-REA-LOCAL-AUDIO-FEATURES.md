## 로컬 분석

`analyzeLocalReferenceAudio`는 검사에서 확인한 단일 음원 트랙의 스트림 인덱스로 같은 관리 사본을 디코딩합니다. FFmpeg가 관찰된 트랙 구간을 mono 8 kHz PCM으로 변환하고, 분석기가 프레임 순서·샘플 PTS 연속성·샘플 수를 확인합니다. 50ms 구간별 RMS를 관찰값으로 기록하고, RMS 0.01을 기준으로 이어지는 무음·신호 구간을 묶습니다. [오디오 분석 코드](../../lib/reference-analysis/audio-features.ts) · [로컬 파일 검사](../../lib/reference-analysis/local-file.ts)

BPM에는 RMS 상승 시점이 5개 이상 필요합니다. 상승 임계값은 0.02와 최고 RMS의 35% 중 큰 값입니다. 상승 간격의 중앙값이 300~1,000ms이며 각 간격의 편차가 50ms와 중앙값의 10% 중 큰 값 이내이면, `60000 / 중앙값(ms)`를 반올림해 BPM을 추정합니다. 추정에는 상승 시점·간격 중앙값·최대 편차가 포함됩니다. 편차 기준을 넘거나 상승 시점이 부족하면 BPM을 확인 불가로 반환합니다. 반복 신호가 실제 박자의 세분 단위를 나타낼 수 있으므로 복잡한 음악에서의 템포 정확도는 별도 검수가 필요합니다.

입력은 기존 64MiB 한도, 트랙은 24초, 표본은 192,000개, FFmpeg의 각 출력 스트림은 1MiB로 제한합니다. 기본 30초 제한은 검사와 디코딩에 함께 적용합니다. 취소·시간 초과 시 FFmpeg 자식 프로세스 종료를 기다려 사본을 삭제하고 오디오 관찰값 없이 종료합니다. 트랙이나 샘플 시각을 확인할 수 없는 경우에는 오디오 상태만 반환합니다.

## 검증

| 로컬 합성 표본 | 결과 |
| --- | --- |
| 3초 무음 M4A | 24,000개 표본, 무음 구간 1개, BPM 확인 불가 |
| 4초 규칙 펄스 M4A | 32,000개 표본, 상승 시점 0~3,500ms에 500ms 간격, 120 BPM 추정 |
| 불규칙 펄스 M4A | RMS 관찰값 기록, 간격 편차로 BPM 확인 불가 |
| 시작 시각 미확인 WAV 및 음원 트랙 2개인 M4A | 트랙 확인 불가 |
| 25초 음원 | 분석 한도 초과 |

기존 로컬 FFmpeg·ffprobe 9.0.2를 사용했습니다. 실제로 실행한 대체 자식 프로세스로 불연속 샘플 PTS, 취소 및 시간 초과 처리와 사본 삭제를 확인했습니다. [오디오 테스트](../../tests/reference-analysis/audio-features.test.ts)

REA의 계약·경계·로컬 파일·영상·오디오 Vitest 5개 파일에서 네이티브 포함 70/70 통과했습니다. 기본 설정에서는 36개 통과, 네이티브 테스트 34개 건너뛰었습니다. 변경 범위 TypeScript와 ESLint도 통과했습니다. 사용자 미디어, 외부 서비스, DB·스토리지 및 UI 통합은 검증 범위 밖입니다.
