## 0. 한눈에

- 미리보기는 **저장된 타임라인 + 지금 화면에서 고친 값**을 그대로 그린다. 아무것도 저장하지 않는다.
- 키는 **초점이 있는 곳 하나만** 처리한다(T-033 3.2.1). 문서 전체 단축키 없음 → 글자 칸에서 타이핑할 때 미리보기가 끼어들 수 없다.
- 시간은 `분:초.프레임`(프레임 두 자리, 30fps). 쉬운 말 버튼 이름은 "1/30초 뒤로/앞으로"(T-066 F-2와 같은 말).
- 비율 버튼은 **미리보기 전용**: 저장된 비율·위치·버전·편집 중 표시가 바뀌지 않는다(T-033 3.2.2).
- 파일·글꼴이 없거나 불러오지 못해도 **편집은 계속**된다. 미리보기 문제는 미리보기 안에서만 알린다.

## 1. 화면 구성 (1280)

```
[머리: 저장됨 · 타임라인 r4 · 14:20 | 버전 목록 | 영상 만들기]
[미리보기 비율 16:9 · 저장 안 됨] [원래 비율로(9:16)]      ← 원래 비율과 다를 때만
┌ 미리보기 (최대 폭 360px, 지금 비율) ┐   ┌ 글자 편집 ┐
│ [샘플] 배지(샘플 장면이 있을 때)     │   │ …         │
│  화면 + (켜면) 안전 영역 점선        │   └───────────┘
└──────────────────────────────────────┘
[▶ 재생] [◀ 1/30초] [1/30초 ▶]  00:08.10 / 00:25.00
[9:16][16:9][1:1]  [안전 영역 보기]
키 안내(작은 글씨, 시안 문구 그대로)
[타임라인 — 전체 폭]
```

## 2. 상태 전이

### 2.1 재생 상태 (하나만)

| 상태 | 들어가는 때 | 보이는 것 | 재생 버튼 이름 | 나가는 때 |
|---|---|---|---|---|
| **불러오는 중** | 화면 처음 열림, 비율 바꿈 직후 | 무대에 회색 칸 + 스피너 + "미리보기를 준비하고 있어요." 조작 버튼은 `disabled` + 이유 "준비가 끝나면 쓸 수 있어요." | 재생(비활성) | 준비 끝 → 멈춤 / 실패 → 오류 |
| **멈춤** | 준비 끝(0프레임), 멈춤 누름, 끝까지 재생 | 현재 프레임 정지 화면 | 재생 | 재생 누름 → 재생 중 |
| **재생 중** | 재생 누름 | 시간 흐름, 재생 위치선(타임라인) 이동 | 멈춤 | 멈춤 누름 / 마지막 프레임 도달 → 멈춤 / 오류 |
| **기다리는 중** | 재생 중 다음 장면 파일을 아직 못 읽음 | 무대 위 작은 스피너, 시간 멈춤. 글자는 그대로 | 멈춤 | 읽음 → 재생 중 / 멈춤 누름 → 멈춤 |
| **오류** | 미리보기 자체를 띄우지 못함 | 무대 자리에 `Callout(danger)` "미리보기를 띄우지 못했어요. 글자 편집과 저장은 그대로 할 수 있어요." + `Button` "미리보기 다시 불러오기" | — | 다시 불러오기 → 불러오는 중 |
| **비어 있음** | 타임라인에 장면이 하나도 없음 | `EmptyState` "보여 줄 장면이 없어요. 만들기 단계에서 장면을 추가해 주세요." + 만들기 링크 | — | 장면 생김(새로고침) |

- 끝: 마지막 프레임(`전체 프레임 − 1`)에서 멈춤. 그 상태에서 재생을 누르면 **0프레임부터** 다시.
- 재생 중 seek(키·버튼): 재생을 멈추지 않고 그 위치에서 이어 감. 멈춤 중 seek: 멈춘 채 위치만 바뀜.
- 화면 밖으로 탭 전환·창 숨김: 재생 중이면 멈춤으로(소리가 혼자 나지 않게). 돌아와도 자동 재생하지 않음.

### 2.2 겹치는 표시 (재생 상태와 따로 켜고 끔)

| 표시 | 켜는 때 | 보이는 것 | 저장에 영향 |
|---|---|---|---|
| 미리보기 비율 | 원래와 다른 비율 버튼 | 머리 칩 "미리보기 비율 16:9 · 저장 안 됨" + "원래 비율로(9:16)". 안전 영역 밖으로 나가는 글자는 화면에서만 안으로 옮기고 그 글자에 점선 칩 "미리보기 위치". 처음 한 번 Toast(info) "미리보기에서만 글자 위치를 옮겨 보여 줘요. 저장하지 않았어요." | **없음**(aspect·box·dirty·버전 번호·DB 그대로) |
| 안전 영역 보기 | 토글 | 옅은 빨강 + 점선 | 없음 |
| 고친 내용 반영 | 글자 칸에서 고침(저장 전) | 미리보기에 바로 반영. 무대 아래 작은 글씨 "저장하지 않은 고침도 미리보기에 보여요." (편집 중 표시가 있을 때만) | 없음 — 저장은 기존 저장 버튼·API(D-10)만 |
| 움직임 줄이기 | `prefers-reduced-motion: reduce` | 글자 움직임 대신 바로 나타남/사라짐. 키 안내 아래 "움직임 줄이기 설정이라 글자 움직임은 생략해 보여요. 영상 만들기 결과는 그대로예요." | 없음 |
| 샘플 | 샘플 장면 포함 | 무대 위 왼쪽 `SampleBadge` | 없음 |

### 2.3 구간별 빠진 것 (재생은 멈추지 않음)

| 경우 | 무대 그 구간 | 타임라인 그 클립 | 문구 |
|---|---|---|---|
| 빈 자리(결과 선택 안 함) | 회색 칸 + 가운데 글 | 회색 + "결과 선택 필요" 배지(P2-1과 같은 말) | "장면 {n} · 결과를 선택하지 않았어요." |
| 결과 파일 없음/못 읽음 | 회색 칸 + 가운데 글 | 빨간 테두리 | "장면 {n} 결과 파일을 찾을 수 없어요." (T-033 3.2.3) |
| 글꼴 없음(목록엔 있으나 파일 없음·라이선스 검사 탈락) | 글자를 **Pretendard로 대신** 그리고 그 글자에 점선 칩 "글꼴 없음 · 대신 보여요" | 그 글자 클립에 같은 칩 | 글자 편집 위 `Callout(warning)` "{글꼴} 파일을 찾지 못해 Pretendard로 대신 보여 줘요. 영상 만들기 전에 글꼴을 확인해 주세요." |

- 위 세 경우 모두 **미리보기 안 표시만** 한다. 영상 만들기(P2-4)에서 막을지·어떻게 막을지는 이 문서가 정하지 않는다(Q-2).
- 대신 그린 글꼴 때문에 줄 수·안전 영역 경고가 달라질 수 있으므로, 글꼴 없음 글자의 경고에는 "(대신 그린 글꼴 기준)"을 붙인다.

## 3. 시간 표시

| 규칙 | 값 |
|---|---|
| 모양 | `MM:SS.FF` (FF = 0~29, 두 자리). 1시간 이상이면 `H:MM:SS.FF` |
| 예 | 0프레임 `00:00.00`, 31프레임 `00:01.01`, 254프레임 `00:08.14`, 750프레임 `00:25.00` (T-033 3.4-2) |
| 오른쪽 전체 길이 | 타임라인 전체 프레임(빈 자리 포함) — 마지막으로 갈 수 있는 위치는 그보다 1프레임 앞(`00:24.29`) |
| 읽히는 방식 | 화면 숫자는 `aria-live="off"`. 따로 숨긴 알림 칸(`aria-live="polite"`)이 **멈춤 때**와 **키로 옮긴 뒤 0.3초 조용할 때만** "멈춤, 8초 10프레임" / "8초 14프레임"을 읽음(키 반복 중엔 읽지 않음) |

### 3.1 시간 칸 · P1 묶음 · 저장 후 변환 설명 (T-066 V-1·F-1 통합)

미리보기·시간 칸은 모두 **프레임 시간**을 쓴다. P1에서 옮긴 r1은 묶음(SRT)에만 P1 원래 시간이 남는다. 이 차이를 숨기지 않고 한 문장 체계로 말한다. **원래 P1 값 보존(r1 묶음 = P1 스냅샷)은 그대로 강제**한다 — 문구만 바꾼다.

| 자리 | 언제 | 문구(안) |
|---|---|---|
| 글자 시간 칸 아래(P2-3) | 지금 버전이 옮긴 r1이고 그 글자의 P1 시간이 프레임과 다를 때 | "묶음에는 P1 시간 **0.125초** 그대로 들어가요. 여기는 1/30초 단위로 **00:00.04**(0.133초)로 보여요." |
| 저장 버튼 근처(P2-3) | 지금 버전이 옮긴 r1이고 저장 가능한 고침이 있을 때 | "저장하면 모든 글자 시간이 1/30초 단위로 맞춰져요. 차이는 0.017초 이하예요." |
| SRT 미리보기 아래(지금 P1 안내 대체) | 옮긴 r1 | "지금 묶음은 P1에서 옮긴 시간 그대로예요. 한 번 저장하면 모든 시간이 1/30초 단위로 맞춰져요." |
| 머리 안내(지금 "1초 30프레임") | 항상 | "시간은 1/30초 단위로 저장해요. 음성에 자동으로 맞추지 않아요." |
| 미리보기 | 옮긴 r1 | 별도 문구 없음 — 미리보기는 늘 1/30초 단위로 그린다는 것을 머리 안내가 말함 |

- "프레임"이라는 말은 시간 형식 설명(`초.프레임`, 개발자 도구·키 안내)에서만 쓰고, 행동 안내 문장에서는 "1/30초"로 쓴다.
- 0.125 → 0.133처럼 **실제 숫자 예**는 그 글자의 값으로 채운다(고정 예문 금지).

## 4. 키보드

### 4.1 초점별 처리 (T-033 3.2.1 구체화)

| 초점 위치 | Space | ←/→ | Shift+←/→ | Home/End | 처리 뒤 |
|---|---|---|---|---|---|
| 미리보기 무대 | 재생·멈춤 | 1/30초 seek | 1초(30프레임) seek | 처음/마지막 프레임 | `preventDefault` + `stopPropagation`(페이지 스크롤 막음) |
| 재생·1/30초 버튼 | 버튼 기본 동작(누름) | 1/30초 seek | 1초 seek | 처음/끝 | 위와 같음 |
| 비율·안전 영역 버튼 | 버튼 기본 동작 | **처리 안 함**(Tab으로 이동) | 처리 안 함 | 처리 안 함 | 기본 동작 |
| 글자 칸(input·textarea·select·색·contenteditable) | 글자 입력 | 커서 이동 | 글자 선택 | 줄 처음/끝 | **미리보기 처리기 실행 안 함** |
| 타임라인 선택 클립 / 빈 곳 | T-033 3.2.1 그대로(P2-3 범위) | | | | |

- 처리기는 미리보기 무대·조작 줄 **요소에만** 단다. `document`·`window` 키 처리기 금지.
- seek 범위는 0 ~ 마지막 프레임으로 잘라 냄. 끝에서 →를 눌러도 소리·오류 없음.
- 키를 누르고 있으면(반복) 위치는 바로바로 바뀌되 화면 읽기 알림은 3장 규칙대로 한 번.
- 키 안내 문구는 시안 그대로: "키는 초점이 있는 곳 하나만 움직여요. 재생 화면: ←/→ 한 프레임 · Shift 1초 · Home/End 처음·끝 …"

### 4.2 Tab 순서 (1280)

1. 머리(저장 상태 → 버전 목록 → 영상 만들기)
2. (원래 비율과 다를 때만) "원래 비율로(9:16)"
3. 미리보기 무대 — 접근 이름 "미리보기 · 9:16 · 00:08.10" (`role="region"` + `aria-roledescription` 쓰지 않음, 이름만)
4. 재생/멈춤 → 1/30초 뒤로 → 1/30초 앞으로
5. 9:16 → 16:9 → 1:1 → 안전 영역 보기
6. 글자 편집 → 타임라인(P2-3)

시간·키 안내·칩은 초점을 받지 않는다. 비활성 버튼(불러오는 중)은 `disabledReason`으로 이유를 보이되 Tab 순서에는 남긴다(기존 `Button` 동작).

| Tab 순서 | 4.2에서 타임라인만 빠짐 |

## 6. 수용 기준 (구현 뒤 1280·390, production 빌드, 127.0.0.1)

1. 2.1의 여섯 상태가 각각 보이는 고정 시험 화면(불러오는 중은 지연 주입, 오류는 Player 실패 주입, 비어 있음은 장면 0개 가상 프로젝트). 오류·비어 있음에서도 글자 편집·저장 동작.
2. 무대·조작 버튼 초점에서 Space·←/→·Shift+←/→·Home/End가 4.1대로, 글자 칸 초점에서는 글자 편집만(미리보기 시간 불변 — 값 비교). 페이지가 스크롤되지 않음.
3. 시간 표시 0·31·254·750프레임 = `00:00.00`·`00:01.01`·`00:08.14`·`00:25.00`, 마지막 위치 `00:24.29`.
4. 비율 3종 전환 전후 저장된 `aspect`·모든 `box`·편집 중 표시·타임라인 버전 번호·DB 행 수 같음, "원래 비율로" 뒤 처음 화면과 같음(T-033 3.4-4).
5. 안전 영역 점선 위치가 spec `safeArea`와 ±1px(390·1280 각각 측정).
6. 빈 자리·파일 없음·글꼴 없음 구간에서 재생이 멈추지 않고 2.3 문구 표시.
7. 움직임 줄이기 켠 브라우저에서 글자 움직임 생략 + 안내 문구, 재생·seek 동작 같음.
8. 가로 넘침 0, Tab 순서 4.2(390은 5장), 모든 초점 링 보임(무대는 영상 위에서도), 화면 읽기 프로그램에서 재생 버튼 이름이 상태에 따라 바뀜·시간이 재생 중 읽히지 않음.
9. 옮긴 r1 프로젝트(s4·s5 사본)에서 3.1 문구가 그 글자의 실제 숫자로 나오고, 묶음 SRT는 P1 시간 그대로(T-061 시험과 같은 결과).

## 8. 하지 않은 것·한계
