## 1. 확인 방법

- **직접:** `git archive df094f9` → 대화용 임시 폴더(모듈 옮김, package·lock 같음 확인) → `next build` → 운영 모드 `127.0.0.1:3099`, 고정 가상 백업 s5 사본(OS 임시 폴더). ego lite, 1280×900·390×844(mobile), CDP 실제 마우스·키.
- **실제 충돌 만들기(두 창):** 창 1이 저장 → 서버는 실제로 저장(r n+1), 창 1은 **응답 전달만** 붙잡음(페이지 fetch 감싸기) → 그동안 창 1에서 더 고침 → 창 2가 r n+1을 열어 다른 글자를 고쳐 실제 저장(r n+2) → 창 1 응답 풀기 → refresh가 다른 창 버전을 가져와 상자가 나옴. 4번 반복(1280 ×3, 390 ×1).
- 복사 성공은 브라우저 클립보드 권한을 준 상태, 실패는 `navigator.clipboard.writeText`가 거절하도록 바꾼 상태. 파일 받기는 실제 브라우저 내려받기(ego `waitForEvent("download")`).
- 캡처·받은 파일: `tmp/t099-evidence/`(git 제외) — `t099-a-1280-box.png`, `t099-c-390-box.png`, `t099-d-390-copyfail.png`, `dream-timeline-recovery-r5-to-r7-20261116-2256.json`.
- **간접:** T-098 보고와 `tmp/t098-evidence/`(코딩 담당 실행 기록·캡처), 코드 읽기(`RecoveryBox`). 시험은 다시 돌리지 않음.

## 4. 결론·전달

- 충돌 상자는 외부 최신본을 그대로 보여 주고, 내 변경은 복구 자료에만 두며, 자동 합치기가 없다는 점을 화면 문구로 분명히 말함. 모양·위치·움직임·적다 만 시간·장면 순서·고른 글자가 목록과 자료에 모두 남음. 복사·받기·실패 칸·닫기 초점·새로고침 확인·390 배치가 실제로 동작. **디자인 기준 필수 수정 없음.**
- C-1~C-5는 코딩 담당에 직접 전달(Master 참조). C-1·C-2는 짧은 문구·초점 수정이라 다음 손댈 때 함께 처리를 권장.
- 서버 경합·API·JSON 원문 동일성은 독립 Codex 결과로 판단. 최종 PASS는 Master 통합 판단. 실제 휴대폰·화면 읽기 프로그램·터치는 미확인 그대로.
