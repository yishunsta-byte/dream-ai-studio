# 등록 PNG 초안 비교 시안 독립 검수

고정 `98ba64d753ddf2f77f4dd05aa0b75b1004c0384b`의 HTML blob `24e2c88ce521ecb0c069e4f1d9a087728905f088`과 동일 커밋의 글꼴을 루프백에서 제공했다. Chromium 390×844·1440×900에서 시험했다. `0abded0` 격리 제품은 **창작 초안**을 한 입력란에서 편집하고 복사한다. 생성 초안 유지와 수정본 분리 복사는 시안의 제안이다. 이번 검수는 시안의 상태·조작을 확인했다. [격리 제품 인계](REA-CLOUD-PROTECTED-PNG-BROWSER-PG17.md) · [디자인 인계](../design/rea-cloud-analysis/png-result/HANDOFF.md)

- 두 폭에서 시험 PNG 16×16, 전체 영역의 시작 `0%`·크기 `100%`, `#e02020` 색상 구간, 불투명도 면적 및 밝기 구간 비중과 **이 결과에 포함된 추정이 없어요**를 확인했다.
- 현재 편집란과 제안의 수정본에 서로 다른 문장을 넣었다. 생성 초안은 읽기 전용으로 유지됐고 **제작자가 공개한 프롬프트는 확인되지 않았어요**가 표시됐다. 공백만 있는 편집란은 해당 복사 버튼이 비활성화됐다.
- 두 폭에서 Tab과 Shift+Tab으로 편집·복사 조작에 접근했다. Enter로 **초안 복사**, **생성 초안 복사**, **수정본 복사**를 각각 실행했다. 실제 Ctrl+V의 브라우저 붙여넣기 이벤트와 입력란 값이 버튼별 대상과 모두 일치했다.
- `clipboard.writeText` 거절을 주입한 여섯 경우에도 해당 입력란에 가시 초점이 놓였고 전체 문구가 선택됐다. 안내에 따라 Ctrl+C로 직접 복사한 뒤 Ctrl+V로 같은 문구가 붙여졌다.
- 390px는 1열, 1440px는 2열이었다. 가로 넘침 0px, 복사 버튼 높이 44px였다. HTML과 글꼴을 각 두 번 받았고 API·운영 요청은 0건이다. 시안·제품·운영 변경은 없었다.
