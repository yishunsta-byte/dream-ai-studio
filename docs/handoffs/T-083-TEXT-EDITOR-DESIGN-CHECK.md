## 1. fonts.json `verified` 갱신 (커밋 `3036c14`)

- 바꾼 곳: `verified` 객체 **하나만**. 기존 키(`date`·`by`·`what` = Codex T-005 라이선스 원문 확인)는 그대로 두고 `install` 객체를 더했다.
- `install` 내용 = T-082에서 **실제로 확인한 범위만**: 7종(Pretendard 제외), google/fonts `cc39c4c`, git blob 동일(바이트 동일), TrueType 형식, usWeightClass·fvar 굵기가 weights 포함, fsType 0, OFL 전체 본문. `notVerified` = 브라우저·렌더 그리기와 줄 수 실측(T-081 뒤).
- 다른 필드가 바뀌지 않았음을 스크립트로 확인(`verified`를 비운 두 JSON이 같음). 코드는 fonts.json의 `fonts`만 읽고(`lib/edit/fonts.ts`) `verified`는 읽지 않음 — 동작 영향 없음.
- `specVersion`(2026-11-15.2)은 지시 범위("verified 메타데이터만")에 따라 올리지 않았다.
