# T291-R 작업실 등록 자료 분석 UI 독립 검수

**판정 — 격리 UI 계약 통과.** T284 서버 계약이 실제로 생성한 합성 PNG·MP4 결과를 사용했습니다. 제품 연결에는 취소와 응답 기한을 보장하는 공급자가 필요합니다. [T291 인계](T291-REA-STUDIO-REGISTERED-ANALYSIS-UI.md) · [T284 서버 계약](../../lib/reference-analysis/studio-analysis-contract.ts)

| 독립 브라우저 검증 | 결과 |
| --- | --- |
| 선택·키보드·초기 상태 | 미연결, 빈 목록, 미선택을 구분하고 실행을 막았습니다. 키보드 방향키로 자료를 선택하고 Space로 실행했습니다. 실행 중 같은 버튼을 호출해도 요청은 한 건이고 두 ID와 `AbortSignal`만 공급자에 전달됐습니다. 키보드 실행 후 취소로 포커스가 이동했고 정상 취소 뒤 다시 분석으로 돌아왔습니다. |
| 취소 지연 및 종료 | 취소 중에는 응답을 기다린다는 상태와 중복 실행 차단을 확인했습니다. 공급자가 `cancelled`를 반환하면 완료를 표시했습니다. 뒤늦은 성공과 예외는 모두 결과를 표시하지 않고 취소 완료를 확인할 수 없다는 안내로 끝났습니다. 일반 시간 초과는 별도 안내로 확인했습니다. |
| 선택·공급자 변경·해제 | 자료 또는 공급자를 바꾸거나 컴포넌트를 해제하면 진행 요청의 신호가 중단됐습니다. 이전 결과를 뒤늦게 완료해도 반영되지 않았고, 새 선택에 대한 결과만 표시됐습니다. |
| DTO와 편집 | MP4의 관측 시각 992ms, 장면 전환 추정의 근거 1·2, 편집 격자 약 30프레임을 별도로 표시했습니다. PNG에서도 관찰·추정 영역과 창작 초안을 구분했습니다. 개인 메타데이터와 내부 예외 문구는 노출되지 않았습니다. 초안을 고친 뒤 다른 결과를 보다가 돌아오면 편집 내용이 유지됐습니다. 복사 대상은 편집한 문구였고, 합성 클립보드 실패 시 전체 텍스트가 선택되고 직접 복사 안내가 표시됐습니다. |
| 390px·1280px | 각각 단일 열·두 열이었고 두 너비 모두 가로 넘침이 없었습니다. 측정한 버튼·선택·입력의 최소 높이는 44px였습니다. |

취소 뒤 공급자가 계속 미완료이면 같은 자료의 재실행도 계속 차단됩니다. 현재 UI는 응답 전 취소 완료를 표시하지 않으며, 자체 타이머는 없습니다. 새 자료로 바꾸면 이전 결과를 무효화하고, 서버 작업의 실제 종료와 파일 정리는 공급자가 담당합니다. 운영 연결 전 공급자의 최대 기한, 취소 뒤 정리, 여러 요청의 동시 실행 제한을 함께 검증해야 합니다. [요청 수명](../../components/reference-analysis/studio-registered-analysis.tsx#L169) · [T287-F1-R](T287-F1-R-REA-STUDIO-AUTH-DEADLINE-REVIEW.md)

고정 REA 네이티브 **19개 파일 219/219**, 집중 **2/2**, 관련 파일 타입 검사와 ESLint 경고 0 통과. 공유 작업공간 전체 타입 검사는 기존 `.next` 경로의 생성 Validator가 현재 라우트와 어긋나는 오류 4건으로 실패했습니다. 독립 브라우저는 임시 소스 사본과 헤드리스 Chromium을 사용했습니다. 실제 클립보드 권한·운영 공급자·기존 작업실 연결은 범위 밖입니다.

**Master 전달문** — T291-R 격리 UI 통과. 실제 합성 PNG·MP4, 키보드·390/1280, 응답 지연/실패·교체·해제, 편집/복사 실패를 확인했습니다. 같은 선택에서의 취소 대기는 공급자의 보장된 종료에 의존합니다. 네이티브 219/219 및 범위 타입·린트 통과입니다.
