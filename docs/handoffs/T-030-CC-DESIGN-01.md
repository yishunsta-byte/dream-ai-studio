## 1. 바뀐 내용

- **상단 상태:** "독립 검수 최종 통과" · 꼭 고칠 것 0건 · 접근성 확인 완료 · 독립 재검수 완료 · 은영님 흐름 확인 대기 · 디자인 시안 승인 대기(별도) · 둘 다 끝나야 P2.
- **숫자 구분:** 독립 R-017 전체 221개(건너뜀 0) / 독립 R-018 집중 렌더 2개 + lint·typecheck·build / Master 전체 223개(만든 쪽 확인, 독립과 별도). R-018이 전체를 다시 돌린 것처럼 쓰지 않았다.
- **캡처 출처 표시(새 칸):** 그림마다 A/B/C 딱지. 서로 다른 가상 프로젝트임을 문장으로 밝힘.
  - A = 첫 독립 검수(R-016) "독립검수 가상 민트컵", 장면 5개 — 고치기 전, 바뀌지 않은 1~7단계만 사용
  - B = 독립 재검수(R-017) "독립 검수 가상 민트컵 긴 제목 원본 보존 확인", 장면 5개 — 고친 뒤
  - C = 집중 재검수(R-018) "독립 집중 검수 가상 민트컵", 장면 2개 — 버전 비교 링크
- **새 구역:** "장면을 만들지 못했을 때"(기본 카드 + 버전 비교), "휴대폰 화면" 3장, "설정 · 백업 목록".
- **묶음 설명 정정:** 실제 `editing-{번호}_SAMPLE.zip`, README.txt · manifest.json · scenes · script · edit · subtitles(자막 있을 때만) · provenance · review · fonts · LICENSES, 파일 15개(자막 없으면 14개).
- **확인 방법(하단):** ① 흐름 이해 ② "보실 것" 기능 확인 ③ 번호·제목으로 고칠 곳 ④ 괜찮으면 `P1 확인했어`. 디자인 시안은 링크와 함께 "따로 확인, 따로 답". "이 페이지는 승인을 기록하지 않아요" 명시.
- **아직 확인하지 않은 것:** 실대용량·디스크 고갈·전원 차단, 모든 보조 기기·200% 확대, P2·P3 기능.
- 긴 전체 화면 캡처 4장은 높이 제한 상자 안 스크롤(`tabindex=0`, `role=region`, 접근 이름) + "그림만 크게 보기" 링크. `flow-08-v2.png`는 긴 화면 한 장 촬영 때 왼쪽 메뉴·머리줄이 중간에 겹쳐 찍힌 점을 캡션에 밝힘(제품 화면 문제 아님).

## 4. 한계

- 캡처는 검수자들이 찍은 것을 그대로 썼다. 새로 찍지 않았다. 세 환경의 가상 프로젝트가 달라 한 프로젝트의 연속 화면이 아니다(페이지에 명시).
- 1~7단계 그림은 고치기 전(A) 화면이다. 이 단계들은 이번 수정 대상이 아니지만 화면 세부(날짜 형식 등)는 지금과 조금 다를 수 있다.
- 390에서 긴 PC 캡처는 글자가 작다. "그림만 크게 보기" 링크로 보완했다.
- 페이지는 저장소의 `tmp/` 그림을 상대 경로로 읽으므로 이 PC에서만 그대로 열린다(`tmp/`는 git 제외). 외부 공유는 하지 않았다.
- T-026 m1~m4(비차단 권장)는 이 페이지에 넣지 않았다.
