## 기존 장비 재사용 결정 초안

1. **우선 후보는 이미 보유한 메인 PC와 맥미니, 별도 승인된 기존 원장 자원이다.** Master가 장비 소유자에게 두 시험 송신자의 실제 대상·점유 시간·시험 권한과 독립 원장·감독 환경을 확인한다. 이미 허용된 제한 사설망에서 직접 TLS, 시험 클라이언트, 원장과 감독 접근을 제공할 수 있는지, 추가 청구나 신규 계정·포트 공개가 없는지 함께 대조한다. 이 조합으로 충족되면 신규 구매나 요금제 변경 없이 별도 실행 배정을 할 수 있다.
2. **두 장비만 있거나 기존 연결의 권한이 부족하면 단계 2는 보류한다.** 같은 호스트의 여러 프로세스나 가상 환경은 코드 준비에 쓸 수 있지만 장비 장애·분할·독립 감독을 검증한 것으로 기록하지 않는다. 기존 승인 범위 안의 대체 장비 또는 독립 원장부터 확인한다. 추가 비용·자원·네트워크 또는 권한이 필요하면 Master가 범위·한도·정리 방안을 결정 초안으로 사용자에게 올린다. 기존 승인된 운영 변경으로 간주하지 않는다. [팀 운영 지침](../../AI_TEAM_RULES.md) · [T321 비용 가정](T321-REA-PROTECTED-EGRESS-STAGING-PLAN.md)
3. **장비 간 실행기는 별도 배정을 받는다.** 고정 T322 실행기는 Windows와 `127.0.0.1`에 제한된 시험이다. 현재 실행기의 주소만 바꿔 장비에 올리는 방식은 검증·배정된 경로가 아니다. 실행한다면 대상 OS와 승인 연결에서 별도 합성 실행기를 만들고 고정 SHA와 실행 파일 해시를 서로 대조한다. [고정 실행기](../../tests/reference-analysis/t322-egress-intent-revocation.pg17.mjs)
