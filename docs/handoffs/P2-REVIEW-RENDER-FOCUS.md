# 검수에서 렌더로 이동한 뒤 키보드 초점

검수 링크의 해시가 가리키는 MP4 카드나 영상 만들기 제목에 초점을 둔다. 제목은 일반 Tab 순서에 추가하지 않는다. 해시 없는 렌더 주소에서는 기존 진입 초점이 유지된다.

로컬 Chrome 390px·1280px에서 Tab으로 검수 링크를 선택하고 Enter를 눌렀다. MP4가 없는 경우 새 영상 만들기 제목에, 기존 렌더 동선으로 r45 MP4를 실제 생성한 뒤에는 해당 카드 제목에 초점이 도착했다. 네 번 모두 제목이 화면 안에 보였다. 해시 없는 주소를 직접 열면 초점이 BODY에 남고, 실제 카드 해시가 있는 주소를 새 문서에서 열면 해당 카드 제목에 초점이 잡혔다.

관련 테스트 16건, 전체 타입 검사, 변경 파일 ESLint가 통과했다. 앞서 88151d2 적용 후 공유 트리 전체 회귀에서는 2964건이 통과했고 개발 중인 별도 brief 라우트의 인증 목록 시험 1건이 실패했다. 조건부 시험 390건은 제외됐다.

> 플래너 전달문 — 검수에서 MP4 카드나 새 영상 만들기 제목으로 키보드 초점이 도착합니다. 390px·1280px에서 두 경로의 Tab·Enter를 4회 확인했습니다. 전체 타입 검사와 관련 시험 16건이 통과했습니다.
