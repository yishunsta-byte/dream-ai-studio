# T293 관리자 게시 PostgreSQL 격리 어댑터

기준 `c1bc55e` · Backend 자체 검증 · EnterpriseDB PostgreSQL 17.12 · 임시 루프백 클러스터

기존 T253 SQL의 SHA-256을 검사해 그대로 적용한 뒤, 별도 `t293` 시험 스키마를 설치했습니다. T290-F1의 현재 인증·게시 권한·작품 소유 범위 검사를 거쳐 앱 원장을 조회합니다. 후보 행을 잠근 다음 계정과 요청 UUID 단위로 잠금 순서를 고정합니다. 잠금이 풀린 뒤 원장 조회 앞에서 현재 게시자 권한을 다시 확인합니다. [시험 SQL](../../tests/public-showcase/t293-admin-publication.sql) · [격리 어댑터](../../tests/public-showcase/t293-admin-publication-adapter.ts) · [고정 T253](../../tests/fixtures/postgres/t253-showcase-publication.sql)

준비 시 서버가 검증한 최초 manifest를 소유자·slug·세대로 고정하고, 완료 시 저장된 manifest를 T253에 전달합니다. 앱 원장은 사용자 의도 지문과 결과, manifest 참조를 보관합니다. T253 명령과 원장, 앱 상태·원장·감사는 하나의 트랜잭션에서 커밋됩니다. SQL 결과가 앱의 판정과 어긋나면 모두 롤백합니다. 확정된 앱 충돌·증빙 실패는 앱 원장만 기록하고, 조회 장애나 커밋 결과가 확인되지 않으면 같은 UUID로 재시도합니다. 공개 승인 시각은 커밋 대상 T253 행과 일치시킵니다.

## 운영 적용 전 범위

계정과 파일·권리 증거는 합성입니다. 제한 로그인은 시험용 신뢰 서버 연결입니다. 앱 명령을 실행할 수 있는 이 자격을 브라우저나 운영자에게 직접 부여하면 앱 서비스의 증거 검증을 우회할 수 있으므로, 실제 연결에서는 신뢰 서버 자격과 운영자 세션을 분리하고 쓰기 경계를 검증해야 합니다. 기존 T253의 목록과 표지 조회에는 권리 만료 시각 조건이 없어 이 후보는 명시적 철회로 종료되는 합성 권리만 받습니다. 시한부 권리에는 실제 공개 조회에서 만료를 적용하는 계약이 필요합니다. 실제 Auth·권리 출처·비공개 Storage, 제품 화면 연결, 운영 SQL 및 배포는 후속입니다.
