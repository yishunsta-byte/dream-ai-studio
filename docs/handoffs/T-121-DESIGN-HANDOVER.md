### 1.3 다듬을 것 (C) — 제품 수정은 하지 않음

1. **취소 확인 패널 버튼 "취소 / 취소하기"가 나란히 보임.**
   - 처음 초점은 닫기 쪽 "취소"(안전), Esc로 닫으면 초점이 "취소" 버튼으로 돌아옴.
   - T-102는 닫기 글자를 "계속 만들기"로 정함. 공용 `ConfirmPanel`의 닫기 글자를 받게 하면 됨(이미 T-119 배정 예정).
2. **막힌 "영상 만들기" 버튼이 진짜 `disabled`라 Tab으로 갈 수 없고, 이유 글이 `aria-describedby`로 묶여 있지 않음.**
   - 화면 읽기 사용자는 Tab으로 다니면 이유를 못 들을 수 있음.
   - 공용 `Button disabledReason` 패턴 전체에 해당돼서 렌더 화면만 고칠 일은 아님. 공용 부품 결정이 필요함.
3. **"재생"은 영상 창만 열고 바로 재생하지 않음**(열린 뒤 0초에서 멈춤). 버튼 이름을 "영상 보기"로 바꾸거나 열 때 재생하는 것을 제안함.
4. **대기 중(시도 0번)인데 "시도 1/3"으로 보임.** "첫 시도 전"으로 하거나 대기 중에는 숨기는 것을 제안함.

### 1.4 한 번만 보인 의심 (확정 아님)
- 첫 렌더에서 끝날 때 초점이 진행 카드 제목에서 `body`로 빠짐.
- 이때는 카드가 이미 떠 있는 화면을 새로 열고, 스크립트로 제목에 초점을 줬음. 3단계도 화면에 잡히지 않았음.
- 2·3번째(요청 직후 초점, 취소 버튼 초점)는 새 결과 제목으로 잘 옮겨짐.
- **재현 조건 확인이 필요함**: 새로 연 화면, 카드 제목에 초점, 확인 단계가 짧을 때.

### 1.5 확인하지 못한 것 (남은 조건)
- 확인 실패 행, 취소 뒤 끝남 행, 그 밖의 실패 행(디스크 부족·도구 반복 중단·중단됨), 파일 없음 행, 처리기 꺼짐 이외의 대기 문구.
  - 가상 DB 행을 넣어 화면만 보는 방식이 필요함(T-117 9번과 같이 "화면 흐름 확인용"으로 표시).
- R-1 나머지: 저장 안 한 변경(편집 진입 버튼), 타임라인 없음·파일 없음·글꼴 없음, 검수 stale 안내.
- R-3, R-13(127.0.0.1 밖 요청 0건), R-14(디스크 부족), R-15(백업→복원), R-16(다른 작업 화면 대기 표시, 별도 보완 예정).
- 실제 휴대폰, 화면 읽기 프로그램, 200% 확대.
