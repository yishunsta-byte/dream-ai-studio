# T296 작업실 분석 제품 HTTP 진입점

2026-11-19 KST · Codex(design) · 기준 `1f7632a` · 배정 `msg_27527390f66e` · 범위 조정 `msg_e3ac20a37958`

`POST /api/studio/reference-analysis`를 Node.js Route Handler로 등록했습니다. 공용 API 암묵적 예외가 생기지 않도록 보호 경로 인벤토리에 추가했습니다. 핸들러가 기존 서버 인증으로 세션을 먼저 확인합니다. 인증 거절은 본문과 출처 검사 전에 기존 401·403·503과 `no-store`로 종료합니다. 로컬 인증 모드도 검증된 세션이 없어 401을 반환합니다.

인증을 통과한 요청에는 기존 Origin·Fetch Metadata·JSON 형식 규칙을 적용하고, 요청 호스트 및 스킴을 출처와 일치시킵니다. UTF-8 스트림을 최대 1,024바이트까지 읽습니다. `Content-Length`와 실제 읽은 바이트에 상한을 적용하고 엄격한 JSON 객체에서 프로젝트 ID와 자료 ID를 확인합니다. 정상 형식의 요청을 로그인한 계정이 보내도 제품용 등록 자료 공급자가 연결되기 전에는 503 `analysis_unavailable`이 반환됩니다.

| 경우 | 응답 |
| --- | --- |
| 인증 실패 | 기존 `AUTH_REQUIRED` 401, `AUTH_FORBIDDEN` 403, `AUTH_UNAVAILABLE` 503 |
| 출처 또는 미디어 유형 거절 | 403 또는 415 |
| 잘못된 JSON·초과 본문 | 각각 400·413의 `invalid_selection` |
| 올바른 JSON에 부적합한 ID 또는 추가 속성 | 200 `invalid_selection` |
| 공급자 미연결 | 503 `analysis_unavailable` |
| 연결된 분석 | 200 T284 v1 DTO. 호스트가 연결을 유지한 상태에서 요청 기한이 끝나면 200 `timed_out` |

## 공급자 연결 경계

`createStudioAnalysisPost`에 서버 등록 자료 확인 함수를 명시적으로 주입할 수 있습니다. 이 함수는 검증된 액터와 두 ID, 결합된 `AbortSignal`을 받습니다. 실제 분석은 T284가 수행합니다. T284는 원본 분석 전후에 현재 사용자와 등록 상태를 확인하고 서버 내부 경로와 권한 정보를 제외한 DTO만 반환합니다. 최초 검증된 인증 결과는 해당 요청의 첫 번째 T284 확인에서 재사용하며 분석 후에는 서버 인증을 다시 확인합니다.

3초 기한은 인증부터 본문 수신과 분석까지 적용합니다. HTTP 연결 종료 또는 기한 초과 시 공급자와 본문 읽기를 중단하고, 협조하지 않는 비동기 작업을 기다리느라 응답이 지연되지 않도록 합니다. 실제 공급자는 결합된 신호에 응답하고 임시 파일 및 실행 슬롯 정리를 보장해야 합니다. 생산 활성화 전에 T288의 실제 로그인 세션, 토큰 회전·갱신의 책임과 SDK 갱신 오류 기록, 현재 권한과 관리형 저장소 바인딩, 배포 호스트의 연결 종료 전달을 검증해야 합니다.

## 자체 검증

- 집중 시험 8개는 본문 읽기 전 인증 거절, 인증 후 Origin 확인, 1,024바이트 경계와 청크 스트림, 추가 속성 차단, 제품 공급자 미연결, 실제 T284 합성 PNG 분석과 권한 철회, 본문·공급자 중단을 확인했습니다.
- 격리 Next.js 16.4.6에서 제품 경로의 로그인 없는 401과 GET 405를 확인했습니다. 같은 헬퍼에 검증 세션을 주입한 별도 시험 경로에서 403·413·잘못된 선택 DTO, 연결 유지 중 서버 기한 응답, 실제 소켓 종료가 `AbortSignal`에 전달되는 것을 확인했습니다.
- 공용 인증과 분석 시험은 기준 커밋에 T296 파일만 올린 고정 사본에서 23개 파일 367개가 통과했습니다. 고정 사본에서 `next typegen`과 전체 `tsc --noEmit`, 변경 파일에서 ESLint 경고 0을 확인했습니다. 공유 트리에 함께 있는 T295 관리자 경로의 인벤토리 및 인증 처리에서 실패 5건이 확인됐으며 해당 경로는 T296 변경에 포함되지 않습니다.

제품 연결과 운영 배포는 이 작업 범위 밖입니다.

**Master 전달문** — 보호 인벤토리까지 반영해 작업실 분석 POST 진입점을 구현했습니다. 격리 Next에서 직접 HTTP와 중단 전달을 검증했습니다. 실제 권한 및 T288 세션 전제가 충족될 때까지 제품 분석 공급자는 연결하지 않았습니다.
