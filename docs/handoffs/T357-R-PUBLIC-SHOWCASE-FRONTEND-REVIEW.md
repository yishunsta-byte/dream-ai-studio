# T357-R 공개 홈 장애 안내 독립 검수

2026-11-19 KST · Codex(Tester) · 고정 커밋 `982b357` · Master 배정 `msg_ffadd8454b17`

**격리 검수 통과.** 변경 3경로는 공개 홈 컴포넌트, 집중 시험, 작성자 인계다. 소유 루프백 Next 개발 서버와 headless Chromium에서 390px을 독립 검증했다.

- 합성 조회·권한·계약·설정 장애 네 경우에 대표·목록·음악 영역이 모두 장애를 안내했다. 정상 빈 문구와 예시 표시가 없었고, 카드 0개·제목 한 개·기존 로그인 링크 3개였다. 정상 빈 목록과 명시적 예시 모드는 각각 예시 카드 6개를 유지했다. 이 여섯 상태에서 뷰포트와 문서 폭이 모두 390px이었다. 로딩과 직접 컴포넌트의 빈 배열 문구는 집중 시험에서 별도로 확인했다.
- 합성 승인 영상·음악과 음악 단독 목록에는 예시 표시가 없었다. 상세에 재생 요소가 0개였고 종류별 미연결 안내를 확인했다. 열린 상세의 닫기 버튼에 초점이 갔고 Esc로 닫자 열었던 카드로 돌아왔다. 공급원 계약 회귀에서 정상 빈 목록·승인·장애, 선택 한도와 표지 경로를 확인했다. 원본 승인 공급원과 철회 가드 경로는 고정 변경에 포함되지 않는다.
- 합성 시험은 목록만 제공했다. 승인 표지 요청은 표지 공급원이 비활성인 개발 사본에서 404였다. 승인 영역을 드러내는 인라인 가드의 `hidden` 속성 변경에 대해 React 개발 hydration 경고도 관측했다. 시험한 상세 열기와 초점 복귀는 모두 통과했다. 실제 표지 파일과 재생 연결은 범위 밖이다.
- 관련 회귀 15파일 349건, 소스 타입 검사, 변경 두 파일 ESLint 및 diff 공백 검사가 통과했다. 격리 검증기의 줄바꿈과 탐색 중 실행 컨텍스트 대기를 보정해 재실행했다. 제품 소스는 변경하지 않았다.

## DSP 결과 구분

작성자 전체 실행은 2,857건 통과·387건 건너뜀·DSP 1건 실패였다. 실패 사례는 기대 `STATS_MISMATCH` 대신 `TOOL_FAILED`를 반환했다. 작성자 단독 재실행은 세 번 모두 21/21이었다. 이번에는 승인 FFmpeg/ffprobe 복사본의 해시를 대조한 뒤 같은 DSP 파일을 다른 시험 종료 후 한 번 단독 실행해 21/21을 확인했다. 전체 스위트의 실패 원인과 전체 통과 여부는 이번 독립 검수에서 확인하지 않았다.

검수 서버·브라우저 및 사본을 정리했다. 운영 접속, 빌드, 배포 및 새 세션 생성은 없었다. 물리 모바일 기기와 실제 승인 데이터·미디어는 판정 범위 밖이다.
