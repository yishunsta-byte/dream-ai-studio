**판정 · 격리 T302 흐름 통과, HTTP 출력 경계 보완 후 재검수.** 동일 권한과 객체 GET 1회, 연결 중단 후 정리를 확인했습니다. 전체 분석 콜백이 반환한 계약 외 필드가 원시 HTTP 응답에 포함되는 경우를 재현했습니다.

## F305-1 · 전체 분석 콜백의 계약 외 필드가 HTTP에 포함됨

격리 요청의 전체 분석 콜백에 유효한 `source_unavailable` DTO와 합성 진단 필드를 함께 반환하도록 구성했습니다. [`studio-analysis-http.ts:104`](../../lib/reference-analysis/studio-analysis-http.ts#L104)의 분기가 결과를 그대로 직렬화해 200과 `no-store`를 주었고, 원시 JSON에 그 필드가 포함됐습니다. T292 공급자는 수신한 뒤 스키마 불일치로 `analysis_unavailable`을 반환했습니다. 실제 T302 콜백은 정상 자료에서 제한된 DTO만 반환했습니다. 운영 연결 전에 새 콜백 분기의 출력도 서버에서 엄격하게 검증하고, 계약에 맞지 않는 필드는 응답 전에 차단하는 검증이 필요합니다.

## 독립 검증

| 항목 | 결과 |
| --- | --- |
| 공통 연결과 구 resolver | 고정본 사본의 공통 연결 지점에만 합성 공급자를 주입했습니다. 목록만, 전체 분석만, 기존 resolver와 전체 분석을 모두 넣은 실제 Next에서 GET은 미연결, POST는 503, 목록·권한·객체 작업은 각각 0회였습니다. 기존 resolver만 선택한 구성은 실제 PNG DTO와 `no-store`로 응답했습니다. |
| 실제 SDK Auth·Storage와 A/B | 실제 격리 Next에서 합성 세션의 A/B/A GET–POST를 설치 SDK와 루프백 Auth/Storage로 실행했습니다. 계정마다 자기 자료만 목록에 나왔고 정상 POST마다 비공개 객체 GET 1회였습니다. 정상 응답은 `no-store`였고 객체 키·소유자·이메일·사본 경로·원본 SHA가 없었습니다. |
| 입력·출처·철회 | 미인증 GET은 로그인 이동이었고, 다른 출처는 403, 1,025바이트는 413, 추가 속성은 `invalid_selection`, A의 B 자료는 `source_unavailable`이었습니다. 이 거절들은 객체를 읽지 않았습니다. 다운로드 직후 등록을 철회하자 분석 결과와 다음 목록에서 자료가 사라졌고 사본이 비었습니다. |
| 실제 HTTP 취소·정리 | 다운로드 사본을 보유한 권한 보류 단계에서 클라이언트 연결을 닫으니 권한 연결과 사본이 정리됐고 같은 자료를 다시 분석했습니다. 추가 시험에서는 실제 MP4 FFmpeg 디코더가 실행된 뒤 HTTP를 취소했습니다. 자식 `close`와 다운로드·디코더 사본 부재를 확인한 뒤 정상 요청을 완료했습니다. FFmpeg 입력 속도 조절과 자식 관찰은 임시 검수 사본에만 사용했습니다. |

깨끗한 고정 사본에서 Next 타입 생성, 전체 `tsc --noEmit --incremental false`, 변경 파일 ESLint를 통과했습니다. 공용 인증·저장소·관리자·공개·네이티브 및 헤드리스 분석 회귀는 재실행 **42개 파일 656/656**이었습니다. 첫 실행의 기존 B14 영상 `ffprobe` 검증 시간 초과 1건은 재실행에서 재현되지 않았습니다. 소유 서버·임시 사본·시험 미디어를 정리했습니다. 운영 공통 연결은 미연결이며 실제 Auth·Storage·배포는 검수 범위 밖입니다.

**Master 전달 문구** · T305-R `ca8fc72`에서 실제 Next/SDK A/B, 단일 GET, 부분·이중 연결 닫힘, 구 resolver, 철회와 HTTP 취소 및 실제 FFmpeg 정리를 확인했습니다. F305-1은 전체 분석 콜백의 계약 외 진단 필드가 원시 200에 포함되는 서버 출력 경계입니다. 정상 T302 DTO는 깨끗했습니다. 재실행 656/656, 전체 타입·린트 통과입니다.
