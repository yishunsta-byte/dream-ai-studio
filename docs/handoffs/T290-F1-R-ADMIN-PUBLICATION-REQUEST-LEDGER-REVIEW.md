**판정 — 격리 서비스 범위 통과.** 확정 실패는 같은 UUID로 재전송해도 당시 결과를 반환하며, 일시 오류와 롤백 뒤에는 같은 UUID로 정상 진행할 수 있습니다. [수정 인계](T290-F1-ADMIN-PUBLICATION-REQUEST-LEDGER.md) · [원 검수](T290-R-ADMIN-PUBLICATION-SERVICE-REVIEW.md)

| 독립 검수 | 관찰 |
| --- | --- |
| 확정 실패의 저장과 재생 | 권리 소유 불일치 요청을 동시 두 번 보내 `source-unavailable` 원장 한 건을 확인했습니다. 권리를 복구해도 같은 UUID는 권리·표지를 다시 읽지 않고 동일 실패를 반환했습니다. 미래 버전의 `conflict`도 그 버전에 도달한 뒤 같은 UUID로 재생됐습니다. 같은 UUID에 다른 의도는 `invalid`였습니다. 실패는 작품·감사·공개 목록/표지에 변화를 주지 않았습니다. |
| 일시 장애와 롤백 | 인증 서비스 장애, 증빙 조회 예외, 표지 읽기 예외, 확정 실패 원장 기록 뒤 롤백 및 성공 저장 뒤 롤백은 `unavailable`과 전체 무변경을 유지했습니다. 복구 뒤 같은 UUID로 재시도할 수 있었습니다. 표지 부재를 확정한 `null`은 별도 원장 한 건으로 저장됐고, 이후 표지가 있어도 같은 UUID는 `source-unavailable`이었습니다. |
| 성공 커밋 뒤 응답 유실 | 게시 커밋 직후 응답 예외를 주입했습니다. 공개 표지는 200이었고, 같은 UUID 재전송은 원래 성공을 반환했습니다. 작업·감사·원장에 추가 쓰기는 없었습니다. |
| 인증·권한 회수 | 인증 누락, 게시자 권한 철회, 소유 범위 변경에서 기존 실패·성공 조회가 차단됐습니다. 독립 계측에서 원장 조회 호출 전 거절됐고, 관련 행과 감사 기록은 그대로였습니다. |
