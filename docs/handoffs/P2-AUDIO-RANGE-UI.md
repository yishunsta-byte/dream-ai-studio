# P2 V5 · 페이드 합과 원본 끝 경계

로컬 T173 가상 프로젝트 사본에서 Chrome 157 편집 화면의 4초 음성 클립을 선택했다. 30fps이므로 원본은 120프레임이다. 시간 입력란을 통해 값을 바꾸고 오류 문구 및 ‘장면·글자·소리 설정 저장’ 버튼을 함께 읽었다.

| 조건 | 허용 경계 | 한 프레임 초과 | 수정 후 |
|---|---|---|---|
| 페이드 합 | 처음 90 + 끝 30에서 저장 가능 | 끝을 31로 바꾸면 합이 121. ‘처음·끝 서서히의 합이 소리 길이보다 길어요.’ 표시 및 저장 비활성 | 끝을 30으로 되돌리자 경고 해제·저장 가능 |
| 원본 사용 구간 | 시작 30 + 길이 90에서 저장 가능 | 시작을 31로 바꾸면 원본 끝 121. ‘원본 파일 길이(00:04.00)를 넘어요.’ 표시 및 저장 비활성 | 시작을 30으로 되돌리자 경고 해제·저장 가능 |

화면 판정 6개 통과. 로컬 초안에만 입력했고 시험 중 저장하지 않았다. 작업본의 tmp/p2-audio-range/probe.mjs 및 results.json으로 확인했다.

> 플래너 전달문 — 오디오 편집기의 페이드 합과 원본 끝 경계를 실제 Chrome에서 확인했습니다. 두 경우 모두 정확한 끝은 허용, 한 프레임 초과는 차단, 값 복원 후 경고 해제와 저장 재활성화가 동작했습니다.
