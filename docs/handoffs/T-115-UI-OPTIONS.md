## 4. 추천: A · 할 일 먼저

1. 지금 셸·부품·경로·문구를 그대로 쓰고 **작업실 첫 화면과 프로젝트 머리(세로 단계)** 만 바꾸면 됨 → 렌더 백엔드(T-114)와 겹치지 않고 가장 빨리, 가장 적은 위험으로 연결.
2. DESIGN D1 "지금 손댈 것을 먼저"를 화면 첫 줄에서 그대로 보여 줌. 행마다 행동 하나라 다음 할 일이 분명.
3. B·C의 장점인 "늘 보이는 작업 상태"는 A의 위 띠에 작은 작업 줄(B의 `.jobs`)로 후속 추가 가능.
