# T360-R 공개 홈 표지 대체 표시 독립 검수

2026-11-19 KST · Codex(Tester) · 고정 커밋 `df05e0a` · Master 배정 `msg_38c1468e1c15`

**판정은 보완 필요.** 집중 회귀와 일반 표지·모바일·초점은 통과했다. 재생 파일이 있는 영상 상세에서 이미 실패한 표지를 재요청하고 대체 안내가 없는 사례를 소유 루프백에서 재현했다.

## 보완 항목

1. 합성 승인 영상에 재생 주소를 넣고 표지 주소는 404와 `no-store`를 반환하도록 했다.
2. 카드가 표지 실패로 전환되고 이미지가 제거된 상태에서 상세를 열었다. 그 시점의 표지 요청 카운트가 2에서 3으로 증가했다. 상세의 `video poster`가 같은 주소를 다시 요청했고 표지 실패 문구는 없었다.
3. 플레이어는 별도의 재생 시도 전까지 재생 오류를 표시하지 않았다. 재생 주소 자체의 요청이 실패하자 기존 재생 오류가 표시됐다.

`WorkMedia`의 영상 분기는 URL별 표지 상태를 받은 뒤에도 `poster`에 원래 표지 주소를 지정한다. 알려진 실패 주소를 상세에서 다시 요청하지 않고 표지 실패 표시와 재생 상태를 분리하는 보완이 필요하다. 현재 공개 DTO는 재생 주소를 공급하지 않으므로 합성 재생 주소 조건에서 확인한 결함이다. ## 통과 범위

- 합성 대표 표지는 지연 중 문구가 표시됐고 성공 뒤 이미지가 표시됐다. 성공 카드는 로딩 문구가 사라졌다. 카드 404와 잘못된 이미지 바이트는 모두 이미지가 제거되고 같은 실패 문구를 별도 설명으로 전달했다. 실패한 재생 미연결 카드의 상세에서는 표지 재요청이 없었다. 다음 문서에서 새 세대 주소가 정상으로 읽혔다.
- 음악 모음은 짧은 실패 문구를 표시했고 음악 상세는 대체 표지와 플레이어를 함께 표시했다. 재생 미연결 영상 상세에서는 표지 실패와 재생 미연결 안내가 따로 나왔다.
- 늦은 표지 실패는 열린 상세의 단일 상태 영역에 표시됐고 닫기 버튼의 초점은 유지됐다. Chromium의 Enter 입력에 표준 줄바꿈을 전달해 실패 카드의 실제 키보드 열기와 닫기 버튼의 초점을 확인했다. Esc는 상세를 닫고 해당 카드·음악 버튼에 초점을 돌려줬다. 320·390·1280px에서 가로 넘침이 없었고 측정한 카드 눌림 영역은 모두 최소 44px를 넘었다.
- 서버 HTML의 승인 영역은 `hidden`으로 시작했고 가드 설치 뒤만 표시됐다. 철회된 합성 목록의 새 문서에서는 해당 카드·상세가 없었다. 기존 가드가 `hidden`을 전환할 때 Next 개발 hydration 경고도 관측했다.
- 고정 파일은 컴포넌트·CSS·집중 시험 두 개·인계 5경로다. 공개 홈·공급원·표지·기존 가드 관련 회귀 352건, 소스 타입 검사, 변경 TypeScript ESLint와 diff 공백 검사가 통과했다.

고정 검수 사본에만 합성 공급원·표지 응답을 넣고 소유 Next 개발 서버와 headless Chromium을 사용했다. 브라우저 도구의 자원 대기와 Enter 입력을 보정해 재실행했다. 소유 프로세스와 사본을 정리했다. 운영 접속·배포·프로덕션 빌드·새 창이나 세션은 없었으며 실제 미디어와 스크린 리더 음성은 범위 밖이다.
