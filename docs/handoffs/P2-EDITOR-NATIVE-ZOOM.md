# P2 편집 화면의 브라우저 200% 확대 검증

Chrome 157.0.8103.50의 독립 프로필에서 브라우저 기본 배율을 1에서 2로 변경하고 설정값을 다시 읽었다. 외부 창 너비는 1280px로 같았고, 내부 너비는 1264에서 632 CSS px로 줄었다. DPR은 1에서 2로 변했다. 문서의 CSS zoom과 visualViewport.scale은 모두 1이었다.

T173 고정 앱 44b036a의 가상 프로젝트 사본에서 확대 후 문서 너비와 스크롤 너비가 모두 624 CSS px였다. 각 조작을 세로로 스크롤해 가운데 지점이 실제 대상 요소에 닿는지 검사하고 마우스 입력을 보냈다.

| 조작 | 검증 결과 |
|---|---|
| 제목 문구 수정·저장 | 입력란 너비 550.5px, 저장 버튼 높이 44px. 타임라인 POST 200과 새로고침 뒤 입력값 일치 |
| 원본 듣기·닫기 | 두 버튼 모두 높이 44px, 화면 너비 안에 표시. 재생 위치가 0.070599초까지 진행했고 닫은 뒤 오디오 요소 제거 확인 |

실행 당시 기준 efbd4d9와 대상 편집 패널, 글자 및 오디오 편집 컴포넌트의 Git 차이는 없다. 원자료와 재현 코드는 tmp/p2-native-zoom/first.json 및 probe.mjs에 있다. 모바일, 다른 브라우저, 사람의 음질 평가는 별도 항목이다.
