P1 · 은영님 확인용 자료 (준비본)

쇼핑숏츠 한 편을 처음부터 편집용 묶음까지 만드는 흐름

가상 상품 "가상 민트컵"으로 새 프로젝트를 만들고, 편집용 묶음(ZIP)을 내려받기까지 찍은 화면이에요. 모든 결과는 샘플이고 실제 AI는 쓰지 않았어요.

지금 상태 · 아직 확인을 부탁드리는 단계가 아니에요

독립 검수 불통과

미리 보시라고 준비해 둔 페이지예요. 아래가 모두 끝나면 이 페이지를 새 화면으로 바꾼 뒤 확인을 부탁드릴게요. 지금은 답하지 않으셔도 돼요.

  • 고치는 중장면 실패 안내 — 실패한 장면이 "결과를 기다리고 있어요."로만 보이고 이유가 안 나와요.
  • 고치는 중내보내기 정보 — 묶음을 만들기 전에 들어갈 폴더와 예상 크기가, 만든 뒤에 파일 이름과 크기가 안 보여요.
  • 확인 남음접근성 마무리 — 휴대폰 화면에서 검수표 직접 입력, 키보드만으로 처음부터 끝까지 진행하기.
  • 대기독립 재검수 — 만들지 않은 검수 담당이 위 내용을 다시 확인해요.
  • 대기은영님 확인 — 이 흐름 확인과 디자인 시안 승인. 두 가지가 끝나야 다음 단계(P2 영상 편집)를 시작해요.

전체 흐름 한눈에

  1. 등록
  2. 요구 확인
  3. 기획 승인
  4. 장면 제작
  5. 수정·조립
  6. 검수 승인
  7. 내보내기

단계는 순서대로만 열려요. 앞 단계를 끝내지 않으면 뒤 단계에는 자물쇠가 걸려 있어요. "승인" 표시가 붙은 기획과 검수는 은영님이 직접 눌러야 넘어가요.

화면 8장 · 무엇을 보시면 되는지

  1. 1 · 등록

    새 프로젝트에 필요한 칸을 채워요

    보실 것

    • 제목·목표·보는 사람·화면 비율(9:16)·길이(30초)를 적어요.
    • 광고·협찬을 체크하면 검수 항목이 늘어난다고 미리 알려 줘요.
    • 위쪽 안내: "확인한 내용만 등록해 주세요."
  2. 2 · 자료

    상품 사진을 올려 보관해요

    보실 것

    • 올린 사진에 "원본" 표시와 크기·해상도가 보여요.
    • 출처·권리 메모를 함께 적어 둘 수 있어요.
    • 원본은 바꾸지 않고 그대로 보관해요.
  3. 3 · 요구 확인

    등록한 내용이 맞는지 다시 봐요

    보실 것

    • 위쪽 7단계 진행 표시에서 지금 단계와 잠긴 단계가 구분돼요.
    • 잠긴 단계에는 "이전 단계를 완료하면 열려요."라고 이유가 붙어요.
  4. 4 · 기획

    대본과 장면표를 쓰고 승인해요

    보실 것

    • 고치면 덮어쓰지 않고 새 버전(v1, v2…)으로 저장돼요.
    • 이전 버전과 나란히 비교할 수 있어요.
    • 승인해야 장면을 만들 수 있어요.
  5. 5 · 장면 제작

    장면을 만들고 쓸 버전을 골라요

    보실 것

    • 샘플 결과에는 보라색 "샘플" 표시와 "0원(샘플)"이 붙어요.
    • 새로 만들면 이전 결과는 버전으로 남고, 고른 버전만 쓰여요.
    • "결과 없는 장면만 만들기"로 빠진 장면만 채울 수 있어요.
  6. 6 · 수정·조립

    글자를 얹고 미리 봐요

    보실 것

    • "광고" 표기 글자는 지울 수 없고 위치만 바꿀 수 있어요.
    • 점선 안쪽이 휴대폰에서 가려지지 않는 안전 영역이에요.
    • P1은 정지 화면 미리보기까지예요. 실제 영상 조립은 다음 단계(P2)예요.
  7. 7 · 검수

    항목마다 통과·보류를 정해요

    보실 것

    • 필수 항목이 몇 개 통과했는지 위에 보여요.
    • 자동 확인은 근거만 보여 주고, 통과는 사람이 직접 눌러요.
    • 장면·글자·순서를 바꾸면 검수를 다시 해야 해요.
  8. 수정 후 새 화면으로 바꿀 예정
    8 · 내보내기

    편집용 묶음(ZIP)을 내려받아요

    보실 것

    • "편집용 묶음"이라고 불러요. 완성 영상은 들어 있지 않아요.
    • 묶음을 만든 뒤 모든 파일을 다시 검사해야 내려받기가 열려요.
    지금 화면에서 고치는 중만들기 전: 들어갈 폴더 목록과 예상 크기를 보여 줘요.만든 뒤: 실제 파일 이름·크기·시각을 보여 주고, 긴 확인 번호는 앞 8자리 + "전체 복사"로 줄여요.

샘플과 편집용 묶음이 무엇인가요

샘플 샘플

  • 지금은 실제 AI를 연결하지 않아서 결과 자리에 "샘플 · SAMPLE" 그림이 들어가요. 비용은 0원이에요.
  • 샘플 결과에는 늘 보라색 "샘플" 표시가 붙고, 묶음 안 파일 이름에도 _SAMPLE이 붙어요. 실제 결과로 착각하지 않게 하려는 거예요.
  • 실제 AI 연결은 P3에서, 은영님이 예산과 계정을 정하신 뒤에 해요.

휴대폰 화면과 실패 화면

실패 화면에서 고치는 중실패한 이유와 다음에 할 일을 한 문장씩 보여 줘요. 예: "결과 파일을 저장하지 못했어요. 선택한 v1은 그대로예요." + "저장 다시 시도" 버튼.내용 때문에 거절된 경우는 다시 시도 버튼 대신 "기획 고치기"로 안내해요. 이미 고른 성공 버전은 그대로 남아요.

나중에 확인하실 때

수정과 독립 재검수가 끝나면 이 페이지의 실패·내보내기 화면을 새로 찍은 화면으로 바꾸고, 위의 상태 칸을 갱신해 다시 알려 드려요.

그때 괜찮으시면 P1 확인했어, 고칠 곳이 있으면 화면 번호와 함께 적어 주시면 돼요. 예: 5번 샘플 표시가 작아
