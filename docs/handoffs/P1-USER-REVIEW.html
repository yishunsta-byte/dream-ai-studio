P1 · 은영님 확인용 자료

쇼핑숏츠 한 편을 처음부터 편집용 묶음까지 만드는 흐름

가상 상품 "가상 민트컵"으로 새 프로젝트를 만들고 편집용 묶음(ZIP)을 내려받기까지의 화면이에요. 모든 결과는 샘플이고 실제 AI는 쓰지 않았어요.

지금 상태 · P1 확인 완료

독립 검수 최종 통과
  • 완료꼭 고칠 것 0건 — 장면 실패 안내, 내보내기 파일 정보, 버전 비교 안의 실패 링크까지 모두 고쳤어요.
  • 완료접근성 확인 — 휴대폰 화면에서 검수표 직접 입력, 키보드만으로 등록부터 ZIP 내려받기까지 이어서 진행.
  • 완료독립 재검수 — 만들지 않은 검수 담당이 따로 확인하고 최종 통과로 판정했어요.
  • 완료은영님 흐름 확인 — 2026-11-16 대화창에서 직접 답하셨어요.
  • 완료디자인 시안 승인 — 2026-11-16 흐름 확인과 함께 승인하셨어요. 다음 단계(P2 영상 편집)는 이전 백업 호환 준비부터 시작해요. P2 기능은 아직 만들지 않았어요.

그림을 찍은 곳이 세 군데예요

수정 전후를 따로 확인하느라 검수 때마다 새 가상 프로젝트를 만들어 찍었어요. 그래서 그림마다 프로젝트 제목·장면 수·내용 버전이 달라요. 같은 프로젝트 하나를 이어 찍은 것이 아니에요.

  • A첫 독립 검수 · "독립검수 가상 민트컵", 장면 5개 · 고치기 전 화면(바뀌지 않은 단계만 씀)
  • B독립 재검수 · "독립 검수 가상 민트컵 긴 제목 원본 보존 확인", 장면 5개 · 고친 뒤 화면
  • C마지막 집중 재검수 · "독립 집중 검수 가상 민트컵", 장면 2개 · 버전 비교 안의 실패 링크

전체 흐름 한눈에

  1. 등록
  2. 요구 확인
  3. 기획 승인
  4. 장면 제작
  5. 수정·조립
  6. 검수 승인
  7. 내보내기

단계는 순서대로만 열려요. 앞 단계를 끝내지 않으면 뒤 단계에는 자물쇠가 걸려 있어요. "승인" 표시가 붙은 기획과 검수는 은영님이 직접 눌러야 넘어가요.

단계별 화면 · 무엇을 보시면 되는지

  1. 1 · 등록

    새 프로젝트에 필요한 칸을 채워요

    보실 것

    • 제목·목표·보는 사람·화면 비율(9:16)·길이(30초)를 적어요.
    • 광고·협찬을 체크하면 검수 항목이 늘어난다고 미리 알려 줘요.
    • 위쪽 안내: "확인한 내용만 등록해 주세요."
  2. 2 · 자료

    상품 사진을 올려 보관해요

    보실 것

    • 올린 사진에 "원본" 표시와 크기·해상도가 보여요.
    • 출처·권리 메모를 함께 적어 둘 수 있어요.
    • 원본은 바꾸지 않고 그대로 보관해요.
  3. 3 · 요구 확인

    등록한 내용이 맞는지 다시 봐요

    보실 것

    • 위쪽 7단계 진행 표시에서 지금 단계와 잠긴 단계가 구분돼요.
    • 잠긴 단계에는 "이전 단계를 완료하면 열려요."라고 이유가 붙어요.
  4. 4 · 기획

    대본과 장면표를 쓰고 승인해요

    보실 것

    • 고치면 덮어쓰지 않고 새 버전(v1, v2…)으로 저장돼요.
    • 이전 버전과 나란히 비교할 수 있어요.
    • 승인해야 장면을 만들 수 있어요.
  5. 5 · 장면 제작

    장면을 만들고 쓸 버전을 골라요

    보실 것

    • 샘플 결과에는 보라색 "샘플" 표시와 "0원(샘플)"이 붙어요.
    • 새로 만들면 이전 결과는 버전으로 남고, 고른 버전만 쓰여요.
    • 만들지 못한 장면은 아래 "실패했을 때" 화면처럼 보여요.
  6. 6 · 수정·조립

    글자를 얹고 미리 봐요

    보실 것

    • "광고" 표기 글자는 지울 수 없고 위치만 바꿀 수 있어요.
    • 점선 안쪽이 휴대폰에서 가려지지 않는 안전 영역이에요.
    • P1은 정지 화면 미리보기까지예요. 실제 영상 조립은 다음 단계(P2)예요.
  7. 7 · 검수

    항목마다 통과·보류를 정해요

    보실 것

    • 필수 항목이 몇 개 통과했는지 위에 보여요.
    • 자동 확인은 근거만 보여 주고, 통과는 사람이 직접 눌러요.
    • 보류하려면 이유를 적어야 하고, 장면·글자·순서를 바꾸면 검수를 다시 해요.
  8. 8 · 내보내기

    편집용 묶음(ZIP)을 내려받아요

    보실 것

    • 만들기 전: "묶음에 들어갈 것"에 폴더 목록과 "예상 약 2.4MB · 파일 15개"가 보여요. "파일 이름 모두 보기"로 하나하나 볼 수 있어요.
    • 만든 뒤: 파일 이름, 실제 크기(바이트까지), 만든 시각, 확인 번호 앞 8자리와 "전체 복사"가 보여요.
    • 실패한 묶음은 빨간 상자로 이유와 "현재 내용으로 새로 만들기"를 보여 주고 내려받기 버튼이 없어요.
    • 기획을 고친 뒤의 예전 묶음에는 "지금 내용과 다름"이 붙어요.

장면을 만들지 못했을 때

실패는 실패로 보여요. 이유와 다음에 할 일을 알려 주고, 이미 골라 둔 결과는 그대로 남아요.

장면 카드에 바로 보여요

보실 것

  • 제목 옆 빨간 "실패" 표시와 "선택한 v1은 그대로예요."
  • 굵은 첫 문장으로 이유, 그다음 할 일, 맨 아래 작은 글씨로 코드.
  • 내용 때문에 거절된 경우 "다시 시도" 대신 기획 고치기 · 자료 바꾸기로 안내해요(같은 내용으로 다시 해도 또 거절되니까요).

버전 비교 안에서도 같아요

보실 것

  • "버전 비교·선택"을 펼치면 v3(성공) · v2(실패) · v1(선택됨)이 나란히 보여요.
  • 실패한 v2에도 이유와 기획 고치기·자료 바꾸기 링크가 있어요. 마지막 재검수에서 키보드로 두 링크를 직접 눌러 확인했어요.
  • 실패한 버전에는 "이 버전으로 되돌리기"가 없어요.

휴대폰 화면

설정 · 백업 목록

백업마다 어디서 왔는지 보여요

보실 것

  • "이 환경에서 만든 백업"과 "이전 환경 백업"이 구분돼요.
  • 복원 때문에 멈춘 백업은 회색 "복원으로 멈춤"으로, 실패나 취소로 보이지 않아요.
  • 파일이 없는 백업은 "이 PC에 파일 없음"으로 표시하고 복원에 고를 수 없어요.
  • 복원은 지금 데이터를 건드리지 않고 비어 있는 새 폴더로만 해요.

샘플과 편집용 묶음이 무엇인가요

샘플 샘플

  • 지금은 실제 AI를 연결하지 않아서 결과 자리에 "샘플 · SAMPLE" 그림이 들어가요. 비용은 0원이에요.
  • 샘플 결과에는 늘 보라색 "샘플" 표시가 붙고, 묶음 이름과 안의 장면 파일 이름에도 _SAMPLE이 붙어요. 실제 결과로 착각하지 않게 하려는 거예요.
  • 실제 AI 연결은 P3에서, 은영님이 예산과 계정을 정하신 뒤에 해요.

편집용 묶음(ZIP) 안에 들어가는 것

캡컷 같은 편집 프로그램에서 이어 작업할 재료 묶음이에요. 완성 영상은 들어 있지 않아요. 한 번 만든 묶음은 나중에 기획을 고쳐도 바뀌지 않아요.

확인 방법 (지난 안내)

2026-11-16에 흐름 확인과 디자인 시안 승인을 모두 마치셨어요. 다시 답하실 필요는 없어요. 아래는 확인 전에 드린 안내를 기록으로 남긴 거예요.

  1. 흐름 이해하기 — 위 "전체 흐름"과 단계별 화면을 위에서부터 훑어보세요. 단계 순서와 승인하는 곳이 은영님이 생각하신 작업 순서와 맞는지 봐 주세요.
  2. 기능 확인하기 — 각 화면 옆 "보실 것"이 그림에서 보이는지 확인해 주세요. 특히 실패 안내, 내보내기 파일 정보, "샘플" 표시가 헷갈리지 않는지요.
  3. 고칠 곳 알려 주기 — 단계 번호나 제목과 함께 적어 주세요. 예: 5번 샘플 표시가 작아, 내보내기 파일 이름이 너무 길어
  4. 괜찮으면 — Claude 대화창에 답하는 방식이었어요(완료).

디자인 시안은 앞으로 만들 화면 전체의 모양이에요. 흐름 확인과 함께 승인하셨어요(완료): 디자인 시안 열기

승인의 근거는 이 페이지가 아니라 은영님이 대화창에 직접 남기신 답이에요(2026-11-16, 흐름 확인·시안 승인 모두 완료). 이 페이지는 그 상태를 옮겨 적은 것뿐이에요.

아직 확인하지 않은 것

  • 아주 큰 파일, 디스크가 꽉 찬 상황, 전원이 갑자기 꺼지는 상황은 실제로 시험하지 않았어요.
  • 화면 읽기 프로그램 같은 모든 보조 기기와 화면 200% 확대는 전부 확인하지 않았어요.
  • 실제 AI 결과(P3), 영상 조립(P2)은 아직 없어요.
