- **장면 제작으로 이동** 링크를 선택하면 승인된 기획 버전과 장면의 제목, 설명, 길이, 결과 선택 상태가 저장된 기획 순서대로 표시된다. 결과가 선택됐는지와 다시 확인해야 하는지를 DB에서 읽어 표시한다.

- 기존 제작 API의 조회 메서드, 로컬 PG 조회 권한, 제작 화면과 진입 링크를 추가했다. 장면 읽기는 로컬 PG 읽기 전용 트랜잭션을 사용한다.
