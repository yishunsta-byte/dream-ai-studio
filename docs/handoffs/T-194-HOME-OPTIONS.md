**추천은 A / 01 오픈 데스크.** 주요 가치·지금 가능한 샘플 작업·이어 할 프로젝트가 균형 있게 보이고, 첫 사용/온라인 준비 상태의 안내도 자연스럽다. 반복 제작 우선이면 B, 브랜드·작업 기록의 분위기 우선이면 C를 비교할 수 있다. 최종 선택을 받은 것으로 추정하지 않는다.

이 결과는 기존 T183의 전체 작업실·관리·로그인5화면 탐색과 구분되는 **메인 홈 전용 새 정보 구조**다. T183 HTML/CSS/JS를 복사하지 않았다. 밝음/제작 도구/편집 지면의 방향성은 기존 논의와 일관되게 유지하되 새 홈 템플릿·상태·CSS 제품 일러스트를 작성했다. **재사용은 T183의 로컬 Pretendard 글꼴·OFL·출처 기록3개 자산뿐**이다. 폴더·비교 페이지·보고서에 이를 명시했다. 기존 시안/확정안은 수정하지 않았다.

## 기능·준비 범위를 표현한 방식

- 서비스의 주요 가치는 기획→장면→편집→검수, 원본 보관, 작업 이어가기로 설명한다. 실제 AI 전체 자동 제작이 연결됐다고 표시하지 않는다.
- 현재 시작 가능한 **쇼핑숏츠 샘플 흐름**과 준비 중인 플레이리스트/여행 쇼핑숏츠를 구분한다. 클라우드/로그인 전에는 PC의 샘플 이용과 온라인 저장·제작 준비를 분리한다.
- 모든 프로젝트·작업·처리기 상태는 예시이며 상단/본문/안내 창에서 알린다. 새 프로젝트 이름을 입력해도 **저장하지 않았다는 안내와 예시 다음 단계**만 보여 준다. 가짜 생성 성공·다운로드·완료율·예정시간은 만들지 않는다.
- 이어가기는 실제 편집 화면이 연결되지 않은 미리보기, 개인 관리는 점검·처리기·백업 의미 안내다. 처리기 응답이 작업 성공/종료를 뜻하지 않고, 백업 이력과 현재 파일 존재가 별개임을 구분한다.
- 계정 안내는 실제 이메일·비밀번호 입력이나 메일 요청을 요구하지 않는다. 로그인 전/로그인 뒤 온라인 준비 예시에서도 유용한 기능 설명을 제공한다.

## 상태와 반응형

공통7상태: `normal` 일상 작업, `loading` 읽는 중, `empty` 프로젝트 없음, `error` 목록 오류, `offline` 처리기 응답 없음, `guest` 로그인 전, `cloud` 온라인 준비 중.

- 읽는 중: aria-busy·자리 표시, 가짜0개/통과/완성 상태 없음. 막힌 시작 버튼과 이유를 연결.
- 빈 목록: 첫 샘플 프로젝트 시작 안내. 목록 읽기 오류와 구분.
- 오류: 자료 소실로 단정하지 않고 재확인 행동을 제공. 재시도는 실제 요청이 없는 화면 전환임을 안내.
- 처리기 응답 없음: 기존 작업을 살펴볼 수 있으나 새 제작은 대기할 수 있음을 안내. 종료/실패로 단정하지 않음.
- 로그인 전·온라인 준비: 실제 계정/클라우드 저장 가능으로 꾸미지 않고 안내·기능 둘러보기만 제공.
- 390px: 모든 주요 구역이 단일 열로 읽힌다. 프로젝트의 작은 이미지와 문구는 같은 한 항목 안에 두며, 전체 화면의 다단 구성·가로 carousel은 없다. 조작 최소44px, 주 버튼48px, 상태 전환 시 select 초점 유지.
- 모달: Enter 열기, Tab/Shift+Tab 순환, Esc 닫기·열었던 버튼으로 복귀. 프로젝트 anchor는 실제 제목 영역으로 이동하고 초점을 받을 수 있다.
