# 저장 직후 선택한 자막의 변경 확인

저장 요청 당시 선택한 레이어의 이전 문구와 해당 요청으로 생성한 리비전의 실제 문구를 표시한다. 새 편집기가 표시하는 프로젝트·내용 리비전·타임라인 ID·타임라인 번호가 응답과 일치할 때 해당 자막에서 결과를 볼 수 있다. 다른 자막 선택, 실패, 재시도 대기 상태에서는 결과가 숨겨진다.

격리 SQLite와 Chrome 390px·1280px 각각에서 동일 문구의 두 자막 중 두 번째를 수정해 저장했다. 결과의 번호는 DB 리비전과 일치했고 다른 자막으로 전환하면 결과가 숨겨졌다. 이후 시험용 503 응답으로 실패시켜 DB 리비전 보존과 결과 미표시를 확인했다. 실제 재시도 요청을 지연시킨 동안 결과가 없었고 저장 완료 후 직전 문구와 재시도 문구가 정확히 표시됐다. 원본 영상 배열, 다른 자막, 이전 리비전 JSON 보존을 확인했다.

390px에서는 첫 요청이 서버에서 저장된 직후 응답 전달을 지연시켜 별도 HTTP 요청으로 같은 자막을 다시 저장했다. 화면은 다른 요청의 최신 문구로 갱신됐고 내 요청의 성공 비교는 표시되지 않았다. 두 저장 중 앞선 리비전의 JSON도 보존됐다. 타입 검사와 변경 파일 ESLint 통과.
