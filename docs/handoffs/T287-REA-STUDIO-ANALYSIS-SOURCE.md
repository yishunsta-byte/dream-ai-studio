# T287 작업실 참고 자료 권한과 비공개 사본 어댑터

기준 `4dcabf7` · Backend 자체 검증

`createIsolatedStudioAnalysis`는 루프백 합성 저장소에서 T284 작업실 분석 계약에 등록 자료를 공급합니다. 요청마다 확인된 계정, 프로젝트와 자료 ID를 등록 조회와 대조합니다. 매 조회에서는 활성 링크, 소유자·범위 승인, T281의 링크·소유자·범위 세대, 복원·자료 세대와 현재 스토리지 검증 세대를 확인합니다. 등록 자료도 기존 소유자·키·크기 계약을 통과해야 합니다. T279 관측 결과나 로컬 인증, 권한 세대가 없는 경우에는 파일에 접근하기 전에 차단합니다. [구현](../../lib/reference-analysis/studio-analysis-source.ts)

기존 비공개 reader는 사본을 자체 정리하고 검증 메타데이터를 반환합니다. 이 어댑터는 해당 결과를 등록값과 대조한 뒤 합성 공급자의 스트림을 요청 전용 임시 사본으로 받습니다. 사본 크기와 SHA-256을 다시 비교해 reader가 검증한 콘텐츠와 등록값에 결합합니다. 사본은 처리 한도 안에서 생성되며, 종료 경로마다 이 요청의 파일과 디렉터리만 정리합니다. [비공개 reader](../../lib/storage/supabase/reader.ts)

등록 증거는 처음, 사본 완성 뒤 디코딩 전, 디코딩 후 결과 반환 전에 확인합니다. 사본 완성 후와 분석 완료 후에는 계정도 다시 확인합니다. 계정 변경, 철회·재연결, 등록이나 스토리지 세대 변경을 발견하면 응답을 폐기합니다. 주입된 조회·스트림 공급자는 취소 신호를 준수합니다.
