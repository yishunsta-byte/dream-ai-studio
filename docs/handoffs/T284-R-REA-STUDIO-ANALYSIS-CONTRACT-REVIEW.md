**판정 — 서버 내부 계약 범위 통과.** 검증된 세 매체의 구조화된 관찰과 추정, 창작 제안을 확인했습니다. 권한·세대 변화가 관측되거나 사본 검증·취소·조회가 실패하면 결과가 폐기됩니다. [Backend 인계](T284-REA-STUDIO-ANALYSIS-CONTRACT.md)

## 독립 합성 대조

| 경로 | 결과 |
| --- | --- |
| 인증·등록 순서 | 네이티브 성공 요청에서 인증→등록→재인증→등록 재조회 순서를 기록했습니다. 등록 조회가 받은 액터와 조회 대상은 검증 ID와 일치했습니다. 임의 경로가 들어간 요청은 인증 전에 거절됐습니다. 기본 로컬 인증은 등록 조회에 진입하지 않았고 T279의 `observed` 관측 형태도 분석 권한이 없었습니다. 집중 회귀에서 미인증·타 소유자·프로젝트/자료 불일치가 디코더 전에 닫혔습니다. |
| 파일과 바이트 | 컷이 있는 합성 MP4, 펄스 ALAC/M4A, 절반 투명 PNG를 별도로 생성했습니다. 세 파일 모두 실제 바이트의 SHA-256이 등록값과 일치할 때만 결과를 반환했습니다. 각 해시를 한 자리 바꾸거나 MP4의 원본을 같은 크기의 다른 바이트로 교체하면 `analysis_unavailable`이었습니다. |
| 처리 후 변경과 철회 | 실제 이미지 디코딩이 끝난 뒤 재조회 응답에 스토어, 링크·범위 권한·소유자 권한·복원·자료 세대, 해시, 경로, 소유자를 각각 바꾸거나 조회값을 제거했습니다. 모두 `source_unavailable`만 반환했습니다. 재인증에서 계정이 바뀌면 두 번째 등록 조회도 하지 않았습니다. 앞뒤 등록 조회 예외의 내부 메시지는 응답에 포함되지 않았습니다. |
| 취소와 정리 | 분석 전 사전 취소, 네이티브 MP4 사본이 생성된 직후 취소, 분석 뒤 마지막 등록 조회 중 취소가 모두 `cancelled`를 반환했습니다. 사본 정리 후 임시 분석 디렉터리 목록이 원래 상태로 돌아왔습니다. 집중 시험에서 제한 시간과 내부 디코더 예외의 응답 사유를 확인했습니다. |
| 관찰·추정·초안 | MP4의 관측 PTS 992ms와 편집 격자 30프레임을 구분했습니다. 컷 후보는 `inference`이며 차이 관찰과 디코딩 프레임을 근거로 참조했습니다. 음원의 RMS·온셋은 `observation`, 120 BPM은 `estimated_bpm` 추정이었습니다. PNG에는 알파 커버리지 50%의 색·명도 관찰과 프롬프트가 있었고 시간 추정이 없었습니다. 모든 초안의 종류는 `creative_proposal`이었습니다. |
| DTO | 세 매체 모두 해시, 경로, 파일명, 계정과 프로젝트·자료 ID, 권한/자료/복원 세대, 이미지 바이트·원시 픽셀 없이 허용된 관찰·추정·초안을 반환했습니다. |
