# P2 오디오 포함 출력 · 10분 경계 검증

격리된 T173 합성 프로젝트의 계획 길이를 601초로 준비하고 로컬 타임라인 저장 API를 이용해 제목 끝을 각각 18000, 18001프레임에 저장했다. 원본 음원과 장면은 동일했다. 제한은 음원이 있는 최종 출력의 길이에 적용된다.

| 출력 길이(30fps) | 렌더 사전 검사 | 실제 요청 |
|---|---|---|
| 18000프레임 | ready=true, 차단 이유 없음 | 경계 통과만 확인 |
| 18001프레임 | ready=false, AUDIO_TOO_LONG 단독, 한도 18000 | POST 409, 작업 수 변화 0 |

기존 안내가 정수 초로 반올림해 한 프레임 넘은 출력도 ‘지금 10분’으로 표시했다. 편집기의 프레임 단위 시간 표시를 재사용했다. Chrome의 렌더 화면에서 ‘지금 10분 0초 1프레임’, 비활성 ‘영상 만들기’ 버튼과 해당 프로젝트 편집 링크를 확인했다.

렌더 패널·오디오 UI 시험 19개 및 대상 ESLint 통과. 전체 10분짜리 영상을 출력하는 부하 시험은 별도 항목이다. 실행 및 원자료는 tmp/p2-render-limit 폴더에 있다.

> 플래너 전달문 — 오디오 포함 출력의 10분 경계를 로컬 API와 화면에서 재현했습니다. 정확히 10분은 사전 검사를 통과했고, 한 프레임 초과는 409로 차단되어 작업이 생성되지 않았습니다. 화면에 초과 프레임이 드러나도록 안내를 수정했습니다.
