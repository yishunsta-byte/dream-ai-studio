# T371 생성 폼 요청 키 독립 검수

후보 `2efcfd0`에서 통과했다. 별도 사본의 Next 개발 서버에 제품 ProjectForm과 쇼핑숏츠 설정을 올렸다. 헤드리스 Chromium에서 제출 버튼 클릭과 같은 시점의 추가 제출을 세 차례 발생시켰다. 응답을 지연시킨 합성 API가 관찰한 실제 POST는 차례마다 한 건씩, 총 세 건이었다.

첫 번째 빈 503 응답 뒤 연결 오류 안내를 확인했다. 같은 입력으로 다시 제출하자 요청 본문과 UUIDv7 키가 일치했다. 두 번째 응답의 필드 오류를 표시한 후 제목을 바꿔 다시 제출하자 변경된 본문과 새 UUIDv7 키가 전달됐다. 세 번째 요청에 201을 반환했다.

브라우저 검증은 같은 화면에 마운트된 폼과 HTTP 요청까지다. 페이지 새로고침, 운영 로그인, 실제 DB 저장·서버 중복 방지는 이 시험 범위 밖이다. SQLite 경로에서 응답 유실 뒤 재시도 시 중복 저장 가능성은 남는다.
