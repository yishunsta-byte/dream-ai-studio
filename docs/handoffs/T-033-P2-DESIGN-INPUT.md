## 2. P2-1 · 타임라인 스키마·리비전

### 2.1 데이터

- `timeline_revisions`: `id`(UUIDv7) · `project_id` · `revision`(프로젝트 안 1부터 증가) · `content_revision`(저장 시점 프로젝트 내용 버전) · `timeline_json`(PLAN 11.2, `schemaVersion: 1`) · `source`(`"p1-migration" | "user" | "restore-version"`) · `created_at`. **행은 고치거나 지우지 않는다**(R1·R2). 현재 버전은 포인터 하나(`project.<id>.timeline.current` 또는 projects 칸 — 구현 선택, 2.4 참고).
- `timeline_json`의 시간은 모두 **정수 프레임**, `fps: 30` 고정, `aspect`는 `9:16 | 16:9 | 1:1`.
- `video[]`: P1 `sceneOrder` 순서대로 장면마다 **선택된 버전** 하나(`sceneId`, `sceneVersionId`, `assetId`). 이미지 결과의 클립 길이 = 기획 장면 초 × 30(정수 반올림). 영상 결과는 실제 길이(ffprobe)와 기획 초 중 짧은 쪽, `trimIn/OutFrames`로 표현.
- `text[]`: PLAN 11.3 TextLayer. 이관 규칙은 6장.
- `audio[]`: P2-1에서는 빈 배열 허용(P2-5에서 채움).

### 2.2 이관 (마이그레이션 0005 · K-6 대상)

1. 0005 적용 **전**에 K-6 ⑥ 일관 스냅샷(새 파일만, 실패 시 이관 안 함).
2. 프로젝트마다 `project.<id>.edit.current`가 가리키는 P1 스냅샷이 있으면 → `timeline_revisions` 첫 행(`revision 1`, `source "p1-migration"`, `content_revision` = 스냅샷 값). 없으면 행을 만들지 않는다(처음 편집 화면을 열 때 만든다).
3. P1 settings 스냅샷 행은 **읽기 전용으로 남긴다**(지우지 않음, PLAN 7.2 T-002).
4. 같은 입력이면 같은 결과(K-6 ⑤): 새 ID는 원래 스냅샷 ID에서 결정적으로 만들고, `created_at`은 스냅샷 값 그대로.
5. 이관 검사: 프로젝트마다 current 스냅샷 1개 ↔ 첫 timeline 1개, 글자 수·문구·프레임 시간 일치(6장 표).

### 2.3 저장·버전

- **저장할 때마다 새 타임라인 버전**(r{n}). 자동 저장은 마지막 입력 후 2초 쉬거나 칸을 벗어날 때 한 번(미정 U-4). 같은 내용이면 새 버전을 만들지 않는다(정규화한 JSON 해시 비교).
- 타임라인 저장은 P1 글자 저장처럼 **프로젝트 내용 버전을 올리고 검수·내보내기 자격을 무효화**한다(같은 트랜잭션, R6). 머리 안내: "저장하면 새 내용 버전으로 검수를 다시 해야 해요."(P1 문구 유지)
- 머리 표시: "저장됨 · 타임라인 r4 · {시각}" / 저장 중 "저장하는 중…" / 실패 "저장하지 못했어요. 마지막 저장 r3은 그대로예요." + "다시 저장".
- 버전 목록(서랍): r{n} · 시각 · 바뀐 것 요약(예: "글자 2개 · 순서"). "이 버전으로 되돌리기" = 그 내용으로 **새 버전**을 만든다(`source "restore-version"`), 옛 버전은 그대로.
- 동시에 두 창에서 저장: 기대 버전(`expectedRevision`)이 다르면 거절 "다른 창에서 먼저 저장했어요. 새로고침한 뒤 다시 고쳐 주세요."(P1 선택 변경과 같은 방식).

### 2.4 수용 기준 (P2-1)

1. 0005 적용 전 스냅샷 파일 생성, 실패 주입 시 DB 그대로(K-6).
2. 고정 백업 s4 → 올려서 복원 성공, 이관 결과 = 직접 migrate 결과(K-6 ⑧).
3. P1 글자 스냅샷이 있는 프로젝트: 첫 타임라인 r1의 글자가 6장 표대로 옮겨지고 **화면에서 위치·크기·색이 P1 미리보기와 같다**(1280에서 두 화면 캡처 비교).
4. 저장마다 새 행, 옛 행 불변(행 해시 전후 비교). 같은 내용 저장은 새 행 없음.
5. 저장 시 내용 버전 증가 + 검수 무효, 내보내기 버튼 잠김 이유 표시.
6. 되돌리기 = 새 버전, 옛 버전 목록 그대로.
7. 기대 버전 불일치 저장 거절 문구.

## 3. P2-2 · 미리보기 (PlayerPanel)

### 3.1 화면 (DESIGN 6.8)

- 1280: 위 왼쪽 미리보기(최대 폭 360px, 9:16 기준) + 오른쪽 글자 편집, 아래 타임라인 전체 폭. 태블릿 이하 한 줄로 쌓기.
- 미리보기 아래 조작 줄: 재생/멈춤 · 한 프레임 뒤/앞 · 시간 `00:08.10 / 00:25.00`(초.프레임, 프레임은 두 자리) · 비율 고르기(9:16 · 16:9 · 1:1) · "안전 영역 보기" 토글.
- 안전 영역(spec `safeArea`): 9:16 위 12%·아래 20%·오른쪽 12%, 16:9·1:1 사방 5%. 켜면 옅은 빨강 + 점선.
- 샘플 장면이 있으면 미리보기 위 SampleBadge(P1과 같음). 미리보기는 "완성 영상"이라 부르지 않는다.

### 3.2 동작

- 키보드(미리보기 또는 타임라인에 초점이 있을 때만): Space 재생·멈춤, ←/→ 한 프레임, Shift+←/→ 1초. **글자 입력칸에 초점이 있으면 가로채지 않는다.**
- 비율 전환: 6장 U-2 결정 전까지는 **미리보기 확인용**으로만 동작(저장된 `aspect`를 바꾸지 않음). 전환 시 안전 영역 밖으로 나가는 글자는 미리보기에서만 안쪽으로 옮겨 보여 주고 Toast "글자 위치를 바꿨어요. 확인해 주세요." + 해당 글자 "위치 확인 필요"(T-2).
- 장면 결과 파일이 없으면 그 구간은 회색 칸 + "장면 {n} 결과 파일을 찾을 수 없어요."(재생은 멈추지 않음).
- `prefers-reduced-motion`: 글자 애니메이션은 미리보기에서 바로 나타남/사라짐으로(렌더 결과는 그대로).

### 3.3 접근성

- 재생 버튼 접근 이름이 상태에 따라 "재생"/"멈춤". 시간 표시는 `aria-live="off"`(재생 중 읽지 않음), 멈출 때만 현재 시간 읽기.
- 비율·안전 영역은 버튼 그룹(`aria-pressed`). 안전 영역 겹침은 색만이 아니라 글자로도(편집 쪽 Callout).

### 3.4 수용 기준 (P2-2)

1. 1280·390 재생·멈춤·프레임 이동·1초 이동이 마우스·키보드 모두 동작, 입력칸 초점 중 Space가 글자로 들어감.
2. 시간 표시 = 실제 프레임(30fps) — 0프레임 `00:00.00`, 31프레임 `00:01.01`.
3. 비율 3종 전환 시 안전 영역 표시가 spec 값과 맞음(화면 측정).
4. 비율 전환 후 저장된 `aspect` 불변(U-2 결정 전), 옮긴 글자에 "위치 확인 필요".
5. 결과 파일 없는 장면 구간 안내, 앱 멈춤 없음.
6. 미리보기 위 샘플 표시.

## 4. P2-3 · 글자 편집기 (TextLayerInspector + 타임라인 글자 줄)

### 4.1 화면

- 머리: 글자 종류(자막·훅·강조·제목·엔딩·가사·브랜드·표기) + 시간 `00:01.00–00:03.15`.
- 칸: 문구(최대 줄 수 표시) · 빠른 모양(프리셋) · 글꼴(fonts.json 8종, 각 글꼴 이름을 그 글꼴로) · 크기 · 색 견본 + 외곽선 · 나타날 때/강조/사라질 때(쉬운 말: 서서히·톡 튀어나옴·아래에서 위로·타자 치듯·통통 튐·흔들림·커졌다 작아짐) · 시작/끝 시간.
- 새 글자 추가: 종류를 고르면 **spec 프리셋 기본값**으로 만든다(widthRatio 0.74 등). 옮겨 온 P1 글자에는 프리셋을 자동 적용하지 않는다(spec `migration.fromP1`). "빠른 모양"을 누르면 그때만 바뀐다.
- 타임라인 글자 줄: 클립 = 문구 앞부분, 길이 = 시간. 선택 = 남색 안쪽 테두리, 안전 영역·글자 길이 경고 = 노란 테두리. 마우스 끌기와 키보드(선택 후 ←/→ 한 프레임, Shift 1초, Alt+←/→ 끝 시간만) 둘 다.

### 4.2 경고 (실측)

- **안전 영역:** 숫자가 아니라 **실제 글꼴로 그린 바깥 경계**(외곽선·그림자·배경 포함)를 재서 판단(spec `safeArea.rule`). 걸치면 미리보기 노란 테두리 + 편집 위 Callout(warning) "아래 안전 영역(20%)에 걸쳐 있어요. 휴대폰 앱 버튼에 가려질 수 있어요." + 버튼 "안전 영역 안으로 옮기기"(가장 가까운 안쪽으로, 새 버전 저장).
- **글자 길이:** 실제 글꼴로 줄바꿈해 `maxLines`를 넘으면 "글자가 길어 {n}줄이 돼요. 최대 {m}줄이에요." + 노란 테두리, 검수 "글자 잘림" 항목 자동 근거. **렌더는 막지 않는다**(spec `textFit`).
- 측정은 미리보기와 렌더가 **같은 글꼴 파일**을 써야 한다(fonts.json 경로). 글꼴을 못 읽으면 경고 "글꼴을 불러오지 못해 크기를 확인하지 못했어요."(통과로 치지 않음).

### 4.3 표기 글자 (`disclosure`)

- 타임라인에서 자물쇠·회색. 문구 고정(spec fixedTexts: 광고 / 유료 광고 포함 / AI 생성 / 가상인물), 위치·시간만 바꿈.
- 지우려 하면 ConfirmPanel "이 표기를 지우면 검수 항목 '광고 표기'를 통과할 수 없어요"(T-4). 확인해도 검수에서 막힘은 그대로.
- 프로젝트 등록값(광고·실사형 AI·가상인물)에 필요한 표기가 없으면 편집 위 Callout(warning) + "표기 추가".

### 4.4 휴대폰 (390)

- 타임라인 숨김 + Callout(info) "타임라인 편집은 PC에서 해요."(PLAN 17장).
- 미리보기 + 글자 **문구만** 고치기 + 수정 요청. 위치·시간·모양은 PC에서. 가로 넘침 0.

### 4.5 수용 기준 (P2-3) — DESIGN 10장 P2 항목 포함

1. 안전 영역 겹침이 비율마다 맞고(실측), 걸친 글자에 노란 테두리 + 경고 + "안으로 옮기기" 동작.
2. 비율 전환 후 옮긴 글자에 "위치 확인 필요".
3. 표기 글자 삭제 시 확인 패널, 문구 수정 불가(서버에서도 거절).
4. 타임라인 글자 클립 키보드 선택·이동·끝 시간 조절.
5. 글자 길이 경고가 실제 글꼴 기준(같은 글자 수라도 글꼴에 따라 결과가 다름을 시험으로 확인), 렌더 막지 않음.
6. 새 글자 = 프리셋 기본값, 옮겨 온 P1 글자 = 바뀌지 않음.
7. 글꼴 목록 = fonts.json 중 라이선스 검사 통과한 것만(자동 테스트).
8. 390 타임라인 숨김 + 안내, 문구 수정만 가능, 넘침 0.
9. 글자만 바꾸고 저장해도 장면 결과·선택 불변(P2 종료 기준 T-1의 앞 단계).

## 6. P1 값 → P2 첫 타임라인 이관 표

P1 저장 형식(`lib/edit/schema.ts`): 글자마다 `id, kind(6종), content, fontFamily("Pretendard"), fontSize(18~120), color, position(top|middle|bottom), startSec, endSec(밀리초 정수), locked`. P1 미리보기 좌표(`editing-panel.tsx`, `.overlay`): 가로 중심 44%, 세로 중심 top 16% · middle 50% · bottom 74%, 폭 76%, 가운데 정렬, 굵게(700), 외곽선 없음.

| P2 TextLayer | P1에서 | 규칙 |
|---|---|---|
| `id` | `id` | 그대로 |
| `kind` | `kind` | 그대로(6종 모두 P2 8종 안에 있음) |
| `content` | `content` | 그대로. 표기 글자가 표준 문구와 달라도 바꾸지 않음(spec `disclosureTexts`) |
| `style.fontFamily` / `fontWeight` | `"Pretendard"` / (미리보기 700) | Pretendard / 700 |
| `style.fontSize` | `fontSize` | 그대로(짧은 변 1080 기준, spec `units`) |
| `style.color` | `color` | 그대로 |
| `style.stroke` · `shadow` · `background` | 없음 | `null`(P1 미리보기와 같게. 프리셋 외곽선을 넣지 않음) |
| `style.align` · `lineHeight` · `maxLines` | 없음 | `center` · P1 CSS 값(`--lh-tight`) · 프리셋 `maxLines` (경고용) — **U-1 확인** |
| `box` | `position` | **U-1:** 권장 = P1 미리보기 좌표 그대로 `x 0.44`, `y 0.16/0.50/0.74`, `anchor center`, `widthRatio 0.76` |
| `timing.startFrame` / `endFrame` | `startSec` / `endSec` | 반올림(초 × 30), 끝 ≥ 시작 + 1 (spec `secondsToFrames`) |
| `animation` | 없음 | 모두 `none`, `durationFrames 0` (P1은 움직임 없음) |
| `locked` | `locked` | 그대로 |
| `video[]` 순서 | `sceneOrder` | 그대로, 장면별 현재 선택 버전 |

이관 뒤 실측 경고가 나면 글자를 옮기지 않고 "위치 확인 필요" 표시만 한다(조용히 바꾸지 않음).

## 8. 읽은 범위·검증·미실행

- **읽음:** PLAN 7.2·11장·14장 K-6·18장 P2, DESIGN 4장 P2 부품·6.6·6.8·6.9·7장·10장 P2, spec `text-presets.json`(units·safeArea·presets 8종 좌표·textFit·migration), `fonts.json`(installRule·글꼴 8종), 코드 `lib/edit/schema.ts`, `components/editing-panel.tsx`의 미리보기 좌표, `finishing-panel.module.css .overlay`.
- **확인:** P1 글자 필드·좌표는 코드 원문으로 대조했다. spec 프리셋 좌표는 JSON을 직접 읽어 확인했다.
- **하지 않음:** 앱·시안을 새로 띄워 보지 않았다. Remotion·글꼴 실측 동작은 시험하지 않았다(설계 입력만). `package.json`에 Remotion 의존성은 아직 없다. 0005 마이그레이션·K-6 코드는 없다.
- 이 문서의 수치(2초, 76px 등) 중 DESIGN·spec에 없는 것은 **권장값**이며, 확정은 Master 배정 때 한다.
