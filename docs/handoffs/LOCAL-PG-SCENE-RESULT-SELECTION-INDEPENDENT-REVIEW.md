# 로컬 PG 장면 결과 선택 독립 검수

MASTER 배정 `msg_ae6bae360208`. 커밋 `0729d65`의 격리 사본에서 실제 Next.js HTTP·Chromium·임시 PG17로 검수했다. 기존 HTTP 시험으로 새 프로젝트의 브리프와 기획을 승인하고 검증 PNG 결과를 등록했다. 두 번째 장면에는 같은 검증 원본을 등록한 뒤 브라우저 선택 시험을 추가했다.

| 확인 항목 | 관측 결과 |
|---|---|
| 명시 선택과 재진입 | 두 번째 장면의 결과 선택 버튼을 Enter로 실행하자 HTTP 200이었다. 성공 안내에 초점이 이동했고 결과에 `사용 중`이 표시됐다. 새로고침과 프로젝트 상세에서 재진입한 뒤에도 유지됐다. |
| 같은 기준의 중복 선택 | 기존 HTTP 동시 요청은 200·409, 감사 기록 1건이었다. 이미 선택된 결과를 최신 기준으로 다시 요청하면 기존 선택을 그대로 반환했다. 두 탭에서 같은 기준으로 선택했을 때도 두 번째 탭은 409였고, 다시 불러오면 적용된 결과를 표시했다. |
| 실패 원자성 | 감사 INSERT 실패 주입은 503을 반환했다. 다시 읽은 프로젝트 내용 리비전과 선택 포인터에 변경이 없었다. |
| 보존 | 브라우저 선택 후 포인터 설정·재확인 해제와 리비전·감사 각각 1 증가를 확인했다. 원본 권리 메모와 결과 입력 JSON·결과 행 수는 동일했으며 제작은 `todo`, 편집은 `locked`였다. |
| 거절 | 다른 계정·장면·이전 기획에 속한 결과와 보관 상태는 거절됐다. |

기존 [HTTP 시험](../../tests/postgres/local-project-brief-http.mjs)에 격리 사본 전용 브라우저 대조를 연결했다. 전체 실행은 종료 코드 0이었다. 브라우저 공간과 PostgreSQL 프로세스·리스너·임시 클러스터 정리를 확인했다.
