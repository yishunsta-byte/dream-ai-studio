# 최근 출력 50건 밖에 있는 현재 MP4

검수는 현재 프로젝트·내용 리비전·타임라인 ID로 완료된 후보를 최신순으로 조회한다. 취소되지 않았고 실제 파일 크기가 저장 기록과 일치하는 첫 후보를 연결한다. 렌더 결과 화면은 최근 50건에 이 후보가 없을 때 해당 결과 카드도 표시한다.

고정 SQLite 백업의 격리 사본에 정상 완료 결과 1건, 파일이 누락된 완료 결과 1건, 이후 취소된 50건을 저장했다. 최근 목록에서 정상 결과가 빠진 상태로 검수의 MP4 선택과 렌더 서비스의 결과 목록에 같은 ID가 반환됐으며 그 결과의 현재 버전 및 파일 존재 표시를 확인했다. 다른 내용 리비전 조회는 빈 결과였다. 이 회귀 시험은 조회 경계와 파일 존재 판정을 검사한다. 브라우저 재생 근거는 [r38·r39 실측](P2-SUBTITLE-CURRENT-MP4.md)에 있다.

관련 테스트 45건, 전체 타입 검사, 변경 파일 ESLint 통과.
