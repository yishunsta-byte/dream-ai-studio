# P2 원본 소리 업로드 취소 및 같은 파일 재시도

T150의 업로드 취소 잔여 항목. 별도 앱 사본, 가상 SQLite 및 Chrome 157에서 실제 파일 선택과 XHR로 점검했다.

- 수정 전 첫 진행률 이벤트 전의 요청을 보류하면 취소 버튼이 없고 파일 선택기가 활성 상태였다. 연결 오류를 주면 선택 파일이 남았다.
- 파일을 고른 즉시 진행 상태와 취소 버튼을 표시하고 전송 중 중복 선택을 막았다. 연결 오류에서도 파일 입력을 초기화해 같은 파일을 다시 선택할 수 있다.
- 브라우저에서 첫 요청을 보류하고 취소한 뒤 같은 파일 재선택, 연결 오류 후 재선택까지 요청 3개를 확인했다. 취소·실패 뒤 파일 선택은 비었고 미저장 제목 문구가 유지됐다.
- 별도 실전송에서 384078바이트 합성 WAV를 전송 속도 제한으로 올렸다. 브라우저에 4% 표시 시 취소했다. 취소 후 가상 DB의 해당 제목 행 0개, 검사 시 임시 .part 파일 0개였다. 같은 WAV를 다시 선택해 로컬 HTTP 201, 동일 제목 행 1개, 편집 초안 유지까지 확인했다. 임시 파일이 작성되던 순간은 관찰하지 못했다.
- 오디오 편집기와 곡 연결 회귀 15개 통과. 원자료 tmp/p2-audio-cancel/fixed.json, wire.json. 서버가 이미 저장을 마친 시점의 취소·운영 스토리지는 별도 조건이다.

> 플래너 전달문 — 소리 업로드의 첫 진행률 전 취소와 같은 파일 재시도를 보완했습니다. 4%에서 실제 취소한 뒤 같은 WAV가 한 건만 등록되고 미저장 편집 문구가 유지됐습니다.
