# 로컬 PG 편집 완료와 검수 승인

| 항목 | 동작 |
|---|---|
| 조회 | GET /api/projects/{id}/review에서 현재 revision, timelineId, editCompleted, approved, blockedReason 및 검수 항목을 반환한다. 조회는 행을 생성하지 않는다. |
| 편집 완료 | POST에 action=complete-edit, revision, timelineId를 보낸다. 현재 제작이 승인됐고, 저장한 타임라인의 활성 장면과 선택 결과가 같은지 확인한다. 편집 완료와 검수 단계 열기를 같은 트랜잭션에서 기록한다. |
| 검수 기록 | action=review-item과 같은 revision, timelineId, input={itemId,status,note}를 보낸다. status는 unchecked, pass, hold 중 하나다. hold에는 사유가 필요하다. 저장된 타임라인에 음악이 포함되면 음악 권리도 사람이 확인해야 한다. |
| 검수 승인 | action=approve-review를 같은 기준으로 보낸다. 모든 필수 항목이 pass일 때 승인 활동과 후속 단계 상태를 함께 기록한다. 기존 렌더 요청 경로가 이 승인을 확인한다. |
| 편집 충돌 | 내용 버전 또는 타임라인 ID가 달라지면 CURRENT_TIMELINE_CONFLICT를 반환한다. 같은 기준의 완료·승인 재시도는 현재 결과를 반환한다. 타임라인을 다시 저장하면 새 버전에서 검수를 시작하며 이전 항목은 보존된다. |
| 실행 범위 | 시험용 로컬 PG17의 소유자 권한으로 검증한다. 실제 작품 생성, 화면 연결과 운영 배포는 별도 작업이다. |

POST 성공 본문은 GET과 같다. 시험은 저장소 루트에서 PowerShell로 실행한다.

```powershell
$env:T371_VERIFY_HTTP='1'
node --conditions=react-server --import tsx tests/postgres/t368-run-private-image-project-create.mjs
```

## Tester 독립 검수

고정 커밋 `722c7c74b5698ec4f45480625827d457cb701d65`를 실제 로컬 Next.js·임시 PG17에서 검수했다. 새 합성 프로젝트의 선행 제작 승인과 선택된 검증 PNG 장면만 DB에 준비했다. 첫 타임라인과 WAV 첨부·저장은 제품 HTTP로 수행했다. 검수 시작 시 편집은 진행 중, 검수·내보내기는 잠김이었으며 세 단계의 승인 기록은 모두 비어 있었다. 편집 완료·검수 판정·승인은 제품 검수 API로 처리했다.

| 시험 | 결과 |
|---|---|
| 편집·소유 조건 | 익명 조회 401, 타인 404. 제작 승인 누락과 재검토 대상 장면, 이전 저장 기준을 거절했다. 동일 편집 완료 두 건은 200이었고 완료 활동은 1건이었다. |
| 필수 항목과 음악 권리 | 보류 사유 누락은 400이었다. 필수 13개 중 음악 권리를 제외한 12개를 먼저 통과 처리했지만, `x.music-rights` 하나가 미판정이면 승인 409 `REQUIRED_ITEMS_INCOMPLETE`였다. 음악 권리에 별도 통과 판정을 기록했다. |
| 승인 기록 실패 | 승인 활동 INSERT 실패를 주입하자 503이었다. 검수는 미승인, 내보내기는 잠김, 렌더 요청은 409였으며 접수 작업은 0건이었다. |
| 명시 승인과 렌더 접수 | 승인 POST 두 건이 200을 반환했고 DB에는 승인 활동 1건과 필수 항목 13건이 있었다. 승인 전 렌더 409, 승인 후 202 및 작업 1건이었다. |
| 내용 리비전 r3 → r4 | WAV 추가 저장 뒤 이전 기준 렌더는 409 `CURRENT_TIMELINE_CONFLICT`, 현재 미승인 기준은 409 `REVIEW_APPROVAL_REQUIRED`였다. 현재 판정은 전부 미확인, 이전 항목 13건은 보존됐고 기존 대기 작업 한 건은 `stale`로 표시됐다. |

공용 HTTP 시험은 종료 코드 0이었고 임시 PG17 프로세스·리스너·클러스터를 정리했다. 관련 인증·기존 경로·워크플로 자동 테스트 279건이 통과했다. 이번 검수는 접수까지의 승인 연결을 대상으로 했다.

> Master 전달문 — 722c7c7에서 새 소유 프로젝트의 편집 완료부터 필수 판정·명시 검수 승인·렌더 202까지 실HTTP로 확인했습니다. 음악 권리 하나만 미판정이어도 승인 409였고 승인 활동 실패 뒤 렌더 접수 0건을 확인했습니다. 편집 이후에는 이전·현재 미승인 기준이 모두 거절됐습니다.
