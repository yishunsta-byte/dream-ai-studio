**판정 · 통과.** 실제 Next에서 기본·불완전·초기화 오류 구성은 예시 홈과 비활성 표지를 유지했습니다. 완비 격리 구성에서 승인·철회·만료가 홈과 표지 응답에 함께 반영됐습니다.

| 항목 | 독립 검증 결과 |
| --- | --- |
| 기본·누락·초기화 오류 | 실제 Next 서버를 기본값, 표지 최종 확인 누락, 초기 검증 예외로 각각 시작했습니다. 쿼리·헤더·쿠키에 승인 모드 표식을 넣어도 홈 GET은 기존 예시, 표지 GET·HEAD는 404였습니다. 목록·표지 조회·파일·최종 확인 호출은 각각 0건이었습니다. |
| 완비 승인·철회·만료 | 공통 초기화 지점에만 격리 공급원을 주입했습니다. 승인 홈 GET은 실제 표지 주소를 포함했고, 표지 GET은 원본 WebP 바이트, HEAD는 빈 본문을 반환했습니다. 이전 세대·쿼리 포함 표지는 404였습니다. 철회와 시험 권리 만료 뒤 새 홈은 승인 결과를 제외했고 GET·HEAD가 404였으며, 만료 뒤 파일과 최종 확인은 추가 호출되지 않았습니다. 조회한 홈과 표지의 `no-store`를 확인했습니다. |
| 공급자 오류 | 목록 오류에서는 승인 작품과 예시를 표시하지 않고 로그인 경로를 유지했습니다. 최종 표지 확인 오류는 이미지 없이 HEAD 503 `no-store`였습니다. 합성 내부 오류 원문은 홈 HTML에 없었습니다. |
| CSP와 브라우저 뒤로 가기 | 격리 Next 응답에 `script-src 'none'`과 `style-src 'none'`을 적용했습니다. Chromium에서 승인 영역이 `hidden`이고 화면 영역을 차지하지 않았으며 로그인 대체 링크가 보였습니다. 일반 승인 홈에서 실제 관리자 로그인 링크를 연 뒤 작품을 철회했습니다. 브라우저 이력으로 뒤로 가자 목록 조회가 증가하고 철회된 카드가 표시되지 않았습니다. |
