## 측정 방식

`analyzeLocalReferenceImage`는 형식과 소유 경계를 검사한 관리 사본으로 픽셀을 관찰합니다. 기존 Sharp 0.35.5로 EXIF 방향을 적용한 뒤 긴 변을 최대 96px로 줄입니다. 확대 없이 최근접 표본을 선택해 전체 및 최대 4×4 격자의 관찰을 반환합니다. 각 격자의 사각형은 표시 방향 기준 0~1 좌표입니다. 파일 메타데이터에는 저장된 치수를 남기고 이미지 특징에는 방향을 적용한 표시 치수와 표본 치수를 기록합니다. [이미지 분석 코드](../../lib/reference-analysis/image-features.ts)

색은 sRGB 채널별 64단계 폭의 구간으로 양자화한 뒤 비중이 큰 최대 3개 구간을 반환합니다. 색상 표기의 HEX는 각 구간의 중앙값입니다. 명도는 선형화한 sRGB의 상대 명도를 0–0.25, 0.25–0.5, 0.5–0.75, 0.75–1 구간으로 분류합니다. 색과 명도는 alpha 가중치로 집계합니다. alpha가 모두 0인 영역에는 색과 명도 분포가 없습니다. alpha 커버리지는 전체 표본에서 불투명도 0~1의 평균입니다. 표본 방식이므로 작은 물체나 가는 경계는 누락될 수 있습니다. 원본 바이트, 샘플 픽셀 버퍼, 사본 경로는 결과에 포함되지 않습니다.

기존 파일 64MiB·메타데이터 검사 4,000만 픽셀 제한 안에서, 특징 분석 입력을 1,200만 픽셀로 추가 제한합니다. 특징용 RGBA 표본은 최대 36,864바이트입니다. 관리 사본을 읽은 버퍼를 검사와 특징 분석에서 공유해 Sharp의 Windows 파일 잠금을 피합니다. 공통 기본 시간 한도는 30초입니다. Sharp는 남은 시간을 초 단위로 올림해 적용하며, 중단된 작업의 관찰 결과는 반환하지 않습니다. Sharp가 다중 프레임을 보고하면 특징을 건너뜁니다. [관리 사본 검사](../../lib/reference-analysis/local-file.ts)

## 합성 파일 검증

| 표본 | 실제 결과 |
| --- | --- |
| 8×8 쿼드런트 PNG | 좌상단 빨강·우상단 투명·좌하단 반투명 흰색·우하단 검정, 전체 및 영역 관찰 17개 |
| EXIF 방향 6 JPEG | 저장 32×16, 표시 16×32, 저장 래스터 좌우 색을 표시 방향 위아래로 확인 |
| 투명 1×1 WebP | 단일 전체 영역, alpha 0, 색·명도 결과 없음 |
| 200×100 PNG | 96×48로 샘플링 |
| 4,000×3,001 PNG / 2프레임 WebP | 각각 분석 한도 초과 / 다중 프레임, 픽셀 특징 미출력 |
| 잘린 PNG / PNG를 JPG로 제출 | 각각 파일 무효 / 형식 불일치, 픽셀 특징 미출력 |
