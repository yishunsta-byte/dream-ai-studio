## 확인 근거

- 독립 회귀 Tester의 기본 검증을 MASTER가 공유했다. Chromium 320·390·1440px, 세 시안, 네 메뉴의 36개 조합과 Enter 초점, 검색, 미연결 표현이 통과했다.
- 별도 기능 비교는 고정 커밋에서 HTML·JS·CSS·이미지·글꼴을 추출해 루프백 HTTP로 실행했다. Chromium 390×844와 1440×900에서 실제 Enter 조작과 DOM 위치를 읽었다. 제품 기능은 동일 커밋의 `app/admin/page.tsx`, `components/admin/admin-navigation.tsx`, `components/admin/admin-hub.tsx`, `components/admin/admin-projects.tsx`, `components/admin/publication-queue.tsx`, `components/auth/account-menu.tsx`를 기준으로 대조했다.
- 02에서 마지막 행의 ‘검수표 보기’에 Enter를 누르면 390px에서 제목 초점은 이동했지만 제목 하단은 뷰포트 상단보다 186px 위였다. 1440px에서는 제목이 뷰포트 y=190~247px에 보였다. 03에서 마지막 프로젝트 선택 후 390px의 선택 영역 오른쪽은 x=378px, 초점 버튼의 왼쪽은 x=434px였고 가로 스크롤은 0으로 돌아갔다.
- 재현 자료는 로컬 `tmp/admin-topnav-review-a32bc4b7`의 `compare.mjs`, `observations.json`, `390-console-drill.png`, `390-studio-picker.png`에 있다.

**MASTER 전달문** — 02 작업 콘솔을 추천합니다. 프로젝트 검색·상태별 분류·다음 작업 진입에 가장 직접적입니다. 390px에서 리비전·출력 요약과 상세 진입 초점 가시성을 먼저 보완하고, 기존 관리자 주소·실제 프로젝트 이동 및 재조회·게시 큐·계정 조작을 연결해 검수합니다. 03의 단계·파일 구성은 콘솔에서 연 프로젝트 상세에 적합합니다.
