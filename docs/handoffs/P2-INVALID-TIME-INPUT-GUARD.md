# P2 편집기 · 입력 중인 시간 값 보존

정상 타임라인 값이 유지된 상태에서 시간 칸에 잘못된 값만 남으면, 기존 편집기는 저장과 렌더를 막지만 ‘수정 확인 완료’는 허용하고 새로고침 경고와 ‘변경 취소’를 제공하지 않았다. Chrome의 가상 프로젝트 음성 클립 시작 칸에 00:x를 입력해 aria-invalid=true, 새로고침 경고 0건과 입력 소실을 재현했다.

편집 중 원시 시간·소리 값도 미저장 입력으로 취급하도록 변경했다. 정상 타임라인 비교 및 실제 저장 검증은 기존 규칙을 따른다. 현재 입력에 오류가 있으면 저장·렌더·검수 완료를 막고, 명시적으로 취소하면 기존 값을 되돌린다.

로컬 실제 편집 페이지에서 글자 시작과 소리 시작을 각각 잘못 입력했다. 두 경우 모두 세 가지 진행 조작 차단 및 변경 취소 표시를 확인했다. 브라우저 기본 새로고침 확인을 취소하자 입력한 값이 보존됐고, ‘변경 취소’ 후에는 기존 값 복원, 렌더 진입 복귀, 경고 없는 새로고침을 확인했다. 편집기·복구·렌더 회귀 63개와 대상 ESLint 통과. 로컬 재현 코드는 tmp/p2-invalid-field/probe.mjs.

> 플래너 전달문 — 시간 칸만 잘못 입력한 경우에도 검수 완료와 새로고침에 의한 초안 소실을 방지했습니다. 실제 Chrome에서 글자와 소리 시간 입력 각각에 대해 복구와 취소를 확인했습니다.
