# 로컬 PG 기획 초안 독립 검수

MASTER 배정 `msg_4fa2f3872384`. 커밋 `ef02165`의 격리 Git 사본에서 실제 Next.js·Chromium·임시 PG17로 검수했다. PNG 프로젝트를 HTTP로 생성하고 실제 브리프를 승인한 뒤 기획을 열었다.

| 항목 | 관측 결과 |
|---|---|
| 최초 접근 | 브리프 승인 전 기획 저장은 거절됐다. 승인 후 소유자의 기획 조회는 200을 반환했다. 다른 계정의 기획 조회와 저장은 404, 비로그인 저장은 401이었다. |
| 실제 동시 쓰기 | 같은 초안 버전의 두 HTTP 저장을 동시에 보냈다. 응답은 201과 409였고 초안 버전이 한 번만 증가했다. |
| 브라우저 저장 및 다시 열기 | 두 탭에서 DB에 저장된 버전 2를 열어 각각 다른 대본과 장면 설명을 입력했다. 첫 탭의 저장 이후 새로고침해 버전 3의 두 입력이 일치함을 확인했다. |
| 구버전 탭 | 두 번째 탭의 저장은 409였다. 충돌 안내, 두 입력값 유지, 저장 비활성을 확인했다. `저장된 초안 불러오기`를 누르자 버전 3의 대본·장면 설명을 표시했다. |
| DB와 잠금 | 브라우저 검수로 초안과 저장 감사가 각각 2건에서 3건이 됐다. 버전 3은 `draft`였고 두 필드가 DB에도 일치했다. 브리프 승인 이력 1건, 프로젝트 승인 포인터 NULL, 제작·편집 잠금, 타임라인 0건을 확인했다. |

기존 [HTTP 시험](../../tests/postgres/local-project-brief-http.mjs)에 검수 사본 전용 Ego Browser 대조를 연결했다. 초기에는 격리 사본에 `ffprobe`가 없었고 브라우저 선택자가 모호했다. 기존 바이너리를 연결하고 선택자를 바로잡은 뒤 전체 실행이 종료 코드 0으로 끝났다. 브라우저 공간을 닫고 PostgreSQL 프로세스·리스너·임시 클러스터 정리를 확인했다.
