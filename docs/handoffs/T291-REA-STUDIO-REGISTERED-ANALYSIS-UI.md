# T291 작업실 등록 자료 분석 화면

2026-11-19 KST · Codex(design)

## 구현

- `StudioRegisteredAnalysis`는 클라이언트 작업실이 주입한 등록 자료 목록과 분석 함수를 소비합니다. 목록에는 표시 이름과 프로젝트·자료 ID가 필요합니다. 실행할 때는 선택된 두 ID와 `AbortSignal`만 함수에 전달합니다. 공급자가 없으면 실행을 비활성화하고 연결이 필요하다고 안내합니다. 빈 목록과 미선택 상태도 각각 안내합니다.
- 결과는 T284 계약의 반환 타입을 사용합니다. 동영상의 원본 프레임 표시 시각과 편집 그리드 기준 프레임을 서로 다른 섹션에 표시합니다. 추정이 참조하는 관찰 근거는 화면 안의 목록 번호로 연결합니다. 초안은 결과 항목마다 편집할 수 있으며 복사 버튼은 그 항목의 현재 문구를 복사합니다. 복사가 실패하면 문구를 선택하고 직접 복사할 수 있도록 안내합니다.
- 실행 중 중복 요청을 막고, 취소 후에는 공급자의 응답까지 대기합니다. 공급자가 `cancelled`로 종료한 경우에만 취소 완료를 표시합니다. 취소 후 도착한 결과는 표시하지 않습니다. 자료 교체·공급자 교체·컴포넌트 해제는 기존 요청을 무효화하고 취소 신호를 보냅니다. 이후 도착한 이전 결과는 화면에 반영되지 않습니다.

## 연결 경계

`RegisteredAnalysisProvider`는 클라이언트 컴포넌트에서 주입합니다. 동일한 연결을 유지하는 동안 공급자 객체의 참조를 안정적으로 유지해야 합니다. 연결 교체는 현재 자료 선택과 결과를 초기화합니다. 결과 초안은 해당 화면의 임시 상태이며 다시 분석하면 초기화됩니다. 취소 신호에 응답하거나 정해진 시간 안에 요청을 종료하는 책임은 공급자에게 있습니다.

이번 변경의 범위는 분리된 UI 컴포넌트와 집중 시험입니다. 운영 공급자 연결과 실제 계정 세션 검증은 후속 통합 범위입니다. 기존 작업실 라우트, 실험실, 인증, 운영 환경과 T289 배포에는 변경 사항이 없습니다.

| 정적·계약 검증 | 집중 ESLint 및 TypeScript 통과. 네이티브 분석을 포함한 레퍼런스 분석 시험 19개 파일, 219개 통과. 신규 시험은 실제 T284 분석 계약이 생성한 합성 PNG DTO의 표시와 원본 메타데이터 제외, 미연결·빈 목록·미선택 상태의 실행 차단을 확인합니다. |
| 격리 브라우저 | 실제 T284가 합성 PNG와 두 색상의 MP4에서 생성한 DTO를 지연 응답 공급자에 주입했습니다. 선택과 실행·취소를 키보드로 조작하고, 중복 실행 차단, 취소 완료, 취소 후 결과 숨김, 자료 및 공급자 교체, 해제, 시간 초과, 예외 문구 비노출을 확인했습니다. 영상에서 원본 시각 1000 ms, 장면 전환 추정의 관찰 근거 2건, 약 30프레임 편집 위치를 확인했습니다. |
| 편집·레이아웃 | 편집 중 다른 결과를 조회한 뒤 돌아왔을 때 편집 문구가 복원됐습니다. 격리 클립보드에 편집 문구만 전달되는 경로와 실패 시 텍스트 선택을 확인했습니다. 390px 단일 열 및 1280px 두 열에서 가로 넘침이 없고 입력·버튼 높이가 44px 이상이었습니다. |
