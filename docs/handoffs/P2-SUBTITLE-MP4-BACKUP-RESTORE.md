# 자막 수정 전후의 MP4 백업·복원 확인

기존 합성 프로젝트의 SQLite와 미디어를 새 폴더에 복제했다. 앞선 반응형 시험에서 직접 바꾼 프로젝트 비율 때문에 첫 백업은 이관된 P1 리비전과 원본 불일치로 거절됐다. 복제본의 프로젝트 비율을 P1 이관 원본 값으로 돌린 뒤 다시 실행했다. 아래 판정은 그 복제본의 자료 보존 검증이다.
