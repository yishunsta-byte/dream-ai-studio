## 1. 맞는 곳

진행 카드 4단계·퍼센트·경과·취소, "창을 닫아도 작업 처리기가 켜져 있으면 계속돼요", 파일 확인 통과 칩(해상도·길이·코덱·음량·자막 오차), 샘플 장면 표시, 확인 실패 = 실패 + 문장 → 이유 → 행동 → 작은 코드 줄(T-013 순서), "글자만 바꾼 뒤 … 장면은 다시 만들지 않아요", 내보내기 잠김 + 이유. 390 문서 가로 넘침 0(탭 줄은 원래 가로 스크롤).
