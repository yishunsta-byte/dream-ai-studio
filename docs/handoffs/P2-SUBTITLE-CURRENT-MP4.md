# 자막 수정 후 현재 MP4 확인

로컬 샘플 두 장면에 LOCAL 자막을 각각 0~2초, 2~4초로 넣고 r38을 출력했다. 편집 화면에서 두 번째 자막만 MP4 VERIFIED로 고쳐 저장한 r39를 기존 영상 만들기 화면에서 다시 출력했다. 저장한 두 타임라인 JSON은 해당 문구 하나를 제외하고 일치했다.

결과 카드의 기준은 서버의 내용 리비전과 타임라인 ID 일치 여부다. r38은 보관본, r39는 현재 저장본으로 표시됐다. 각각의 재생 버튼에서 Chrome의 영상 시간이 실제로 진행됐으며, 카드별 다운로드 링크에서 MP4를 받았다. r38 파일은 136737바이트, SHA-256 a8af9b8bd8d04b0ea285aee904f1ee68c2f27000b5511b35c6b3177d86212dc2였다. r39는 141404바이트, a422ef84cd065f7cc5ff5b15ebc6fa18d8512874bcf9796e3310513e2310e9c4였다.

1초 지점의 디코딩 자막 영역은 두 파일에서 픽셀 단위로 일치했다. 3초 지점에서는 아래와 같이 두 번째 자막만 바뀌었다. 두 이미지는 각 카드의 실제 비디오에서 추출했다.
