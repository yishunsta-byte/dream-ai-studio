# T277 REA 등록 파일과 분석 사본 해시 결합

2026-11-19 KST · Codes(Backend) · 기준 `4ad2484af80c79412ceb2ae7f5d7ae072e541120` · 배정 `msg_43474ef5a803` · 독립 검수 대기

`analyzeRegisteredReferenceSnapshot`은 서버가 확인한 관리 경로, 등록 SHA-256, 자료 세대를 받아 기존 영상·오디오·이미지 분석기를 호출합니다. 기존 스트리밍 복사에서 한도와 등록 크기를 검사하고, 사본으로 전달하는 바이트의 SHA-256을 동시에 계산합니다. 등록값과 일치한 동일 사본으로만 형식을 검사하고 특징을 추출합니다. 분석과 사본 정리까지 완료되면 사본 해시와 자료 세대를 분석 결과와 함께 내부용으로 반환합니다. 해시·세대·경로·원본·픽셀은 기존 화면 및 공유 DTO에 추가하지 않았습니다. [등록 사본 어댑터](../../lib/reference-analysis/registered-snapshot.ts) · [관리 사본 구현](../../lib/reference-analysis/local-file.ts)

등록 파일 경로는 관리 루트 밑의 정규 경로와 일치해야 합니다. 내부 디렉터리 링크와 하드 링크를 거절합니다. 복사 전후 같은 파일 핸들의 식별 정보와 크기·변경 시각을 비교하고 형식 검사 전과 분석 뒤에 원본 경로를 다시 확인합니다. 관찰 구간에서 교체나 불일치가 확인되면 근거와 해시 증명을 내보내지 않습니다. 기존 64MiB 제한, 취소·시간 초과와 사본 정리를 재사용합니다.

등록 소유자와 활성 자료·링크/권한·복원 세대의 실제 조회는 호출자에게 남아 있습니다. 어댑터에 전달된 세대는 내부 결과에 묶이며 등록 권한의 증거로 검증되는 값은 아닙니다. 제품 연동에는 서버 관리 경로 밖에서 파일을 바꿀 수 없는 권한 경계와 분석을 저장할 때의 현재 권한·세대 재확인이 필요합니다. | 격리 합성 표본 | 결과 |
| --- | --- |
| MP4, M4A, PNG | 해시가 일치하는 파일에서 영상 프레임·오디오 표본·이미지 색 영역을 반환했습니다. MP4는 프로브와 디코더가 같은 관리 사본을 읽었고, 그 경로의 바이트를 시험에서 재해시해 등록값과 대조했습니다. |
| 같은 크기의 다른 바이트, 내부 디렉터리 링크, 하드 링크, 64MiB 초과 | 분석 근거와 증명을 반환하지 않았습니다. 영상 사례에서는 프로브 실행도 없었습니다. |
| 프로브 시작 후 동일 바이트의 다른 파일로 교체 | 원본 파일 식별 정보가 달라 결과 전체를 폐기했습니다. 사본 경로는 정리됐습니다. |
| 취소와 시간 초과 | 실제 자식 종료를 기다렸고, 사본 정리와 분석 근거·증명 미출력을 확인했습니다. |
| 미등록 해시·세대 및 화면/공유 투영 | 잘못된 등록 정보를 거절했습니다. 기존 투영에서 해시, 세대, 파일명, 경로와 픽셀 제외를 확인했습니다. |
