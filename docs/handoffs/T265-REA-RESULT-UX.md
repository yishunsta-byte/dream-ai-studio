# T265 레퍼런스 분석 결과 시안

Codex Design · 배정 `msg_fd7567c98515` · 수락 `msg_5dd43bdc07a0` · ready_review.

브라우저에서 HTML을 바로 열고 합성 표본을 고릅니다. **표본 분석 시작 → 분석 중 상태 보기 → 합성 결과 보기**를 누르면 근거와 편집용 프롬프트를 탐색할 수 있습니다. 작업 상태 버튼에서 실패, 재시도, 취소 요청, 종료 확인, 빈 결과도 체험할 수 있습니다. [로컬 시안](../design/rea-analysis-prototype.html)

## 화면과 계약

- 입력 영역은 합성 표본, URL, 파일 및 본문으로 나뉩니다. URL은 조회 없이 본문 또는 캡처 파일로 전환합니다. 대체 입력의 내용은 분석하거나 결과로 복제하지 않습니다. 표본의 형식·크기·길이는 T263에서 확인한 합성 표본의 메타데이터 예시를 사용합니다. 관찰·추정 및 캔버스 파형·이미지·영상 위치표는 시안을 위해 만든 도식입니다.
- **관찰**은 영상·음악의 타임코드 또는 이미지 정규화 영역을 표시하고 도식의 강조 영역을 바꿉니다. **파일 메타데이터**는 별도 카드로 표시합니다. **추정**은 관찰까지 역으로 탐색할 수 있고, 해당하는 경우 대안을 함께 씁니다. **확인 불가**에는 확인하지 못한 항목을 적습니다.
- **제작자 공개 문구**는 별도 합성 본문 예시로 표시합니다. 매체의 관찰·메타데이터와 출처를 합치지 않습니다. 실제 구현에서는 제출자가 공개 문구로 지정한 본문의 정확한 인용과 원본 UTF-16 반열린 구간을 대조해야 합니다. 제출자 표지가 제작자 신원 확인을 뜻하지 않습니다.
- **편집용 프롬프트**는 분석 근거에서 착안한 제작 제안입니다. 사용자에게 표현 방향 선택과 별도 편집 메모를 제공합니다. 기본 복사는 화면에 보이는 구성된 문구만 사용합니다. 미리보기와 복사 payload는 같은 텍스트입니다. 입력 본문·URL·파일명·비공개 근거 원문·자유 편집 메모는 이 payload의 재료에서 제외합니다. 클립보드가 거절되면 미리보기 문구를 선택하고 수동 복사를 안내합니다.

## Front 구현 명세와 검수 기준

1. T263 입력 상태 `ready`, `replacement_required`, `invalid`를 구분합니다. 접근 제한과 권한 미확인의 URL은 이유와 본문·캡처·파일 대안을 인접 배치합니다. 지원 URL 정규화와 공급자 열람 성공 여부는 실제 연결 계약을 따릅니다. 파일은 서버가 소유권·실제 byte 상한·실제 유형을 검증합니다.
2. 서버 작업 식별자로 대기 → 진행 → 완료/실패 상태를 바인딩합니다. 취소 요청 뒤에는 종료 확인을 기다립니다. 종료 확인을 받은 작업의 화면에는 늦게 도착한 이전 응답을 적용하지 않습니다. 실제 서버 상태로 파일 손상, 도구 부재·실패, 시간 초과를 구분하고 해당 사유에 맞춰 재시도를 제공합니다. 시안에서 수동 버튼으로 넘기는 상태는 제품에서 작업 이벤트를 통해 전환합니다.
3. 소유자 전용 결과와 복사·공유용 출력을 분리합니다. 비신뢰 원문과 메타데이터를 평문으로 표시하고, 공유 인터페이스는 별도 허용 필드로 조립합니다. 기본 복사에 자유 편집 텍스트를 자동으로 합치지 않습니다. 프롬프트의 생성 제안과 원본 제작 설정을 별도로 취급합니다.
4. 실제 재생과 연동할 때 영상·음원 길이를 확인하고 시작점과 종료점을 검사합니다. 길이를 모르면 탐색 동작을 막고 이유를 표시합니다. 이미지 영역은 실제 이미지의 표시 사각형에 매핑합니다. 출처와 맞지 않는 위치 또는 존재하지 않는 직접 근거는 결과로 노출하지 않습니다. 결과가 비면 프롬프트와 위치 조작을 제공하지 않습니다.
5. 1280px의 입력/결과 두 열과 390px의 한 열 배치에서 DOM 순서를 유지합니다. 상태 안내는 `aria-live`, 결과 탭은 방향키·Home·End, 근거 위치는 텍스트와 시각 표시를 함께 사용합니다. 완료 후 첫 탭, 취소 확인 대기 중 다음 상태 조작, URL 대체 후 대상 필드의 초점을 유지합니다. 링크·버튼은 44px 이상을 확보합니다.

관련 기준은 5836075, T263-R 및 REA 2 개발표입니다. T263-R에서 확인된 시간 상한, 소유자/공유 경계, 작업 종료·예산은 제품 연결 시 검증해야 합니다. [T263-R 검수](T263-R-REA-LOCAL-CONTRACT-REVIEW.md)

## 자체 검증

- Ego Chromium에서 HTML을 파일로 직접 열어 1280px·390px를 검증했습니다. 두 폭에서 초기 빈 화면, URL→본문, 입력이 알림에 재노출되지 않음, 취소 요청과 확인, 실패·재시도·완료 후 빈 결과, 표본 3종의 근거 위치, 인용 위치, 완료 포커스, 방향키 탭 전환, 표현 수정, 기본 복사 범위, 가로 넘침 0과 노출 버튼 높이 44px 이상을 확인했습니다.
- 390px에서 URL→파일 선택 필드 포커스와 파일 미선택 안내, End 키 탭 이동, 클립보드 거절 시 허용 문구 선택을 확인했습니다. 클립보드 성공·거절을 브라우저에서 모의해 호출 payload와 fallback을 검사했습니다. OS 클립보드에 직접 기록하거나 실제 파일을 첨부하지 않았습니다.
- 캡처는 `tmp/t265/evidence-1280.png`, `evidence-390.png`, `prompt-390.png`입니다. 1280px·390px 근거 화면을 직접 확인했습니다. 반복 실행 스크립트는 `tmp/t265/qa-final.mjs`, `fallback.mjs`입니다. 검증 후 결과 탭을 사용자 확인용으로 남겼습니다.
- 검증 범위는 로컬 상태 전환과 접근성 구조입니다. 실제 분석·실시간 작업 종료·공유 서버·물리 모바일·스크린리더·제품 구현과 배포는 후속 범위입니다.
