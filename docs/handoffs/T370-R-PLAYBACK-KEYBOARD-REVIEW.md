작품 버튼에서 Enter로 상세를 열었을 때 닫기 버튼에 초점이 왔다. Tab으로 플레이어에 진입하고 Shift+Tab으로 닫기에 돌아갈 수 있었다. 네 조합 모두 표지 오류 문구가 표시됐고 가로 넘침은 0px이었다. 영상의 실패한 `poster`는 생략됐고 대체 영역은 포인터 이벤트를 받지 않았다. 파일을 열기 전까지 상세 진입만으로는 재생 파일 요청이 없었다. 오류는 `role=status`로 표시됐고 Escape 뒤 기존 플레이어 객체가 일시정지 상태임을 확인했다.

MP4와 M4A는 FFmpeg로 생성한 7초 시험 파일이다. 실제 Chromium이 디코딩하고 재생한 구간은 각각 0.23–0.25초와 0.27–0.30초였다. 첫 404를 유도할 때만 시험 스크립트가 `play()`를 호출했다. 준비 전 플레이어의 Space만으로 첫 재생 요청이 시작되는지, 브라우저 기본 탐색 막대와 각 버튼의 순차 키보드 동작은 이 결과에 포함되지 않는다. 검수 범위는 소유 루프백의 시각·초점·미디어 응답이며 공개 재생 권한, 운영 저장소, Vercel, 모바일 실기기와 화면 낭독기의 음성 출력을 포함하지 않는다. 외부 요청, 제품 코드 변경, 운영 변경은 0건이었다. 시험 서버는 종료했다.
