# T348-F1 관리자 메뉴 현재 위치 접근성

2026-11-19 KST · Codex(design) · 기준 `865d269` · 배정 `msg_ea27ba993461`

관리자 메뉴 링크에서 주소의 현재 프래그먼트와 일치하는 항목 하나에 `aria-current="location"`을 제공합니다. URL 변경을 구독하는 코드는 관리자 메뉴 컴포넌트에만 있습니다. 링크는 기존 브라우저 프래그먼트 이동을 사용하며 본문 초점과 CSS 강조는 기존 동작을 따릅니다. 프래그먼트가 없거나 알려진 섹션이 아니면 개요가 현재 위치입니다. 서버에는 주소의 프래그먼트가 전달되지 않아 첫 HTML은 개요를 표시하고, 브라우저에서 컴포넌트가 연결되면 직접 지정된 섹션을 반영합니다.

## 자체 검증

- 관리·인증·게시·세션 보호 시험 13개 파일 296개와 변경 경로 ESLint가 통과했습니다. 기존 집중 시험은 서버 HTML에 현재 링크가 개요 하나인지 확인합니다.
- 격리 Chromium에서 직접 해시 진입, URL 인코딩된 해시, 없는 해시와 알 수 없는 해시, 메뉴 클릭, 뒤로·앞으로 가기를 검증했습니다. 각 상태에서 `aria-current` 링크가 한 개이며 화면에서 강조된 링크와 일치했습니다.
- 320px·390px·1280px에서 기존 메뉴 레이아웃을 확인했습니다. Tab·Enter로 네 링크를 열었을 때 각 본문 영역에 초점이 이동했으며 계정 설정 다음 Tab은 비밀번호 변경 링크로 이동했습니다.

브라우저 접근성 속성과 키보드를 검증했습니다. 스크린 리더 음성 검증 및 운영 배포는 이번 범위 밖입니다.

**Master 전달문** — 관리자 메뉴에 `aria-current="location"`을 적용했습니다. 최초 해시·기본·클릭·Tab/Enter·뒤로/앞으로에서 CSS 강조와 해당 속성의 일치를 확인했습니다. 296개 시험과 변경 경로 린트를 통과했습니다.
