## 1. 만든 것

`docs/handoffs/P1-USER-REVIEW.html` — 은영님이 한 장으로 P1 흐름을 훑어볼 수 있는 페이지.

1. **상단 상태 칸**(맨 먼저 보임): "아직 확인을 부탁드리는 단계가 아니에요" + `독립 검수 불통과`. 남은 일 5줄 — F-016-1 장면 실패 안내(고치는 중), F-016-2 내보내기 정보(고치는 중), V13 남은 접근성(390 검수표 입력·키보드 연속 흐름), 독립 재검수(대기), 은영님 확인 = 흐름 + 디자인 시안 승인(대기, 둘 다 끝나야 P2). 숫자는 R-016 기준(191개, 12/13, 2건)이고, Master T-022의 207개는 "만든 쪽 확인, 독립 검수 대신 아님"으로 따로 적음.
2. **전체 흐름 한눈에**: 등록 → 요구 확인 → 기획 승인 → 장면 제작 → 수정·조립 → 검수 승인 → 내보내기. 잠금·승인 규칙 한 문장.
3. **화면 8장**: 캡처마다 단계 이름, 한 줄 제목, "보실 것" 2~3개. 문장은 실제 캡처에 보이는 것만 적음(예: 6번 "광고 표기는 위치만 변경", 7번 "필수 13개 중 13개 통과").
4. **샘플과 편집용 묶음 설명**: 샘플 표시·0원·`_SAMPLE`, P3에서 실제 AI. 묶음 폴더 구성(PLAN 13장 기준, P1에 있는 폴더만 + final/은 P2부터).
5. **휴대폰 2장 + 실패 1장**, 각 그림 설명.
6. **나중에 확인하실 때**: 수정·재검수 후 갱신해 다시 알림, 그때 `P1 확인했어` 또는 번호+고칠 점. 디자인 시안 링크(`../design/prototype.html`).

**수정 후 교체 예정 표시**: `flow-08`, `flow-m-export`, `flow-fail` 세 장은 그림을 흐리게(`.shot.pending`) 하고 노란 딱지("수정 후 새 화면으로 바꿀 예정"/"수정 후 교체 예정")를 붙였다. 옆에 "지금 화면에서 고치는 중" 상자로 무엇이 바뀌는지 적었다(T-013 명세 기준).

**교체 순서**
1. 새 캡처를 `tmp/p1-review/`에 넣는다. 원래 캡처를 남기려면 `-v2` 이름으로 넣고 페이지의 `src`만 바꾼다(원본 덮어쓰기 없음).
2. 바꾼 그림의 `<div class="shot pending">` → `<div class="shot">`, 그 안 `<div class="flag">…</div>` 삭제, `alt` 문구를 새 화면에 맞게.
3. 8번과 실패 그림 옆 `<div class="fix">` 상자를 "보실 것" 목록으로 바꾼다(고친 점을 확인 항목으로).
4. 상단 상태 칸: 배지와 5줄을 실제 결과로 갱신(예: `독립 검수 통과`, 고치는 중 → 완료). 숫자 칸을 재검수 보고 기준으로. "지금은 답하지 않으셔도 돼요" 문장은 **재검수 통과 뒤에만** 확인 요청 문장으로 바꾼다.
5. 1280·390 넘침 0, 그림 로드, 개인정보·경로 없음 다시 확인.

**공유 방법(선택)**: 이 페이지는 저장소 안에서 `tmp/` 그림을 상대 경로로 읽는다(`tmp/`는 git 제외라 그림은 커밋되지 않음). 은영님께 링크로 보내려면 그림을 함께 묶어 claude.ai 아티팩트로 올릴 수 있다(이미 준비한 비공개 페이지 방식, 그림 경로만 `flow-01.png` 식으로 바꿈). 올리는 것은 Master가 요청할 때만 한다.
