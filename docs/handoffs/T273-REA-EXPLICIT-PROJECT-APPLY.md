# T273 REA 미리보기의 명시적 프로젝트 적용

## 적용 범위

기존 타임라인은 현재 선택된 장면의 순서와 `{ type: "cut", durationFrames: 0 }` 전환을 저장합니다. 이 범위에서만 컷 후보를 적용합니다. 사용자가 지정한 기존 장면을 다른 기존 장면 바로 뒤로 옮깁니다. 두 장면 모두 같은 프로젝트의 저장된 타임라인에서 소재가 연결돼 있어야 합니다. 나머지 장면과 클립의 값, 텍스트와 오디오의 절대 시각을 보존합니다. 확인 요약에 이동 전후 위치와 시각을 유지하는 텍스트·오디오 항목 수를 반환합니다. [REA 적용 서비스](../../lib/reference-analysis/project-apply.ts) · [타임라인 서비스](../../lib/services/timeline.ts) · [타임라인 저장소](../../lib/repo/timeline.ts)

1. `prepare`는 검증된 액터, 활성 프로젝트·소스·분석 리비전, 미리보기 신선도, 선택한 컷, 현재 타임라인 ID·내용 리비전과 이동 대상을 대조합니다. 확인 요약과 같은 서비스 인스턴스에서 쓰는 불투명 객체를 반환합니다. 이 단계는 읽기 전용입니다.
2. `apply`는 같은 액터와 해당 객체, 명시적으로 전달한 `true`가 필요합니다. 쓰기 트랜잭션에서 최신 권한과 근거, 신선도, 타임라인 및 대상 장면을 다시 대조합니다. 기존 `timelineService.save`의 CAS와 워크플로를 사용하므로 새 리비전 생성, 포인터 이동과 후속 단계 무효화가 함께 처리됩니다.
3. 먼저 성공한 적용이 타임라인 ID와 내용 리비전을 진행시킵니다. 같은 기준의 재전송과 경쟁 요청은 충돌합니다. 최신 화면에서 같은 위치를 다시 제안하면 `no_change`를 반환합니다. 저장 실패 시 트랜잭션이 롤백되며 동일 확인으로 재시도할 수 있습니다.

원본 탐색 PTS와 30fps 편집 격자 근사는 미리보기에 남습니다. 프로젝트 배치는 명시 선택한 장면 위치를 사용합니다. 적용 요약 및 새 타임라인에는 참조 URL·파일명·원문·픽셀·PCM과 분석 식별자·프롬프트·근거가 추가되지 않습니다.

## 연동 경계

기존 타임라인 스키마에는 프롬프트·참조 근거 저장 위치가 없으며, 이미지·음악 초안을 실제 장면 버전 또는 선택 오디오 자산으로 만드는 계약도 별도입니다. 이미지·음악 제안과 프레임 단독 관찰은 적용 후보에서 제외했습니다. 역할별 권한 및 현재 프로젝트·소스·분석 상태는 실제 서버 호출자가 제공해야 합니다. 새 서비스는 `resolveOwnedScope`를 호출하며, 소유권·연결 관계·활성 상태를 확인할 수 없으면 조회자는 `null`을 반환해야 합니다. 트랜잭션 일관성이 필요한 조회는 제공된 DB 연결을 사용합니다. 제품의 실제 권한 조회·시작 점검·확인 요청 연계와 다중 프로세스 간 확인 객체 연결은 후속 범위입니다. 기존 서비스·라우트·스키마는 그대로 사용했습니다.

## 검증

격리된 합성 S4 사본을 실제 마이그레이션한 뒤 다음을 확인했습니다.

- 확인 전과 거부 후 DB 스냅샷이 같았습니다. 소유자 확인 후 선택한 장면만 이동했고 내용 리비전은 1 증가했습니다. 기존 리비전 행과 텍스트·오디오 값이 보존됐고 검수 단계는 잠겼습니다.
- 다른 액터·프로젝트, 변조한 확인 객체, 철회한 소스, 변경된 소스·분석 리비전, 만료, 빈 장면·프로젝트 밖 장면과 허용 범위 밖 제안을 거절했습니다.
- 연결 두 개에서 독립적으로 준비한 같은 기준의 확인 중 첫 번째만 적용됐습니다. 포인터 갱신 실패를 주입했을 때 전체 변경이 롤백됐고 이후 재시도는 한 번만 저장했습니다.
- 기본 REA 10개 테스트 파일에서 **80 통과·45 건너뜀**, 네이티브 REA와 기존 타임라인·오디오 계약을 포함한 12개 파일에서 **161/161** 통과했습니다. 범위 TypeScript `tsc -p tmp/t273-rea-typecheck.json`와 변경 파일 ESLint `--max-warnings 0`도 통과했습니다. [집중 시험](../../tests/reference-analysis/project-apply.test.ts)
