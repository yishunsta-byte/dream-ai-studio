# T282-F1 대기 중인 적용 요청의 종료 전 권한 확인

기준 `0893fc7` · Backend 자체 검증

합성 저장소에서 실행 만료, 분석 변경, 타임라인 리비전 충돌로 대기 요청을 종료하기 전에 같은 트랜잭션에서 확보한 권한 범위와 링크·범위·소유자 권한 세대를 검사합니다. 명시적 취소에도 같은 검사를 적용합니다. 권한 정보가 없거나 일치하지 않거나 이전 방식의 권한 세대만 일치할 때는 `unavailable`을 반환하며 요청 행과 계획을 포함한 DB 전체를 보존합니다. 권한이 확인된 요청은 기존 판정에 따라 종료됩니다. 완료 v2의 적용 결과 확인과 재전송은 공통 조회 경로를 사용합니다.
