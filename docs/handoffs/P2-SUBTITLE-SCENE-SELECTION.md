# 자막 선택 목록의 장면과 시간

편집 목록은 초안의 영상 순서와 프레임 길이로 자막이 걸치는 장면을 표시한다. 장면 경계에서 끝나는 자막은 다음 장면을 포함하지 않는다. 구간이 여러 장면에 걸치거나 마지막 장면을 지나면 마지막 위치도 표시한다.

격리된 Chrome과 SQLite 프로젝트에서 같은 문구의 자막을 0~2초와 2~4초에 저장했다. 1280px와 390px에서 장면 번호와 시간이 구분되고 Enter로 두 번째 자막을 선택했다. 두 너비 모두 가로 넘침은 0px였다. 390px에서 두 번째 문구를 수정해 저장한 후 첫 번째 문구, 영상 목록, 이전 리비전 JSON이 보존됨을 확인했다. 장면 단위 테스트 6건 및 타입 검사 통과.
