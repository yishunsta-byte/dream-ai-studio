## 재현과 판정

1. `compare.html`을 열고 **접근 거절**을 선택한다. 주소가 `#admin-login`으로 바뀌고 **관리자 화면에 접근할 수 없어요**가 표시된다.
2. 주소를 새 문서에서 연다. 390px와 1440px 모두 주소는 `#admin-login`인데 **내 프로젝트 2개**와 관리자 메뉴가 표시된다. 기대 결과는 접근 거절 상태 선택, 로그인 안내 표시, 관리자 메뉴와 목록 숨김이다.
3. 스크립트는 새 문서에서 `showScenario("list", false)`를 호출하고 `renderRoute`가 `admin-login`을 알려진 프래그먼트에서 제외한다. 직접 열기와 새로고침에서 접근 거절 상태를 유지하는지 수정 후보에서 확인한다. 시안의 시험 데이터에서 관찰한 표시 결함이다.

나머지 관리자·개인 프래그먼트 5개는 직접 열었을 때 해당 화면을 표시했다. Enter로 관리자 목록을 선택하면 제목에 초점이 갔고, Tab·Enter로 상세를 연 뒤 브라우저 뒤로 가기에서 관리자 **내 프로젝트**와 목록 제목 초점이 복원됐다. 직접 연 프래그먼트에서는 제목에 초점을 보내지 않았다. 두 폭에서 가로 넘침 0px, 보이는 조작 높이 44px 이상이었다. 요청은 HTML 14건, 글꼴 14건, 브라우저의 favicon 30건이었다. API 및 운영 요청은 0건이며 제품·운영 변경은 없었다.
