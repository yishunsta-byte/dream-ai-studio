# T370 공개 재생 후보 독립 화면 검수

Git 아카이브의 공개 홈 구성 요소와 CSS, 작품 DTO 해시를 후보와 대조했다. 절차는 Chromium 390px·1440px에서 실행했다. 루프백에 시험용 MP4·MP3를 연결했고 목록의 빈 상태·철회 상태와 미디어 실패 응답은 격리 대역을 사용했다. `next/image`는 로컬 이미지 태그로 대체했다.

| 항목 | 독립 검수 결과 |
|---|---|
| 기본 소개 작품 | 대표 설명과 예시 전용 안내가 나타났고, 상세는 재생 파일 미연결을 설명했다. 영상·음악 재생기 없음. |
| 첫 재생·탐색·닫기 | 두 폭에서 영상과 음악 모두 Tab으로 기본 재생에 들어가 Space로 시작했다. 별도 루프백 실행에서 두 매체를 2초로 탐색했다. Escape 뒤에는 상세를 연 버튼으로 초점이 돌아왔다. |
| 재생 실패·재조회 | 영상 503 대역에 실패 안내와 다시 불러오기 표시. 재조회 후 실제 미디어가 준비되고 영상으로 초점이 돌아왔다. |
| 철회·빈 목록 | 철회된 영상이 제외된 새 응답에는 영상 카드가 없고 남은 음악은 표시됐다. 빈 응답은 공개 작품이 없다는 안내와 재생기 0개를 표시했다. |
| 공개 분석 링크·반응형 | 기존 `/analysis-results`로 키보드로 이동. 두 폭에서 가로 넘침 0. |
