## 만들어 둔 동작

- 공통 5개 화면 이동, 새 프로젝트 안내 창, 계정 안내 창.
- 편집 문구 입력 → 미리보기와 미저장 표시 → 시안 안에서 저장. 재생·소리 버튼은 연결되지 않은 예시임을 안내.
- 영상 결과의 진행 중·성공·실패 전환, 재시도, 취소 확인. 진행 중에는 가짜 완료율·남은 시간을 표시하지 않는다. 성공 수치·파일명은 예시다.
- 개인 관리의 시작 점검·작업 대기열·백업 위치 저장·백업 대기·복원 검사 안내. 입력한 경로는 시안 내 재그리기에서도 유지된다. 실제 디스크에 접근하지 않는다.
- 이메일 입력 후 메일함 안내 화면. 실제 메일 발송·계정 검증·인증 요청 없음.
- 모달과 모바일 메뉴의 Tab/Shift+Tab 순환, Esc 닫기와 초점 복귀. 현재 화면 표시·본문 건너뛰기·입력 레이블·알림 영역 제공.

개인 관리는 T180의 개인 사용 범위로 구성했다. 저장 점검 통과와 전체 기능 검증, 처리기 최근 응답과 작업 성공, 백업 성공 이력과 현재 파일 존재를 구분한다. 이전 환경 이력을 현재 환경의 마지막 성공으로 합치지 않는다. ZIP은 완성 MP4나 합친 소리가 아니며 다시 불러오기를 지원한다고 표시하지 않는다.

## 제한과 다음 단계

이 결과는 3개 디자인을 비교하는 **동작 가능한 로컬 시안**이다. 저장·렌더·다운로드·로그인·백업·복원은 시뮬레이션이다. 메모리는 새로고침 시 초기화된다. 실제 미디어, 이메일 발송, Supabase/Vercel 연결, 최신 제품 상태 연동, 사용자 데이터 기반 빈 화면·모든 오류 상태, 실제 휴대폰·스크린리더·완전한 접근성 적합성은 검증하지 않았다. 전체 P2 완료나 배포 완료를 주장하지 않는다.

Master는 비교 페이지와 3개 개인 관리 화면을 사용자에게 보여 주고, 최종 선택 뒤 별도 작업 ID로 제품 적용 범위를 배정하면 된다. 백엔드 연동·권한·DB 변경은 이 시안의 후속 자동 승인 범위가 아니다.
