## 접속 경로와 재개 조건

- 운영에서 이미 확인된 경로는 기존 Supabase HTTPS Data API에 대한 공개키 기반 무자료 읽기 요청이다. 앱의 선택형 HTTPS 어댑터는 검증된 사용자 JWT를 전달하고 공개 목록·상세 읽기 뷰를 사용한다. 이 경로의 운영 사용자 조회는 스키마 노출과 DB 확인을 기다린다. [앱 연결](T356-PROJECT-HTTPS-READ-APP-INTEGRATION.md)
- PostgreSQL 직접 읽기 어댑터는 로컬에서 소유자 확인과 TLS로 목록·상세를 검증했다(`5da505b`). 과거 메인 PC의 운영 Direct IPv6 연결은 실패했다. Session pooler는 과거 넓은 관리 역할로 접속했고 DB 세션의 SSL 표시는 false였다. 이번 프로세스의 연결 설정 이름과 표준 서비스 프로필 파일 존재 여부를 확인한 결과, 운영에 사용할 승인된 제한 프로필 근거는 추가로 발견되지 않았다. [기존 연결 기록](T346-EXISTING-PROJECT-READ-PREFLIGHT.md) · [경로 비교](T347-EXISTING-PROJECT-READ-CONNECTION-OPTIONS.md)
- MASTER가 동일 운영 대상의 기존 승인 제한 세션 위치와 프로필 이름을 확인하거나, 운영 DB 권한자가 실행 시각·대상 일치·항목별 판정만 전달하면 재개한다. 읽기 전용 트랜잭션에서 준비된 9개 점검을 대조한다. 이력 열람 권한이나 카탈로그 가시성이 부족하면 해당 항목을 미확인으로 남긴다. 개인 프로젝트 행과 승인 사용자 UUID는 카탈로그 판정에 필요하지 않다. [읽기 판정 기준](T362-R-PROJECT-READ-ACTIVATION-REVIEW.md)
- 완전 설치와 최소 권한 일치가 확인되면 재설치 없이 노출·운영 검증의 별도 적용 판정으로 진행한다. 미설치면 설치 전제를, 부분 설치나 과다 권한이면 차이와 소유자를 MASTER에게 돌려준다. 사용자가 볼 운영 목록·상세의 최종 판정에는 실제 운영 런타임의 승인 시험 계정과 허용된 시험 자료로 행 격리를 확인하는 단계가 남아 있다. [전환 및 복귀 기준](T362-R-PROJECT-READ-ACTIVATION-REVIEW.md)
