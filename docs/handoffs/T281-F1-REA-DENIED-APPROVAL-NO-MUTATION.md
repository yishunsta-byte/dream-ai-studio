# T281-F1 REA 승인 거절의 무변경 보장

2026-11-19 KST · Codes(Backend) · 기준 `4d586b67dbc39ef0d29e8d1a30bd551625fdc586` · 배정 `msg_35fa05665339`

기준 후보에서는 소유자 잠금 함수가 생성한 초기 행이 승인 거절 뒤에도 커밋됐습니다. 같은 입력을 고정 코드에 재현해 미등록 소유자의 초기 행과 비활성 범위 행이 남는 것을 확인했습니다. 수정한 권한 함수는 소유자 행 생성·잠금부터 승인 또는 철회까지를 PL/pgSQL 서브트랜잭션에 넣습니다. 예상된 거절 또는 상태 변화가 없는 경우 전용 SQLSTATE를 발생시켜 내부 변경을 롤백한 뒤 `false`를 반환합니다. 다른 SQL 오류는 기존 경로로 전달합니다. 정상인 요청은 종전의 고유 키와 소유자 잠금 순서로 직렬화합니다.
