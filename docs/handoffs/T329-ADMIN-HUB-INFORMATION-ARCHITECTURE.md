# T329 관리자 화면 메뉴 재구성

2026-11-19 KST · Codex(design) · 기준 `fa52ca4` · 배정 `msg_41ce9917ef00` · 회귀 단언 승인 `msg_dafbeb2bd027`

`/admin`에 개요, 내 프로젝트, 완성본 검수·게시, 계정 설정으로 바로 이동하는 메뉴를 배치했습니다. 넓은 화면에서는 왼쪽 메뉴를 고정하고 좁은 화면에서는 본문 위에 2열 메뉴를 표시합니다. 각 메뉴는 일반 프래그먼트 링크이며 키보드로 활성화하면 제목이나 이름이 연결된 해당 영역으로 초점이 이동합니다.

내 프로젝트는 기존 계정 범위 읽기와 상세 링크를 사용합니다. 게시 영역은 기존 `PublicationHttpQueue`와 서버의 첫 목록을 그대로 받아 기존 검수·게시·철회 동작을 제공합니다. 둘 다 기존 인증 및 세션 보호 영역 안에 있습니다. 개요는 기존 클라우드 개인 관리와 프로젝트 화면으로 이어지고, 계정 설정은 현재 계정과 기존 비밀번호 변경 경로를 제공합니다. 미연결·실패·빈 목록과 정상 목록에 대한 구분은 공급자와 기존 컴포넌트의 실제 상태를 따릅니다.

## 운영 연결에 남은 항목

계획 5장과 현재 경로를 대조했습니다. 작업 큐·자료·백업·활동 기록의 로컬 작업실 화면과 일부 API는 존재하지만, 클라우드 관리자용 조회와 권한 계약에 해당하는 공급자를 찾지 못했습니다. 회원 관리와 통합 서비스 상태 공급원 역시 관리자 허브에 연결돼 있지 않습니다. 아래 항목은 화면에 상태와 범위만 표시했습니다.

| 항목 | 운영 연결에 필요한 기능 |
| --- | --- |
| 작업 대기열 | 서버 작업 상태와 취소·재시도 가능 범위 조회 |
| 자료 관리 | 원본·렌더·ZIP 사용량, 참조·보관 및 권리 기록 |
| 백업·복원 | 최근 백업 결과, 사본 존재, 복원 요청 단계 |
| 운영 로그 | 민감값을 제외한 오류·활동·요청 이력 |
| 회원 관리 | 회원·역할 범위와 별도 권한 계약 |
| 서비스 상태 | 작업 처리기 최근 응답, 파일 저장소와 백업 점검 결과 |

내 프로젝트 목록은 기존 클라우드 프로젝트 읽기 설정에, 게시 쓰기는 기존 운영 게시 공급원과 권한 설정에 의존합니다. 이번 변경은 화면 구성 범위입니다.

## 자체 검증

- 고정 `fa52ca4` 사본에 T329 변경만 적용해 관리자·로그인·재설정·게시·공용 인증 시험 11개 파일, 254개를 통과했습니다. 집중 시험 3개는 메뉴 대상, 미연결 운영 항목의 링크·버튼·통계 부재, 실제 프로젝트·게시 큐의 빈 목록 및 실패 상태를 검증했습니다. 기존 큐의 정적 JSX 단언 한 줄을 새 배치에 맞췄습니다. Next 타입 생성과 전체 `tsc --noEmit --incremental false`, 변경한 TypeScript 파일 ESLint도 통과했습니다.
- 격리 Next 및 헤드리스 Chromium에서 미인증 `/admin` 로그인 이동, 운영 공급자 없는 화면, 합성 조회 성공·빈 결과·실패 상태를 확인했습니다. 1280px에서는 왼쪽 메뉴와 본문, 390px 및 320px에서는 본문 위의 2열 메뉴가 표시됐고 가로 넘침이 없었습니다. 네 메뉴의 실제 클릭 영역은 48px였으며 Tab·Enter로 각 대상에 초점이 이동했습니다. 계정 설정에서 다음 Tab은 비밀번호 변경 링크로 이동했습니다.
- 격리 화면 캡처는 로컬 `tmp/t329/admin-desktop.png`(1280px 미연결), `tmp/t329/admin-desktop-linked.png`(1280px 합성 목록), `tmp/t329/admin-mobile-full.png`(390px 합성 빈 목록)에 있습니다.

실제 운영 계정과 게시 데이터, 물리 모바일 기기, T328 데이터베이스는 사용하지 않았습니다. 운영 푸시와 배포는 이번 범위 밖입니다.
