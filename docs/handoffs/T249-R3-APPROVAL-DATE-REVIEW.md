달력 검사는 원문 연도에 그레고리력 윤년 규칙과 월별 일수를 적용한다. `Date.UTC`의 0–99년 재해석이 사라져 이전에 거절된 `0000-02-29T00:00:00Z`, `0001-01-01T00:00:00Z`, `0004-02-29T00:00:00Z`, `0099-12-31T23:59:59.999-01:00`이 모두 통과했다. 월·일·시각 범위를 검사한 뒤 `Date.parse`로 절대 시각을 비교하는 흐름은 유지된다.

독립 합성 검사에서는 `setUTCFullYear`에 연·월·일을 직접 지정하고 결과를 원문과 대조하는 방식으로 0000–0399년의 모든 월에서 28–32일 경계 24,000개를 검사했다. 변환 결과가 모두 일치했다. 전용 시험에서 0100년·1900년의 평년 윤일, 없는 날짜, 24:00, 잘못된 분·초·오프셋을 거절하고 0400년과 2000년 윤일을 허용함을 확인했다.

`0099-12-31T23:00:00-01:00`와 `0100-01-01T00:00:00Z`는 같은 시각으로 처리돼 ID 오름차순으로 정렬됐다. 두 입력보다 1ms 앞선 작품은 뒤에 표시됐다. 기준 시각과 같은 오프셋 입력은 허용하고 1ms 미래인 입력은 거절했다.
