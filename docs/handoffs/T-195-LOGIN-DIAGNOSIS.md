## 판단
1. **가장 큰 원인: 계정에 비밀번호가 없어요.** 어떤 비밀번호를 넣어도 로그인은 안 돼요. "비밀번호 찾기"로 처음 한 번 정해야 해요.
2. 18:36 로그인 400은 Supabase까지 가지 않았어요. 앱에서 400 INVALID_CREDENTIALS를 바로 돌려주는 경우는 다음뿐이에요.
   - (a) 입력한 이메일이 운영 허용 목록에 없음(예: r 붙은 주소, 오타)
   - (b) 비밀번호가 비었거나 72자 초과
   - 형식 오류는 INVALID_EMAIL이라 다른 문구예요.
   - 화면 검사상 (b)는 드물어서 **(a)일 가능성이 높아요.** 다만 운영 `DREAM_ALLOWED_EMAILS`는 Vercel Secret이라 값을 다시 읽을 수 없어요. 08:4x Z에 제가 r 없는 주소로 다시 넣었지만, 실제 값은 이번에 독립 확인하지 못했어요.
3. 로그인 후 화면은 원래 "클라우드 작업실 준비 중"이에요. 로그인에 성공해도 작업 화면이 없는 것은 데이터 미연결 때문이고, 로그인 실패와는 다른 문제예요.

## 주인님께 안내할 절차(비밀번호는 채팅으로 받지 않음)
1. 같은 브라우저에서 `https://dream-ai-studio-orpin.vercel.app/login` → **"비밀번호 찾기"**를 눌러요.
2. 이메일은 **r 없는 Gmail 주소**(지금 받은편지함 주소)를 그대로 넣어요.
3. Gmail에서 Supabase "Reset Your Password" 메일을 열어요(스팸·Updates 탭 포함). 링크는 같은 브라우저에서 열어요.
4. 새 비밀번호(8자 이상, 영문+숫자)를 두 번 넣어요 → 로그인 화면 → 그 주소와 새 비밀번호로 로그인해요.
5. "클라우드 작업실을 준비하고 있어요" 화면이 보이면 로그인 성공이에요(작업 기능은 아직 없음).

## 진단용 확인(주인님이 3단계를 하면 바로 판별)
- 재설정을 누른 직후 Supabase 인증 기록에 `/recover` + `mail.send`가 생기면, 허용 목록은 정상이에요.
- **화면에는 "메일을 보냈어요"가 나오는데 Supabase에 `/recover`가 없으면**, 운영 허용 목록 값이 틀린 거예요. 화면은 허용 밖 주소에도 같은 안내를 보여 주도록 설계돼 있어요.
  - 조치: Vercel `DREAM_ALLOWED_EMAILS`를 r 없는 주소로 다시 넣고 재배포해요(설정 변경이라 Master 승인 필요).
