# T-184 이메일·비밀번호 로그인과 회원가입

- 담당: Codex(Front)(term_a0a6f98c) · 지시: 주인님 직접(참고 화면 `login_concept_1.png`, "이 방식으로 가입 및 로그인 작업 해줘")
- 상태: 자체 검수(독립 검수 아님)

## 바뀐 것
- 로그인 화면: 가운데 카드, 아이콘 배지, 로그인/회원가입 탭, 아이콘 입력칸, 비밀번호 보기, 비밀번호 찾기. 색·글꼴은 이 앱 값을 썼어요.
- `POST /api/auth/login`: 이메일·비밀번호 로그인. 틀린 비밀번호·없는 계정·허용 밖 주소는 같은 안내. 메일 인증 전(403)·시도 과다(429)는 따로 안내.
- `POST /api/auth/signup`: 회원가입. 메일 인증을 마쳐야 계정이 쓸 수 있어요. 허용 밖·이미 가입한 주소도 같은 안내, 허용 밖 주소는 Supabase에 보내지도 않아요.
- `POST /api/auth/reset`: 비밀번호 찾기 메일 → `/auth/callback` → `/account/password`.
- `POST /api/auth/password` + `/account/password`: 로그인한 허용 계정만 새 비밀번호를 정해요. 바꾸면 로그아웃 후 로그인 화면으로.
- 비밀번호 규칙: 8~72자, 영문과 숫자를 함께.
- 로그인 없이 열리는 곳: `/login`, `/auth/callback`, `/api/auth/login|signup|reset`. `/account/password`는 로그인 필요.
- Supabase: "새 가입 허용"을 켰어요. "메일 인증 필수"는 그대로 켜짐.
- 약관 문구는 실제 문서가 없어서 넣지 않았어요.

## 주인님 확인이 필요한 것
- 기존 주인님 계정은 비밀번호가 없어요. 처음 한 번은 "비밀번호 찾기"로 정해 주세요.
- 실제 메일 받기(가입·재설정)는 Supabase 기본 메일이라 영어 문구·시간당 발송 제한이 있어요.
