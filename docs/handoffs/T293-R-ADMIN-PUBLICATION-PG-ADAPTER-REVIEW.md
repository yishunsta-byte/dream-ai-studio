| 항목 | 검증 결과 |
| --- | --- |
| 원자성·최초 manifest | 완료 명령의 쓰기 직후 COMMIT을 보류했습니다. 별도 관리 연결에서 앱 상태·원장·SQL 상태·원장·감사·manifest 스냅샷이 이전과 같았고, 공개 목록·표지에도 항목이 없었습니다. COMMIT 직후 응답 실패 뒤에는 앱·SQL이 모두 반영됐습니다. SQL 완료 요청이 최초 준비 manifest를 사용했고 앱의 manifest 참조, 앱·감사·공개 승인 시각이 일치했습니다. 다른 연결의 동일 UUID 재전송은 같은 성공을 돌려주고 스냅샷을 바꾸지 않았습니다. |
| A/B·공개 역할 | A/B는 각자 소유 행만 읽었습니다. 같은 UUID를 각기 소유한 별도 작품에 동시에 보냈을 때 양쪽 앱·SQL 원장에 독립 기록이 생겼습니다. SQL 권한은 공개 목록과 표지 로그인별로 분리됐고, 두 공개 역할 모두 쓰기 함수 실행 권한이 없었습니다. 앱 시험 로그인은 T253 직접 명령 실행 권한 없이 T293 게이트웨이 실행 권한을 가졌습니다. |
| 경쟁·대기 중 권한 철회 | 인계 실행에서 `pg_blocking_pids`로 동일 작품·UUID, 다른 작품에 동일 UUID, 완료와 철회의 양쪽 실행 순서를 재확인했습니다. 별도 독립 시험에서 UUID advisory lock을 잡고 기다리는 재전송을 관측한 뒤 게시자 권한을 삭제했습니다. 잠금이 풀린 재전송은 `denied`였고 스냅샷이 그대로였습니다. |
| 재시도와 공개 범위 | 쓰기 후 롤백, 저장소 전송 중 일시 실패, 앱·SQL 판정 불일치 이후 같은 UUID 재시도를 재확인했습니다. 대기 세대를 철회한 뒤 과거 준비 성공을 재생해도 표지는 공개되지 않았습니다. 게시 후 활성 세대를 철회하면 목록과 해당 표지가 비공개로 바뀌었습니다. |
| 시한부 권리 | 준비가 끝난 자료의 완료 시점에 만료 시각 누락과 미래 만료 시각을 각각 주입했습니다. `source-unavailable`이 앱 원장에만 남고 감사·manifest·SQL 상태·공개 결과는 바뀌지 않았습니다. 명시적 철회형 권리로 복구한 뒤에도 같은 UUID는 실패를 재생했고, 새 UUID로 정상 게시됐습니다. |

## F293-1 · 네이티브 실행기의 저장소 타입 검사 실패

저장소 `tsconfig.json`을 상속하고 `next-env.d.ts`와 고정본의 어댑터·실행기를 포함한 `tsc --noEmit`이 종료 코드 2를 반환했습니다. [`t293-admin-publication-native.ts:23`](../../tests/public-showcase/t293-admin-publication-native.ts#L23)의 허용 목록으로 구성한 하위 프로세스 환경은 Next가 확장한 `NodeJS.ProcessEnv`의 필수 `NODE_ENV`를 만족하지 않습니다. `execFile` 및 `spawn` 호출(35, 41, 69, 76행)의 `TS2769`와 후속 `TS2339`, `TS7006`이 발생했습니다. 인계의 범위 타입 통과 결과를 저장소 타입 환경에서는 재현하지 못했습니다. 허용 목록을 유지하면서 격리 시험용 `NODE_ENV`를 명시하고 같은 설정에서 재검증하는 것을 권장합니다.

관리자·공개·분석·인증 선택 회귀는 네이티브 분석 활성화 상태에서 **30개 파일 365/365**, 변경 TypeScript 파일 ESLint는 통과했습니다. PG 실행기와 독립 시험은 모두 임시 DB 프로세스, 루프백 리스너와 데이터 디렉터리 제거를 확인했습니다. 임시 커밋 사본도 제거했습니다.

## 운영 연결 전 범위

현재 T253 공개 목록과 표지는 만료 시각을 조건으로 쓰지 않습니다. 합성 어댑터는 `expiresAtMs === null`인 권리만 허용하므로, 이 결과는 명시적 철회형 권리의 시험 범위를 충족합니다. 시한부 권리를 사용하려면 목록과 표지 조회 양쪽에서 만료를 집행하는 계약이 필요합니다. 시험 앱 로그인은 쓰기 게이트웨이 실행 및 범위 내 원장 기록 권한이 있으므로 운영에서는 브라우저·운영자 세션과 신뢰 서버 접속 자격을 분리해야 합니다. 실제 Auth, 비공개 Storage, 운영 DB, 제품 라우트와 배포는 검수 범위 밖입니다.
