# T279 REA 등록 자료 소유권 대조

2026-11-19 KST · Codes(Backend) · 기준 `843be5c86265bd17b96cac43ccdef8b8f06b7e27` · 배정 `msg_b94af84bf4f5` · 독립 검수 대기

추가된 범위는 서버 내부의 **현재 등록 상태 조회**입니다. 관리형 Postgres에서 해당 시점에 소유자가 프로젝트와 자료를 연결하고, 등록 객체에 유효한 최신 스토리지 검증 기록이 있는지를 확인합니다. 조회가 성공해도 `analysisAuthority: "unavailable"`이며, 원본 분석이나 적용을 시작하는 호출부는 연결하지 않았습니다. | 경로 | 기존 코드에서 대조한 근거와 결과 |
| --- | --- |
| 로컬 SQLite | `projects`·`assets`에 사용자 소유자 열이 없고 `project_assets`는 연결과 용도만 가집니다. 로그인 비활성의 `kind: "local"`에 검증된 액터가 없습니다. 로그인에 성공해도 SQLite의 행 소유권을 보장할 수 없어 로컬 조회를 닫았습니다. 기존 합성 테스트 소유 모델은 사용하지 않습니다. |
| 기본 관리형 스키마 | 소유자 열·복합 FK·RLS, 현재 프로젝트 링크와 등록 해시가 있습니다. 스토리지 현재 검증 기록을 조회할 관계가 없는 기본 스키마에서는 안전한 실패로 끝납니다. 기본 자산이나 로컬 DB로 자동 대체하지 않습니다. |
| `0004_storage_verification` 계약이 있는 관리형 스키마 | Auth의 검증된 사용자 ID를 실제 `withActorTransaction`에 전달해 읽기 전용 반복 읽기를 엽니다. 고정 SQL에서 현재 소유의 프로젝트·활성 자산·링크, 등록 객체 및 최신 `ready` 검증 기록을 한 번에 대조합니다. 객체 키·자료 크기·SHA-256·형식과 검증 시각, 활성 저장소 검증 세대가 맞아야 합니다. 기존 객체키 계약을 재사용하며 REA의 64MiB 이내 등록 이미지·영상을 대상으로 합니다. 성공 결과는 서버 내부 등록 메타데이터와 스토리지 검증 세대로 제한합니다. |
| 링크 재연결과 복원 | 현재 링크가 없거나 스토리지 권한이 철회되면 등록 상태가 반환되지 않습니다. 같은 조합을 재연결하면 조회는 현재 링크를 관측할 수 있습니다. 기존 `project_assets`의 복합 키에는 재연결 이전과 이후를 구별할 세대가 없습니다. 스토리지의 검증 세대를 링크·권한·복원 세대로 사용하지 않습니다. |

## 다음 연결의 선행조건

- **로컬 권한** · 사용자별 프로젝트·자료 소유와 연결 권한을 DB에서 해석할 수 있는 모델과 기존 행의 명시적 귀속 이관이 필요합니다. 대안은 운영자가 승인한 단일 사용자 작업공간과 OS 경계이며, 현재 로컬 로그인 판정만으로는 입증되지 않습니다.
- **관리형 권한** · 보호된 시험 대상의 스키마·제한 API 역할부터 검증합니다. 같은 소유자의 프로젝트와 자료 연결에 묶인 서버 관리 링크·권한 세대 또는 동등한 이력을 설계하고, 연결 해제·재연결·철회·아카이브·복원 시 이전 확인을 무효화하는 동일 트랜잭션 규칙을 정합니다. 복원 게시에서 새 복원 세대를 발급해야 합니다. `0004`의 객체 검증 수명은 이 프로젝트 권한 전이를 증명하지 않습니다.
- **제품 경로** · 세대가 갱신되는 권한 조회와 검증된 바이트 사본 인계를 결합한 뒤 격리 환경의 두 계정으로 검증해야 합니다. 분석 저장과 적용 직전에 최신 권한·세대와 파일을 대조하고, 확인 소비·타임라인 CAS·영수증을 같은 제한 쓰기 권한에서 검증합니다. 공유 스키마·라우트와 배포는 이번 작업 범위 밖입니다.

## 검증

집중 시험 **8/8**에서 현재 소유 링크와 유효 영수증 조회, 미인증·금지·로컬·잘못된 액터, 타 사용자와 없는 자료, 링크 제거·재연결, 스토리지 철회·아카이브·만료·세대 변경, 객체키 불일치, 검증 테이블이 없는 경우를 확인했습니다. 질의는 인메모리 SQLite의 합성 관계에서 실제 SQL을 실행했고, Postgres 클라이언트의 역할·트랜잭션은 모의했습니다. 실제 Postgres의 RLS·관리형 배포·키에는 접속하지 않았습니다. 기본 REA **108 통과·60 건너뜀**, 네이티브 REA와 타임라인·오디오·Postgres 요청/백엔드 회귀 19개 파일 **247/247** 통과. 범위 TypeScript `tsc -p tmp/t279-rea-typecheck.json`와 변경 파일 ESLint `--max-warnings 0`도 통과했습니다.
