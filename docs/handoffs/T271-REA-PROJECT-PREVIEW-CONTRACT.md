# T271 REA 프로젝트 적용 미리보기 계약

서버가 검증한 액터와 소유 범위에서 로컬 분석 결과를 `createPrivateReferencePreviewRecord`로 묶습니다. `previewReferenceProject`는 현재 프로젝트·소스·소스 리비전·분석 리비전과 호출자의 소유권을 다시 대조합니다. 서버가 전달하는 현재 시각과 최대 허용 수명으로 만료 여부를 확인합니다. 애플리케이션의 권한 확인과 현재 리비전 조회는 호출자가 맡습니다. 레코드는 한 프로세스에서 쓰는 불투명 객체이며, 직렬화하거나 요청 본문으로 받지 않습니다. [미리보기 모듈](../../lib/reference-analysis/project-preview.ts)

호출은 한 분석 결과를 대상으로 합니다. 근거 ID로 선택하며, 응답 순서는 요청 순서를 따릅니다. 빈 선택, 중복, 미확인 항목이 포함된 선택은 `selection_unavailable`을 반환합니다. 취소·실패·잘못된 근거 위치·관측 트랙 누락·가시 색이 없는 영역에는 후보를 생성하지 않습니다. `owner_required`와 `stale`은 후보 없이 반환됩니다. 기본 응답에는 URL, 파일명, 원문, 추정 설명 원문, 경로, 원본·픽셀 바이트, 소유자나 리비전 식별자가 들어가지 않습니다.

| 선택 항목 | 결과 |
| --- | --- |
| 영상 관측 프레임 또는 컷 후보 | 실제 참조 시각, 컷의 RGB 변화량과 양쪽 시각, 컷 추정에 연결된 근거 ID. 기존 타임라인의 30fps 변환으로 **참조 프레임**을 표시하며, 컷 제안에는 기존 0프레임 전환 형식을 사용합니다. |
| 오디오 음량 또는 템포 | 확인된 PCM 구간·채널 수·최대 정규화 RMS, 또는 관측된 상승 시각과 간격 및 추정 BPM. 음악 초안은 `music` 역할을 제안합니다. |
| 이미지 영역 | 방향 보정된 정규화 좌표, 투명도, 색 구간, 상대 명도 비중. 영역 배치와 색·명도 방향을 담은 이미지 프롬프트 초안을 반환합니다. |

관찰에는 `observation`, 컷·BPM 추정에는 `inference`, 생성하거나 편집할 초안에는 `creative_proposal`을 붙였습니다. 초안은 사용자의 자체 소재를 쓰는 형식입니다. 참조 프레임과 좌표는 참조 자료에 속합니다. 프로젝트 클립 위치·길이·트림 또는 오디오 gainDb는 계산하지 않습니다. 타임라인 쓰기, DB·스토리지 접근, 생성, UI 연결은 후속 범위입니다. [타임라인 계약](../../lib/edit/timeline.ts)

REA Vitest 8개 파일을 실행했습니다. `DREAM_REA_NATIVE_TEST=1`로 **104/104**, 기본 설정으로 **59 통과·45 건너뜀**을 확인했고, 범위 TypeScript와 ESLint `--max-warnings 0`도 통과했습니다. 실제 로컬 합성 MP4의 800–1,000ms 컷 후보와 30번 참조 프레임, M4A의 120 BPM 추정, PNG의 위치·색 구간을 기존 분석기부터 미리보기까지 검증했습니다. 오인된 소유권·프로젝트·소스·리비전, 만료, 취소·실패, 잘못된 근거 연결과 민감 정보 제외를 집중 시험에서 확인했습니다.
