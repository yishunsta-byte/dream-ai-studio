# T269-R REA 로컬 이미지 독립 검수

2026-11-19 KST · Codex(Tester) · 기준 `5b53aba225a0edd23f0c138ad470d7be272dd616` · 배정 `msg_aca0231c1312`

**통과.** 표시 방향의 영역 좌표, 알파 가중 색·명도, 특징 미출력과 사본 정리를 확인했다. 로컬 이미지 관찰을 다음 단계에서 사용할 수 있다. 표본 통계는 원본 촬영·제작 방법의 증거가 아니며 실제 사용자 자료·화면 연결은 후속 검증 범위다. [구현 보고](T269-REA-LOCAL-IMAGE-FEATURES.md)

## 독립 합성 표본 결과

| 표본 | 관측 결과 |
| --- | --- |
| 18×10 JPEG EXIF 2 및 8 | EXIF 2는 저장 좌우를 거울 반전해 표시 좌상단의 파랑을 확인했다. EXIF 8은 저장 치수 18×10을 메타데이터에 남기고 표시 치수 10×18, 위 파랑·아래 빨강을 반환했다. 마지막 격자는 표시 기준 `x=0.7`, `y=13/18`, 오른쪽과 아래 끝 1로 검증했다. 기존 시험의 EXIF 6도 통과했다. |
| 2×2 RGBA PNG | 불투명 빨강·검정, 투명 파랑, 알파 128 흰색에서 알파 커버리지 `638/1020`. 색 비중은 검정·빨강 각각 `255/638`, 흰색 `128/638`이었다. 상대 명도의 첫 구간 `510/638`, 마지막 구간 `128/638`을 확인했다. 투명 파랑 셀의 색·명도 분포는 비어 있었다. |
| 완전 투명 2×1 WebP | alpha 0, 팔레트 빈 배열, 명도 `null`. 숨은 색은 집계되지 않았다. |
| 가로로 긴 3001×1 PNG | 확대 없이 `96×1`, 4열·1행으로 제한됐다. |
| 합성 두 프레임 APNG를 PNG로 제출 | 형식 불일치, 이미지 특징 미출력. 별도 기존 네이티브 시험의 두 프레임 WebP는 `multiple_frames`로 분리됐다. |

기존 회귀에서 4000×3001 PNG의 1200만 픽셀 특징 한도, 손상 PNG와 형식 불일치, 96px 변 제한을 재검증했다. 별도 표본에서 사전 취소와 1ms 기한은 각각 `cancelled`와 `timed_out`이었으며 관찰을 내보내지 않았다. Sharp는 실행 중인 네이티브 작업의 즉시 종료를 보장하지 않으며, 이번 검수는 중단된 호출의 결과 폐기와 정리를 확인했다. [표본 처리](../../lib/reference-analysis/image-features.ts) · [네이티브 회귀](../../tests/reference-analysis/image-features.test.ts)

공용 검사 경로는 승인된 관리 사본을 제한된 버퍼로 읽고 검사와 이미지 분석에 재사용했다. 별도 성공·실패 전후 검사 사본 디렉터리 목록이 같았다. 결과에서는 원본 버퍼, 샘플 버퍼와 사본 절대경로가 나오지 않았고 공유 DTO는 비공개 파일명을 제외했다. 공용 경로 변경 후 영상·음원 트랙, PTS, 특징, 취소·시간 초과와 자식·사본 정리 회귀도 통과했다.
