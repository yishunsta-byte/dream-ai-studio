## 키보드 초점 개선 항목

- 재현은 URL 입력 → Tab으로 권리 확인 → Space → Tab으로 실행 → Enter → 결과 표시다. 세 번 모두 결과가 표시됐을 때 활성 요소는 `BODY`였다. 결과 영역의 상태 문구가 있고 다음 Tab으로 결과 조작에 도달한다.
- `local-url-analysis.tsx`에서 실행 중 버튼을 비활성화하고 새 결과를 그린다. 성공 시 결과 제목이나 결과 영역으로 초점을 옮기는 코드는 없다. 따라서 키보드 사용자가 결과 표시를 즉시 따라갈 수 있도록 결과 제목 초점을 관리하는 경로를 단독 수정 후보로 제안한다. 재검수 기준은 키보드 제출 후 제목이 보이고 초점이 있으며 다음 Tab이 결과 조작으로 이어지는 것이다.
