# T284 작업실 등록 참고 자료 분석 서버 계약

기준 `2553021` · Backend 자체 검증

작업실에서 사용할 서버 내부 기능 `analyzeStudioReference`를 추가했습니다. 요청에는 프로젝트와 자료 ID만 받습니다. 검증된 로그인 계정과 서버 등록 조회 결과의 소유자·프로젝트·자료를 대조합니다. 등록 조회 결과에는 활성 링크, 권한 범위와 소유자 권한, 복원 세대, 자료 세대와 등록 파일 해시가 모두 있어야 합니다. [구현](../../lib/reference-analysis/studio-analysis-contract.ts)

- `registered-authority.ts`의 관리형 관측은 저장 등록 상태만 입증합니다. 이 값을 공급하면 서버 계약은 `source_unavailable`을 반환합니다. 로컬 인증 경로도 같은 결과를 반환합니다.
- 등록 파일의 바이트를 기존 분석 사본 검사기로 검증하고 이미지·음악·영상 분석을 실행합니다. 분석이 끝난 뒤 로그인과 권한, 자료 식별 정보를 다시 조회해 철회나 교체가 관측되면 결과를 폐기합니다.
- 기존 프로젝트 미리보기의 허용된 출력에서 관찰 근거, 추정, 프롬프트 초안을 반환합니다. 초안에는 `creative_proposal` 유형이 붙습니다. 내부 권한 세대·해시·경로·파일명·계정 식별자와 디코딩 원본은 응답에서 제외합니다.
- 이 단계에서는 등록 조회를 서버 어댑터 계약으로 정의했습니다. 관리형 권한·바이트를 실제로 입증하는 어댑터, 작업실 화면 연결, 분석 및 수정 프롬프트 저장은 후속입니다. 외부 URL과 유료 공급자는 호출하지 않았습니다.
