# P2 V5 · 오디오 권리 기록 입력 오류

Chrome 157의 로컬 편집 화면에서 같은 가상 음원의 출처 주소와 요금제 이름을 순서대로 편집했다. 아래 판정은 사용자가 보는 문구와 타임라인 저장 버튼을 기준으로 한다.

| 입력 | 결과 |
|---|---|
| 출처 주소에 ftp://example.test/sound | HTTP(S) 주소를 입력하거나 비워 두라는 안내와 저장 차단 |
| 주소 오류가 있는 채로 요금제 이름에 한글 121자 입력 | 120자 제한 안내와 저장 차단 |
| 주소만 https://example.test/sound로 고침 | 주소 경고 제거. 요금제 길이 경고와 저장 차단 유지 |
| 요금제 이름을 120자로 줄임 | 남은 경고 해제, 저장 버튼 활성화 |

화면 판정 4개 통과. 실제 권리 판정·외부 URL 접속·서버 저장은 수행하지 않았다. 원자료 tmp/p2-audio-range/rights.json. 이 결과는 P2 타임라인 음원 권리 편집기의 검증이며, 비공개 PNG/WAV 등록 기능은 해당 담당자 기록을 따른다.

> 플래너 전달문 — P2 V5 권리 입력의 주소 형식과 한글 120·121자 경계, 오류를 하나씩 고칠 때의 저장 차단·해제를 확인했습니다.
