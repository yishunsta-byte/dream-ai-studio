# T281-F1-R REA 승인 거절 무변경 독립 재검수

2026-11-19 KST · Codex(Tester) · 고정 커밋 `96a7c9612a57f7f409f473a8f8fd342834ebea94` · Orca `msg_b526d09172de`

**판정 — 격리 PG17 승인 후보 범위 통과.** 미등록 소유자의 범위 승인이 거절될 때 남던 비활성 기준 행이 수정 후에는 커밋되지 않습니다. 기존 소유자와 미연결 범위의 거절도 DB 상태를 보존했습니다. 거절 뒤 정상 최초 승인이 가능했고, 선행 정상 요청이 롤백되자 대기 요청이 새 승인이 됐습니다. [수정 인계](T281-F1-REA-DENIED-APPROVAL-NO-MUTATION.md) · [이전 독립 검수](T281-R-REA-MANAGED-AUTHORITY-GENERATIONS-PROBE-REVIEW.md)

## 독립 PostgreSQL 대조

EDB 서명과 로컬 `17.12` 바이너리 경로를 검증한 뒤 임시 루프백 클러스터에서 원본 실행기와 별도 사례를 실행했습니다. 새로운 클러스터·데이터 디렉터리·리스너의 소유 프로세스를 대조한 뒤 연결했습니다. 독립 비교는 `auth`, `dream`, `rea_t281`의 33개 일반 테이블을 정렬한 논리 행 스냅샷으로 수행했습니다.

| 경로 | 결과 |
| --- | --- |
| 미등록·미연결 상태 | REA 링크가 없는 새 소유자에게 범위 승인·철회와 소유자 철회를 요청했습니다. 모두 `false`였고 바깥 트랜잭션 커밋 후에도 전체 33개 테이블이 동일했습니다. |
| 기존 소유자 | 이미 허용된 소유자의 반복 승인, 비활성 범위 철회, 링크가 없어진 옛 범위의 승인은 `false`였습니다. 전체 스냅샷이 동일했습니다. |
| 거절 후 잠금 해제 | 거절한 연결의 바깥 트랜잭션을 계속 열어 두고 다른 연결에서 해당 소유자·프로젝트·자산을 `FOR UPDATE NOWAIT`로 잠갔습니다. 세 잠금 모두 즉시 성공했습니다. 원본 실행기의 거절 대 최초 승인 경합에서도 `pg_blocking_pids`로 실제 대기를 확인했고, 바깥 커밋 전에 대기 승인이 진행됐습니다. |
| 거절 후 정상 승인과 선행 롤백 | 앞서 거절됐던 소유자의 최초 승인과 링크 연결 뒤 최초 범위 승인 각각에서, 선행 쓰기를 롤백하자 대기 중인 요청이 승인됐습니다. 최초 소유자·링크·범위 권한의 세대는 각각 1이었습니다. |
| 예상 밖 SQL 오류 | 잘못된 승인 인수 `22023`, 타 소유 대상 `42501`, 프로젝트 행 잠금 대기 제한 `55P03`이 `false`로 변환되지 않고 호출자에게 전달됐습니다. 롤백 후 33개 테이블은 모두 동일했습니다. |

두 권한 함수는 기준 행 생성과 잠금부터 PL/pgSQL 예외 블록 안에서 실행합니다. 예상된 거절의 `R2810`만 포착해 내부 변경과 그 블록에서 획득한 잠금을 되돌린 뒤 `false`를 반환합니다. 정상 경로는 기존 소유자 기준 행과 고유 키를 유지합니다. 이 무변경 판정은 두 승인·철회 함수에 대한 것입니다. [후보 SQL](../../tests/reference-analysis/managed-authority-generations.sql#L108)

## 이전 회귀와 범위

- 원본 PG17 실행기에서 A/B 제한 로그인 및 강제 RLS, 직접 DML 거절, 동일 트랜잭션 재연결, 양쪽 링크 이동과 `23505` 중복의 전체 롤백을 재확인했습니다. SQL1–4는 고정 소스를 사용했고 SQL5 원문은 `B27_PREFLIGHT_UNVERIFIED`로 거절됐으며 예약 스키마와 역할이 생기지 않았습니다. [실행기](../../tests/reference-analysis/managed-authority-generations.pg17.mjs)
- 실행기 `node --check`와 ESLint `--max-warnings 0`이 통과했습니다. 실행에서 사용한 임시 프로세스·리스너·클러스터 정리를 확인했습니다. 보고서 외 공유 SQL과 제품 파일을 변경하지 않았습니다.
- 실제 Supabase Auth·운영 및 PG18에서의 SQL5 호환성, 종결 영수증과 타임라인 적용은 이번 판정 범위 밖입니다.

**Master 전달문** — T281-F1-R 통과. 고정 `96a7c96`에서 미등록·기존·미연결 승인 거절 전후 33개 일반 테이블이 동일했고, 바깥 트랜잭션 중에도 새 잠금이 해제됐습니다. 예상 밖 SQLSTATE는 전달됐고 최초 승인·선행 롤백 승계, A/B 회귀와 SQL5 원문 거절을 재확인했습니다.
