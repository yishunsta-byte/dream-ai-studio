# 등록된 로컬 PG 장면 결과 선택

Master 배정 `msg_9e93bf009768`. 기존 PNG 결과 등록 `a2f06f7`을 바탕으로 제작 화면의 결과 행에서 **이 결과 사용**을 선택하면 해당 장면의 현재 결과가 저장되도록 연결했다. 목록을 다시 열면 선택한 행에 **사용 중**이 표시된다.

- 현재 승인 기획, 프로젝트 내용 리비전, 기존 선택 ID를 모두 확인한다. 현재 기획과 대상 장면에 속하고 원본 검증이 유효한 성공 PNG 결과만 선택할 수 있다.
- 선택이 바뀌면 장면의 결과 포인터, 프로젝트 리비전, 활동 기록을 한 트랜잭션에 저장한다. 같은 기준으로 동시 요청하면 한 건만 성공한다. 최신 기준에서 이미 선택한 결과를 다시 요청하면 같은 선택을 반환한다.
- 제작 단계가 열려 있고 타임라인이 생성되기 전에 결과를 선택할 수 있다. 기존 결과 행과 원본 PNG 및 권리 메모가 보존된다. 제작 상태는 별도 승인 절차를 따른다.

## 검증

- 변경 파일 ESLint, 전체 타입 검사, 인증·기획 관련 시험 172건 및 제작 POST legacy 가드 시험 3건 통과.
- 공유 검사에서는 별도 개발 중인 review API가 정적 인증 가드 및 캐시 헤더 검사에서 실패했다. Master에게 `msg_e9dd52bae829`, `msg_28195135bb21`로 보고했다. 결과 선택 시험은 `18a9dbc` 기준 사본에 이 변경을 적용해 수행했다.
- 고정 사본의 전체 타입 검사, 인증·가드·기획 시험 269건과 실제 Next.js·PG17 HTTP 시험이 통과했다. `T371_VERIFY_HTTP=1`로 `node --conditions=react-server --import tsx tests/postgres/t368-run-private-image-project-create.mjs`를 실행했다. 다른 계정, 다른 장면, 보관된 원본·장면·프로젝트, 이전 기획과 오래된 리비전을 거절했다. 동시 선택은 200과 409였고 선택 기록은 한 건이다. 활동 기록 실패 시 포인터와 리비전이 함께 롤백됐고, 기존 결과 행과 권리 메모는 같았다.
- Chromium에서 실제 등록된 PNG를 Enter로 선택한 뒤 알림으로 옮겨 간 초점을 확인했다. 이전 기준을 가진 두 번째 탭에서는 충돌 안내 후 **다시 불러오기**로 같은 선택을 확인했다. 새로고침과 프로젝트 상세에서 재진입한 뒤에도 **사용 중**이 표시됐으며 제작은 **할 일**, 편집은 **잠김** 상태였다.
