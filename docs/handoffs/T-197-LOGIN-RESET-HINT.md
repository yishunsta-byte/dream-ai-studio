# T-197 로그인 실패 뒤 비밀번호 찾기 안내

- 담당: Codex(Front)(term_a0a6f98c) · 배정: CX-MASTER-01 · 상태: 자체 검수, **로컬 커밋만(push 안 함)**

## 바뀐 것(`components/auth/login-form.tsx`만)
- 로그인 화면에서 서버가 `INVALID_CREDENTIALS`를 돌려주면 안내를 덧붙여요: 기존 문구 + "처음 쓰시거나 비밀번호를 정한 적이 없다면 '비밀번호 찾기'로 먼저 정해 주세요."
- 알림 아래에 **"비밀번호 찾기로 정하기 →"** 버튼을 둬요.
  - 허용 밖·없는 계정·틀린 비밀번호가 모두 같은 서버 응답이라, 안내도 똑같아요(계정 존재 여부를 드러내지 않아요).
- 로그인·회원가입·비밀번호 찾기 사이를 오갈 때 **입력한 이메일만 유지**해요. 비밀번호는 옮기지 않아요.
- 비밀번호 찾기로 바꾸거나 로그인으로 돌아가면 이메일 칸에 초점을 둬요. 오류와 안내는 지워요.
- 화면 전환은 상태만 바꿔요. 재설정 요청은 "재설정 메일 받기"를 눌렀을 때만 보내요.
- `post()`가 서버의 `code`를 오류에 붙여요(화면 판단용, 표시 안 함).
- 서버 라우트·서비스·환경변수·CSS는 바꾸지 않았어요.

## 알려 둘 점
- 이미 있던 Tab 순서: 이메일 → (비밀번호 제목 줄의) "비밀번호 찾기" → 비밀번호 칸이에요. 참고 시안의 배치 그대로라 이번에는 바꾸지 않았어요.
