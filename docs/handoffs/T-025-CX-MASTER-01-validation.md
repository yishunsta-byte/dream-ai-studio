# T-025 · P1 필수 수정 통합·독립 재검수 실행 기준

책임 CX-MASTER-01, 입력 T023 결과커밋/실제diff·R016·T013명세·T021/22인계. 현재 **준비 문서**이며 아래 검증은 아직 새 구현에서 실행하지 않았다. T023코드반환전 같은코드파일 수정/전체검사로 담당의 작업을 방해하지 않는다.

## Master 통합 순서

1. 실제HEAD·git status·T023허용변경/커밋과재현결과를확인하고추가파일이있으면범위를검토한다. 기존별도claude-coding-p1-fixes의변경은자동통합하지않는다.
2. build/lint/typecheck/전체tests, 운영audit와Q001전체감사를기록한다. 작성자결과와Master재실행결과를구분한다. 실제로실행하지않은검증은통과로적지않는다.
3. 가상데이터격리환경에샘플모드/loopback서버·worker만실행한다. 현재실제사용자data/storage/backups를읽거나변경하지않는다. 자신이시작한프로세스만정리한다.

## F0161 장면 실패

- 선택된기존성공v1이있는장면에CONTENT_REJECTED실패: 기본카드/버전비교모두한글원인·다음행동, 대기문구없음·retry/선택불가. 기존v1선택·다른장면·원본파일/해시유지. 실패표시를샘플완성으로보이지않게한다.
- STORAGE_FAILED: 결과수신후저장실패를구분하고허용된저장재시도만. 기존provider ID/생성1건유지. 임시fixture로실패주입·복구하며실사용권한을바꾸지않는다.
- 재시도예정queued·실행중·canceled·결과없음 각각을실패와구분. 사용자조작에맞는정확한버튼/안내, 원문경로/키노출0.
- 1280/390 기본카드/펼친버전의넘침0·명확한접근이름·오류포커스/토스트중복여부.

## F0162 내보내기

- 만들기전실제번들구성과맞는폴더/파일수·예상크기와추정임을표시. 필수표기/SRT/폰트/샘플여부일치. 잠김상태는서버게이트유지.
- 생성완료파일명·바이트수·시각·SHA·revision·샘플을화면에서확인하고브라우저실제다운로드/Content-Disposition/바이트수와대조.
- ZIP을새격리폴더에풀어manifest전체파일SHA/size대조. 기존ZIP/manifest변경없음. 수정후검수무효화도유지.
- 1280/390 긴이름/해시/미리보기/실패행넘침0. 실패다음행동/retry가현재승인조건을우회하지않음.
