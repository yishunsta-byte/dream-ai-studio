## 2. P2-4(소리 없음)와 P2-5(오디오)의 경계

| | P2-4 (이번) | P2-5 (다음) |
|---|---|---|
| 만드는 것 | 장면 + 글자, **소리 없음** | 음성·음악·loudnorm −14 LUFS·ducking·acrossfade |
| 진행 단계 | **3단계**: 준비 → 장면과 글자 합치기 → 파일 확인 | 4단계(시안대로 "소리 맞추기 · 음량 −14 LUFS" 추가) |
| 파일 확인 항목 | 길이·해상도·비율·영상 코덱(H.264)·30fps, **소리 트랙 없음이 맞는지** | + AAC 트랙 있음·음량 |
| 확인 칩 | `1080×1920` `25.0초` `H.264` **`소리 없음 · 다음 단계에서 붙여요`** | + `AAC −14.1 LUFS` |
| 이름 | "소리 없는 영상" (행 제목 옆 Badge) | "영상" |
| 영상 내보내기 | 잠김 유지. 이유 "소리를 붙이는 단계(P2-5)와 자막 파일(P2-6)이 끝나면 열려요" | P2-6에서 열림 |

- 하지 않을 것: P2-4에서 "소리 맞추기" 단계를 회색으로 보여 주거나 0%로 지나가게 하지 않음(가짜 진행). 없는 단계는 안 보임.
- P2-4 결과는 검수 `c.files-exist`·`c.spec-match` 자동 확인에 쓸 수 있지만, `c.sync`(음성-자막)는 소리가 없으므로 사람 평가 그대로.

## 3. 시작 전 확인 (버튼을 누르기 전 화면이 막는 것)

서버가 같은 조건을 다시 확인하고, 화면은 이유와 갈 곳을 보여 줌. **새 승인 단계 아님**(이미 있는 저장·결과 선택·자료 상태를 읽기만 함).

| 상태 | 버튼 | 이유 글(버튼 아래, `disabledReason`) | 갈 곳 |
|---|---|---|---|
| 편집에 저장 안 한 변경 | 막음 | "편집에서 저장하지 않은 변경이 있어요. 영상은 저장한 타임라인으로만 만들어요." | "편집으로 가기" 링크 |
| 저장한 타임라인 없음(P1 묶음만) | 막음 | "아직 저장한 타임라인이 없어요. 편집에서 한 번 저장해 주세요." | 편집 |
| 결과를 고르지 않은 장면 | 막음 | "결과를 고르지 않은 장면이 {n}개 있어요: 장면 3." | 장면 제작 |
| 장면 파일 없음·열 수 없음 | 막음 | "장면 2의 결과 파일을 찾지 못했어요. 장면 제작에서 다시 고르거나 다시 만들어 주세요." + 작은 글자 코드 `RENDER_INPUT_MISSING` | 장면 제작 |
| 영상 만들기 도구(렌더용 브라우저) 없음·버전 다름 `RENDER_BROWSER_MISSING` | 막음 | "영상 만들기 도구가 아직 설치되지 않았어요. 설치는 한 번만 하면 돼요: {설치 안내}." | 설치 안내(T-101 D-2 스크립트, 실행은 승인 뒤) |
| 디스크 공간 부족(시작 전 확인) `DISK_FULL` | 막음 | "디스크 공간이 모자라요. 필요 약 {x}GB · 남은 {y}GB." | — |
| 글꼴 파일 없음 | 막음 | "Do Hyeon 글꼴 파일을 찾지 못했어요. 이 글꼴을 쓰는 글자: 자막 "…" 외 1개." + `FONT_MISSING` | 편집(글꼴 바꾸기) |
| 검수가 지금 내용과 다름(stale) | **막지 않음** | 안내만: "검수는 영상을 만든 뒤 지금 내용(타임라인 r5)으로 다시 해요." | — |
| 같은 버전·비율이 만드는 중 | "만드는 중이에요" 대신 진행 카드로 이동 | — | 진행 카드 |
| 처리기가 꺼져 있음 | 누를 수 있음 | 누른 뒤 대기 상태에 "작업 처리기가 켜지면 시작해요." | — |

- 여러 이유가 동시에 있으면 목록으로 모두 보여 줌(하나 고치고 또 막히지 않게).
- 샘플 장면만 있으면 막지 않음. 결과는 `_SAMPLE`.

## 4. 화면 위치·구성

**D-1 (Master 판단):** DESIGN 표는 `/projects/[id]/render`. 그런데 지금 단계(Stepper)는 7개(등록~내보내기)이고 "영상 만들기" 단계가 없음. 제안: **단계는 늘리지 않고**, `/projects/[id]/render`를 "수정·조립" 단계 안의 하위 화면으로(탭 "수정·조립"이 선택된 채, 머리에 "수정·조립 › 영상 만들기"). 들어가는 길: 편집 화면 머리의 "영상 만들기" 버튼(시안 1484줄), 검수·내보내기 잠김 이유 안 링크. 단계를 새로 만드는 것은 Stepper·상태 전이(PLAN 5.2)가 바뀌므로 하지 않음.

구성(위→아래, 기존 부품만):

1. `PageHeader` — 제목 "영상 만들기", 부제 "저장됨 · 타임라인 r5 · 9:16" + SampleBadge(해당 시).
2. **만들기 Card** — 3장 막는 이유 목록 또는 `Button` "영상 만들기"(primary). 글자만 바뀐 경우 안내 "글자만 바뀌었어요 — 장면은 다시 만들지 않아요"(서버가 장면 재사용을 확인했을 때만). **예상 시간은 같은 PC에서 잰 이전 기록이 있을 때만** "약 40초", 없으면 쓰지 않음.
3. **진행 Card**(작업이 있을 때만, 한 번에 하나) — 5장.
4. **만든 영상 Card** — 결과 행 목록(최신 위). 6장.
5. 내보내기 안내 Card — 잠김 이유(2장 표).

## 5. 진행 카드 상태

제목 `h2` "영상 만드는 중 · 타임라인 r5 · 9:16" (`tabIndex=-1`, 시작하면 초점).

| 상태(job) | 상태 Pill | 본문 | 막대 | 버튼 |
|---|---|---|---|---|
| 대기 `queued` | `StatusPill` 대기 "차례를 기다려요" | 앞에 작업이 있으면 "앞에 작업 {n}개" | 숨김 | 취소 |
| 처리기 꺼짐(대기 30초 넘게 안 집힘) | 대기 | "작업 처리기가 켜지면 시작해요. 창을 닫아도 작업은 남아 있어요." | 숨김 | 취소 |
| 다른 작업 뒤에서 기다림(전체 동시 1) | 대기 | "다른 작업(장면 만들기·묶음·백업)이 끝나면 시작해요." | 숨김 | 취소 |
| 준비 `running` 1단계 | 진행 | 단계 목록(아래), "준비 · 장면 4개, 글자 6개" | 퍼센트 모름 → 막대 없이 "준비 중" | 취소 |
| 합치기 2단계 | 진행 "64% · 1분 40초 지남" | 현재 단계 굵게, 지난 단계 ✓ | `--accent-bar`, 프레임 기준 퍼센트 | 취소 |
| **파일 확인 중** 3단계 | 진행 "파일 확인 중" | "만든 파일의 길이·해상도·코덱을 확인하고 있어요. 확인을 통과해야 완성으로 쳐요." | 100% 막대 대신 "확인 중"(퍼센트 숨김 — 100%인데 안 끝난 것처럼 보이지 않게) | 취소 |
| 처리기·도구 중단 → 자동 다시 시작(lease 만료 또는 `RENDER_BROWSER_CRASHED`, 최대 2번 — T-106) | 대기 "다시 시작해요 · {n}번째"(서버 값) | "영상 만들기 도구가 멈춰서 처음부터 다시 만들어요. 이미 만든 영상은 그대로예요." | 숨김 | 취소 |
| 취소 요청 중 | 대기 "취소하는 중" | "지금 단계가 끝나는 대로 멈춰요." | 그대로(멈춤) | 없음 |

- 단계 목록: `ol`, 각 항목 앞 아이콘(✓ 끝남/● 지금/○ 남음, `aria-hidden`) + 글자 "끝남/지금/남음"을 `sr-only`로.
- 작은 글자: "PC에서 만들어요. 창을 닫아도 작업 처리기가 켜져 있으면 계속돼요."
- 폴링 2초(9장). 화면을 떠났다 오면 진행 카드가 다시 나타남(서버 상태 기준).

### 5.1 읽어 주기 (폭주 막기)

| 무엇 | 방법 |
|---|---|
| 진행 막대 | `role="progressbar"` + `aria-valuenow`·`aria-valuetext="64% · 1분 40초 지남"`. **live 영역 아님**(2초마다 읽지 않음) |
| 단계 바뀜 | 카드 안 `aria-live="polite"` 한 곳에 "2단계 장면과 글자 합치기를 시작했어요." / "파일을 확인하고 있어요." — 단계가 바뀔 때만 |
| 퍼센트 | 읽어 주지 않음. 사용자가 막대로 가면 valuetext로 들음 |
| 끝남·실패·취소 | Toast(이미 `aria-live`) 한 번 + 카드 안 live 글은 비움(두 번 읽지 않게) |
| 경과 시간 | 1초마다 바꾸지 말고 폴링 때(2초)만 갱신, `<time>` 안 |
| `prefers-reduced-motion` | 막대 애니메이션·도는 아이콘 멈춤, 글자는 그대로 |

### 5.2 초점

| 순간 | 초점 |
|---|---|
| "영상 만들기" 누름 → 작업 생김(또는 기존 작업 보여 줌) | 진행 카드 제목 |
| 같은 작업이 이미 있음(중복 클릭·다른 창) | 진행 카드 제목 + Toast "이미 만들고 있어요. 그 작업을 보여 드려요." |
| 취소 확인 열림/닫힘 | `ConfirmPanel` 규칙(열면 패널, 닫으면 취소 버튼) |

| 다시 만들기 | 새 진행 카드 제목 |

- 재시도·다시 만들기는 **새 작업·새 행**. 실패 행은 남김(기록).
- **재생**: 행 안에 `<video controls muted playsinline preload="metadata">`를 펼침(새 창 아님). 소리 없는 영상이라 `muted`. 재생 중 다른 행 재생을 누르면 앞의 것을 멈춤. 키보드 Space는 video 기본 동작.

- 파일이 사라진 통과 행: 칩 "파일 없음" `danger`, 재생·받기 대신 "영상 파일을 찾지 못했어요. 백업에 함께 들어가는 파일이라 원래 있어야 해요. 파일을 옮겼거나 지웠는지 확인해 주세요. 다시 만들 수도 있어요." — **정상 상태가 아니라 오류**로 보임(T-106: 통과·취소 뒤 끝난 MP4도 백업 포함).
- 결과가 없으면 `EmptyState` "아직 만든 영상이 없어요".
