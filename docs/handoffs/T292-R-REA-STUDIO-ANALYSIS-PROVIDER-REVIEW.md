## F292-1 · HTTP 오류 본문과 연결이 열린 채 남음

로컬 HTTP 서버가 `503` 헤더와 JSON 본문 첫 바이트를 보내고 본문을 끝내지 않도록 했습니다. 공급자는 즉시 `analysis_unavailable`을 반환했습니다. 반환 직후 호출자의 신호를 중단하고 400ms를 기다려도 내부 전송 신호가 중단되지 않았고 TCP 연결도 열려 있었습니다. 설정한 요청 기한은 200ms였습니다. 같은 자료를 재시도해 성공한 뒤에도 첫 연결이 남아 있었고, 검수 서버에서 첫 응답을 직접 종료한 뒤 닫혔습니다.

[`studio-registered-analysis-provider.ts:115`](../../components/reference-analysis/studio-registered-analysis-provider.ts#L115)의 `!response.ok` 분기가 본문을 읽거나 전송을 중단하지 않고 반환합니다. `finally`가 기한 타이머와 호출자 취소 리스너를 제거하므로 남은 본문에 두 중단 경로가 모두 적용되지 않습니다. HTTP 오류를 일반 실패로 반환할 때 응답 본문을 취소하거나 전송을 중단하고, 끝나지 않는 오류 본문을 사용하는 회귀 검증으로 연결 종료와 같은 자료의 재시도를 확인하는 것을 권장합니다.
