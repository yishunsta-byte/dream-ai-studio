## 독립 재검증 결과

- 기존 Ego Chromium의 별도 검수 탭에서 고정 HTML을 열었다. CSS 뷰포트 1280px은 두 열, 390px은 한 열이었다. 세로 스크롤바를 제외한 실제 너비와 문서 너비가 각각 1265px·375px로 같았고, 측정한 노출 버튼의 최소 높이는 44px였다. 두 폭의 결과 캡처에서 근거 카드와 인용 버튼의 키보드 초점 표시를 확인했다. 검수 탭과 임시 캡처를 정리했다.
- 건너뛰기 링크에서 `main`으로 이동하고, URL 대체에서 본문·파일 필드로 이동했다. 잘못된 주소와 파일 미선택 안내를 확인했다. 대기 → 분석 → 취소 요청에서는 결과가 숨겨져 있었고, 별도 종료 확인 뒤 취소 완료가 표시됐다. 실패 뒤 재시도, 완료 후 빈 결과, 합성 완료 뒤 근거 탭 초점 이동을 각각 확인했다.
- `ArrowRight`, `Home`, `End`와 탭 순환 상태를 확인했다. 영상·음악 타임코드와 이미지 영역을 텍스트로 확인했고, 추정에서 연결된 관찰 버튼으로 초점을 옮길 수 있었다. 메타데이터·추정·확인 불가와 별도 합성 본문 인용 예시가 구분됐다. 빈 결과에서는 근거와 편집용 프롬프트가 모두 숨겨졌다.
- 클립보드 성공·실패를 브라우저 안에서 모의했다. 기본 복사 payload가 표시된 조합 프롬프트와 같았고, 합성 URL·본문·파일명·자유 편집 메모에 넣은 비공개 표지는 각각 제외됐다. 거절 시 일반 경로에서는 초점과 선택 영역이 표시 문구로 이동했다. OS 클립보드와 실제 자료를 사용하지 않았다.

## 실제 계약 연결 시 검증

- 제품에서는 서버가 작업 종료를 확인해야 취소를 완료할 수 있다. 서버 상한, 소유권, 취소·시간 초과·도구 부재 및 실패·파일 손상은 실제 작업 상태로 검증한다. 시안에서는 수동 상태 전환을 확인했다.
- 실제 탐색은 검증된 파일 길이와 표시 이미지 사각형에 연결한다. 본문 인용에는 원문 UTF-16 범위를 적용하고 제출자 표지와 확인된 제작자 출처를 구분한다. 지원 URL·공급자 열람 여부는 실제 연결 계약을 따르며, 복사·공유용 결과는 허용된 필드로 구성한다. [T263-R 검수](T263-R-REA-LOCAL-CONTRACT-REVIEW.md)

보조기기 실제 발화, 물리 모바일, 서버 작업과 배포는 이번 로컬 시안 검수 범위 밖이다. Designer 탭과 시안·공유 변경을 보존했으며 보고서 한 파일을 추가했다.
