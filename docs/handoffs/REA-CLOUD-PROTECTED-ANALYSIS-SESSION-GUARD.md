## 바꾼 제품 파일

### `components/reference-analysis/studio-registered-analysis-provider.ts`

- **선택 옵션 `onDenied(status)` 추가:** 분석 POST가 401·403이면 결과를 돌려주기 전에 한 번 알린다.
  - 반환값은 이전과 같은 `analysis_unavailable`이다. 결과 DTO는 그대로다.
  - 시간 초과나 사용자 취소 뒤에 도착한 거절은 알리지 않는다.
- **주입 응답의 `status`:** 선택 값으로 받는다. `status`가 없는 기존 주입 수단은 이전처럼 `ok`만 본다. `onDenied`가 없는 기존 호출자는 이전과 똑같이 동작한다.

### `components/reference-analysis/studio-protected-materials-analysis.tsx`

- **POST 401·403**
  - 그 목록 세대에서 한 번만 처리한다.
  - 진행 중인 목록 요청을 취소한다.
  - 401은 목록 GET 401과 같은 ‘다시 로그인해 주세요’ 상태로, 403은 ‘이 화면에 접근할 수 없어요’ 상태로 바꾼다.
  - 공급자가 사라지므로 선택, 권리 확인, 결과, 초안, 편집이 함께 지워진다.
  - 초점은 안내로 옮기고, 다음 Tab이 ‘다시 로그인’ 링크다.
- **경계 `epoch` 변경** (다른 탭 알림, `pageshow` 복원)
  - 진행 중인 목록 요청을 버린다.
  - 목록과 공급자를 비운다. 그러면 분석 화면이 내려가면서 진행 중인 분석 요청을 취소하고, 늦은 응답과 이전 선택·권리 확인·결과·초안을 다시 그리지 않는다.
- **경계가 `current`로 돌아온 뒤**
  - 이때만 목록을 새로 받는다. 그래서 새 선택은 확인된 상태에서만 생긴다.
  - 가려진 동안 초점을 잃었으면 초점을 자료 선택으로 되돌린다.
- **경계 밖 (`null`)과 `focus` 복귀:** 경계 밖이면 이전과 같다. `epoch`가 바뀌지 않는 `focus` 복귀 재확인은 상태를 그대로 둔다.

## 디자인 권장안과 대조 (`5b27bfc`)
