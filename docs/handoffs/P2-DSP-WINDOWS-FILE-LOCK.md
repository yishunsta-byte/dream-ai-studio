# Windows에서 DSP 고정 도구 변경 시험의 파일 잠금

4bfa4fb의 첫 전체 회귀에서는 STATS_MISMATCH를 기대한 DSP 시험이 TOOL_FAILED로 끝났다. 같은 사례를 진단 출력을 붙인 고정 사본에서 7회 단독 실행했고 각 실행과 전체 회귀 2961건이 통과했다. 처음 실패에는 errno 기록이 없어 실제 실패 지점은 확정할 수 없다.

Windows 시험 파일에 공유 금지 핸들을 보유하면 Node readFileSync가 EBUSY로 실패하는 경로를 재현했다. 원래 시험은 쓰기에서만 짧게 재시도했다. 읽기, 쓰기와 수정 시각 기록의 일시적 잠금을 각각 유한 재시도하도록 보완했다. 변경할 바이트는 한 번만 계산하며 경로 경계 검사와 설치 도구 해시 보존 단언을 유지한다.

격리 사본에서 첫 읽기에 EBUSY 1회 주입 후 두 번째 읽기와 원래 STATS_MISMATCH 단언 통과. 주입을 제외한 변경으로 DSP 시험 21건과 ESLint 통과.

> 플래너 전달문 — Windows 파일 공유 잠금에서 읽기 EBUSY를 재현하고 DSP 시험의 유한 재시도에 읽기와 속성 처리를 포함했습니다. 제어된 EBUSY 주입 후 원래 STATS_MISMATCH 및 DSP 21건이 통과했습니다.
