| 항목 | 독립 검증 결과 |

| 사본 수명·정보 비노출 | 콜백 안에서 검증 메타데이터, 신호, 사본 경로를 확인했습니다. 직렬화에는 경로가 없었고, 콜백이 반환한 경로도 최종 결과에 포함되지 않았습니다. 완료 후 경로 접근자는 `STORAGE_UNAVAILABLE`, 캐시한 문자열을 경로로 조회하면 파일 부재였습니다. 경로와 합성 자격을 포함한 콜백 예외는 메시지·원인 없이 고정 오류로 반환됐습니다. `verify()`는 같은 메타데이터를 반환했습니다. |
| 성공·취소·기한·예외와 슬롯 | 예외와 정상 완료 뒤 사본이 제거됐습니다. 다운로드 취소는 실제 HTTP 연결이 닫혔고 소비자가 실행되지 않았습니다. 소비자 대기 중 취소 또는 기한 초과는 각각 `STORAGE_ABORTED`·`STORAGE_TIMEOUT`을 반환하고 신호·경로를 닫고 사본을 지웠습니다. 각 경우 진행 중에는 한 슬롯을 점유했고, 반환 뒤 같은 reader의 다음 `verify()`가 정상 실행됐습니다. 늦은 소비자 거절은 Node 미처리 거절 엄격 모드에서 오류를 남기지 않았습니다. |
| 실제 Windows 삭제 금지 핸들 | 별도 소유 프로세스가 삭제 공유 없는 읽기 핸들을 보유한 상태에서 취소했습니다. `STORAGE_TEMP`를 반환하고 인계 경로 접근을 막았으며, 첫 사본이 디스크에 남은 상태에서도 같은 reader의 다음 요청은 성공했습니다. 핸들을 닫은 뒤에도 첫 사본은 남아 있어 검수 소유 디렉터리를 직접 정리했습니다. 라이브러리의 기한 내 삭제 재시도 밖에서 소비자가 보유한 핸들은 이 계약의 제한입니다. |
