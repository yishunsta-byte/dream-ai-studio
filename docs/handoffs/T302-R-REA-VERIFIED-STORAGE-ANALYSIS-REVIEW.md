## F302-1 · 런타임 신호 형식 오류에서 단일 슬롯이 고착됨

직접 서버 호출에 유효한 선택과 `AbortSignal` 인스턴스가 아닌 객체를 전달했습니다. Node의 `ERR_INVALID_ARG_TYPE`이 외부로 전파됐고, 이어 같은 `maxConcurrent=1` 인스턴스의 정상 `AbortSignal` 요청도 `source_unavailable`이었습니다. 인증과 네트워크는 두 번 모두 0회였습니다. [`active++`와 신호 생성](../../lib/reference-analysis/studio-verified-storage-analysis.ts#L82)이 `try/finally` 앞에 있어 `AbortSignal.any` 실패 시 슬롯 반환을 건너뜁니다. 신호 검증·생성을 슬롯 점유 전에 완료하거나, 점유 뒤 예외도 `finally`로 정리하도록 보완할 수 있습니다. 이 재현은 타입 계약 밖의 직접 호출이며 현재 제품 HTTP는 이 함수에 연결돼 있지 않습니다.

깨끗한 고정 사본의 전체 `tsc --noEmit --incremental false`, Next 타입 생성과 변경 파일 ESLint가 통과했습니다. 네이티브·헤드리스 저장소, REA, 공개·관리자 회귀는 재실행 **40개 파일 522/522**였습니다. 첫 실행은 기존 B14 `ffprobe` 영상 검증에서 `STORAGE_TIMEOUT` 1건이었으며 재실행에서 재현되지 않았습니다. 서버, 시험 파일과 사본을 제거했습니다.
