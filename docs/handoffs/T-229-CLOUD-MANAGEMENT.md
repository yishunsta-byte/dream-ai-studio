## 2. 화면 동작
- **인증 먼저**
  - 401이면 `/login?next=%2Fcloud%2Fmanage`, 403이면 `?error=forbidden`, 인증 확인이 안 되면 `?error=unavailable`로 보내요.
  - 이 경우 목록 읽기는 0번이에요.
  - 이 PC(로그인 꺼짐)에서는 기존 로컬 안내를 h1 "개인 관리"로 보여 줘요.
  - SQLite·시작 점검·메뉴 파일은 읽지 않아요.
- **정상**
  - "표시 목록 N개"와 "이번에 불러온 프로젝트 목록 기준이에요."를 보여 줘요.
  - 목록 조회 시각은 읽기에 성공한 뒤의 서버 시각이고, (한국시간)으로 표시해요.
  - 기록된 상태 분포는 확인 필요·만드는 중·승인 대기·완료·대기 순서의 `dl`이에요. 합계는 N과 같아요.
  - 분포 아래에 "기록된 프로젝트 상태 기준이며, 처리기의 현재 실행 여부를 뜻하지 않아요."를 둬요.
- **빈 목록(성공)**: "표시 목록 0개", 조회 시각, "이번에 불러온 목록에 프로젝트가 없어요."를 보여 줘요. 옮김·PC 보관 같은 짐작 문구는 없어요.
- **읽기 실패**: "관리 정보를 불러오지 못했어요 / 잠시 뒤 다시 불러와 주세요."와 다시 불러오기를 보여 줘요. 숫자·분포·조회 시각은 없어요.
- **연결 범위**
  - 작업 처리기 → 파일 저장소 → 백업 순서로, 각각 중립 "미연결" 배지와 확인할 수 없다는 문장을 보여 줘요.
  - 0·정상·실패·실행 버튼은 없어요.
- **이동과 다시 불러오기**
  - 상단에 "내 프로젝트 | 개인 관리(현재)"(`aria-current="page"`)가 있어요.
  - "다시 불러오기"는 같은 주소로 가는 **일반 `<a>`**예요. 새 문서를 요청하므로 서버에서 새로 읽어요.
  - 폼·버튼·폴링·타이머·client 코드는 없어요.
- **날짜 오류 방어**: 날짜가 잘못돼도 화면 전체가 실패하지 않고 "확인 불가"로 보여요. 화면에 표시되는 시각은 조회 시각 하나뿐이에요.
- **세션 경계**: 기존 `(cloud)` 레이아웃의 SessionBoundary/ProtectedContent를 그대로 써요.
