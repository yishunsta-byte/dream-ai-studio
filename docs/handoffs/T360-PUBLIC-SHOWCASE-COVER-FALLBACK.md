- 새 요청이나 공급원 변경은 없어요. 기존 이미지 주소만 써요.

**`neon-showcase.tsx`의 바뀐 동작**
- **상태 공유:** 표지 상태를 주소별로 `NeonShowcase` 한곳에 둬요(`coverStates`). 대표·카드·음악·상세가 같은 상태를 함께 써요.
  - 실패는 그 주소에서 되돌리지 않아요. 같은 주소의 다른 자리는 이미지를 다시 요청하지 않아요.
  - 주소(작품·세대)가 바뀌면 새 주소는 '불러오는 중'에서 다시 시작해요.
- **수화 전 완료 확인:** 서버 HTML 이미지가 수화 전에 끝난 경우를 위해, 연결될 때 `complete`·`naturalWidth`로 한 번 확인해요.
  - `onLoad`에서도 `naturalWidth` 0이면 실패로 봐요.
- **`CoverPlate`:** 장식 아이콘(`aria-hidden`)과 상태 문구를 그려요.
- **카드:** 실패일 때만 버튼 `aria-describedby`로 상태 문구를 연결해요. 이름은 `〈작품명〉 자세히 보기` 그대로예요. 재생 삼각형 `▶` 대신 상세 화살표 `↗`(장식)를 써요.
- **대표:** 제목·설명 아래 한 줄로 상태를 보여 줘요. 자리를 미리 잡아 버튼이 움직이지 않아요. 표지가 없으면 그라데이션 바탕을 쓰고, 버튼은 `▶` 없이 "작품 자세히 보기"예요.
- **음악 모음:** 정사각 `coverBox` 안에 바탕과 이미지를 둬요. 실패하면 "표지 조회 실패"예요.
- **상세 (`DetailCover`):** 재생 파일이 없는 작품과 음악 재생 작품의 표지 자리예요.
  - 연 순간 '불러오는 중'이었다가 실패하면 화면에 보이지 않는 알림 영역(`role=status`)에서 한 번만 알려요. 초점은 옮기지 않아요.
  - 영상 재생 작품은 기존 `<video poster>` 그대로예요. poster 실패는 재생 오류로 보지 않아요.
