# P2 글자 편집기 · 저장 전 새로고침과 탭 닫기

T171의 P2-3 잔여 검증 중 일반 문구 초안을 대상으로 했다. Chrome 157.0.8103.50 데스크톱 headless 모드에서 독립 프로필 3개로 각각 실행했다. T173 고정 앱 44b036a에서 가상 프로젝트 사본을 열었다. 이탈 경고를 설치하는 editing-panel.tsx와 문구 입력을 처리하는 text-editor.tsx는 작업 기준 377e266의 소스와 줄바꿈 정규화 후 일치했다.

| 편집 상태와 브라우저 조작 | 관찰 결과 | 재현 |
|---|---|---|
| 저장된 문구 그대로 새로고침 | 확인창 없이 문서가 교체되고 저장 문구 표시 | 3/3 |
| 문구 수정 후 새로고침 취소 | 기본 beforeunload 확인창이 열림. 취소 후 같은 문서에 입력한 초안 유지 | 3/3 |
| 이어서 새로고침 승인 | 새 문서에서 마지막 저장 문구 표시 | 3/3 |
| 수정한 문구를 원래 값으로 되돌린 뒤 새로고침 | 확인창 없이 다시 로드 | 2/2 |
| 문구 수정 후 탭 닫기 취소 | 기본 확인창에서 취소한 뒤 탭과 입력값 유지 | 3/3 |
| 이어서 탭 닫기 승인 | 브라우저 대상 목록에서 해당 탭이 사라짐 | 3/3 |

**재현 방법** — T173 합성 runtime을 별도 경로에 복사해 DREAM_DATA_ROOT로 지정한다. 격리 앱에서 `node node_modules/next/dist/bin/next dev --webpack -H 127.0.0.1 -p 3188`로 실행하고 가상 프로젝트 `019b8b74-3f10-7137-8265-68b11d809f0c`의 편집 화면을 연다. 제목 ‘1:1 모바일 저장 확인’에 문자열을 입력한 뒤 위 순서대로 새로고침 및 탭 닫기를 수행한다. 복원 대조에서는 입력란을 전체 선택하고 원래 제목으로 교체한다.

자동 검증에서는 Chrome의 Page.reload와 Page.close를 호출하고 javascriptDialogOpening.type이 beforeunload인 경우에만 확인창에 응답했다. 문서 교체는 performance.timeOrigin, 초안은 실제 입력값으로 대조했다. 세 실행에서 타임라인 저장 POST는 모두 0건이었다. 브라우저와 로컬 서버를 종료했다. 실행별 JSON과 재현 스크립트는 작업본의 `tmp/p2-native-unload/`에 있다.

**후속 검수 범위** — 외부 저장 경합 후 복구 상자만 열린 상태의 기본 확인창과 모바일 브라우저는 별도 확인 대상이다.
