- **검수 후 준비**는 완료 원본의 ID·리비전·해시, 같은 원본의 공개 권리, 승인 대상 공개 문구와 커버 증빙에 대기 세대를 묶습니다. 권리 확인 체크는 운영자의 의사 확인이며 서버 증빙이 있어야 통과합니다.
- **게시**는 대기 세대와 결정을 다시 대조합니다. 해당 세대의 불변 WebP 객체 키, 길이·SHA-256·실제 디코딩·너비·높이와 현재 권리 유효 시각이 맞으면 게시합니다. 최초 지원은 T253의 이미지·표지 범위입니다. 영상·음악 재생 파일의 증빙과 제공은 후속입니다.
- **철회**는 요청에서 확인한 대기 또는 활성 세대 하나에만 적용합니다. 별도 활성·대기 세대가 있으면 유지합니다. 활성 세대의 철회·교체·권리 만료 이후에는 새 목록과 이전 표지 조회가 닫힙니다. 표시용 목록과 공개 파일 조회에는 같은 커밋 상태가 필요합니다.
- 상태 변경, 관리자 감사 기록, 성공 요청 원장을 한 트랜잭션에 저장합니다. 같은 actor·요청 ID·지문의 성공 재전송은 당시 결과를 반환하며 공개 상태를 바꾸지 않습니다. 권한·입력·충돌·증빙·저장 실패는 전체 상태를 보존합니다. 현재 서비스는 성공 결과만 원장에 기록합니다. T253의 합성 SQL은 충돌과 원본 부적합도 원장에 기록하므로 운영 저장소를 연결할 때 이 차이를 정합화해야 합니다.
