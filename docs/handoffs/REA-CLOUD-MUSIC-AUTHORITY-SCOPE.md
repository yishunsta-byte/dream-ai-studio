# 클라우드 콘텐츠 분석의 음악 등록 권한 범위

2026-11-20 KST · Codes(Backend) · Master 배정 `msg_00c7cef325e6` · 기준 `7514ad0`

**첫 후보는 소유 루프백 환경의 검증된 PCM WAV 한 건이다.** 비공개 WAV 등록은 검증 원문과 SHA-256을 보관하고, 음악 분석기·결과 형식은 이미 존재한다. 두 기능을 이어 줄 음악용 분석 승인·현재 등록 증거가 필요하다. MP3는 분석이 검증됐지만 등록 공급원은 별도다. ## 음악만 추가하는 최소 후보

1. **PCM WAV 등록 증거와 분석 허가를 격리 환경에 결합한다.** WAV 원문·자산을 읽을 수 있는 별도 최소 권한 역할을 준비한다. 기존 업로드 역할의 쓰기 권한을 재사용하지 않는다. 새 소유 루프백 시험 한 곳에서 실제 등록 검사와 동일 소유자 프로젝트·자산·`rea-reference` 링크를 대조한다. 기존 두 시험의 대상 가드는 보존한다. 범위 허가는 검증된 계정·프로젝트·자산, 사용 목적, 별도 승인 세대에 묶고 권리 메모를 승인 판단에서 제외한다.
2. **등록 사본의 해시·현재성·철회를 한 계약으로 확인한다.** 서버가 소유자와 ID로 등록된 바이트를 구해 저장소·복원 세대, 자료·권한 세대, 정규 MIME·크기·SHA-256·PCM 메타데이터 및 유효 기한과 함께 대조한다. 제한 디렉터리의 요청별 사본을 `analyzeRegisteredReferenceSnapshot`에 전달하고 완료·취소·실패 때 삭제한다. 권한, 프로젝트 링크, 등록 증거, 복원 세대가 바뀌면 이전 선택에서 결과를 만들 수 없어야 한다. 재승인은 새로운 현재 증거와 세대로 검사하며 발급·철회와 읽기 권한을 분리한다. [현재 증거와 경합](T311-REA-CURRENT-STORAGE-EVIDENCE-PG17-PROBE.md)
3. **WAV 시간축은 등록 원본으로 검증한다.** 기존 실측에서 컨테이너와 트랙 시작 시각을 확인할 수 없는 WAV는 프롬프트를 만들지 못했다. 우선 실제 등록한 단일 PCM WAV가 검증된 시간 범위를 만드는지 확인한다. 시작 시각을 도구에서 얻을 수 없을 때는 검증된 단일 PCM 청크의 첫 샘플과 연속된 프레임으로 0부터의 파일 내부 시간축을 계산할 수 있는지 별도 시험한다. 검사와 디코딩이 일치하지 않으면 결과를 보류한다.
4. **기존 목록·분석 경계에 음악 검증 결과만 연결한다.** 동일한 승인 판단을 격리 목록과 POST에 사용한다. 목록은 프로젝트 ID·자료 ID·표시 이름, 결과는 기존 `media: music` 제안 DTO를 이용한다. 현재 등록이 확인된 WAV에 한해 동작을 비교한다. MP3는 별도 등록에서 실제 포맷·코덱과 단일 트랙 검증, 비공개 원본·SHA-256·등록 증거·철회 시험이 확보된 뒤 추가한다. M4A도 로컬 분석 입력으로 분류되지만 첫 등록 후보에는 포함하지 않는다. [음악 결과 DTO](../../lib/reference-analysis/studio-analysis-result-dto.ts)

## 구현 후 독립 검수 기준

| 검증 | 최소 합격 기준 |
| --- | --- |
| 긍정 경로 | 소유 루프백 PG17의 합성 모노·스테레오 PCM을 기존 입력 검사로 등록한다. 실제 등록 원본·사본의 해시와 길이 일치, 각 소유자 목록, 음악 RMS·시간 범위와 제안 DTO를 확인한다. 등록 원본에 대한 바이트·업무 데이터 변경이 없는지 확인한다. |
| 형식·소유권 | 위장 MIME, 잘린 청크, 초과 크기·채널, 미확인 시간 범위, 등록 해시 불일치, 등록 전 MP3, 타인 프로젝트·자료, 제작용 링크 단독, 미확인 분석 권한을 거절한다. 목록·제안에는 원문·권리 메모·저장 키·해시를 노출하지 않는다. |
| 철회·수명 | 공급원 미연결 503, 익명 401, 비허용 403, 정상 빈 목록 200, 모든 목록 응답의 `private, no-store`. 범위 승인 철회·재승인, 자산 보관, 다운로드 중 교체, 같은 SHA를 가진 새 세대, 복원·만료, 계정 전환, 취소·시간 초과에서 이전 자료와 결과 차단 및 임시 사본·자원 정리를 확인한다. |
| 자료 비노출 | 실제 Next HTML·인라인 RSC·Flight와 프리페치에서 음악 ID·라벨·결과 미포함 및 목록 호출 0을 확인한다. 기존 이미지·영상, WAV 등록·편집과 공개 경로의 회귀를 함께 대조한다. |
