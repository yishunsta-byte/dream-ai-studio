## 1. 바꾼 것

T097의 "정확한 자기 버전에서만 이어받기"는 그대로 둬요. refresh가 다른 창의 더 새 버전을 가져온 경우를 이렇게 바꿨어요.

- **편집 기준은 외부 최신본 그대로예요.** 자동 저장·자동 합치기·재기준화는 하지 않아요. 복구 자료를 적용하는 버튼도 없어요.
- **복구 자료 = 이 화면의 마지막 상태 전체(JSON)**
  - `draft`: 보낸 뒤 고친 것까지 포함한 Timeline 전체(문구·시간·style·box·animation·kind·locked, 글자 순서, 장면 순서, 그 밖의 필드)
  - `sent`: 보낸 Timeline 전체
  - `timeFields`: 시간 칸에 적다 만 값과 오류 그대로
  - `selectedTextId`, `selectedAtSend`
  - 버전: `sentFrom`(보낸 기준 내용 revision·타임라인 id·r), `ownSave`(자기 저장 응답), `shown`(지금 화면 버전)
  - `createdAt`, 형식 이름·버전, 안내 문장
  - 프로젝트 id 외에 개인정보·경로는 없어요.
- **상자가 나오는 조건**: 보낸 뒤 바뀐 것이 하나라도 있을 때예요. 글자의 어느 필드든, 글자 순서, 장면 순서, 그 밖의 설정, 시간 칸 입력, 고른 글자 중 하나라도 바뀌면 나와요. 아무것도 안 바뀌었으면 상자 없이 그 버전만 보여 줘요.
- **상자** (디자인 제안 반영)
  - 목록
    - 고친 글자·새로 넣은 글자·뺀 글자마다 종류, 시간, 바뀐 것(문구 / 시간 / 모양(글꼴·크기·색·외곽선·띠·그림자) / 위치 / 움직임 / …), 문구 전체
    - 장면 순서, 글자 순서, 그 밖의 설정
    - 시간 칸에 적다 만 값 (원문 그대로)
    - 고른 글자
  - "복구 자료 복사"
    - 클립보드에 복사하고 `role=status`로 "복사했어요. 메모장 같은 곳에 붙여 두세요."를 알려요.
    - 클립보드가 막히면 같은 자리에 읽기 전용 칸이 나와요. 칸에는 JSON 전체가 들어 있고 최대 높이 200px로 스크롤돼요. "아래 내용을 모두 골라 복사해 주세요."라고 안내해요.
  - "파일로 받기": 브라우저 Blob 다운로드로 `dream-timeline-recovery-r{보낸 기준 r}-to-r{새 r}-{YYYYMMDD-HHmm}.json`를 내려받아요. 서버·DB에는 아무것도 쓰지 않아요.
  - 닫기 안내: "닫으면 이 목록과 복구 자료는 다시 볼 수 없어요. 다른 화면으로 가거나 새로고침해도 사라져요." + "확인했어요"(사용자가 직접 누를 때까지 유지)
  - 상자가 열려 있는 동안은 저장하지 않은 변경이 없어도 새로고침·창 닫기 때 브라우저 확인이 나와요(`beforeunload`).
  - 초점: 상자가 나오면 상자로, 복사·받기 뒤에는 그 버튼에 머물러요. 닫으면 저장 상태 글로 가요.
  - 390: 버튼은 세로로 쌓이고 폭 100%·높이 44px예요. JSON 칸은 pre-wrap이라 가로 넘침이 없어요.
- 코드
  - `lib/edit/text-ops.ts`: `laterChanges`가 바뀐 필드 갈래(`parts`)·글자 순서·그 밖의 설정까지 돌려줘요. `hasLaterChanges`, `recoveryJson`, `recoveryFileName`을 새로 넣었어요(순수 함수).
  - `components/editing-panel.tsx`: handover에 `sentFrom`과 `sentSelectedId`를 더했어요. `RecoveryBox`를 새로 만들었어요(fetch·router·setDraft 없음).
  - `text-editor.module.css`
- 전체 편집 잠금 대안은 쓰지 않았어요. 정상 경로(자기 버전)의 저장 중 편집 유지를 지키면서도, 버리는 입력이 없어서예요.

- 31초 지연, 다른 프로젝트 왕복, StrictMode는 이번에 다시 돌리지 않았어요. 이번에 바꾼 것은 다른 버전이 왔을 때의 상자뿐이라, T097 증거를 이어받아요.
