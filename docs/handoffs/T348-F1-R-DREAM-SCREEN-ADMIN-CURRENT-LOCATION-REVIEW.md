# T348-F1-R 관리자 메뉴 현재 위치 독립 검수

2026-11-19 KST · Codex(Tester) · 고정 커밋 `a297c0f031d8ec177d7a118105167ec77e4d523b` · Master 배정 `msg_3afc567258db`

**판정은 통과.** T348에서 확인한 현재 위치 상태 누락이 해소됐다. 고정 4경로는 관리자 허브, 신규 관리자 메뉴, 구조 집중 시험, 작성자 인계다.

- 기존 개발 검증기와 합성 인증을 사용한 격리 Chromium에서 직접 `#admin-project-list`와 인코딩한 `#%61dmin-review` 진입을 확인했다. 해시 없음, 미등록 해시 `#not-registered`, 해석 불가 해시 `#bad-%ZZ`에서는 개요가 현재 위치였다. 각 상태에서 `aria-current="location"`은 한 링크에만 있었고 CSS 배경으로 강조한 링크와 일치했다. 서버 HTML의 기본 현재 위치는 집중 시험에서 개요 한 개로 확인했다.
- 내 프로젝트와 완성본 검수·게시를 차례로 클릭하고 뒤로·앞으로 이동했을 때 주소·현재 위치 속성·강조가 함께 바뀌었다. 390px에서 Tab·Enter로 네 메뉴를 각각 활성화하자 각 본문 영역으로 초점이 이동했고, 계정 설정 다음 Tab은 비밀번호 변경으로 갔다.
- 1280px에서는 왼쪽 탐색, 390·320px에서는 본문 앞 2열 탐색이었다. 세 폭 모두 가로 넘침이 없었다. 메뉴 높이는 48px 이상이었다. 미인증 `/admin`의 307 로그인 이동과 확인 계정의 프로젝트·게시 미연결 안내를 확인했다. 합성 정상 목록·빈 목록·조회 실패도 각각 구분됐다.
- 관리자·인증·세션 보호·비밀번호 재설정·프로젝트·게시 집중 회귀 13파일 352건, 소스 타입 검사, 변경 TypeScript ESLint 및 커밋 diff 공백 검사가 통과했다.

Chromium의 에뮬레이션 폭과 DOM 접근성 속성·초점을 검증했다. 물리 모바일 기기, 다른 브라우저, 스크린 리더 음성, 실제 운영 계정·공급자는 범위 밖이다. 개발 검증기 사본의 한글 선택자 인코딩을 바로잡아 재실행했으며 고정 제품 파일은 수정하지 않았다. 검증 자원과 사본을 정리했다. 운영·프로덕션 빌드·배포 변경 및 새 창·에이전트·worktree 생성은 없었다.
