# T359 공개 홈 표지 대체 표시 명세

2026-11-19 KST · Codex(design) · Orca `msg_1ab51099bcef`

T357-R 격리 검수에서는 합성 승인 작품의 카드와 상세가 정상적으로 열렸고, 표지 공급원이 비활성인 사본의 표지 요청은 404였습니다. 재생 파일도 연결돼 있지 않았습니다. 아래 명세는 공개 홈의 DREAM SCREEN 스타일을 사용하며, 승인 목록·표지·재생 상태를 각자 표시합니다. [T357-R 격리 검수](T357-R-PUBLIC-SHOWCASE-FRONTEND-REVIEW.md) · [기존 공개 홈 시안](../design/t232-public-showcase/neon-screen.html)

## 표시 상태와 문구

| 표지 상태 | 화면 문구 | 처리 |
| --- | --- | --- |
| 로딩 | `표지 불러오는 중` | 승인 작품의 제목·설명·상세 이동은 즉시 표시합니다. 이미지 자리에는 같은 크기의 고정 바탕을 둡니다. |
| 로드 성공 | 상태 문구 없음 | 기존 이미지와 비율, 크롭을 사용합니다. |
| 조회 실패 | `표지를 불러오지 못했어요` | 이미지 요소와 깨진 이미지 아이콘을 화면에서 숨기고 고정 바탕으로 전환합니다. 404와 네트워크 오류, 디코딩 오류의 화면 문구는 같습니다. |
| 미연결 | `표지 미연결` | 공개 표시 계약에서 표지 미연결을 명시적으로 확인할 수 있는 경우에만 씁니다. 이 경우 이미지 요청을 시작하지 않습니다. |

브라우저의 이미지 오류 이벤트만으로는 미연결이나 철회 원인을 단정할 수 없습니다. T357-R과 같이 현재 화면이 미연결 상태를 별도로 받지 못하면 404는 `표지를 불러오지 못했어요`로 표시합니다. 상태를 구분하려고 별도 조회를 추가할 필요는 없습니다. 원인 안내에 HTTP 코드, 저장 키, 권한 상세를 넣지 않고, 이미지 오류가 자동 요청을 반복하거나 다른 작품·샘플 이미지를 대신 불러오지 않게 합니다. 새 작품이나 표지 세대로 바뀌면 이전 이미지의 성공·실패 상태를 이어 쓰지 않습니다.

## 화면 적용

| 위치 | 대체 표시와 동작 |
| --- | --- |
| 작품 카드 | 기존 16:9 틀을 채운 무광 바탕에 작은 이미지 아이콘과 상태 문구 한 줄을 둡니다. 제목·제작자·형식은 이미지 바깥의 기존 위치에 유지합니다. 카드 전체는 상세를 여는 버튼입니다. 재생 삼각형 자리에는 상세 열기를 뜻하는 중립 화살표를 사용하고, 접근 가능한 이름은 `〈작품명〉 자세히 보기`로 유지합니다. |
| 음악 모음 | 같은 바탕을 기존 정사각형 틀에 적용합니다. 공간이 좁으면 조회 실패 문구를 `표지 조회 실패`로 줄일 수 있습니다. 작품 제목과 음악 상세 열기 동작을 유지합니다. |
| 대표 작품 | 제목과 설명 아래에 표지 상태를 한 줄로 표시하고, 이미지 영역에는 기존 네온 계열의 어두운 그라데이션을 사용합니다. 기존 대표 영역 크기와 `작품 자세히 보기`를 유지하고 버튼 앞의 재생 삼각형은 제거합니다. |
| 상세 대화상자 | 기존 미디어 영역 크기에서 표지 대체 바탕을 표시하고 작품 제목·설명·닫기 버튼을 유지합니다. 재생 파일이 없는 영상·음악에는 `재생할 수 있는 영상 파일이 아직 연결되지 않았어요.` 또는 `재생할 수 있는 음악 파일이 아직 연결되지 않았어요.`를 사용합니다. 대표 이미지가 있다고 전제하는 문장은 쓰지 않습니다. 재생 파일이 있으면 표지 실패와 별개로 플레이어와 기존 재생 오류 안내를 유지합니다. 동영상의 poster 요청 문제를 동영상 자체의 재생 오류로 처리하지 않습니다. |

대체 바탕은 기존 다크 토큰 `#171622`와 `#242133`, 보조 텍스트 `#bcb6cd`를 사용합니다. 대표 영역만 기존 어두운 퍼플·블루 그라데이션을 사용합니다. 실패·미연결 모두 같은 바탕과 아이콘을 쓰고 문구로 구분합니다. 인위적인 작품 이미지, 애니메이션 스켈레톤, 새 액션 배지를 추가하지 않습니다. 정상 로드된 예시 카드와 승인 카드의 기존 표지 표시는 유지합니다.

## 모바일·접근성 검수 기준

- 320px·390px·1280px에서 대표 영역, 카드, 정사각형 음악 모음, 상세의 틀이 이미지 로드 및 오류 전후에 유지됩니다. 상태 문구는 320px에서 최대 두 줄로 읽히며 이미지 안 문구와 카드 이름이 겹치지 않습니다. 가로 넘침을 추가하지 않고, 인터랙션의 크기는 최소 44×44px로 유지합니다.
- 상태 문구는 텍스트로 읽히고 작은 글자는 실제 배경과 최소 4.5:1 대조를 유지합니다. 장식 아이콘은 보조기기에서 숨깁니다. 카드 버튼의 이름은 작품 제목과 상세 열기 동작으로 유지하고, 표지 상태는 필요한 경우 별도 설명으로 연결합니다. 같은 제목·상태를 이미지 대체 텍스트와 버튼 이름에서 반복하지 않습니다.
- 카드 여러 개의 로딩·실패를 라이브 영역으로 한꺼번에 읽지 않습니다. 열린 상세에서 사용자가 보고 있는 표지가 비동기로 실패한 경우에만 짧은 상태 문구를 한 번 알릴 수 있습니다. 기존 재생 피드백과 별도로 유지합니다. 표지 상태가 바뀌어도 초점을 이동시키지 않습니다.
- Tab·Enter로 표지 성공·실패 카드 모두 상세를 열 수 있고, 열리면 닫기 버튼에 초점이 갑니다. Esc와 닫기 버튼을 쓰면 해당 카드나 대표 상세 버튼으로 돌아갑니다. 새 목록에서 카드가 사라졌다면 남아 있는 탐색 영역의 제목이나 컨트롤로 돌아갑니다.

## 공개 권한과 Front 인계

대체 표지는 현재 공개 목록이 표시하도록 승인한 작품에만 적용합니다. 철회·만료·비공개·미승인으로 새 목록에서 제외된 작품에는 카드, 대표, 상세, 대체 표지를 보여주지 않습니다. 새 데이터에서 제외된 작품의 이전 상세는 닫고 이전 썸네일을 보이지 않게 합니다. 기존 공개 세대 주소, 표지 최종 권한 확인, `no-store`, 공개 홈의 뒤로 가기 재조회 및 CSP 가드는 그대로 사용합니다. 목록이 장애일 때는 기존 홈 장애 안내를 사용하며, 빈 목록·명시적 예시는 기존 피드 정책에 따릅니다.

Front 검수는 정상 이미지, 지연 로드, 404, 디코딩 오류, 명시적 미연결이 제공되는 경우, 표지 오류와 재생 연결의 조합을 각각 시험합니다. 철회 후 새 홈과 상세 상태도 함께 확인합니다. T357-R 합성 조건에서는 승인 작품의 텍스트와 상세 동작이 유지되고, 카드·대표·상세에는 대체 표지, 상세에는 별도의 재생 미연결 문구가 보여야 합니다.
