# T281 REA 등록 권한 세대 최소 PG17 격리 시험

2026-11-19 KST · Codes(Backend) · 기준 `242a5d4b24d26bb96e843f99956fb2df526f60d9` · 배정 `msg_262cb0a6fb5c` · PG17 범위 확인 `msg_c0d3f2409a34`

고정 SQL1–4 위에 시험 전용 후보 하나를 적용했습니다. 기존 프로젝트·자료 연결에서 소유자 및 범위 기준 행을 **비활성**으로 초기화합니다. 별도 제한 승인 역할은 먼저 소유자 행의 고유 키에 삽입을 시도하고, 새 문장에서 그 행을 잠가 승인 또는 철회를 진행합니다. 링크 변경은 소유자→프로젝트→자료 순서로 잠근 뒤 수행하며, 이동은 이전·새 프로젝트와 자료를 정렬해 잠급니다. REA 용도의 연결이 바뀌면 해당 링크 세대를 진행시키며 기존 승인을 닫습니다. [격리 후보 SQL](../../tests/reference-analysis/managed-authority-generations.sql) · [T280-F1 독립 검토](T280-F1-R-REA-MANAGED-AUTHORITY-GENERATIONS-REVIEW.md)

후보는 고정 시험 DB 이름, 부트스트랩 역할, 실제 PG17, 루프백 주소 및 시험 설정을 검사합니다. 소유자·범위 테이블에 강제 RLS를 적용했고, 소유자 설정은 시험 로그인에서 트랜잭션 로컬로 주입했습니다. 제한 API는 자신의 상태를 읽고 검증된 링크 함수만 호출하며, 제한 운영자는 승인·철회 함수만 호출합니다. 시험에서는 API·worker가 링크를 직접 변경하거나 프로젝트/자료의 보관 값을 직접 갱신할 수 없게 관련 권한을 회수했습니다. 제품의 열별 ACL 이관과 실제 Auth 출처 검증은 별도입니다.

## 실제 PG17.12 시험

실행 명령은 `node tests/reference-analysis/managed-authority-generations.pg17.mjs`입니다. 기존 서명된 EDB 바이너리를 사용하고, 신설 루프백 임시 클러스터에서 임의로 생성한 시험 로그인과 합성 행으로만 실행했습니다. [집중 실행기](../../tests/reference-analysis/managed-authority-generations.pg17.mjs)

| PG17 검증 | 관측 |
| --- | --- |
| 고정 SQL1–4 | 저장소 소스 해시를 대조한 후 임시 DB에 적용했습니다. |
| 고정 SQL5 | 원문 그대로 제출했으며 PG18 사전조건의 `B27_PREFLIGHT_UNVERIFIED`를 확인했습니다. 롤백 뒤 예약 스키마와 역할이 없었습니다. 원문과 게이트를 그대로 보존했습니다. |
| 초기 상태·동시 첫 승인 | 기존 A 링크의 소유자·범위는 비활성이었습니다. B의 동일 소유자 최초 승인과 같은 범위의 최초 승인을 각각 두 연결로 경합시켰습니다. `pg_blocking_pids`에서 실제 대기 관계를 확인했고, 각각 첫 커밋만 승자가 되어 소유자·범위 세대가 한 번 진행했습니다. |
| A/B 액터와 ACL | 제한 로그인으로 상대 소유자 행 접근과 B의 링크를 A가 변경하는 호출을 거절했습니다. 직접 링크·보관 변경, API의 승인 권한, helper의 직접 실행 및 운영자의 직접 상태 갱신을 차단하고 스냅샷을 대조했습니다. 두 후보 테이블의 강제 RLS도 카탈로그에서 확인했습니다. |
| 삭제·재연결·이동 | 같은 트랜잭션 내 삭제·재연결은 세대가 2 증가하고 기존 승인 상태가 비활성으로 바뀌었습니다. REA 용도가 아닌 별도 링크 변경은 해당 세대를 유지했습니다. 프로젝트와 자료를 함께 옮기자 이전·새 범위가 모두 진행했습니다. |
| 쓰기 실패·철회 | 이동 대상의 중복 키로 INSERT를 실패시켰습니다. 먼저 삭제했던 링크 및 진행했던 세대가 포함된 전체 후보 스냅샷이 롤백됐습니다. 범위 철회와 소유자 철회·재승인 뒤 이전 범위는 비활성이고 다른 소유자의 상태는 그대로였습니다. |

실행기 구문 검사와 ESLint 경고 0을 확인했습니다. 최종 실행은 정상 종료했고 소유 프로세스, 리스너와 임시 클러스터를 정리했습니다. 첫 실행의 Windows 경로 표기 검사가 실패했을 때도 소유 PID·실행 파일·데이터 경로·루프백 리스너를 대조해 해당 프로세스만 종료하고 임시 파일을 정리했습니다. 공유 SQL1–5는 기준 커밋과 동일합니다.

후보의 활성 값은 **시험용 프로젝트 권한**입니다. 실제 Auth, 해시·스토리지 전이, `SQL5`와 후보의 상호작용, 종결 영수증·복원 게시/읽기 경합은 입증 범위 밖입니다. SQL5 상호작용은 고정 PG18 조건을 만족하는 별도 격리 검증이 필요합니다. CAS의 `content_revision`, 타임라인 포인터와 `stage_states` 쓰기 권한 계약이 확정될 때까지 타임라인 적용 연결도 보류합니다.
