## 4. 미확인 조건

1. **구현자 캡처 육안 대조 안 함** — 원본이 아직 오지 않음. 오면 1280·390에서 옮긴 글자 위치·크기·색, 새 경고 줄바꿈, 검수·내보내기 링크를 본다.
2. 이관 **전** P1 화면 캡처 없음(보고 62줄) — 전후 같음은 시험과 화면 값으로만 확인됨. 디자인 쪽 픽셀 비교 증거는 없음.
3. 실제 실행(production Next·CLI·브라우저)은 구현 보고와 독립 검수 T-065 몫. 이 문서는 읽기 판정만.
