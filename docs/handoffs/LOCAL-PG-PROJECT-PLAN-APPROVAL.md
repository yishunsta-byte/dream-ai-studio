# 로컬 PG 기획 승인과 장면 제작 단계 개방

Master 배정 `msg_13dbf700ddc3`. 로컬 기획 초안 저장 `ef02165`를 기준으로, 프로젝트 소유자가 저장된 기획 버전을 검토하고 승인하는 동작을 연결했다.

- 기획 화면에서 저장된 대본과 장면을 확인한 뒤 확인란을 선택하고 **기획 승인하고 장면 제작 열기**를 누른다. 대본이나 장면을 수정하면 확인이 해제되며, 변경을 저장하고 다시 확인해야 한다.
- [기획 API](../../app/api/projects/%5Bid%5D/plan/route.ts)는 서버가 확인한 소유자, 현재 내용 리비전, 최신 초안의 ID와 버전을 확인한다. 초안 저장과 승인은 같은 프로젝트 행을 잠근다.
- 한 트랜잭션에서 해당 기획과 승인 장면 목록을 고정하고, 순서대로 제작용 장면을 생성하고, 프로젝트와 기획 단계에 승인된 기획을 연결한다. 제작 단계가 `todo`가 되며 승인 활동을 한 건 기록한다.
- [로컬 PG 권한](../../lib/db/postgres/local-project-brief/local.sql)은 임시 PG17에 적용한다. 이미 연결된 장면·자료·캐릭터를 포함한 기존 초안은 이 화면에서 읽을 수 있다. 이 승인 동작은 새 로컬 초안의 장면 생성에 적용한다.

## 자체 검증

- `npm.cmd run typecheck`, 변경 코드 ESLint 및 인증·기존 가드·기획 시험 256건 통과.
- `T371_VERIFY_HTTP=1`로 `node --conditions=react-server --import tsx tests/postgres/t368-run-private-image-project-create.mjs` 종료 코드 0. 실제 Next.js와 임시 PG17에서 익명·타인·다른 출처·구버전·다른 초안 ID·미확인 요청을 거절했다. 동시 승인 두 건은 200과 409를 반환했고 승인 활동은 한 건이다.
- 활동 기록 INSERT를 실패시킨 뒤 기획 승인, 승인 포인터, 장면 및 제작 단계 변경이 함께 롤백되는지 확인했다. 승인 성공 후 재조회는 동일한 대본·장면과 열린 제작 단계를 반환했다. 편집 단계는 잠겨 있고 타임라인은 0건이다.
- 브라우저에서 미확인 상태 승인 차단, 수정 시 확인 해제, Space와 Enter로 확인·승인, 승인 완료 제목으로 초점 이동을 확인했다. 새로고침 후에도 대본과 장면 두 개가 읽기 전용으로 표시됐고 프로젝트 상세는 기획 **승인됨**, 장면 제작 **할 일**, 수정·조립 **잠김**을 표시했다.
