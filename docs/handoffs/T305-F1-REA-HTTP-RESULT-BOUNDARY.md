# T305-F1 작업실 분석 HTTP 결과 경계

2026-11-19 KST · Codex(design) · 기준 `ca8fc72` · 배정 `msg_3619e8669785` · 네이티브 실행기 승인 `msg_d29d171c5306`

기존 등록 자료 resolver를 통한 T284 결과와 전체 분석 콜백 결과를 HTTP 직렬화 전에 동일한 공개 DTO 스키마로 검증합니다. 새 서버·클라이언트 공용 모듈은 T292의 버전 1 검사와 관찰 시각·근거 참조 검사에 기반합니다. 같은 결과 안의 중복 관찰 ID, 관찰과 추정의 ID 충돌 및 중복 근거 참조도 차단합니다. 클라이언트는 같은 스키마를 HTTP 수신 뒤 다시 적용합니다.

계약 외 키, 중첩 내부 키, 버전 변경, 잘못된 관찰 참조와 허용되지 않은 JSON 형태를 받으면 HTTP 503 `analysis_unavailable`과 `Cache-Control: no-store`를 반환합니다. 유효한 결과는 스키마가 만든 공개 객체를 직렬화합니다. 응답과 서버 로그에 원본 진단이나 검증 상세를 기록하지 않습니다. 유효한 T284 실패 DTO 다섯 가지, 취소 및 시간 초과 응답은 기존 규칙을 따릅니다. 표시용 문자열의 작성 책임은 기존 분석 공급자에 있습니다.

## 자체 검증

- 집중 시험에서 두 응답 경로에 상위·중첩 내부 필드, `toJSON`, 버전 오류, 잘못되거나 중복된 관찰 참조를 넣었습니다. 두 경로 모두 안전한 503과 `no-store`를 반환했고 응답 원문과 오류·경고 로그에 합성 진단이 없었습니다. 유효한 분석 결과와 다섯 가지 실패 DTO는 유지됐습니다.
- 네이티브 분석을 켜고 합성 PNG, 색상이 바뀌는 MP4, 주기적으로 펄스가 발생하는 M4A를 실제 T284로 처리했습니다. 두 HTTP 경로 모두 PNG 초안, MP4 장면 전환 후보, M4A 템포 추정을 포함한 정상 DTO를 반환했습니다. 경로·파일명·해시·사용자 및 자료 ID는 응답에 없었습니다. T292 공급자의 오류·본문 정리·기한·취소·재시도 시험도 통과했습니다.
- 기존 격리 실행기는 기준 `4f26134` 사본에 공용 스키마와 T292 공급자를 추가로 복사합니다. 실제 Next와 루프백 SDK에서 전체 분석 콜백이 내부 진단 필드를 반환하는 경우 원시 응답이 503 `analysis_unavailable`과 `no-store`로 제한됐습니다. 응답과 해당 시점의 서버 로그에 합성 진단이 없었습니다. 기존 A/B/A, 단일 객체 GET, 철회, HTTP 취소와 사본 정리도 통과했습니다.
