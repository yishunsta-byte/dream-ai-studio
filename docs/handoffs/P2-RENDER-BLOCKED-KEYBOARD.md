# 키보드로 영상 만들기 차단 사유 확인

렌더 화면의 기본 만들기 버튼에 차단 사유가 있으면 Tab 순서에 남고 접근성 트리에서 비활성 상태와 사유를 제공한다. 이 상태에서는 버튼의 요청 처리기를 연결하지 않는다. 영상 만들기 제목으로 이동한 직후 사용자가 이미 다음 요소에 초점을 옮겼으면 제목으로 되돌리지 않는다.

로컬 프로젝트에서 렌더 요청 1건을 대기 상태로 만들었다. Chrome 390px와 1280px에서 영상 만들기 제목 → Tab → 만들기 버튼을 확인했다. 두 폭의 접근성 트리에 버튼 이름, 비활성 상태, 실제 차단 사유가 함께 있었다. Enter와 Space 뒤에도 초점은 버튼에 있었으며 렌더 POST와 추가 출력 레코드는 각각 0건이었다. 시험용 요청을 취소한 뒤 검수에서 실제 r45 MP4 카드로 이동하는 두 화면 폭의 초점 회귀도 통과했다.

렌더 테스트 24건, 전체 타입 검사, 변경 파일 ESLint 통과. 접근성 확인은 Chrome 트리와 실제 키 입력 기준이다.

> 플래너 전달문 — Tab으로 영상 만들기 차단 사유까지 이동합니다. Chrome 두 폭에서 접근성 이름·비활성·설명과 Enter·Space 요청 0건을 확인했습니다.
