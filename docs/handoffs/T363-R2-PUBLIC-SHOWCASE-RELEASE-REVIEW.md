# T363-R2-R 공개 홈 후보 r2 증분 독립 검수

**판정: 공개 홈 증분 검수 통과.** 후보 `2511a1e5448dcac5f15b8ffd4f0e29d816119f53`, 부모 `3c57eff6724886d104faab1937059579647e5ffb`, 직전 후보 `90ac7d1`을 대조했다.

## 적용 범위

| 지정 경로 | r1 대비 확인 |
| --- | --- |
| `components/public-showcase/neon-showcase.tsx` | 상단·하단 안내, 카드·대표·상세의 사용자용 ‘예시’ 표기를 제거했다. 재생 미연결 안내와 재생 오류·다시 불러오기, 표지 대체, 이미지 최적화, 포커스 로직은 r1과 같다. |

Front 인계에 기록된 사용자 예외 범위는 공개 홈의 ‘예시’ 문구 제거와 로컬·후보 반영이다. 로컬 커밋 `b447556`에도 동일한 사용자용 변경이 있다. 고정 후보의 부모 대비 변경은 위 네 파일이며 라우트·공급원·CSP·설정은 그대로다. 공개 홈은 기존 소개용 자료만 전달하며 게시 동작과 실제 재생 주소는 추가되지 않았다. 부모 및 r1 대비 `git diff --check`가 통과했다.

## 후보 자체 검증

- 1280px·390px의 원본 홈에서 작품 여섯 건, ‘대표 작품’ 배지, ‘DREAM · PUBLIC SHOWCASE’ 푸터와 최적화된 대표 이미지를 확인했다. 화면에 ‘예시’가 없고 가로 넘침이 없었다.
- 양쪽 폭에서 여섯 작품의 상세를 모두 열었다. 머리글은 따옴표 없는 ‘PUBLIC SHOWCASE’였고 설명에 ‘예시’가 없었다. 영상·음악에 맞는 재생 미연결 안내가 표시됐고 재생 요소는 없었다. 상세의 가로 넘침이 없었고 Enter로 여니 닫기 버튼에 초점이 가고 Escape로 닫으니 원래 카드 버튼으로 복귀했다.
- 합성 표지 404에서 재생 주소가 없는 상세는 표지 실패와 재생 미연결을 함께 표시했다. 별도의 영상 404 사례는 재생 시도 전까지 표지 실패만 표시했고, 재생 시도 후 영상 오류와 다시 불러오기 버튼을 표시했다. 이미 실패한 표지의 브라우저 요청 수는 열기 전·후와 재생 실패 뒤에 모두 최적화 2건·원본 0건이었다.
- 390px에서 재생 가능한 합성 영상의 대체 표시가 조작부 56px을 비우고, 조작부 위치가 포인터를 받는 것을 확인했다. 실제 재생 시간이 진행되자 표지 대체 표시가 사라졌다.
- 집중 Vitest 2개 파일 30건, TypeScript 타입 검사, 대상 경로와 공개 홈의 ESLint 검사가 통과했다.

## 전체 DSP 시험 이력

Front의 전체 Vitest 실행은 2,201건 통과와 `p2-5b-dsp-fixes`의 `TOOL_FAILED` 1건을 기록했고, 해당 파일의 단독 재실행은 21건 모두 통과했다. 후보의 r1 대비 변경에 DSP 경로는 없다. Tester도 같은 고정 후보에서 해당 파일만 재실행해 21건 모두 통과했다. 전체 스위트는 Front 결과이며, 이번 독립 검수에서 전체 스위트를 재실행하지 않았다.

기존 격리 방식으로 후보를 복사해 루프백 Next 개발 서버와 헤드리스 Chromium을 사용했다. 화면 폭은 브라우저에서 설정했고 표지·재생 실패는 합성 입력으로 확인했다. 격리 서버 종료 및 임시 사본 정리를 확인했다. 운영 확인, 빌드, 배포는 이번 검수 범위 밖이다.
