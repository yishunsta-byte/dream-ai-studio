## 남은 한계
1. 확인한 브라우저는 Windows ego lite Chromium 하나예요. Firefox·Safari·모바일은 확인하지 않았어요.
2. **운영 CSP는 별도 단계예요.** 운영에서 인라인 스크립트를 막으면 공개 홈은 앱 번들 경로에 의존해요. 그런데 Next 인라인 데이터까지 막으면 수화가 되지 않아 대체 안내만 보여요. 안전한 쪽이지만 작품이 보이지 않아요. 실제 활성화 전에 nonce나 해시 정책을 정해야 해요. 가드 해시는 빌드와 무관하게 상수 문자열에서 정해져요.
3. 숨김 상태로 남는 문서에서 eager 대표 이미지(스크립트 완전 끔이면 전체)가 요청되고, DOM에는 작품명이 남아요. 화면과 접근성에는 나오지 않아요.
4. 스크립트 완전 끔이나 strict 조건에서 열린 대체 안내 문서는 bfcache로 복원돼도 그대로예요(새 조회 없음). 철회 작품을 보여 주지 않으니 안전하지만, 승인 작품을 보려면 새로고침해야 해요.
5. 프록시 noguard 모드는 응답 본문의 인라인 스크립트를 해시로 허용하는 시험용 정책이에요. 실제 운영 정책과는 달라요.
6. F255-R2 문구와 F255-R3 시간 상한은 범위 밖이에요. 실제 공급원·운영·배포는 하지 않았어요. 운영은 명시 예시 모드예요.
