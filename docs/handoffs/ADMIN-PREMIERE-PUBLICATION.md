# 프리미어 관리자 · 분석 결과 공개와 메뉴 이동

`165d5cb` 위에서 Style DNA·음악·쇼츠 결과에 **공개 준비**를 연결했다. 공개용 제목·요약·생성 프롬프트를 편집하면 같은 평문과 매체를 미리 볼 수 있다. 공개 동의를 별도로 체크한 뒤 **공개하기**를 눌러야 저장 요청이 시작된다.

**분석 결과 관리**에서 이전·신규 공개 결과를 한 목록으로 조회한다. 목록의 지정 항목을 확인한 뒤 철회할 수 있다. 공개 웹 `/analysis-results`에서는 승인된 읽기용 카드만 표시한다. 이미지·음악·쇼츠의 매체 값은 각각 `image`, `music`, `video`다.

공개 요청에는 요청 ID와 제목·요약·프롬프트·매체·승인 필드만 사용한다. 초안에는 모델 결과에서 선택한 요약만 넣고 URL·계정·키로 보이는 텍스트를 비운다. 공개 편집과 미리보기에서도 해당 텍스트를 검사한다. 변경 없는 재시도는 같은 ID를 보내고, 내용 변경과 409는 별도 동의와 새 ID가 필요하다. 프로그램을 떠나는 동안 완료된 공개 알림은 분석 결과 관리에서 확인할 수 있다. 로그인 만료 시 초안과 목록을 숨기고 로그인 이동을 표시한다.

구 `AdminReferenceAnalysis`, Spectrum 화면 및 전용 검수를 삭제했다. Style DNA가 사용하는 공용 이미지 경로, 기존 공개 데이터와 공개 읽기, 완성본 검수·게시 및 기존 관리자 해시의 Style DNA 이동은 유지한다.

키보드와 메뉴 링크는 해시 이력을 만들고 선택한 구획의 제목으로 직접 초점을 이동한다. 내 프로젝트 기본 화면, 직접 링크, Tab 후 Enter, 뒤로·앞으로 이동을 각각 확인했다. 고정 메뉴 오프셋은 실제 높이를 사용하며 메뉴가 가용 화면의 절반을 넘을 때 고정을 푼다.

## 검수

- 관련 Vitest 301개, 변경 파일 ESLint, Windows Next Webpack 빌드 및 산출물 검사 통과.
- 390·1440px Chromium에서 세 초안, 동의 전 공개 요청 0건, 주소 차단, 동일 ID 재시도, 편집·409의 새 ID, 실제 공개 UI로 렌더한 모의 카드, 철회 후 카드 없음, 세션 만료와 다른 메뉴의 초점 보존을 확인했다.
- 320×360과 1280×900에서 글자 토큰 2배를 적용해 새 세 메뉴와 기존 운영 메뉴 제목이 가려지지 않는 것을 확인했다.
- 테스트는 [로컬 관리자 화면](http://127.0.0.1:8805/admin#admin-style-dna)에서 합성 저장을 사용했다. 운영 쓰기와 배포는 진행 전이다.

서버는 `node tests/admin/admin-premiere-publication-run.mjs`로 실행하면 로컬 주소를 출력한다. `tests/admin/admin-premiere-publication.ego.mjs`에 그 주소를 `globalThis.FIXTURE_ORIGIN`으로 넘긴다. 브라우저 검수 기록은 `D:/starwork/design-analysis-check/premiere-admin-publication-results.json`에 남겼다.
