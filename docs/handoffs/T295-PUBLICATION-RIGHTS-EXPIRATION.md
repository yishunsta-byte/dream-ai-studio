# T295 공개 작품의 권리 만료 적용

T293-F1 독립 수용 기준 · Backend 자체 검증 · EnterpriseDB PostgreSQL 17.12 임시 루프백

고정 T253·T293 SQL의 SHA-256을 대조하고 원문 그대로 적용했습니다. 격리 오버레이는 최초 준비 시 T253 manifest와 권리 참조, 무기한 여부, 유효 종료 시각을 동일 작품·소유자·세대로 고정합니다. 완료 전에 현재 권리 증거와 최초 내용을 대조하고, 활성 세대의 권리 기록을 T253 상태 및 요청 결과와 같은 트랜잭션에 저장합니다. 권리 자료는 서버 증거이며 요청 의도 지문과 구분합니다. 재시도는 현재 인증 범위를 확인한 뒤 원장 결과를 읽습니다. [오버레이 SQL](../../tests/public-showcase/t295-publication-rights.sql)

공개 목록과 표지는 활성 세대·최초 manifest·활성 권리 기록이 일치할 때만 반환합니다. 기준 시각은 앱 시간이 아닌 두 함수 각각의 PostgreSQL `statement_timestamp()`입니다. 시한부 권리는 **조회 시각이 종료 시각보다 앞설 때**만 유효합니다. 명시적으로 입증된 무기한 권리는 종료 시각 없이 유지됩니다. 목록은 권리 검사를 통과한 작품만 정렬하고 상위 25개를 반환합니다.

## 검증

- DB 판정 함수로 종료 1µs 전·정각·1µs 후를 직접 대조했습니다. 실제 목록·표지는 만료 전 허용됐고, 만료 뒤의 동시 조회에서는 두 경로 모두 차단됐습니다. 만료 전에 시작한 `REPEATABLE READ` 트랜잭션에서도 만료 뒤 새 조회는 차단됐습니다.
- 권리 누락, 준비 후 권리 시각 변경, 활성권리 기록 불일치·누락, 롤백과 만료 이후 지연 커밋을 대조했습니다. 검증된 무기한 작품은 유지됐고, 철회 뒤 새 세대를 게시하거나 과거 UUID로 성공을 재생해도 이전 세대의 표지는 열리지 않았습니다.
- A/B 교차 변경, 공개 역할의 직접 테이블 쓰기, 목록·표지 역할을 바꿔 호출하는 경우와 기존 만료 미적용 함수 접근을 거절했습니다. `node --conditions=react-server --import tsx tests/public-showcase/t295-publication-rights-native.ts` 통과 후 소유 프로세스·리스너·임시 클러스터를 정리했습니다. [네이티브 시험](../../tests/public-showcase/t295-publication-rights-native.ts)
- 관리자·공개·REA 선택 회귀 33개 파일 386건 통과, 1건 건너뜀. ESLint와 범위 TypeScript 통과. 커밋 `1f7632a7`에 이 후보만 추가한 깨끗한 사본에서 Next 타입을 새로 생성하고 전체 `tsc` 및 공용 API 인증 113/113을 통과했습니다. 공유 작업 트리의 별도 작업실 API와 이전 생성 타입에서 나온 공용 인증 5건 및 타입 검사 실패는 Master에게 전달했습니다.

## 연결 범위

이번 결과는 합성 권리 증거와 신뢰 서버 역할로 실행한 격리 DB 후보입니다. 운영에서는 목록과 표지 모두 만료가 적용된 읽기 역할로 연결해야 합니다. 만료 규칙은 새 DB 조회부터 적용됩니다. 호스트·브라우저 캐시, 이미 전송됐거나 조회가 시작된 응답과 운영 권리 철회 증거의 도입은 후속입니다. 제품 SQL·라우트·운영 배포에는 변경 사항이 없습니다.
