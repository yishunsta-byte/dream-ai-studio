# 관리자 프로젝트 상태와 재시도 독립 검수

2026-11-19 · 대상 `d939b59` · Codex(Tester)

관리자 페이지 및 메뉴 구성 시험 2개 파일 10건이 통과했다. 모의 인증·조회 결과로 페이지를 렌더링했을 때 미연결은 연결 확인 안내, 조회 실패는 오류 안내와 재시도 링크 하나, 성공한 빈 목록은 0개와 조회 시각, 목록은 건수와 프로젝트 제목을 표시했다.

실패 상태의 실제 페이지 컴포넌트가 생성한 HTML을 로컬 HTTP 서버의 `/admin`에서 제공했다. Ego Chromium에서 도움말에 초점을 둔 뒤 Enter로 열고 Space로 닫았다. 이어 ‘다시 불러오기’에 초점을 두고 Enter를 눌렀다. 주소의 해시와 키보드 초점은 모두 `admin-project-list`로 이동했다.

**재조회 결함.** 서버가 받은 `GET /admin`은 첫 페이지 요청 1회뿐이었다. 링크의 목적지 `/admin#admin-project-list`는 현재 문서 안의 위치만 바꾸므로 실패한 읽기를 다시 실행하지 않았다. 제품 수정 후에는 실패 상태에서 서버가 다음 조회에 성공하도록 설정한 뒤, 재시도 한 번으로 목록이 갱신되고 초점이 같은 섹션에 복귀하는지 확인해야 한다.

브라우저 검수에는 서버 렌더링 HTML과 요청 계수기를 사용했다. 실제 운영 인증·DB 및 Next.js 전체 앱을 통한 재시도는 이 검수 범위 밖이다.

수정본 `8168b89`의 페이지 컴포넌트로 같은 로컬 HTTP 시험을 반복했다. 첫 GET에 조회 실패를, 다음 GET에 running 상태의 프로젝트 한 건을 공급했다. Enter 한 번으로 GET 및 목록 조회가 각각 1회 추가됐고 성공한 프로젝트가 표시됐다. 최종 주소 해시와 초점은 admin-project-list에 있었으며 성공 카드의 재조회 링크도 하나였다. 첫 시도의 합성 상태 draft는 지원되지 않아 시험 데이터를 running으로 정정해 재실행했다.
