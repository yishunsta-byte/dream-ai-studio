# T277-R REA 등록 해시와 분석 사본 독립 검수

2026-11-19 KST · Codex(Tester) · 고정 커밋 `6d823e2` · Orca `msg_4db394d599f7`

**판정 — 통과.** 내부 분석 어댑터에서 등록 SHA-256과 일치한 관리 사본의 바이트가 MP4 영상, M4A 음원, PNG 이미지의 특징 추출로 이어집니다. 이번 범위에서 승인 차단 결함은 확인되지 않았습니다. [구현 인계](T277-REA-ANALYSIS-SNAPSHOT-BINDING.md)

| 검수 항목 | 확인 결과 |
| --- | --- |
| 등록 해시와 읽기 경로 | 복사 스트림의 같은 청크를 해시하고 배타적으로 생성한 사본에 기록합니다. 등록 크기와 해시 검사가 끝난 뒤 영상·음원은 사본 경로를 프로브 및 디코더에 전달하고, 이미지는 사본에서 읽은 버퍼로 특징을 추출합니다. 내부 증명은 검사와 정리 성공 뒤에 반환됩니다. |
| 교체·링크·한도 | 집중 시험에서 동일 크기 바이트 불일치, 관리 루트 내부 디렉터리 별칭, 하드 링크, 64 MiB 초과를 프로브 전에 거절했습니다. 프로브가 시작된 뒤 동일 바이트의 다른 파일로 바뀌었을 때도 원본 식별 정보 차이로 결과와 증명을 폐기했습니다. |
| 취소와 정리 | 집중 시험에서 실행 중 취소와 시간 초과 시 자식 프로세스 종료 및 사본 디렉터리 정리를 확인했습니다. 별도 합성 시험에서는 세 매체에서 사전 취소를 확인했고, 실행 전후 임시 분석 디렉터리 목록과 원본 해시가 같았습니다. |
| 공개 DTO | 세 매체의 소유자 화면과 공유 요약에서 허용된 파일 메타데이터를 확인했습니다. 해시 값과 필드, 자료 세대, 이름, 경로, 이미지 바이트와 원시 픽셀 필드는 노출되지 않았습니다. 소유자 화면은 이미지 특징의 텍스트 설명을 제공합니다. |

[관리 사본](../../lib/reference-analysis/local-file.ts) · [등록 어댑터](../../lib/reference-analysis/registered-snapshot.ts) · [화면·공유 투영](../../lib/reference-analysis/projection.ts) · [집중 시험](../../tests/reference-analysis/registered-snapshot.test.ts)

독립 합성은 컷이 있는 MP4, 120 BPM 펄스 M4A, 알파 커버리지 50% PNG를 새로 생성해 실행했습니다. 각 표본은 등록 해시로 특징과 증명을 반환했고, 등록 해시 한 자리 변경 또는 등록 크기 1바이트 차이로 근거와 증명 없이 거절됐습니다. 실제 자료나 운영 환경은 사용하지 않았습니다.

검수는 Windows 작업 환경의 로컬 파일과 내부 어댑터 호출까지입니다. 현재 제품 호출부는 연결 전입니다. 연동 시 서버 호출자가 소유자, 활성 링크와 권한, 현재 자료 세대를 조회하고 저장 시점에 재확인해야 합니다. 분석 사본과 원본 관리 경로의 쓰기 권한은 서버 경계에서 관리해야 합니다.
