## 4. 마우스·펜·터치 (pointer)

| 동작 | 결과 |
|---|---|
| 클립 누름 | 그 글자를 고름(목록·편집 칸·미리보기 테 같이). 초점 = 그 클립 |
| 클립 끌기 | 누른 뒤 **3px 넘게** 움직여야 시작(그 전은 고르기만). `setPointerCapture`. 이동량 = 프레임 반올림. 길이 그대로, 시작 ≥ 0, 끝 ≤ `textEndLimit` 안에서 멈춤 |
| 끝 손잡이 끌기 | 끝만 바뀜, 최소 길이 1프레임, 상한 같음 |
| 끄는 동안 | 클립 위에 시간 말풍선 `00:02.15–00:05.08`. **초안(draft)은 놓을 때 한 번만 바꿈** — 끄는 동안은 화면의 임시 위치만(미리보기·실측을 매 움직임마다 다시 하지 않게) |
| 놓기(pointerup) | 초안에 한 번 반영 → 미리보기·실측·"저장하지 않은 변경". 바뀐 게 없으면 아무 일 없음 |
| Esc (끄는 중) | 끌기 취소, 원래 시간으로. 끄는 중이 아니면 Esc는 아무것도 안 함(가로채지 않음) |
| `pointercancel`·`lostpointercapture` | **취소**(원래 시간). 브라우저가 동작을 가져간 것이라 반쯤 옮긴 값을 남기지 않음 |
| 눈금 누름·끌기 | 재생 위치 이동(seek, `controlRef.seek`). 클립 시간은 안 바뀜 |
| 줄의 빈 곳 누름 | 그 시간으로 seek, 고른 글자는 그대로 |
| 잠긴 표기 끌기 | 움직이지 않음 + 상태 글 "필수 표기는 시간을 바꿀 수 없어요." |
| 저장 중 | 타임라인 조작 잠김(`aria-disabled`, 상태 글 "저장하는 중이에요.") — 9장 |

## 5. 키보드 (T-033 3.2.1, 한 키 = 한 동작)

탭 멈춤은 **두 곳**: ① 초 눈금(재생 위치) ② 클립 묶음(고른 클립 하나만 `tabIndex=0`, 나머지 −1). 클립 100개를 Tab으로 지나가지 않게.

| 초점 | 키 | 동작 | 하지 않는 것 |
|---|---|---|---|
| 초 눈금 (`role="slider"`, 이름 "재생 위치", `aria-valuetext` "00:02.15") | ←/→ | 1프레임 seek | 클립 시간 |
| | Shift+←/→ | 1초 seek | |
| | Home/End | 처음/끝 | |
| | Space | 재생·멈춤 | |
| 고른 클립 (안 잠김) | ←/→ | 클립 1프레임 이동 | **seek 안 함**(재생 위치 그대로) |
| | Shift+←/→ | 1초 이동 | |
| | Alt+←/→ | 끝 시간만 1프레임 (Alt+Shift = 1초) | |
| | ↑/↓ | 위·아래 줄 클립 고르기(초점 같이), 끝에서 멈춤 | 시간 |
| | Enter | 편집 칸 "문구"로 초점(T-033) | |
| | Space | 재생·멈춤(버튼 기본 동작 막음) | 고르기 |
| 고른 클립 (잠긴 표기) | ←/→·Shift·Alt | 아무 변화 없음 + 상태 글 "필수 표기는 시간을 바꿀 수 없어요."(한 번) | seek |
| | ↑/↓·Enter·Space | 위와 같음(Enter = 편집 칸 제목, 문구 칸이 없으므로) | |

- 처리한 키는 `preventDefault` + `stopPropagation`. `window`·`document` 키 처리 없음(지금 시험을 타임라인 폴더까지 넓힘).
- **키 반복:** 누르고 있는 동안 rAF마다 모아 초안에 반영(한 프레임에 한 번). 끝에 닿으면 멈추고 상태 글 "더 앞으로 옮길 수 없어요." / "영상 끝 {mm:ss.ff}까지만 옮길 수 있어요."(한 번).
- **읽어 주기:** 클립 접근 이름 "{종류} {문구 전체} {시작}부터 {끝}까지{ · 확인할 것 있음}{ · 저장 안 된 변경}{ · 필수 표기, 시간 고정}". 키로 옮기면 0.5초 쉰 뒤 한 번 `aria-live="polite"` "{시작}부터 {끝}까지"(누르는 동안 계속 읽지 않음). 클립 묶음에 `aria-describedby` = 2장 한 줄 안내.
- 입력 칸·목록 줄·편집 칸은 지금 그대로(T-080 7장).

## 9. 코딩 담당에게 확인 요청 (재현 안 함, 코드 읽기만)

- **저장 중 편집:** `save()` 성공 뒤 `router.refresh()` → `EditingPanel`의 `key`(타임라인 id·revision)가 바뀌어 편집기가 새로 붙고 초안이 저장값으로 바뀐다. 저장 요청이 진행되는 동안(`pending`) 편집 칸·타임라인에서 고친 값은 **사라질 수 있다.** P2-3b는 TL-6대로 저장 중 타임라인을 잠그고, P2-3a 편집 칸에도 같은 위험이 있는지 확인해 주세요(있으면 저장 중 편집 잠금 또는 진행 중 고침을 새 초안에 다시 얹기).
