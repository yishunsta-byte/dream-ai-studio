# T329-R 관리자 화면 정보 구조 독립 검수

기준 `e990c77` · Master 인계 `msg_40a7c19a682a` · Codex(Tester)

**판정은 고정 소스·회귀·Design 화면 대조 통과.** 관리 메뉴는 개요, 내 프로젝트, 완성본 검수·게시, 계정 설정 네 개다. 각 링크는 본문 순서와 일치하는 고유 프래그먼트를 가리키고, 해당 영역에 접근 가능한 이름과 `tabIndex={-1}`이 있다. 개요의 클라우드 관리·프로젝트 링크와 계정 설정의 비밀번호 변경은 기존 제품 경로를 사용한다. [관리자 허브](../../components/admin/admin-hub.tsx)

- **프로젝트·게시와 미연결 안내.** 프로젝트는 기존 계정 범위 조회와 상세 링크를 쓴다. 게시 영역은 서버에서 받은 목록을 기존 게시 큐에 전달한다. 미연결과 공급자 실패, 연결됐지만 항목이 없는 상태를 구분한다. 작업 대기열·자료·백업·로그·회원·서비스 상태 여섯 항목은 미연결 안내로 표시되며 실행 링크, 버튼, 임의 지표가 없다.
- **인증과 본문 보호.** 관리자 페이지의 인증 및 로컬·401·403·503 분기가 유지됐다. 확인된 계정에서만 프로젝트와 게시 목록을 읽는다. 메뉴 및 계정·프로젝트·게시 본문이 기존 `SessionBoundary` 안의 `ProtectedContent`로 묶여 있다. [관리자 페이지](../../app/admin/page.tsx)
- **키보드·화면 대조.** Design의 1280px 미연결·합성 목록 캡처와 390px 합성 빈 목록 전체 캡처를 직접 확인했다. 데스크톱 왼쪽 메뉴와 모바일 본문 위 2열 배치, 모바일에서 계정 설정까지 이어지는 표시가 고정 소스와 일치했다. 고정 CSS의 메뉴 높이는 최소 48px이며 링크와 대상의 `focus-visible` 스타일이 있다. Design 실행기는 네 링크를 Tab·Enter로 활성화해 대상 초점이 이동하는지, 계정 설정 다음 Tab이 비밀번호 변경인지, 320/390/1280px에서 가로 넘침이 없는지를 검사한다. 이 키보드·320px 동작은 Design의 실행 결과와 소스로 대조했고 Tester가 브라우저에서 재실행하지는 않았다.
