# T268-F1 REA 스테레오 에너지

2026-11-19 KST · Codes(Backend) · 기준 `232957e650e698e5d5990f01fa374bc33f53a2ad` · 배정 `msg_e3f6d5549201`

FFmpeg가 확인한 음원 트랙의 채널을 보존한 채 8 kHz PCM으로 변환합니다. 프로브가 확인한 채널 수와 디코더 프레임의 채널 수를 대조하고 시각·프레임 수 검증을 유지했습니다. 50ms 창의 표시 단위는 최대 PCM 진폭을 1로 놓는 정규화 RMS입니다. 각 채널의 샘플 제곱을 전체 프레임·채널 수로 나누고 제곱근을 취하므로 위상이 반대여도 에너지가 상쇄되지 않습니다. `samplesRead`는 채널당 표본 수입니다. [독립 검수](T268-R-REA-LOCAL-AUDIO-FEATURES-REVIEW.md) · [측정 코드](../../lib/reference-analysis/audio-features.ts)

| ALAC 합성 음원 | 50ms RMS | 신호 구간 | BPM |
| --- | --- | --- | --- |
| 2초 역위상 스테레오 | 약 0.35355 | 0–2,000ms | 확인 불가 |
| 2초 동일 위상 스테레오 | 약 0.35355 | 0–2,000ms | 확인 불가 |
| 2초 무음 스테레오 | 0 | 무음 0–2,000ms | 확인 불가 |

입력 64MiB, 24초·채널당 192,000표본, 디코더 출력 스트림별 1MiB 및 기존 시간 제한을 유지했습니다. 최대 8채널이며 1MiB PCM 예산을 넘는 트랙은 디코딩 전에 분석 한도로 반환합니다. 6채널 12초 무음으로 이 제한을 검증했습니다. 모노 합성 신호의 120 BPM 추정과 영상 분석, 취소·시간 초과 시 자식 종료 및 사본 정리 회귀도 통과했습니다. [합성 시험](../../tests/reference-analysis/audio-features.test.ts)

REA 계약·경계·파일·영상·오디오 Vitest 5개 파일에서 `DREAM_REA_NATIVE_TEST=1`로 73/73, 기본 실행에서 36 통과·37 건너뜀을 확인했습니다. 집중 TypeScript `tsc -p tmp/t268-rea-typecheck.json`과 변경 파일 ESLint `--max-warnings 0`도 통과했습니다. 실제 음악의 BPM 정확도와 화면 연결은 이번 검증 범위 밖입니다.
