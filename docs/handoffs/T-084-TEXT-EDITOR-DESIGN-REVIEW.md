### B-1 · 글꼴 20초 시간 초과 안내가 실제 화면 동작과 맞지 않음

| | 내용 |
|---|---|
| 재현 | 1280, 자막 하나 → 글꼴 Noto Serif KR, 네트워크 150KB/s로 제한(캐시 끔). 서버 전송 9.6MB(압축) |
| 20초 뒤 | 미리보기 아래 Callout "Noto Serif KR 글꼴을 불러오지 못해 기본 글꼴로 대신 보여 줘요. 글꼴 파일이 커서 20초 안에 다 읽지 못했어요. **미리보기를 다시 불러와 보세요.** …", 편집 칸 "글꼴을 불러오지 못해 크기를 확인하지 못했어요.", 목록 "확인 전" (`t084-l`) |
| 문제 1 | 안내가 말하는 **"미리보기 다시 불러오기" 버튼이 이 상태에는 없다.** 그 버튼은 미리보기 그리기 오류(`status==="error"`)에서만 나온다(`player-panel.tsx` 118행). 있다 해도 `reload()`는 Player만 다시 붙이고 글꼴은 다시 읽지 않는다(글꼴 effect는 `[key,fonts]`만 봄) |
| 문제 2 | 제한을 풀자 글꼴이 약 24.6초에 도착해 견본·글꼴 select·미리보기 글자는 **실제 명조로 그려지는데**, Callout 두 개와 "확인 전"은 그대로 남는다(`t084-m`). 비율 바꾸기로도 안 풀리고, 글꼴을 다른 것으로 바꿨다 되돌려야만 풀렸다. 페이지 새로고침은 저장 전 고침을 잃는다 |
| 왜 B | T-084 지시 항목("20초 안내가 Player 다시 불러오기와 실제로 맞는지")에서 **맞지 않음**. A-16(상태별 문구가 표대로·편집이 막히지 않음)과 6.1("다 불러온 뒤에만 판정") 어긋남 — 화면이 사실과 다른 말을 한다 |
| 고칠 것 | ① 시간 초과 뒤에도 그 글꼴의 불러오기가 끝나면 상태를 `ok`로 바꾸고 다시 잰다(이미 `document.fonts`에 들어가 그려지고 있음). ② 시간 초과·실패 Callout에 **그 Callout 전용 버튼 "글꼴 다시 불러오기"**(글꼴만 다시 읽기, Player 다시 붙이기 아님, 저장 전 고침 유지). 초점은 누른 버튼에 남기고 성공하면 Callout이 사라지면서 편집 칸 제목으로 |
| 확정 문구 | 시간 초과: 제목 "{이름} 글꼴을 아직 다 불러오지 못했어요." 설명 "파일이 커서 시간이 걸려요. 그동안은 기본 글꼴로 보여 줘요. 다 받으면 저절로 바뀌어요." 버튼 "글꼴 다시 불러오기" · 실패: 제목 지금 그대로, 설명 "글꼴 파일을 읽지 못했어요. 영상 만들기 전에 글꼴을 확인해 주세요." 버튼 같음. **"미리보기를 다시 불러와 보세요."는 지운다** |

### B-2 · 필수 표기에 "영상보다 긴 글자예요 … 끝 시간을 직접 줄여 주세요"가 늘 붙음

| | 내용 |
|---|---|
| 재현 | s5를 열면 첫 줄(표기 "광고", 00:00.00–00:30.00)이 고른 상태로 열리고 바로 경고 Callout "영상보다 긴 글자예요. 자르지 않고 그대로 두었어요. **필요하면 끝 시간을 직접 줄여 주세요.**"(`t084-c`). 목록 ⚠ + 버튼 이름 "확인할 것 있음", 미리보기 점선 경고 테(`t084-i`). 390에서도 같은 문구(`t084-o` 이전 상태) |
| 문제 | 표기 시간은 0~기획 끝 **고정**(T-080 2.3, 서버도 강제)이라 사용자는 끝 시간을 줄일 수 없다. 영상이 기획보다 짧으면 **고칠 수 없는 경고가 항상** 남고, 화면이 할 수 없는 행동을 시킨다 |
| 왜 B | A-8(표기: 시간 고정 글)·A-16 문구와 충돌. 첫 화면 첫 Callout이 이것이라 진짜 경고(안전 영역·줄 수)가 묻힌다 |
| 고칠 것 | 잠긴 필수 표기는 `beyond`를 경고에서 뺀다(⚠·"확인할 것 있음"·경고 테·Callout 모두). 대신 편집 칸 시간 자리 글을 "{시작}–{끝} · 표기는 기획 길이만큼 보여요. 영상이 이보다 짧아도 고칠 것은 없어요."로. 일반 글자의 "영상보다 긴 글자예요"는 지금 그대로 |
