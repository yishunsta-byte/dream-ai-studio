## 1. 바꾼 파일

| `components/audio-editor/audio-editor.tsx`·`.module.css`(신규) | '소리' 카드예요. 같은 draft/dirty/저장 흐름을 써요(자동 저장·두 번째 저장 버튼·별도 revision 없음). PC에서는 넣기(파일·역할을 명시해서 고르고, 파일 이름으로 정하지 않음), 역할·시작·사용 길이·원본 시작·크기(dB)·처음/끝 서서히, 덮킹(음악만), 곡 연결을 편집해요. 곡 연결은 바뀔 값을 보여 주고 확인한 뒤 적용하며, 겹침을 바꾸면 다음 곡 시작이 같이 움직여요. 권리 4칸(빈 값 = null)을 적을 수 있고, 보관함 메모는 버튼을 눌러야만 라이선스 메모로 옮겨요. 기존 업로드 API로 올릴 수 있고(진행률·취소, 끝나면 목록만 새로 읽음), 원본 미리듣기가 있어요. 390에서는 목록·권리 보기·원본 듣기만 되고 "PC에서 바꿔요" 안내가 나와요. 소리 카드 조작은 모든 폭에서 44px 이상이에요. |
| `components/editing-panel.tsx` | 소리 카드를 넣었어요. 원시 소리 칸·고른 소리를 handover로 넘기고(저장 중 변경 인계), 복구 목록·복구 파일에도 넣어요. 저장 막힘 이유를 추가했어요(소리 칸 / 소리 문제). 영상 만들기 진입은 잘못된 칸이나 저장 중이어도 막혀요. 저장 버튼 이름은 "장면·글자·소리 설정 저장", 첫 안내 문구도 실제 범위로 바꿨어요. 복구 목록은 소리 변경을 쉬운 말로 따로 보여 주고, '그 밖의 설정'에서는 소리를 빼요. |

## 3. 관찰
- 원본 미리듣기(`preload="none"`)는 첫 Space에서 재생이 시작되지 않고 두 번째에 시작된 적이 있어요(불러오기 시작). 재현과 원인 확인은 하지 않았어요.
- 편집 Player 아래의 기존 문구 "소리는 다음 단계에서 붙여요."(`components/player/player-panel.tsx`)는 이제 사실과 어긋나요. 허용 범위 밖이라 고치지 않았고, 소리 카드에서 "편집 미리보기는 지금도 소리 없이 보여요…"로 바르게 안내해요. 고칠지는 Master가 판단해 주세요.
- 렌더 화면의 `AUDIO_SOURCE_MISSING`에서 편집의 해당 소리로 가는 링크(T146 5장)는 U1 render-panel 범위라 넣지 않았어요.

## 4. 미검증 (사실대로)
- **실제 청취를 하지 않았어요**(스피커·음질·음량). 재생은 디코딩·재생 상태만 확인했어요. 최종 믹스 듣기는 U1 렌더 결과 화면 범위예요.
- 실제 휴대폰, 스크린리더, 200% 확대, 실제 탭 숨김(합성 이벤트만), 페이지 이동 때 원본 재생 중단(요소 제거로만 봤어요), 브라우저가 열지 못하는 형식의 미리듣기 오류(오류 문구 코드만 있음)
- 렌더 막힘 사유 4종(바이트 바뀜·도구 없음·10분 초과·누락)이 렌더 화면에 나오는 것: 이번에는 렌더를 실행하지 않았어요(T137 서버 검사 그대로).
- 통합 초안 믹스 미리듣기: 범위 밖이라 만들지 않았어요.
