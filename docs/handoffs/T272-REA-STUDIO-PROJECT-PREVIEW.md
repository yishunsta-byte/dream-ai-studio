## 1. 연결 방식 (최소 방식)

미리보기 계약은 서버 전용이에요. 검증된 액터, 서버가 확인한 프로젝트·소스·리비전, 프로세스 안의 불투명 레코드가 있어야 해요. 그래서 체험 화면은 계약을 실행하지 않고, **계약의 허용 출력만 고정 표본으로** 받아요.

1. 시험 보조 파일 `tests/reference-analysis/studio-project-preview-fixture.ts`에 고정 합성 입력을 둬요. 합성 입력은 체험 표본과 같은 값이에요.
   - 영상 500ms: 관찰 프레임 0·120·340ms, 컷 120→340ms
   - 음악 500ms: 1채널 음량
   - 이미지 12×8: 화면 전체와 중앙 영역
2. 시험에서 이 입력을 실제 `createPrivateReferencePreviewRecord` → `previewReferenceProject`에 시험 액터로 넣어요. 나온 허용 출력이 `components/reference-analysis/project-preview-sample.ts`와 **정확히 같은지** 매번 대조해요(`studio-project-preview.test.ts`). 계약이 바뀌면 이 시험이 실패해요.
3. 보호 페이지(`legacyPageGate` 뒤)가 표본을 체험 화면에 props로 넘겨요.
   - 표본 파일은 계약 모듈을 `import type`으로만 참조해요. 그래서 `server-only` 코드가 브라우저 묶음에 들어가지 않아요. 빌드 묶음에서 계약 함수 이름도 0건이에요.
   - 브라우저는 소유자·프로젝트·리비전·만료를 만들거나 판정하지 않아요. 액터를 만드는 코드는 시험에만 있어요.
   - 다른 액터 `owner_required`, 리비전·만료 `stale`, 빈 선택 `selection_unavailable`은 서버 판정 그대로 시험에서 확인했어요.

실제 사용자 분석 결과와 연결하려면 다음이 필요해요. 남은 조건이에요.
- 서버가 확인한 소유자·프로젝트·리비전으로 레코드를 만들고 미리보기를 부르는 서버 경로. 경로를 만들지, 서버 액션으로 할지 Backend 결정이 필요해요.
- 그 경로의 응답을 이 화면이 받는 방식.

## 2. 화면

결과 탭에 **프로젝트 미리보기**를 추가했어요(근거 · 편집용 프롬프트 · 프로젝트 미리보기).
- 탭 이동: ←/→ 순환, Home/End.
- **근거 선택:** 체크 상자로 고르고, 고른 순서대로 보여요. 계약 응답도 요청 순서를 따르므로 같은 순서예요. 고른 근거가 없으면 미리보기를 만들지 않는다고 안내해요.
- **항목별 표시:** 대상(컷 구성·이미지·음악) → 관찰 → 추정(컷 후보·BPM일 때, 근거 연결 수) → 제안(창작 제안 문장, 컷이면 "바로 이어 붙이기(전환 0프레임)").
- **원본 탐색(영상):**
  - `sourceSeek.ptsMs`를 초로 바꿔 "원본 탐색 0.340초 · 관찰 프레임 기준"으로 보여요.
  - "원본 위치 보기"를 누르면 합성 0–0.500초 막대에 표시하고, 위치를 소리로 알려 줘요.
- **편집 격자 근사:** 원본 탐색과 **따로** "편집 격자 근사 30fps 기준 10번 프레임 · 편집용 제안이라 원본 위치와 다를 수 있어요"로 보여요.
- **복사:** 고른 순서의 제안 문장만 복사해요. 관찰 수치·근거 번호·원본 위치·파일명은 넣지 않아요.
- **실제 재생기:** 연결하지 않았어요. 막대 아래에 "실제 재생기는 연결하지 않았어요"라고 적었어요.
  - 이유: 체험 표본과 정확히 일치하는 자체 합성 영상 자산을 저장소에서 내보내는 경로가 이번 수정 범위에 없어요.
  - 남은 조건: 분석값과 일치하는 합성 MP4를 Studio 안에서 제공하는 것. 제공되면 `video.currentTime = ptsMs / 1000`으로 컷 탐색을 확인할 수 있어요.

**작업·복사 경계** (T266 규칙 확장)
- 근거 선택은 작업마다 새로 시작해요. 새 작업·다시 시작하면 지워요.
- 복사 요청은 요청·작업·초안 판·누른 탭에 묶여요.
  - 선택을 바꾸면 초안 판이 올라가요. 기다리는 사이 바꾸면 알림만 바뀌어요.
  - 작업이 바뀌었거나 결과가 닫혔으면 늦은 응답을 모두 무시해요.
  - 복사 알림은 누른 탭에만 보여요.
